# TASK-0880 — 《Blocksail》資源類型：分類與資源表（標出還缺圖的資源）

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [ ] 資源表落在 Blocksail 的 docs/RESOURCES.md：每種資源一列，寫明大類、小類、現況（已在貨物表／規劃中）、來源、繪圖批次、有沒有圖
- [ ] 分類照 Tim 的四類（食物、礦物、加工品、成品）展開，多出來的類別各寫為什麼要有；Tim 看過分類，拍板原話記在單上
- [ ] 表與貨物表（world/goods.js）對得上：貨物表的每一種在表上都標「已在貨物表」、標了的貨物表都有、名字一字不差
- [ ] 缺圖照磁碟填：標「有圖」的，圖檔都在而且是 128×128；標「缺圖」的都不在
- [ ] 反向對照：貨物表拿掉一種、或表上多標一筆，對帳會指出那一筆
- [ ] 第 1 批繪圖子單掛在本單下；表上寫明「貨物表新增資源 ⇒ 增開一張繪圖子單」的規矩
- [ ] 食物等級：能吃喝的每一種在表上有一個等級值，每一級的意思另外寫在定義表（0 荒年糧／1 主糧／2 家常／3 佳餚／4 奢侈品），每一種的等級 Tim 看過


## 任務描述

## 要什麼（Tim 2026-10-24）

- 「目前城鎮已經可以開始生產資源了 因此會需要對應的資源表&圖示 開一個 /scp-task 來管理資源類型吧」
- 「先按照資源類型先分類 例如 食物(小麥 小麥粉 麵包 糖 蛋 蛋糕 香蕉) 礦物(鐵礦石 銅礦石等) 以及加工產品(生鐵 熟鐵 鋼等)以及成品(炮 帆布 等) 可以在由妳發揮想一下分類以及基本的資源類型 然後記錄在一份資源表上(單上關聯) 並且要標記哪些資源還缺圖片」
- 「目前設想是資源圖片為128 x 128(精緻像素風格) 然後另開一張子單(也可以是多張 有新增資源時增開) 繪製資源圖片」

## 資源表在哪

Blocksail repo 的 `docs/RESOURCES.md`（分類、圖示規格、清單、改表規矩都在那裡）。本單只管「表齊了沒、對得上沒」；圖由子單畫，一批一張。

## 一件要先知道的

貨物表已經有 `cat` 欄，但它管的是「能不能直接當糧食吃」與市場（小麥是原料、要磨成粉）—— 跟 Tim 要的顯示分類（小麥放食物）是兩把尺。資源表的大類／小類是顯示用的；進程式時另開一欄，⛔ 不覆寫 `cat`。
