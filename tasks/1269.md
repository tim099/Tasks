# TASK-1269 — 城鎮模式點船廠：看正在造的船、造船菜單（吃多少料）、船市現貨

> `feature` / `normal` / `todo`　開單：basecamp　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 城鎮模式點船廠：看得到正在造哪一型、做到幾成（船殼段／索具段）、預計還要幾天、今天卡在哪（缺哪一種料、缺人、缺錢）
- [ ] 看得到那一型的造船菜單：整艘吃哪些料、各幾桶、幾個工天，已經吃了多少、還差多少
- [ ] 看得到這座船廠造得了哪幾型、下一艘打算造哪一型、這座城的船市上有哪幾艘現貨
- [ ] 沒在造船的船廠（只修船）照舊顯示修船
- [ ] 數字跟模擬同一份帳（點開那一刻的城鎮帳，不另外估）

## 任務描述

Tim 2026-11-10：「希望城鎮模式點造船廠可以看到目前在造的船以及菜單(消耗多少資源) 可以開task」

依賴 TASK-1261（船從船廠來，分支 basecamp/1261-shipyard，還沒合 main）。資料都在城鎮帳裡：
- 正在造的船殼：船廠那一座的 `b.hull` ＝ { type 船型, work 整艘工天, prog 做了多少, in 整艘要吃的料, cut 船殼段做到哪, rig 索具段的料, day 開工那天 }（1／1000 單位）
- 造船菜單：`BSW.hullMenu(船型)` ⇒ { in: { 貨: 桶 }, work 工天, hand 手調的格子, bad 造不了的原因 }（world/fleet.js HULL_MENU：自動算法＋手調；`node tools/ship_menu.cjs` 印全部）
- 這座船廠造得了哪幾型：`BSW.yardCan(b, 船型)`（大船只在大船廠）；下一艘會造哪一型：`BSW.yardPick(S, b)`
- 那座城的船市：`S.towns[城].shipStock`（做好賣給城鎮、等主人來買的船）、`shipWants`（有人想要卻沒現貨）、`shipSold`（最近賣掉的）
- 今天的進度與缺料：prodDay 的 `rep.prod.b[船廠 id]`（w 雇到幾人、rate 開工率、rIn 料卡在幾成、used 今天吃了什麼）
- 城鎮模式點建築的資訊面板：world/site.js（建築那一格的 R：崗位、配方、產出／吃料、note）
