# TASK-0978 — Blockside：海戰開炮音照砲種、口徑變音色（合成音，照參考錄音的聲紋調）

> `improvement` / `normal` / `in_progress`　開單：kotoko　參與：kotoko(dev)

## 驗收標準

- [ ] 開炮音照砲種與口徑變：`shotFx` 把砲種傳給音效；全部現場合成（⛔ 不用音檔）
- [ ] 照參考錄音的聲紋調：CC0 參考錄音分小砲（黑火藥）、中口徑、大口徑、速射砲四組，量三分之一八度頻帶形狀與 −20／−40 dB 衰減；合成音逐組列頻帶差（dB）與衰減秒數，錄音不進 repo
- [ ] 口徑越大越低沉、越長（主頻照彈重的立方根）；同口徑不同砲種（黑火藥前膛、carronade、早期鍛鐵、線膛、後膛、速射、轉膛）聽得出差別
- [ ] 遠處的炮聲只剩低沉的轟鳴（距離越遠低通越低）
- [ ] 試聽集（`__game.boomLab`）：每種砲錄一段 WAV 給 Tim 聽；舊的 boom 當對照
- [ ] Tim 在遊戲裡聽過

## 任務描述

## 要什麼
Tim 2026-10-26：「接著想做海戰開炮聲音優化 一樣用合成音 不過希望根據砲的種類 口徑有音色變化」「可以下載音效檔案並比對頻譜來模仿」「另外不是實際使用真實錄音 而是參考頻譜用合成音模擬」

## 現況
- 02_audio.js `sfxPlay('boom')`：所有砲同一聲 —— 低通雜音（1,400 → 90 Hz、1.3 秒）＋ 70 → 32 Hz 的正弦。21_gunnery.js `shotFx` 沒把砲種傳下去。
- game.json `guns` 29 種，彈重 0.5～450 kg。

## 做法
- 同 TASK-0868（碰撞音）：CC0 參考錄音 ⇒ 量聲紋 ⇒ 在比對頁調合成音 ⇒ 搬進遊戲 ⇒ 用遊戲的離線錄音再量一次。
