做法（只在成品裡；_cache 的 .vxk 不動）：
- admin.py pack_html 先把每艘處理完（帆只留配方、網格換成池子編號），再拿改裝船跟原船比：**兩邊寫成 JSON 逐字相同**的欄（物件不同就往下一層找；陣列不拆；短於 32 位元組的不記）⇒ 從改裝船拿掉、記成 `header.vh = { el: 原船, k: [路徑…] }`。
