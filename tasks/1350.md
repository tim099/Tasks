# TASK-1350 — 《Blocksail》船廠造船建造演出：參考建築建造演出，依自動算法從龍骨、船殼到桅帆在船台上逐階段完工（TASK-1269 延伸）

> `feature` / `normal` / `todo`　開單：ridge-001　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 給任意一型船與進度 0～1，自動算法依造船邏輯分階段長出船體：龍骨與船底骨幹最先，接續肋骨／船殼外板與甲板由下往上（船殼段），再來立桅、橫桁與索具帆裝（索具段）；10／25／50／75／100% 截圖能清楚辨識階段順序（不要求每艘船手寫 meta，但預留覆寫出口）
- [ ] 城鎮模式下，正在造船的船廠船台上顯示對應船型與目前建造進度（接上城鎮帳的造船進度與船殼／索具分段），並可搭配臨時木撐、腳手架或船邊木料等施工裝飾隨進度出現與撤除
- [ ] 船台上的建造船與船廠模型不互相穿模或雙重疊船（解決既有船廠模型上靜態船骨架與動態造船重疊的問題），船身姿態與斜度對齊船台滑道
- [ ] 獨立預覽入口：不依賴經濟模擬也能挑選船型、拉動進度 0～1 或播放整段造船演出
- [ ] 完工與換船銜接：一艘船造完交船後船台清空或切入下一艘在造船隻，存讀檔或城鎮時間推進時畫面進度與城鎮帳一致
- [ ] 反向對照：進度 1.0 時船體與成品船逐格一致且施工裝飾 0 格；沒在造船（閒置或只修船）的船廠不顯示在建船體；不開造船演出／無在造船時城鎮模式畫面與效能不受影響

### 既有基礎（可參考與複用）
1. **建築建造演出與工地輪詢（TASK-0908／0912）**
   - `Blocksail/tools/townrise.py`：計算每格施工門檻 `bo`（1～255，照非空格順序壓成 base64）—— 有 meta 照 meta，無 meta 走自動算法（由下往上＋部件順序）。
   - `Blockside/src/js/63_townrise.js`：依門檻排序計數（`townRiseLoad`／`townRiseCount`）、逐區塊增量重網格化（`Grid.cv`）、周圍現算腳手架與建材堆、每 2 秒輪詢 `townUI 'sites'` 同步城鎮帳進度、並提供獨立預覽入口（`?rise=1`／`__game.townRise`）。
2. **船廠造船帳（TASK-1261／1269）**
   - `Blocksail/world/prod.js`：船廠正在造的船掛在 `b.hull = { type, work, prog, in, cut, rig, day }`，已天然分成 **船殼段**（`0..cut`）與 **索具段**（`cut..work`）。
   - `Blocksail/world/site.js`：`townSites`／`yardInfo` 已有城鎮帳接口，可擴充回傳各船廠地塊目前在造的 `{ type, prog, work, cut }` 給 Blockside 繪製。
3. **船台位置與下水對齊（TASK-0899／下水演出）**
   - `Blocksail/docs/BUILDING_SPEC.md` §5、§6.6、§6.24：水上船廠模型帶 `slip = "len,w,drop"` 船台參數。
   - `Blockside/src/js/58_traffic.js`：`trafficLaunchPrep`／`trafficLaunchSit` 已實作「依地塊 `l.water.slip` 與 `m.slip` 對齊船台位置、斜度 `th` 與龍骨貼合（`groundKeel`）」。

### 實作設計重點與已知坑
- **自動造船分段算法**：
  - 船殼段（對應 `0 → cut/work`）：自動依船體幾何抽出「龍骨（中線最底層）」→「肋骨／底板由中線往兩舷、由下往上生長」→「舷牆、甲板、上層建築／艙房」之順序門檻；
  - 索具段（對應 `cut/work → 1`）：依序長出立桅（由下往上）→ 橫桁／斜桁 → 纜索與帆（船砲屬交船後的武裝裝備，依 TASK-1260 不於船廠殼體階段畫砲）。
  - 可評估要離線預烘焙每型船的 `bo` 門檻表，或在 Blockside 載入船型時即時算一次並快取（後者可免重烘全部船檔，需量首次載入耗時）。
- **既有船廠模型上的靜態船骨架重疊**：
  - 目前 `common-shipyard-small`／`common-shipyard-large` 及水上版（`BUILDING_SPEC.md` §6.6、§6.24）船台上已雕有靜態船骨架（16 m sloop／30 m 骨架與龍骨）。動態在建船擺上船台前，需處理好靜態骨架的隱藏、拆件或空船台版本，避免新舊兩艘船重疊穿模。
- **陸上／水上與多船台船廠**：
  - 確認 `shipyard-small`（1 船台）與 `shipyard-large`（2 船台）以及陸上版／水上版的擺放策略與尺寸上限（`BSW.yardCan`），大船不超出船台過頭。
- **完工銜接**：
  - 一艘造完交船時可清空船台或銜接既有下水演出（`58_traffic.js`），再切換至下一艘 `b.hull`。
