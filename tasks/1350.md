## 驗收標準

- [x] 船台上的建造船與船廠模型不互相穿模或雙重疊船（解決既有船廠模型上靜態船骨架與動態造船重疊的問題），船身姿態與斜度對齊船台滑道　✅ ridge-001 2026-11-22

- [x] 完工與換船銜接：一艘船造完交船後船台清空或切入下一艘在造船隻，存讀檔或城鎮時間推進時畫面進度與城鎮帳一致　✅ ridge-001 2026-11-22
- [x] 反向對照：進度 1.0 時船體與成品船逐格一致且施工裝飾 0 格；沒在造船（閒置或只修船）的船廠不顯示在建船體；不開造船演出／無在造船時城鎮模式畫面與效能不受影響　✅ ridge-001 2026-11-22

   - `Blocksail/world/site.js`：`townSites`／`yardInfo` 已有城鎮帳接口，可擴充回傳各船廠地塊目前在造的 `{ type, prog, work, cut }` 給 Blockside 繪製。

   - `Blocksail/docs/BUILDING_SPEC.md` §5、§6.6、§6.24：水上船廠模型帶 `slip = "len,w,drop"` 船台參數。

### 實作設計重點與已知坑
- **自動造船分段算法**：
  - 船殼段（對應 `0 → cut/work`）：自動依船體幾何抽出「龍骨（中線最底層）」→「肋骨／底板由中線往兩舷、由下往上生長」→「舷牆、甲板、上層建築／艙房」之順序門檻；
  - 索具段（對應 `cut/work → 1`）：依序長出立桅（由下往上）→ 橫桁／斜桁 → 纜索與帆（船砲屬交船後的武裝裝備，依 TASK-1260 不於船廠殼體階段畫砲）。
  - 可評估要離線預烘焙每型船的 `bo` 門檻表，或在 Blockside 載入船型時即時算一次並快取（後者可免重烘全部船檔，需量首次載入耗時）。
- **既有船廠模型上的靜態船骨架重疊**：
  - 目前 `common-shipyard-small`／`common-shipyard-large` 及水上版（`BUILDING_SPEC.md` §6.6、§6.24）船台上已雕有靜態船骨架（16 m sloop／30 m 骨架與龍骨）。動態在建船擺上船台前，需處理好靜態骨架的隱藏、拆件或空船台版本，避免新舊兩艘船重疊穿模。
- **陸上／水上與多船台船廠**：
  - 確認 `shipyard-small`（1 船台）與 `shipyard-large`（2 船台）以及陸上版／水上版的擺放策略與尺寸上限（`BSW.yardCan`），大船不超出船台過頭。
- **完工銜接**：
  - 一艘造完交船時可清空船台或銜接既有下水演出（`58_traffic.js`），再切換至下一艘 `b.hull`。
