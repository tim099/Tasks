# TASK-1361 — 《Blocksail》WIC 三角貿易首航：強制勞工人口帳、港口結算與整環損益

> `subtask` / `normal` / `in_progress`　開單：Sirius　參與：Sirius(dev)

## 驗收標準

- [ ] 1666 首輪只有埃爾米納可從地圖外轉入強制勞工。人口按港口、年代與批次記帳並受補入頻率和候船上限約束。未啟用港口不產生人口，埃爾米納既有居民、移民和商品庫存不增減。
- [ ] 只有 NPC 公司透過獨立運輸單承運。埃爾米納實際上船按人頭付出港費，威廉斯塔德 WIC 分公司在出航前從自己的金庫預留抵港費。人口沿用移民的人口轉移與在途資料，在候船、船上及到港三處都能核對。玩家市場維持現有規則。
- [ ] 從同一份開場分別跑威廉斯塔德有缺工、零缺工兩趟。兩組都按實際交接人數收取抵港費。就業與船費分開，未就業者進當地待安置人口並消耗口糧。保存重讀後不重複產生人口、扣人或付款。
- [ ] 有缺工和零缺工各跑完整三角環並回到阿姆斯特丹，以實際成交、逐段補給、薪資、稅費、出港費、抵港費和期末存貨對帳，列每段及整環現金淨利。分支內部撥款和抵港費在 WIC 合併帳沖銷，與對外現金流分列。
- [ ] 反向對照涵蓋未啟用港口、抵港費或安置容量不足，以及承運單取消或人員獲釋。人口、預留款與已付欄位能對上，已結算批次不可重複收費。

## 任務描述

Tim 要模擬三角貿易中段。遊戲內一律使用「強制勞工（Forced Labor）」。人口轉移沿用現有移民帳，強制勞工使用獨立人口階層和承運單；移民仍照現有上船與落地規則。NPC 公司承運沿用 WORLD_LORE §5.2 與 TRADE_SIM §4 的玩家攔截和獲釋設定。

首輪從埃爾米納集結，將尚未模擬的內陸與其他沿岸來源抽象成「地圖外轉入」。模擬總人口因此增加，變動記一筆有來源區、接收港、日期和人數的外部人口流入。用港口與年代白名單、有限的候船池和補入批次控制。埃爾米納作現有港口的試航入口，阿克西姆首輪沿用物資供貨港角色。開場頻率、批量和費率是遊戲平衡值，由實測決定。

歷史依據可交叉查閱 SlaveVoyages 的 Rebecca 航次（1667，埃爾米納至庫拉索，https://www.slavevoyages.org/voyage/11772）及基於航次資料的研究（https://pure.knaw.nl/ws/files/12451692/IJH_Antunes_RibeirodaSilva_Proofs.pdf）。埃爾米納在該時段可作集結港，來源模型涵蓋內陸與沿岸轉運。首輪設定不把單一航次外推成 1666 年各港吞吐量。

航次用阿姆斯特丹 → 埃爾米納 → 威廉斯塔德 → 阿姆斯特丹，依到港月份選豐沙爾、布里奇敦、安格拉等可行的補給中繼。歐洲出製成品，加勒比回程載現有區域特產。上船費由船東付給來源地承辦方，到港費用由威廉斯塔德 WIC 獨立金庫預留並按交接人數分批結清，取消或未使用餘額原路退回。落地用安置容量與口糧約束，職缺只決定就業。交付需附兩組整環的開場、每段船期與資金對帳，可重跑且能看出獲利或虧損。
