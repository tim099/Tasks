# TASK-0931 — 《Blocksail》精細層的船隊與海盜：加勒比海的商船隊、海盜船隊在地圖上真的航行、追擊、搶劫（照史料），量損失率對照概略層

> `feature` / `normal` / `todo`　開單：erina　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 史料：海盜怎麼接近與拿下商船（掛假旗、追、警告射擊、升旗、登船）、多少是不打就投降、商船怎麼應對（逃、投降、抵抗、結伴、護航）、拿下之後拿走什麼（整船、部分貨、補給、人、贖金、放走、燒掉）—— 數字與出處寫進 TRADE_SIM
- [ ] 精細層（玩家船隊所在的海區，先做加勒比海）：簡易船隊不再只是「還要幾天」，照導航圖的路線在海上有真的位置，每天（或更細）往前走
- [ ] 海盜船隊：從海盜活動區的據點出航、在區裡巡航、看得到範圍內的商船就追（照兩邊航速，追不上就放棄）、追上就照史料結算（投降、抵抗、逃掉）、滿載或巡航夠久就回據點銷贓；回港之後在港裡待一段時間（享樂、修船；Tim 2026-10-25「可能會有一段時間在港口內享樂 修船等」）再出航
- [ ] 海盜船受自己的貨艙容量限制：搶不走全部，照每公斤最值錢的先拿（Tim 2026-10-25「海盜船應該會受限於自身容量 搶不走全部商品」）；概略層的「整船拿走」也照海盜船的容量封頂
- [ ] 地球儀上看得到：商船隊、海盜船隊的位置與航向（不同記號），點了看得到是誰、載什麼、要去哪
- [ ] 損失率：精細層跑一年，各航線被劫的次數與貨物比例 vs 概略層擲骰的同一個量；兩層差太多就調**海盜船的數量**（Tim 2026-10-25「可以調控海盜數量來平衡被搶的數量」；TRADE_SIM §2.3 第 6 條），讀數寫進 TRADE_SIM
- [ ] 錢、貨守恆：精細層跑 365 天每天錢與貨總數不變；兩次跑、存讀逐位元組相同
- [ ] 效能：精細層一天要算多久（地球儀與 node 各量一次），不拖慢地球儀
