# TASK-1276 — 《Blocksail》倉庫的資訊面板：顯示倉儲容量與主人（不再寫「不在經濟模擬裡」）

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 點規劃裡的倉庫、港邊倉庫列：資訊面板寫建築的名字（不是用途 id）、倉儲容量（桶）、主人；而且明說「還沒進城鎮帳，容量不算進模擬」
- [ ] 帳上真的有的倉庫（玩家或家族蓋的）：主人照帳、容量照它那一級；只有家族的、蓋好的才說「算進這個家族在這座城的倉儲」（同 storeCap）

- [ ] 其他種類的面板（住宅、生產、服務、軍事、真的不在帳上的地標）讀數跟改之前一樣
