## 驗收標準

- [x] 生產建築的配方可以換：一座建築照它的種類支援的配方（buildings.js recipes）每隔一段時間（間隔〔佔位〕）照情況重挑一次 —— 市場缺什麼、原料有沒有、賣不賣得回成本；換的那幾天有沒有轉換的代價（停工、少產）寫成規則　✅ gura 2026-10-26
- [x] 帶田的（農莊、種植園、葡萄園）：換作物要照季節／田的狀態，不是每天換；讀數列出一年換了幾次、換成什麼　✅ gura 2026-10-26
- [x] 規劃挑的配方、玩家在建築模式自己挑的配方 ⇒ 鎖住不換（反向對照：鎖住的那一座一年都不換）　✅ gura 2026-10-26
- [x] 自動建築（world/auto.js）挑要蓋什麼時，算上「現有的建築可以換配方」⇒ 不為了一種貨多蓋一座　✅ gura 2026-10-26
- [x] 讀數：同一份開場跑一年，動態換配方開 vs 關 ⇒ 各城缺貨天數、價格、產量；錢、貨守恆、兩次跑逐位元組相同　✅ gura 2026-10-26
- [x] 城鎮介面看得到每一座現在跑哪一條、上次什麼時候換、為什麼換；文件（PRODUCTION）寫上規則與讀數　✅ gura 2026-10-26
