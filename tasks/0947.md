# TASK-0947 — 《Blocksail》生產建築動態換配方：照市場缺貨、原料、成本每隔一段時間重挑（帶田的照季節換作物；規劃或玩家挑的鎖住）

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [x] 生產建築的配方可以換：一座建築照它的種類支援的配方（buildings.js recipes）每隔一段時間（間隔〔佔位〕）照情況重挑一次 —— 市場缺什麼、原料有沒有、賣不賣得回成本；換的那幾天有沒有轉換的代價（停工、少產）寫成規則　✅ gura 2026-10-26
- [ ] 帶田的（農莊、種植園、葡萄園）：換作物要照季節／田的狀態，不是每天換；讀數列出一年換了幾次、換成什麼
- [ ] 規劃挑的配方、玩家在建築模式自己挑的配方 ⇒ 鎖住不換（反向對照：鎖住的那一座一年都不換）
- [ ] 自動建築（world/auto.js）挑要蓋什麼時，算上「現有的建築可以換配方」⇒ 不為了一種貨多蓋一座
- [ ] 讀數：同一份開場跑一年，動態換配方開 vs 關 ⇒ 各城缺貨天數、價格、產量；錢、貨守恆、兩次跑逐位元組相同
- [ ] 城鎮介面看得到每一座現在跑哪一條、上次什麼時候換、為什麼換；文件（PRODUCTION）寫上規則與讀數

## 任務描述

## 要什麼
Tim 2026-10-25 晚（做 TASK-0946 酒館時）：「可以先維持單菜單 但是有多做酒館時 可以根據情況動態分配使用的菜單（其他生產建築也是 可以每天（或每一段時間）動態調配菜單」

## 分工
- 服務建築（酒館、教堂、修道院、醫院）的動態菜單：在 TASK-0946 做（一座一天一道、城裡照需求與物資分）。
- 生產建築的動態配方：這一張。牽動田的作物（annex）、自動建築挑什麼、建築模式玩家自己挑的配方，所以另開。

## 現況（2026-10-25，Blocksail main bd68db3）
- 生產建築一座一條配方：規劃或建築模式挑的 b.recipe（world/prod.js；沒選 ⇒ 第一條用得了的）。
- 田的作物照配方的 crop（world/annex.js）。
- 自動建築照市場需求蓋新的（world/auto.js），不會叫現有的換配方。

## 邊界
- 不動服務建築（0946）。
- 間隔、轉換代價都先標佔位，讀數出來再給 Tim 定。
