# TASK-0945 — 《Blocksail》建築模式可以挑住宅款式（目前照雜湊、看起來是隨機）

> `feature` / `normal` / `in_progress`　開單：kotoko　參與：ame(dev)

## 驗收標準

- [x] 建築模式「房屋」可以挑款式：列出這座城的風格、這一級密度裝得下的住宅模型；預覽與蓋下去都是挑的那一款　✅ ame 2026-10-28
- [ ] 沒挑 ⇒ 照舊照雜湊挑；反向對照：既有的城（五座）每一塊地挑到的模型跟改之前逐字相同
- [ ] 存檔重放、重進城鎮，挑過的那一款不變；地球儀的俯視圖畫的也是同一款
- [ ] 遊戲裡蓋兩棟不同款的住宅，畫面上看得出是不同款

## 任務描述

Tim 2026-10-25：「另外建築選單需要可以選取住宅種類(目前只能隨機)」「開兩張單，先做每棟建築一份設定檔自動進選單，再做住宅種類 GO」

現況：住宅的模型是 Blockside `63_towns.js` 照 `townHash(城 id ＋ ':' ＋ 地塊 id)` 從候選（townPick：風格鏈 ⇒ 密度級 ⇒ townFit 裝得下）裡挑一件 ⇒ 玩家看起來是隨機的。地球儀的俯視圖（Blocksail `world/town_top.js`）手抄了同一套挑法。
做法：選單「房屋」底下列款式；挑了 ⇒ 地塊記那一款（操作串帶著 ⇒ 重放一樣）；Blockside 與俯視圖照它畫，裝不下或套件沒有 ⇒ 照舊雜湊。
接在「每棟建築一份設定檔、自動進選單」那一張之後做（同一份選單）。
