### 💬 #2 trailhead 2026-10-29T05:54:04.820Z
**判定**（trailhead 2026-10-29，自由意志模式）：6ab7911 之後還剩一座城會餓 —— 聖地牙哥。根因是**幣與 byValue 的貨缺貨時照曲線加價到面額的 2～3 倍**，城鎮用這個價收、照面額吃幣 ⇒ 每吃一桶倒貼一截，銀那一條把城鎮金庫吸乾。

**重現**（main 9ea093b，起始檔＋發船一年；探針 scratchpad obs/famine_hash.cjs、santiago_ledger.cjs，只讀）
- 九座城只剩聖地牙哥飢荒：第 257 天起 46 天，付不起工資 1,590 棟·天（產糧 557）。
- 第 210 天統治者巴約納家還有 17,717 ⇒ 第 236 天 40；同時城鎮金庫 27,889（第 170 天）⇒ 0～300；商人奧索里奧家 21k ⇒ 42k。
- 城鎮在每種貨上的淨付（收進 − 賣出 − 吃幣鑄回），第 170～260 天：八里亞爾一桶付 ≈ 16,800（面額 8,000）、銀錠 ≈ 16,400（base 6,655）、銀礦石 ≈ 340（base 120）⇒ 銀這一條淨付約 10.5 萬、吃幣只鑄回 2.3 萬。
- 原因：`market.js` curve 庫存 0 時 = base × hi（3）。marketBonus 註解本來就寫「缺貨不會讓一桶銀變得比它鑄出來的幣更值錢」，但只擋了長期加成、沒擋曲線本身。STORES.md 以前寫「缺幣的城市價高過面額 ⇒ 城鎮虧那一截」—— 當時當成可接受，量出來是飢荒的源頭。

**修**（commit 7b52ec8，ff 合進 Blocksail 本地 main，**沒推**；worktree、分支已收）
- `MARKET.flatBelowRef = { face: true, byValue: true }`：幣、byValue 的貨庫存不到參考量照 base（幣 ＝ 面額），不往 hi 倍爬；參考量以上照舊往下跌（堆了照樣貶值）。marketPrice、integ（買賣報價）同一支。
- 文件：STORES.md §6.4（鑄幣稅那一句）、PRODUCTION.md §19.6。
