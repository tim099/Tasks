# TASK-1140 — 《Blocksail》海盜船開到陸地上 —— 精細層的海盜船直線走向目標、不看陸地（30 天 177／720 小時在陸上），進海戰也在陸上；被追的商船逃跑一樣

> `bug` / `wrong` / `high` / `in_progress`　開單：zenith　參與：zenith(dev)

## 驗收標準

- [ ] 海盜船不上陸：托爾圖加新存檔精細層跑 30 天（含巡航、追、回港），逐小時讀每艘海盜船的位置，用最細那一層查 `W.at(…).land` ⇒ 0 小時在陸地上（改前 177／720）
- [ ] 海盜船照航道圖走：巡航、回港、追擊都沿 `NAV_NET`（商船走的同一張圖）開；埋伏點不偏出航道
- [ ] 被追的商船逃跑也不上陸：同一段模擬裡逃、回航線的商船逐小時查陸地 ⇒ 0；不再靠沒接上的 `BSW.fineSea`
- [ ] 舊存檔：讀檔時已經在陸上的海盜船移回最近的航道點
- [ ] 地球儀、node 讀數工具同一個存檔、同一段小時算出來的位置逐位元組相同（不靠地圖載了多少）
- [ ] 進海戰：追上海盜、按「開打」，海戰裡海盜船在水上（截圖）
- [ ] ① 重現讀數：見「任務描述 › 🔬 證據」（讀數＋怎麼拿到的）
- [ ] ② 修正落盤（commit 帶 `Fixes TASK-1140`）

## 任務描述

## 現象
Tim 2026-10-31（附地球儀與海戰截圖）：「目前海盜船可以開到陸地上的Bug」「進入海戰後也確實在陸地上」。

## 原因（zenith 2026-10-31 查）
- `world/fleetfine.js` 海盜船每小時都用 `toward(位置, 目標, 速度)` **直線**往目標走：巡航往下一個埋伏點、追商船、回據點，三種都不看陸地。
- 埋伏點本身在航道上（向風海峽 243 個航道點，0 個在陸上），兩個埋伏點之間直線連過去常常橫越島與岬角；埋伏點還會在航道點旁邊隨機偏移最多 3 km（抽 2000 個，69 個偏到陸上）。
- 讀數：托爾圖加新存檔精細層跑 30 天，逐小時用最細那一層查 ⇒ **177／720 小時在陸地上**，全部是巡航（例：第 66～71 小時從托爾圖加南岸據點直接橫越托爾圖加島；第 143 小時切過古巴東端）。
- 進海戰照這個位置放船（globe.html trafficFor）⇒ 海戰裡也在陸上（船殼在地上推水 ⇒ 一大團白色水花）。
- 第二個洞：被追的商船逃跑（offStep／fleeStep）靠 `BSW.fineSea` 判斷陸地，註解寫「地球儀給」，但整個專案沒有任何地方設定它 ⇒ 一直全當海（TASK-0949 第 5 格）。

## 修法
- 海盜船與逃跑的商船改沿航道圖 `NAV_NET`（商船走的同一張圖）移動：不靠地圖載了多少 ⇒ 地球儀與 node 讀數工具算出來一樣、存讀照樣逐位元組相同。
- 埋伏點不偏出航道；舊存檔讀檔時已經在陸上的海盜船移回最近的航道點。

## 關聯
TASK-0931（精細層的船隊與海盜）、TASK-0949（航線快取、離開航線）、TASK-1078／1079（航海模式的海盜、追上開打）。

### 🔬 證據（開單時附；含「讀數怎麼拿到的」）

- Tim 截圖（2026-10-31）：地球儀上海盜船圖示在古巴北岸陸地上；進海戰後海盜船停在沙灘、樹林中間，船邊一大團白色水花。
- 托爾圖加新存檔（globe.html?save=pir1）精細層跑 720 小時：pirate-windward-passage-p1 有 177 小時 `W.at(lon, lat).land`（W.need 0.25° 格、zmax 之後查），全在 cruise；例 H66 (-72.7499, 20.0056)、H143 (-74.1683, 20.2129)。
- 埋伏點：同一支 waypoint 抽 2000 個 ⇒ 69 個在陸上；航道點本身 243 個 0 個在陸上。
- `grep -rn fineSea`：只有 world/fleetfine.js 讀它，沒有任何地方設定。
