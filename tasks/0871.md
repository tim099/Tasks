# TASK-0871 — 《Blocksail》城鎮資訊系統（城鎮帳）：每座城一份，人口、生產、市場、家族倉庫讀寫同一份；一支查詢給出那座城現在的所有資訊、存得成讀得回

> `feature` / `normal` / `todo`　開單：ame　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 每座城一份城鎮帳，人口、生產建築、市場、家族倉庫讀寫的都是這同一份（不另存第二份）；開場照世界資料建出來（範圍層那一筆的名字、勢力、規模、開場人口）
- [ ] 一支查詢：給城鎮 id ⇒ 那座城現在的所有資訊（基本資料、人口的年齡與男女分佈、勞動人口與分到的崗位、建築、市場庫存與價格、家族倉庫）
- [ ] 每天推進一次：照固定順序跑各系統（人口照它自己的間隔、生產每天）；同一份輸入跑兩次逐位元組相同
- [ ] 整份存成 JSON 再讀回來繼續跑，結果跟沒存過一樣（給存檔用）
- [ ] 工具印得出一座城的城鎮帳，也印得出全部城鎮的總表（人口、勞動、建築數）
- [ ] 反向對照：只改一座城的人口，其他城鎮帳一個數都不變
- [ ] 文件：權威文件寫清楚城鎮帳有哪些欄位、誰寫哪一欄；`ARCHITECTURE.md` 加這張系統卡與進度

## 任務描述

## 要什麼（Tim 2026-10-23）
「另外會需要一個管理城鎮所有資訊的系統(包含人口)」—— 接在城鎮人口（TASK-0870）之後說的。

## 現況（ame 查的）
- 城鎮的資料散在好幾處：範圍層那一筆（`world/areas.js`：名字、勢力、規模、開場人口 `pop`）、規劃（`world/town.js`）、生產的狀態（`world/prod.js` 的 `S.towns[id] = { pop: { 身分: 人數 }, market }`、`S.buildings`、`S.stores`）、市場（`world/market.js`）。
- 沒有一個地方能問「這座城現在怎樣」。

## 做法
- 把 `world/prod.js` 那一份狀態升格成城鎮帳：每座城一筆，人口（TASK-0870 的年齡層）、市場、建築、家族倉庫都在裡面；生產、人口各自只寫自己那幾欄。
- 世界資料唯讀（`ARCHITECTURE.md` §1）：城鎮帳只放會變的東西，名字、勢力、規模照 id 回去查範圍層。

## 邊界
- 跟 TASK-0870 同一個 worktree 做（人口住在城鎮帳裡）；`world/prod.js` 是 kaguya（TASK-0862／0863）的，動之前酒館先講。
- 存檔本身（存到哪、怎麼載）不在這張單；這張只保證整份存得成、讀得回、讀回來跑起來一樣。
