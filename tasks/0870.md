# TASK-0870 — 《Blocksail》城鎮人口：年齡五年一階（分男女）、每次增長往上一階＋各階死亡率、16～40 生育；勞動力照年齡；鎮民演出照人口挑角色

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 每座城一份人口帳：年齡層 0～5、6～10、11～15、16～20……一直到最後一階（每階分男女）；開場照範圍層的 `pop` 拆成一個預設的年齡分佈
- [ ] 一次增長：每一層往上一階、每一層照自己的死亡率少一些人（嬰幼兒、老人高）、最後一階不再往上只會減少；多久觸發一次是設定值（遊戲裡幾天一次），不寫死五年
- [ ] 生育：16～40 的女性照生育率生出 0～5 那一階、男女各半；生育率怎麼算（吃哪些輸入）寫在文件
- [ ] 同一座城、同一個開場、跑同樣次數 ⇒ 每一階的人數每次都一樣（可重現）
- [ ] 勞動力只看年齡：每一階一個工作比例，取代 `world/prod.js` 照身分算的 LABOR；生產建築分人手照新的勞動人口
- [ ] 鎮民演出照那座城的人口：照年齡層與男女比例挑哪一類角色、職業照生產建築分到的崗位；兒童比例照人口算，不再是寫死的 `child_share`（設定檔的 `weight` 還是在同一類裡加權）
- [ ] 量：一座城連跑 100 次增長，印每一階人數、總人口、出生、死亡；反向對照：生育率 0 ⇒ 人口只減不增；生育率、死亡率都 0 ⇒ 總人口一個都不變
- [ ] 反向對照（演出）：一座只剩最後一階老人的城，街上一個小孩都沒有
- [ ] 文件：`TOWN_SIM.md` §5 人口那一節照這版改寫；`ARCHITECTURE.md` 人口那一列的進度更新

## 任務描述

## 要什麼（Tim 2026-10-23）
- 「另外接下來希望增加城鎮人口系統 會跟鎮民演出有關(出現比例) 掛在 864母單下」
- 「目前構想的系統是 年齡以5年為一個階段(0~5 6~10 11~15 16~20) 然後年齡增長算法是每處發一次增長(不一定是五年 根據遊戲性可能遊戲中1年就觸發一次或更短」
- 「然後16~40的年齡層會生育後代(根據算法計算生育率) 之後就可以根據人口年齡分布 & 職業隨機生成鎮民了」
- 「然後人口跟家族無關」

## 已拍板（Tim 2026-10-23，ame 問的三題）
- 死亡：每個年齡層各有死亡率；最後一階不再往上長、只會減少（之後飢荒、疫病可以乘在這個率上）。
- 性別：每一階分男女；生育照 16～40 的女性人數算。
- 勞動力：只看年齡（每一階一個工作比例）；身分（殖民者、契約工……）不再影響能不能工作。

## 邊界
- 人口跟家族（`FAMILIES.md`、TASK-0863）無關。
- 移民、一籃需求與繁榮（`TOWN_SIM.md` §5.1）不在這張單；生育率先留好接口，之後吃繁榮、食物。
- 鎮民演出接的是 TASK-0849 的 `63_townfolk.js`（Blockside）與 `world/townkit/_people.js`（Blocksail）。
