# TASK-0863 — 《Blocksail》家族粗框架：建築的主人（公共的歸城鎮）、資金、地產、艦隊；每個家族在每座城一個倉庫（照桶數、倉庫建築加容量）；放不下的賣進城鎮市場；每種貨一桶的重量

> `feature` / `normal` / `in_progress`　開單：kaguya　參與：Tim(qa)、kaguya(dev)

## 驗收標準

- [ ] 家族的格式寫進 Blocksail 文件（id、名字、玩家或 NPC、資金、本家），Tim 看過
- [ ] 公共建築與地標歸城鎮；其他建築的主人是一個家族，還沒有家族的歸城鎮（Tim 2026-10-23）；反向對照：主人寫了不存在的家族 ⇒ 自檢報出來
- [ ] 地產、艦隊從建築與船的主人數出來，不另存一份清單
- [ ] 每個家族在每座城一個倉庫，容量照桶數：基礎容量＋那個家族在那座城的倉庫建築；多蓋一座倉庫容量照表加上去
- [ ] 放不下的當天賣進城鎮市場、錢進家族資金；反向對照：容量夠 ⇒ 一桶都不賣、資金不變
- [ ] 每種貨一桶有自己的重量；船裝貨要同時過桶數與重量兩條（規則寫進文件；船那一半之後接）
- [ ] 同一份輸入跑兩次，資金、倉庫、市場逐位元組相同

## 任務描述

Tim 2026-10-23：「建築物除了公共建築(屬於城鎮) 其他建築會有擁有者(家族) 需要新增家族概念(先做粗框架就好) 玩家本身也屬於一個家族 然後每座城鎮會有至少一個家族(掌握城鎮內的建築) 可以有多個家族
家族本身會有資金(玩家也有) 以及持有的地產 艦隊等 然後生產出來的資源會進入到倉庫(每個家族在每座城有獨立倉儲量) 倉庫可以透過建造倉庫建築擴大容量 不過會有基礎容量 容量單位用桶算(一桶資源) 然後每種資源一桶的重量不同(影響船隻載重 除了看能裝幾桶還要考慮重量)
然後城鎮本身是無限倉儲(市場) 超過倉儲量的貨物會被直接賣到城鎮市場」

粗框架：家族是什麼、擁有什麼、倉庫怎麼算、放不下的怎麼進市場。設計在 Blocksail docs/FAMILIES.md。
不做（之後）：家族屬於哪個勢力、家族之間的關係、繼承、NPC 家族怎麼經營、從市場買原料、介面。

跟 TASK-0862（生產建築）：產出進主人在那座城的倉庫、原料從那裡拿 —— 0862 的一天推進直接用這張的倉庫與市場。
