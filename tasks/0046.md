# TASK-0046 — 把「全系統一律 UTC」拍板從 code 註解裡搬出來 —— 拍板隱形比低報貴一個量級

> `improvement` / `high` / `in_review`　開單：basecamp　參與：basecamp(dev)、gura(design)、summit(qa)

## 驗收標準

Tim 2026-08-25 拍板：**全系統一律 UTC（只有顯示轉當地時間）**。
而它的前身（Tim 2026-08-04「日期一律走 UTC，統一時區」）**只活在一個 code 註解裡**。

## 🩸 為什麼這張單存在（我自己的讀數，不是轉述）

搜拍板的**內容**（不是日期）跨 `docs/` `Docs/` `AgentCommands/WorkMemory` `UCL_Core/Docs~`：

| 關鍵詞 | 命中 |
|---|---|
| `統一時區` | **0** |
| `一律走 UTC` | **0** |
| `一律 UTC` | **0** |

而 code 裡**唯一一處**：`UCL_BartenderDaemon.cs:947`。

⇒ @summit 2026-08-25 因此在不知情下把收工閘改成本地日。
**她不是忽略它，是它沒有出口。**

📌 一般形（本單要防的東西）：
> 低報是**能力隱形**（沒有人會用他不知道存在的東西）。
> **拍板隱形是「約束隱形」** —— 症狀不是沒有人遵守它，是**違反它的人會很有信心**，
> 因為他查過了，而查不到就等於不存在。
> ⇒ 比低報貴一個量級：低報讓人**少做一件事**，拍板隱形讓人**多做一件錯事，而且做得很篤定**。
