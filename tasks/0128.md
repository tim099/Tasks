# TASK-0128 — check_compile.py 在 in-progress 時同一份輸出頭尾矛盾：第一行說尚未定案，最後一行印 Clean compile

## 驗收標準

- [ ] **先量 exit code**：造一次 in-progress 活體，記下 `check_compile.py` 的 exit code
      ⇒ 已經非 0 的話本單只剩「文字誤導」那一半（優先度下修，但不取消）
- [ ] **in-progress 時不得印 `✅ Clean compile.`** —— 那一行是結論句，
      而 in-progress 時沒有結論。改成明說「這次編譯還在跑，這份讀數不是結論」
- [ ] **綠訊號要帶定語**：`Errors: 0` / `ErrorLog 對帳 ✅` 在 in-progress 時要標明
      「量的是**目前為止**，不是這次編譯的結果」
- [ ] ⚠ **尾端也要有那句警告**：`⏳` 現在只印在第一行，而讀輸出的人（與 agent 的 `| tail -N`）
      看的是尾端 ⇒ 警告要出現在**結論的位置**，不是只在開頭
- [ ] **反向對照（不能省）**：編譯真的乾淨時，輸出**仍要**印 `✅ Clean compile.`

## 🔬 證據（summit，2026-09-04 10:13–10:14，做 TASK-0071 時撞到）

改完 `Cmd_StreamWatch.cs` 送 `Cmd_Recompile`（回 Success）後立刻跑
`python check_compile.py --errors-only`，**連跑兩次拿到完全相同的輸出**：

```
> ⏳ **Compile in progress** — 結果尚未定案，請稍後再查。

- Timestamp: `2026-09-04T10:13:55`
- Duration: 0.00s
- **Errors: 0**
- Warnings: 0
- Total messages: 0 (raw)
- Distinct after dedupe: **0**
- 🔍 ErrorLog 對帳: ✅ 一致：**兩邊都沒有錯**（10:13:55 起）
- (filter: errors only)

✅ **Clean compile.**（已與 ErrorLog 對帳，兩個來源一致）
```

**同一份輸出的頭尾自相矛盾**：
- 第 1 行：**結果尚未定案，請稍後再查**
- 最後 1 行：**✅ Clean compile.（已與 ErrorLog 對帳，兩個來源一致）**

而 `Duration: 0.00s` ⇒ 那次編譯根本還沒跑完。等它結束後再查：

```
- Timestamp: `2026-09-04T10:14:15`
- Duration: 19.52s
- **Errors: 0**
- Warnings: 106
```

⇒ **Warnings 0 → 106、Duration 0.00 → 19.52**：前一份不是「乾淨」，是**什麼都還沒讀到**。

### 為什麼這隻值得開單

`ucl-compile-error` skill 把這支定位成「**編譯狀態的唯一可信來源**」，
而 agent 的標準動作正是「改完 `.cs` → 送 Recompile → 立刻查」——
**那個時間點命中 in-progress 的機率最高**（本次編譯 19.5 秒）。

🩸 而輸出的形狀讓假綠特別容易被收下：
1. `⏳ 尚未定案` 在**第一行**，`✅ Clean compile` 在**最後一行** —— 而最後一行是最容易被當結論的。
2. `Errors: 0` 與 `🔍 ErrorLog 對帳 ✅ 一致` 都是真話（那一刻兩邊確實都沒有錯），
   **它們只是在回答一個還沒發生的問題**。⇒ 三個綠訊號互相佐證，而三個同源。
3. 對 agent 而言更糟：多數 agent 用 `| tail -N` 讀輸出 ⇒ **`⏳` 那行剛好被切掉**。
   🩸 我自己 09-03 才踩過 `head -10` 切掉關鍵行那隻，今天是它的鏡像。

📌 形狀跟今天 TASK-0104 抓到的那隻**完全同形**：
一份輸出裡兩行來自不同地方、講相反的事，而沒有任何一層會喊。

### ⛔ 我沒量的（照實標）

- **exit code**：`⏳` 那次回什麼我沒記（當時沒想到要看）。若它已經是非 0，
  那本單的射程就只剩「文字誤導」那一半，優先度下修。**要有人在下一次 in-progress 時量一格。**
- 造活體的方法：改任何一個 `.cs`（加一行空白即可）→ 送 `Recompile` → **立刻**查，
  在 `Duration: 0.00s` 那一瞬間抓。
