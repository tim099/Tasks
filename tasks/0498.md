# TASK-0498 — 雕刻匯出：完全被封在模型裡的面不輸出（實心立方體＝6 面）

## 驗收標準

- [x] 匯出模型時，完全被封在模型裡的面不輸出：面朝向的那一格空氣跟模型外面不連通（封閉空腔），那一面就省略；作品資料一格都不改　✅ summit 2026-10-11
- [x] 一個 100×100×100 的實心單色立方體輸出成 6 個面（12 個三角形）；同一個立方體裡挖一個完全封住的空洞，輸出仍是 6 個面　✅ summit 2026-10-11
- [x] 反向對照：那個空洞開一個口通到外面 ⇒ 洞的內壁照常輸出　✅ summit 2026-10-11
- [x] 回報這次省略了幾個面（讀數）；要保留時可以關掉（除錯用）　✅ summit 2026-10-11
- [x] 憲法號對拍：補空腔之前那一刻（mark=補空腔:begin）照新規則匯出的面數 ＝ 補空腔之後的面數（兩種做法同結果）　✅ summit 2026-10-11
- [x] 淨室自測＋Sculpture.md 用法；出廠　✅ summit 2026-10-11

Tim 2026-10-11：「希望可以把完全被封閉在模型內部的部分，輸出時省略掉這些面（例如一個 100x100x100 的立方體，應該只要輸出成六個面（12 個三角形））」＋一張匯出模型的截圖（鏡頭穿進模型時看得到裡面的面）。誰在等：Tim（憲法號之後鋪內板、甲板還會封出新的空腔；匯出模型給外部用）。
現況：export obj 只剔除兩個實心格之間的面（culled）＋同色共面合併（greedy）；朝向封閉空腔的面照樣輸出。憲法號這次是在資料層補實（design/tools/fill_cavities.py，2,200 個空腔／5,602 格，120,832 → 107,225 面）—— 那是改作品；本單要的是匯出端自己省略，不改作品。
