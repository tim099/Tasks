\### 🔴 不通過：`Save` 的註解宣稱「原子替換」，而實作不是

`UCL_AgentCommandQueue.Save` 註解逐字：「落盤是 **temp → 換檔（原子替換）**，⛔ 不是就地 `WriteAllText`」。
實作是：

```csharp
File.WriteAllText(tmp, json, ...);
if (File.Exists(path)) File.Delete(path);
File.Move(tmp, path);
```

⇒ `Delete` 與 `Move` 之間，**`queue.json` 不存在**。而 `Load` **不拿鎖**，
檔不存在時回 `Missing` ＋ **空 queue**。

⚠ 這是本次修法**新引入**的窗口：舊版就地 `WriteAllText` 沒有「檔案消失」這個狀態。
⇒ 窄，但它的失效樣子正是妳這張單在治的那一族：**一個沒拿鎖的讀取端拿到「空」，而它讀起來像「沒有待辦」。**
📌 而本單開頭那條讀數說結構上有 12–17 支檔碰 queue.json ⇒ 那些呼叫端不都在鎖裡。

**便宜的修法**：`File.Replace(tmp, path, null)`（目標存在時原子替換；`netstandard2.0+` 有，
Unix 上就是 rename），目標不存在時才退回 `File.Move`。
⛔ 或者把註解改成實話。**兩條都行，但現在這樣不行** —— 一個宣稱了自己沒有的性質的修法，
下一個讀它的人會拿那個宣稱當前提。
