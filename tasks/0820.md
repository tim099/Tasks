# TASK-0820 — 《Blockside》小艇的外殼改成平滑的低面數網格＋體素顏色烤成貼圖（meta render；只改畫面）

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 模型 meta render 新的一種（外殼）⇒ 畫的時候外殼換成平滑的低面數網格＋體素顏色烤成的貼圖、殼以外照體素出方塊網格；沒標 ⇒ 照原本的；跟 render=lathe／pole 同一個「照 meta 選算法」的入口
- [ ] 模型的著色器吃得到貼圖（主畫面、倒影、合批、陰影都照常）；沒用貼圖的模型畫面一位元不變
- [ ] 兩種小艇標在子作品的預設 meta（雕刻 part=work）；造船規格、雕刻說明寫明
- [ ] 三角形數：兩種小艇改前／改後；有小艇的船整艘量給數字
- [ ] 反向對照：只改畫面 —— 戰局、匯入檢查跟改之前相同；沒有標的模型照原本的網格
- [ ] 截圖給 Tim 看小艇的樣子（近看、遠看）

## 任務描述

Tim 2026-10-22（TASK-0815 槳之後）：「小艇 GO」「可以考慮表面合併成平滑的 並轉成貼圖嗎(外殼)」「不是2D貼圖 是3D mesh+voxel顏色轉貼圖」「可以找看看有沒有合適的Voxel轉mesh算法」。

盤點（TASK-0792 留言）：小艇是面數第三名 —— 全艦隊 26 艘小艇 24.8 萬個三角形；兩種作品 10,930（9 m：ember／tridente／cosecha／napoleon／gloire／susquehanna／定遠號 ×4／松島號）與 8,278（8.55 m：憲法號 ×3、phoenix、tidegrave、松島號 whale）。
小艇的船殼是一格厚的薄板彎成 U 形，體素的階梯讓三角形大半花在殼上；車床式不對（不是旋轉體），通用的網格簡化收不了（匯出的網格有 T 形接縫）。

做法（照 meta 選算法再加一種，跟 render=lathe、render=pole 同一個入口）：外殼合成平滑的低面數 3D 網格，原本體素的顏色烤成那一層外殼的貼圖；殼以外的（座板、收著的槳、槳座）照體素另外出方塊網格。只換給 GPU 畫的那一份網格，佔格、碰撞、戰局照舊。
