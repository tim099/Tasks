# TASK-0983 — 《Blocksail》礦坑照礦區：只能蓋在礦的範圍裡（礦區劃成城區），產量照礦區裡的礦坑數與儲量

> `feature` / `normal` / `todo`　開單：kiara　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 礦坑只能蓋在那一種礦的資源分布區裡（建築模式、自動建築、開場檔同一條規則）；「離城的中心 10 km 內」那條舊判準拿掉
- [ ] 礦區可以劃成那座城的城區（TASK-0817）：礦離主城很遠也蓋得到、進得去
- [ ] 每一塊礦區有儲量；產量照那一塊裡的礦坑數與剩下的儲量算，挖完就停
- [ ] 讀數：埃爾科夫雷的銅礦區一年模擬銅礦石 > 0，儲量照實遞減（寫在單上）
- [ ] 反向對照：礦區外擺礦坑 ⇒ 建築模式紅、自動建築不蓋、開場檔報出來
- [ ] 儲量的數字寫明出處（史料，或照實標佔位）
- [ ] 一座城挖得到哪些礦 ＝ 碰到它每一個城區範圍（主規劃、遠的城區）的礦區合起來（開場檔 land、規劃取樣同一把；埃爾科夫雷的銅算進聖地牙哥）
- [ ] 亞拉斯的礦區劃成遠的城區（銅＋硝石那兩塊）：開場的銅礦坑、硝石礦坑搬進那一份規劃、擺在礦區裡；路接回亞拉斯（TASK-0988）；一年模擬銅礦石、硝石都 > 0
- [ ] 讀數：每座城取消 10 km 前後挖得到的礦逐座列出（金斯敦、皇家港、聖地牙哥的鐵在範圍外 ⇒ 拿掉；Tim 2026-10-27 先不開這三塊的遠城區）

- 沒有儲量這個概念。
