# TASK-1290 — 《Blocksail》橋：一種特殊的路 —— 路跨運河、窄的天然水面時自動變成橋；外觀照 指定 ⇒ 城的勢力預設 ⇒ 通用預設（第一版預設石拱橋）

## 驗收標準

- [x] 生成器找路可以跨運河、跨度在上限內的天然水面；跨水那一段自動成為橋（規劃裡的一種路，同棧橋、海堤，有寬與面高）　✅ gura 2026-11-14
- [x] 手動配置可以手擺橋、指定外觀；外觀照「指定 ⇒ 城的勢力預設 ⇒ 通用預設」挑，挑到的是哪一層查得到　✅ gura 2026-11-14
- [x] 第一版預設外觀石拱橋：遊戲裡畫得出來（拱跨過水、兩頭接上路面不懸空、不穿岸）　✅ gura 2026-11-14
- [x] 玩家建造模式鋪路跨水，同樣變成橋　✅ gura 2026-11-14
- [x] 鎮民走得過橋　✅ gura 2026-11-14
- [x] 自動架的橋不壓泊位、錨地、玩家停靠處與外海泊位的航道　✅ gura 2026-11-14
- [x] town_check 認得橋：跨水的路段不報落水、橋兩頭都接到路　✅ gura 2026-11-14
- [ ] 規劃變了的城全部重烘、開場檔照規劃差量更新；列出哪幾座城多了橋、房子各變多少
- [x] 反向對照：沒有路跨水的城，規劃逐位元組不變　✅ gura 2026-11-14

## 任務描述

誰在等：Tim（威尼斯的運河要一起處理橋）。

拍板（同日）：
- 自動架橋的範圍：運河＋跨度在上限內的窄天然水面（有河穿城的城規劃會變，要重烘）
- 「區域(國家)」照城的勢力 faction 查表（城轉手，新蓋的橋跟著新主人）
- 預設外觀第一版只做石拱橋；指定外觀可以是雕刻模型（例：里阿爾托橋）
