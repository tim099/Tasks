# TASK-1290 — 《Blocksail》橋：一種特殊的路 —— 路跨運河、窄的天然水面時自動變成橋；外觀照 指定 ⇒ 城的勢力預設 ⇒ 通用預設（第一版預設石拱橋）

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [ ] 生成器找路可以跨運河、跨度在上限內的天然水面；跨水那一段自動成為橋（規劃裡的一種路，同棧橋、海堤，有寬與面高）
- [ ] 手動配置可以手擺橋、指定外觀；外觀照「指定 ⇒ 城的勢力預設 ⇒ 通用預設」挑，挑到的是哪一層查得到
- [ ] 第一版預設外觀石拱橋：遊戲裡畫得出來（拱跨過水、兩頭接上路面不懸空、不穿岸）
- [ ] 玩家建造模式鋪路跨水，同樣變成橋
- [ ] 鎮民走得過橋
- [ ] 自動架的橋不壓泊位、錨地、玩家停靠處與外海泊位的航道
- [ ] town_check 認得橋：跨水的路段不報落水、橋兩頭都接到路
- [ ] 規劃變了的城全部重烘、開場檔照規劃差量更新；列出哪幾座城多了橋、房子各變多少
- [ ] 反向對照：沒有路跨水的城，規劃逐位元組不變

## 任務描述

誰在等：Tim（威尼斯的運河要一起處理橋）。

Tim 2026-11-14：「參考海堤 棧橋 橋梁作為一種特殊道路 當跨水時會自動產生(且要有預設外觀) 然後橋梁可以指定外觀(指定 => 區域(國家)預設 => 通用預設)」
拍板（同日）：
- 自動架橋的範圍：運河＋跨度在上限內的窄天然水面（有河穿城的城規劃會變，要重烘）
- 「區域(國家)」照城的勢力 faction 查表（城轉手，新蓋的橋跟著新主人）
- 預設外觀第一版只做石拱橋；指定外觀可以是雕刻模型（例：里阿爾托橋）
現況：路的找路一律不過水；棧橋、海堤是規劃裡帶面高的路（TASK-1077），遊戲照種類程式畫。
運河是另一張單（同日開）。
