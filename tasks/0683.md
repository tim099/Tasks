# TASK-0683 — Blockside 大漩渦天氣：暴風雨＋海中央（敵我中間）的大漩渦 —— 地形、水流、捲進中心、電腦避開、螺旋白沫

> `feature` / `normal` / `in_progress`　開單：kiara　參與：kiara(dev)

## 驗收標準

Tim 2026-10-17：「分析一下目前的海水&天候系統 是否能做出加勒比海盜3中的大漩渦天候」「暴風雨+海中央大漩渦(在敵我中間)」「如果ok的話 就嘗試加一個大漩渦天氣 GO」。

第一段（這張單）：
- [ ] 主選單「天氣」多一個「大漩渦」（網址 `?weather=maelstrom`）：暴風雨的天色、雨、閃電、風、浪，加上海中央（敵我兩隊正中間，世界原點）一個漩渦。
- [ ] 漩渦的地形接進水面高度 `seaH`（物理）與著色器的 seaH／seaG／seaHs／seaGf（畫面），兩邊同一個式子；船照舊用船底十個點擬合 ⇒ 會往下沉進漏斗、往內側傾。
- [ ] 浪高上下限（`seaBound`）把漩渦的深度算進去：⛔ 不然 33_flood.js「比最低的浪谷還低 ⇒ 一定在水下」會把漏斗裡甲板上的水手判成溺水。
- [ ] 水流：繞著中心轉＋一點往內吸，帶著船走（31_sailing.js 位置積分加上水流）；落水的人、碎片也跟著漂。
- [ ] 中心（眼）：船進到眼裡 ⇒ 被捲下去（開始沉）、上方廣播。
- [ ] 開局：兩隊照舊在中心兩側，船頭改成順著水流的切線（像電影裡繞著漏斗壁打）。
- [ ] 電腦的船：靠近中心太近 ⇒ 往外轉（不自己開進眼裡）。
- [ ] 畫面：漏斗壁上有螺旋的白沫條紋。
- [ ] ⛔ 晴天、暴風雨逐位元組不變（三組對拍照舊）；漩渦不抽 rnd()。
- [ ] 量過：開局 60 秒船的位置／深度／傾斜讀數、電腦不進眼、截圖。
