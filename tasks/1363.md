# TASK-1363 — 《Blocksail》船歸國家：船廠造好的船賣給國庫、國家之間可以買賣船（抵債或單純買賣）

> `feature` / `normal` / `in_progress`　開單：summit　參與：ame(dev)

## 驗收標準

- [x] 船廠造好的船賣給國家（國庫付錢、船進國家的船市），不再賣給所在的城鎮；國庫付不起的那一截怎麼記（欠船廠主人）寫進文件　✅ ame 2026-11-25
- [x] AI 船主、玩家跟國家買船：船價付進國庫；買得到哪幾國的船照規則寫清楚（本國、同盟、開得到的港）　✅ ame 2026-11-25
- [x] 國家之間可以買賣船：單純買賣、拿船抵債兩種都做得到，每一筆在讀數裡查得到（誰賣誰、哪一型、多少錢或抵多少債）　✅ ame 2026-11-25
- [x] 一年起始檔＋發船：船隊支數、總噸數、國庫、城鎮金庫、人口跟改之前比，差距寫在單上（配雙胞胎）　✅ ame 2026-11-25
- [ ] 反向對照：開關關掉 ⇒ 跟改之前（賣給城鎮）逐位元組相同
- [ ] 文件（PRODUCTION §31 船從船廠來、TRADE_SIM 國家那一節）寫上新的歸屬與交易規則

## 任務描述

## Tim 原話（2026-11-24，summit 的 session，TASK-1256 第三輪討論中）

- 「或是船直接歸屬於國家(從原本賣給城鎮變成賣給國家金庫) 然後國家間也可以交易船隻(抵債或單純買賣船)」
- 「另開一張單吧」

## 現在怎麼做（main 60aa4a032）

- 船廠交船：`world/fleet.js` `BSW.shipToTown` —— 船進所在城鎮的船市（`T.shipStock`），城鎮金庫付船價；付不起的那一截記成城鎮欠船廠主人（`T.famOwe`）。
- 買船：AI 船主照 `buildOne` ⇒ `yardBuy`（母港自己的城先、再來同勢力開得到的城）；國家的戰艦 `navyDay` 也跟城鎮的船市買（stock 開關現在關著）。
- 國庫已經有：國家的戰艦開銷、醫院學校名額（`BSW.nationPay`）走國庫。

## 為什麼

TASK-1256 第三輪把船主「自己排路線決定造哪一型」改成「只跟船市買、船廠自己挑型、持續造船、開局屯船」之後，船廠會一直造、沒賣掉的船堆在城鎮手上，城鎮金庫照船價付或欠著。Tim 提議改成國家收船，國家之間再互相買賣、抵債。

**Tim 定的**（本小姐問了之後他選的）

- 玩家買船：停在這座港的國有船都能買，船價付給持有那艘船的國家。
- 國庫付不起交船的船價 ⇒ 照樣收船，不夠的那一截記成國家欠船廠主人（家族或城鎮），國庫有餘錢時照收入還。
