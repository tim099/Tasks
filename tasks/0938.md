## 任務描述

### 🔬 證據（開單時附；含「讀數怎麼拿到的」）

**症狀**：加拉塔（town-galata）的自動建築（Blocksail `world/town.js townAutoBuild`，操作 `{ auto }`）會把地塊擺到手擺的小房子上，模型疊在一起。

**重現**（node；量具在 kotoko 的暫存區 `pick927b.cjs`，照 `tools/town_edit.cjs` 的 `--auto` 那一段寫的）：
1. 照 town_edit 的方式載入加拉塔的規劃 P。
2. 套用 `BSW.townApplyOps(S, P, [{ auto: { id: 'auto-t1', type, recipe } }, …])`。
3. 用 `tools/town_foot.cjs` 的 `foot(plan)` 量互疊（它照 Blockside 原始碼的 `townPick` 挑模型）。

**讀數**（2026-10-25，Blocksail main 0dd7759 前後）：
- 磨坊、漁場、鹽田三座 ⇒ 互疊 0 ⇒ 3：
  - `h-6`（house-a2-xs，7.98 × 8）× auto-t1，疊 8.4 m²
  - `h-24`（house-c-xs）× auto-t2，疊 5.6 m²
  - `h-4`（house-c）× auto-t1，疊 2.2 m²
- 對照：同樣的位置換成鋸木坊、鐵匠鋪、麵包坊（早就有模型的 8 × 12 工坊）⇒ 互疊 0 ⇒ 5（多了 `h-64` 5.8 m²、`h-38` 0.6 m²）。
- 模型都沒溢出自己的地塊（溢出 2 cm，低於門檻）⇒ 是地塊本身疊到手擺的房子上，不是模型的問題。
- 和平港、金斯敦、君士坦丁堡用同一套量法：0 ⇒ 0。

**讀數怎麼拿到的**：node 直接跑遊戲的規劃生成器與 Blockside `townPick`（town_foot.cjs 從原始碼抽出來的），不是截圖目測。

**猜（還沒驗）**：加拉塔的 `h-*` 是手擺的小地塊（8 × 8 的 xs）。townAutoBuild 切槽位時，可能沒把它們佔掉的格子扣掉。
