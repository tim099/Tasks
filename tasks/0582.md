# TASK-0582 — 雕刻觀測頁：類型下拉加「房屋」「城鎮」（照標籤 house／town，不看只列主作品）

> `improvement` / `normal` / `in_progress`　開單：summit　參與：summit(dev)

## 驗收標準

- [ ] 類型下拉多「房屋」「城鎮」兩項，件數照其他篩選條件算；房屋 ＝ 標籤 house、城鎮 ＝ 標籤 town（兩個都有 ⇒ 城鎮）
- [ ] 房屋、城鎮不看「只列主作品」（子作品也列）；船照舊（子作品不算船）；其他 ＝ 不是船、不是房屋、不是城鎮的
- [ ] 淨室測試補上（含反向對照：標籤拼錯就不算）；selftest 全過
- [ ] 岩堡港的作品標上標籤（房屋 8 件 house、地形 town）；出廠後在觀測頁讀得到件數

## 任務描述

Tim 2026-10-14：「可以新增一下房屋 城鎮類型作品（我篩選查看）」。

現況（讀碼）：觀測頁工具列的「類型」下拉寫死 全部／船／其他（SculptWorkType）。船 ＝ 主作品自己的關聯或模型 meta 帶造船規格那幾種 kind；子作品一律是「其他」。
房屋（岩堡港 TASK-0580 的 -house-*）都是子作品（tags sub）⇒ 選不出來，還會被預設勾著的「只列主作品」藏掉。

做法：類型多「房屋」「城鎮」兩項，照標籤認（house、town；城鎮優先）。這兩類不看「只列主作品」—— 房屋本來就是城鎮的零件，篩房屋就是要看零件。船的判法不動。
