## 任務描述

Tim 2026-10-27：「修城鎮那邊，讓城裡跟作品一樣；手擺城的 rot 逐座回頭對」

量到的（TASK-1010 #1）：雕刻引擎是另一個手性（面向 +x、上 +z、+y 在右手邊；Blockside 10_ship.js 檔頭）⇒ 船的 shipBaseMatrix 故意鏡射一次（2026-10-13 修過，EMBER 才讀得正）；城鎮模型的擺法（63_towns.js，3D 行列式 +1）、townmodels.py 都沒翻 ⇒ 城裡每一棟都是作品的鏡像。托爾圖加岩堡三張俯視：作品本尊 砲 → 旗 → 披屋，城裡 砲 → 披屋 → 旗。

做法：在資料那一端（townmodels.py）沿模型 x 翻 —— x 是寬、y 0 是正面 ⇒ 翻 x 正面照樣朝街，生成器排的地塊、朝向都不用動；Blockside 讀模型座標的十幾處照舊，兩次鏡射抵銷。

### 🔬 證據（開單時附；含「讀數怎麼拿到的」）

托爾圖加岩堡三張正上方俯視（雕刻引擎 view yaw 0 pitch 89／城鎮模式／點了換上來的）：繞一圈的順序 作品本尊 砲→旗→披屋、城裡 砲→披屋→旗、換上來的 砲→旗→披屋。程式：Blockside 10_ship.js 檔頭（雕刻引擎手性、shipBaseMatrix 鏡射）、63_towns.js 城鎮擺法行列式 +1、Blocksail tools/townmodels.py 沒翻軸。詳見 TASK-1010 #1。
