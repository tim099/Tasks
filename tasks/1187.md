# TASK-1187 — 《Blocksail》貿易網 P4b：生產缺口跨商圈往上游傳 —— 鐵件的需求拉得動整條鐵鏈（本城做不了的原料傳給做得出來的城，含地區特產）

> `feature` / `normal` / `todo`　開單：ridge-001　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 鐵件的需求拉得動整條鏈：起始檔＋發船兩年，有鐵礦區的城（現在只有聖地牙哥）的鐵礦坑、鐵礦、生鐵、熟鐵、鐵件產量比改前多，逐年讀數列在單上
- [ ] 別的城的鐵件缺口補得到：開場存量用完之後，各城船具行一年裡開得了工的天數比改前多（改前第 6～36 天就停、之後幾乎 0）
- [ ] 值只落在做得出來的城：沒有鐵礦區的城不蓋鐵礦坑；煉鐵場只蓋在有礦、或有穩定進口的城（座數讀數）
- [ ] 同一個缺口不被好幾座城各補一次：兩年內礦坑、煉鐵場、燒炭場的座數不暴增（列改前／改後座數）
- [ ] 跨商圈：一種只在一個商圈產的貨，別的商圈的需求傳得到產地商圈（讀數：傳過去的值、產地多蓋了什麼）
- [ ] 反向對照：開關關掉 ⇒ 收集器 digest ＝ 改前；每天錢的總數不變、兩次跑逐位元組相同、存讀檔不變

## 現況讀數（ridge-001 2026-11-02，Blocksail main 06f982f2）

- 船具行停工全是缺鐵件：一年模擬（起始檔＋發船）每座船具行停工那天，原料那一格是 0，人手、市場價、錢都沒卡；木板、繩一直堆，鐵件從開場約 11 桶掉到 0（第 6～36 天）；船具價漲到上限約 89（基準約 29.7）。
- 鐵件只有聖地牙哥在打（一年 105.6 桶，自己用約 74、船隊帶走 39.9）；鐵礦、生鐵、熟鐵也幾乎都只在那裡。
- `tools/auto_trace.cjs` 一年（不發船）：幾乎每座城的「鐵匠鋪 × 鐵件」每輪值 2～4 萬（聖多明哥 40,988、巴斯特爾 40,049），一年每一輪都被擋（缺熟鐵、木炭）；「煉鐵場 × 生鐵／熟鐵」估值 0（缺鐵礦，不少城還缺磚）；聖地牙哥「礦坑 × 鐵礦」每輪平均只值 1,900，一年 0 座。
- 原因：`world/auto.js` 往上游追只看同一座城（註解：「區裡的城之間還沒有運輸」；以前照區算，沒鐵的加拉塔也蓋煉鐵場）；加上 TASK-1057「通不了的鏈不往上游傳」⇒ 沒鐵礦的城值就停在那裡，傳不到聖地牙哥。
- 進口的鐵礦被鎮民的「撿便宜」吃掉：哈瓦那一年船隊賣進 41.9、鎮民吃 41.9（那裡沒有煉鐵場 ⇒ 生產鏈的理論用量 0 ⇒ 保留的 60 天份也是 0）—— 這一半另開單（消耗曲線）。

## 規劃（〔設計〕，等 P1、P2）

- 本城做不了的原料 ⇒ 記成本商圈的進口需求；商圈也做不了 ⇒ 記到集散地的轉口需求、跨商圈傳。
- 只分給真的做得出來的城（有礦區、物種），照產能比例分；每過一個商圈打運輸折扣。
- 還在蓋、還在運的量整個商圈一起扣（不重演開局 83 座牧場那一種）。
- 先在產地加工（聖地牙哥煉鐵、打鐵件後出口）；進口城自己蓋煉鐵場要等「連續一段時間都有鐵礦進來」才算通得到。
- 東方香料等地區特產同一條路：需求經過集散地傳到產地商圈。
