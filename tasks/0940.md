# TASK-0940 — 《Blocksail》玩家與海盜：船隊視野範圍、會被海盜劫掠、主動打海盜、升海盜旗劫掠船隊

> `feature` / `normal` / `backlog`　開單：erina　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 船隊視野範圍：地球儀上只畫玩家船視野內的商船隊與海盜船（白天、天黑各一個距離，跟海盜瞭望同一把尺）；追船的紅虛線兩端都在視野內才畫；讀數：同一時刻全知與有視野各畫幾艘
- [ ] 玩家會被海盜劫掠：精細層的海盜船看得到玩家船、會追；追上 ⇒ 投降只被搶貨（照海盜船貨艙），開火 ⇒ 進航海開打
- [ ] 玩家可以主動打海盜：在地球儀上點海盜船 ⇒ 追上後進航海開打；打贏的結果（贓貨、海盜船）照設計寫進城鎮帳
- [ ] 玩家可以升海盜旗劫掠船隊：升旗後追上商船 ⇒ 對方照史料投降或抵抗（同 0931 的結算）；搶到的貨要去灰色地帶的港銷贓
- [ ] 升了海盜旗的後果（被各國港口拒絕、懸賞、私掠許可證）寫成設計，Tim 拍板
- [ ] 反向對照：玩家不出海時精細層與城鎮帳逐位元組照舊（0931 的對拍）
- [ ] TRADE_SIM（與相關文件）補上設計與讀數

## 現況（0931 做完時）
- 精細層 `world/fleetfine.js`：商船隊照導航圖走、海盜船在向風海峽巡航／追／搶，一小時一步；玩家船不在精細層裡，海盜看不到玩家、玩家也不能對它們做任何事。
- 地球儀 `globe.html` drawFleets／fleetAt／fleetText：精細層那一片的船**全知**畫出來（海盜在港裡不畫）。
- 海盜瞭望 BSW.FINE.seeKm 18 km（白天、每小時 seeP 0.04 看到）、天黑 nightKm 3 km；結算：投降 surrender 0.9 只搶貨、開火的海盜贏 fightWin 0.85。
- 進航海（Blockside）時這一片的船隊與海盜不會跟著出現（0803 的「遇敵切回真實航行」還沒有地球儀上的敵艦）。

## 已拍板（0931）
- 海盜不挑國籍，除非是有私掠許可證的私掠船隊。
- 不開火就只被搶貨、不被奪船或擊沉（史料＋《海商王》）。
- 海盜船容量有限、回港享樂修船；被搶的量靠海盜數量平衡。

## 邊界
- 程式與讀數放 Blocksail repo；進航海開打動到 Blockside 照它的 dev 流程，跟 TASK-0803（海圖模式遇敵切回）接。
- 私掠船隊（照許可證只劫敵國）可以一起做，或另開。
