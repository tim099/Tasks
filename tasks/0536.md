# TASK-0536 — 《憲法號對轟》船沉進水裡的那一段不再裝填開砲；落水的人游到敵艦被撈起、變成敵方船員

## 驗收標準

Tim 2026-10-13：落水的人可以游到敵艦上，變成敵方船員（接在「落水求生」之後：自己的船在沉、沉了或斷了，落水的人現在只能踩水到溺水）。

- [x] 自己的船上不去（在沉、沉了、斷了）而敵艦還浮著 ⇒ 落水的人往敵艦游；游到敵艦舷邊、敵艦夠慢就爬上去，變成敵方船員（隊色跟著換），之後照敵艦的調度補位　✅ ame 2026-10-13
- [x] 換邊的人從原本那艘的船員名單移到敵艦的名單：兩艘的船員數、HUD、降旗的死傷 % 都照實算（原本那艘少一個、敵艦多一個）　✅ ame 2026-10-13
- [x] 上方廣播：兩艘各自看得到有人被敵艦撈起　✅ ame 2026-10-13
- [x] 量過：一艘沉船、兩艘都停住時敵艦撈得起人；敵艦照常開著走時撈得起幾個、溺水幾個　✅ ame 2026-10-13
- [x] 反向對照：溺水時間 0 ⇒ 戰局讀數與縮圖跟改之前逐位元組相同　✅ ame 2026-10-13

Tim 2026-10-13 補充（這才是落水求生主要要處理的）：船沉到水中的那一段，船員還能裝填、開砲。判定不用太密（效能為主，每 2～3 秒一次就夠），只是避免太離譜的情況。

- [x] 砲口泡在水裡的砲不能裝填、不能開，砲班離開它，HUD 砲列看得出來；浮出水面之後要重新送火藥才能再裝　✅ ame 2026-10-13
- [x] 頭泡在水裡的人不再站在水下裝填、開砲：有砲門的甲板（砲甲板以上）淹過頭就變成在水裡；封閉的艙（住艙以下）照艙內進水或船開始沉才算　✅ ame 2026-10-13
- [x] 判定每 2～3 秒一次；暴風雨的浪頭不會讓沒在沉的船平白有人落水、砲平白浸水（量過）　✅ ame 2026-10-13
