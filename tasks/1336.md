# TASK-1336 — 《Blocksail》VOC 黑胡椒、丁香的生產建築與萬丹／安汶產地城港

> `subtask` / `normal` / `todo`　開單：Sirius　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 確認萬丹及楠榜的黑胡椒供應分工、安汶的丁香產區及收貨港。核對 1666 年勢力、具體城鎮或腹地範圍，附可核對史料。
- [ ] 接上黑胡椒藤與丁香樹、種植／採收／曬乾流程、適地與建築。先評估現有種植園及香料園是否可共用，將熟化、人力、產率與乾貨成本列明。
- [ ] 核對產地、港口和開場存檔，烘雙向航跡。測產地貨進本地倉、市場和巴達維亞集散，再驗公司船的貨量與整趟損益。
- [ ] 驗非產區與未熟作物不產貨。生產、加工、運輸與交易的貨物和金錢守恆。

## 任務描述

對應 TASK-1206 的黑胡椒與丁香。先立單記錄生產與城鎮缺口，與 TASK-1325 的母港／補給站選址對接。貨物鍵採 black-pepper、clove。

- 黑胡椒（Piper nigrum）：候選為萬丹港（Banten／Bantam），接爪哇西部及蘇門答臘楠榜（Lampung）貨源。萬丹在 1666 年按萬丹蘇丹國查，記錄港口集貨和產地分工。胡椒藤須有攀架或支柱，採果乾燥後入庫。參考 [荷蘭亞洲航運網研究 §7](https://www.taylorfrancis.com/chapters/oa-mono/10.5117/9789053565179_CH07/knitting-threads-together-logistics-network-robert-parthesius) 與 [印尼 BRIN 萬丹胡椒考古研究](https://ejournal.brin.go.id/amerta/article/view/3352)。
- 丁香（Syzygium aromaticum）：候選為安汶港（Ambon）與島上產區。丁香園採未開花蕾並曬乾，港口收貨、儲存與轉運。參考 [荷蘭國家博物館安汶圖](https://www.rijksmuseum.nl/en/collection/object/View-of-Ambon--d9613214d8fa28b2bf0dd80cab5951bf?tab=catalogue) 與 [安汶丁香生產研究](https://www.cambridge.org/core/journals/international-review-of-social-history/article/labouring-transformations-of-amphibious-monsters-exploring-early-modern-globalization-diversity-and-shifting-clusters-of-labour-relations-in-the-context-of-the-dutch-east-india-company-16001800/6D2A9DF44C70C44B1AA6BFB773AFF7E2)。
- 巴達維亞候選亞洲集散地，以倉儲和轉口驗收，產地建置各按物種和史實。當前開場需要補這些城鎮、對應生產條件和航跡。
