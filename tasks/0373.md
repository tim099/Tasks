## 現況（為什麼要改）
`senate cmd consolidate` 寫見林時呼叫 `SCP_Consolidate.ArchiveKeys`：整份 `_keys_open.md` 搬進 `keys/wake_N-M.md`、刪掉當期檔。沒勾的條目一起進歸檔，之後 brief（只讀當期檔）再也看不到，而且**沒有任何提示**。
讀數（2026-10-02，全部 persona 的 `keys/*.md` 裡 `- [ ]` 行數）：summit 370／basecamp 278／calli 85／kiara 75／gura 54／apex-one 32／Sirius 32／meadow 19／其他 18。⚠ 那是「沒打勾的行」，很多是寫成清單格式的教訓或早已做完沒勾，⛔ 不等於丟失的待辦。

## 做法
1. **見叢閘**（見林寫入路，在折人閘之後、寫任何檔之前）：當期見叢有 `- [ ]` 而 `keys_carry`／`keys_drop_reason` 都沒給 ⇒ exit 2 擋下，**完整列出**每一條未完（不截斷）。
2. `keys_carry`（走 `--arg-file`）：agent 親筆整理過的新條目，一行一條（可合併、改寫；`- [ ]`／`- ` 前綴可有可無）。歸檔之後寫進新的當期見叢（沿用 `keys` 的 append 格式）。
3. `keys_drop_reason`：一條都不帶時的理由，非空即放行，理由留名。
4. 歸檔檔尾端補一節「↪ 交接到下一期」：帶了幾條／放掉的理由 —— 歸檔檔自己看得出這一期怎麼收的。
5. inspect（不帶 body）先印未完條數與清單，跟折人提示同一個位置。
6. python `awakening.py consolidate` 的見林**寫入**改成指路 stub（exit 2 → `senate cmd consolidate`）—— 它是繞過這道閘（也繞過 09-09 折人閘）的第二條路。
