# TASK-1364 — 《Blocksail》優化貿易公司航次收入、混裝與實際淨利

> `improvement` / `normal` / `todo`　開單：Sirius　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 用同一份開場存檔重現基線，分列各貨的採購與實收、到港未售存貨、補給、工資、稅費、公司資金調撥與集貨／候船成本，對帳後得出整趟營運淨利。
- [ ] 比較出航估價和實際到港成交，確認皮革等貨的估價偏差，以及空艙、供應、買方金庫和固定航程開銷各自造成的損益。
- [ ] 實測至少兩種可調整方向。以同一套開場條件比較自動選線、混裝和留港決策，驗證出港有補給和薪資預備金，並保留原本短途集貨可成交的行為。
- [ ] 跑一次實際盈利的既有公司航線或證明改動可降低基準虧損，並記下收支平衡需要的貨量、價差或航程。公司資金調撥另列，避免計為營運收入。

## 任務描述

Tim 要求把公司貿易收入優化另立待辦。以 TASK-1206 公司航線與混裝和 TASK-1362 糖線為基線。第一條驗證線為 1666 新開場的聖地牙哥 → 威廉斯塔德 → 布里奇敦 → 安格拉 → 阿姆斯特丹。
最新試航在第 44 天由威廉斯塔德裝 29.738 桶糖，混裝船 391 天後售清，糖品毛利 289.272 錢。公司船出港載重 33.179／49.200 噸，含補給與船炮，返航淨利 −6,386.519 錢，連集貨與候船為 −7,357.030 錢。皮革出港看似有利，抵港實虧 1,212.304 錢。總行另調撥 2,060 錢時載重只多約 0.16 噸，返航仍虧 4,169.439 錢。取消採購預算上限試算，出港仍約有 16 噸空位。
先量化港口供銷、長航程中價格變動、買方金庫、配貨方式、補給與工資的影響。優先驗證公司如何按抵港毛利、航程成本與售出風險挑線、混裝或留港。沿用目前遊戲與開場設定作為基準，所有平衡改動用對照試航量測。
