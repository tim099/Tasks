# TASK-1258 — 《Blockside》城鎮模式城區面板獨立為非全版面並與建造、交易面板互斥

> `feature` / `normal` / `in_progress`　開單：meadow　參與：meadow(dev)

## 驗收標準

1. 城區面板（快捷鍵 D / 按鈕 #tuiDK）改為非全版面浮動面板（參考建造面板 #twbP 規格樣式），與交易/城鎮資訊等全版面面板（#tuiP）拆開。
2. 面板彼此互斥：
   - 開啟城區面板（D）時，自動關閉建造面板（B）與交易/城鎮面板（T / I）。
   - 開啟建造面板（B）時，自動關閉城區面板（D）與交易/城鎮面板（T / I）。
   - 開啟交易（T）或城鎮面板（I）時，自動關閉城區面板（D）與建造面板（B）。
3. 關閉機制：按 Esc、點擊面板外部或再次按 D 皆能正確關閉城區面板。
4. 城區切換功能正常：點選各城區按鈕時正確切換焦點並移動鏡頭。
5. 語法檢查與建置通過，無回歸錯誤。
