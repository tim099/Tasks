# TASK-0737 — 《Blocksail》城鎮建造：照地形生成中心城區（城牆、公共建築、港口）、道路與沿路建地，建築用 voxel

> `epic` / `normal` / `in_progress`　開單：summit　參與：Tim(qa)

## 驗收標準

- [ ] 托爾圖加在 Blockside 裡長成一座城：中心城區（城牆、廣場、公共建築、港口）、往外的主要道路、沿路的建地，都貼著海圖塊的地形與植物（建築下面整平、路與建地上沒有樹）
- [ ] 同一筆城鎮資料＋同一個種子 ⇒ 兩次生成的城鎮規劃逐位元組相同；跨海圖塊的路、城牆接得起來
- [ ] 城牆照規模 × 繁榮度換外觀（至少：沒有／木柵／石牆三級），改繁榮度不改路與建地的位置
- [ ] 玩家可以從現有道路往外鋪路（只在城鎮範圍裡、照坡度與水擋），新路旁長出建地，建地上照適地表蓋得了的資源建築才蓋得下
- [ ] 建築全是 voxel 雕刻作品（0.1 m／格），可以組子模組、部件跟船通用
- [ ] 反向對照：沒有城鎮的海域，海圖塊與對局 dump 跟改之前逐位元組相同
- [ ] Tim 驗過

## 任務描述

Tim 2026-10-19：「準備開task實作城市建造功能 目前規劃是會標記城鎮的範圍(可以參考 托爾圖加是如何標記) 然後城市基於目前的地形生成&植物生成產生的地形建設 每個城鎮會有一個核心的中心城區(有城牆包圍 城牆可以根據城鎮的規模 繁榮度有不同外觀(木牆 石牆等) 中心城區會有一些重要建築(教堂 市中心 酒館 總督府等公共建築) 港口城市的話 市中心會包含港口部分 然後是中心會延伸道路出去(玩家也能擴建道路) 道路旁就能建造資源建築(農田 種植園 礦場 住宅等) 可以先規劃」
「然後建築預計跟目前造船一樣 採用Voxel建造(且跟船一樣可以組合子模組 部件也可以跟船通用 一樣0.1m比例尺)」

接在 Blocksail 文件 TOWN_SIM.md §2.1（港口＋市中心＋道路網）、WORLD_FORMAT.md §19（範圍層；第一筆 town-tortuga）、§15／§18（海圖塊、林地與植被段）後面：經濟層（建設、配方、人口）已經有設計；這張傘補「在真的地形上把城長出來」那一層。

## 分層（規劃草案，細節在子單①的設計文件定）

1. **資料**（Blocksail world/areas）：城鎮那一筆加「規模」（村／鎮／城／首府，1715 年開場值照史實底稿 TOWNS_1715_WINDWARD.md），風格預設照勢力；中心城區範圍預設照規模自動生成、可以手畫一圈蓋過。繁榮度是存檔裡的值，不寫進世界資料。
2. **生成器**（Blocksail，跟海圖塊同一套決定論）：輸入 ＝ 城鎮那一筆＋地形（terrainGrid）＋林地與植被＋海岸類型＋種子；輸出一份「城鎮規劃」：中心城區的圈、城牆折線（門、塔）、廣場與公共建築的地塊、港口的碼頭線、從城門往外的主要道路（照坡度與水找路）、沿路的建地、整地範圍。地塊是「位置＋朝向＋大小＋用途」，不綁某一件建築。
3. **匯出與遊戲**（Blockside）：海圖塊多一段或海域多一個城鎮檔；遊戲照它整地、清掉路與建地上的樹、照用途挑建築模型擺上去；城牆沿折線一段一段擺模組（牆、塔、門）。
4. **建築套件**（Sculpture，造船同一套流程）：0.1 m／格、子作品組合、外部模型、meta；砲、燈、桶、格柵這類部件直接引用船上的元件。第一套風格：法國（托爾圖加）；岩堡港（TASK-0580）是現成的樣本。
5. **玩家擴建**（Blocksail 經營層）：從現有道路往外鋪、沿路長出建地、建地上照適地表蓋資源建築；存在存檔，不改世界資料。

子單照上面順序，後面的 blocked_by 前面的（建築套件可以跟生成器同時做）。
