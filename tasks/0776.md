# TASK-0776 — 《Blockside》船隻觀察模式：剖面、甲板、部件清單勾選高亮（看抽水機）；主選單不列建造、航海

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 主選單多一種玩法「🔍 船隻觀察」：只生我艦、沒有敵艦、不判勝負、船停在原地、開砲轉舵那些海戰的鍵不作用；畫面上有觀察面板：剖面開關、甲板一層一層選（全部／拿掉到某一層）、透視
- [ ] 部件清單（觀察面板的一部分）：照種類列出這艘船上的部件（名字、件數，可以展開看每一件）；勾選 ⇒ 3D 裡那幾件高亮，隔著船殼也看得到；擺了抽水機的船列得出抽水機、勾了看得到在哪
- [ ] Blockside 主選單不列 🔨 建造、⛵ 航海；Blocksail 用網址 ?mode=build／?mode=sail 照樣進得去；存檔裡存的是這兩種 ⇒ 照預設玩法
- [ ] 手機寬（375）觀察面板點得到、收得起來，不整片擋住船
- [ ] 反向對照：其他玩法（對戰、觀戰、沙盒、?mode=build／sail）的戰局與縮圖跟改之前逐位元組相同

## 任務描述

Tim 2026-10-21：「是否可以加一個船隻觀察頁面 可以切換剖視圖 & 甲板 作為一種模式(參考 建造 航海) 另外Blockside入口不顯示建造&航海(這兩個是給Blocksail使用的)」「然後觀察頁面要可以顯示船上各個部件名稱(額外UI) 勾選後會高量該部件(我想查看抽水機)」。誰在等：Tim。

現況（ame 讀程式，dev 0405edc）：
- 玩法是一張規則表（04_modes.js MODE_RULES；TASK-0668）：主選單的玩法鈕照表裡 menu 的生；menu 同時決定存檔與 ?mode= 認不認 ⇒ 要拆成「主選單列不列」與「網址認不認」兩格。
- 剖面（Z）與拿掉甲板（L）已經有（74_cutaway.js，CUTV），在停格條裡、要按鍵輪著切；透視（X）在 72_floodui.js。

- Blocksail 的海戰頁走自己的外殼，建造／航海用 ?mode= 帶進來、start=1 跳過 Blockside 的主選單。
