# TASK-1415 — 《Blocksail》高度格的水面層試作：湖、河、可變的海面（台灣）

> `feature` / `normal` / `in_progress`　開單：summit　參與：summit(dev)

## 驗收標準

- [ ] 高度格的檔可以有「沒有值」的格子與整塊沿用上一層；舊檔照樣解得出來，JS 再編逐位元組相同
- [ ] 台灣烘出三樣：刻了河床湖底的加細地表、水面高度層、淹水門檻層；印出檔數與各自的大小
- [ ] hglobe.html 畫得出台灣的湖與河，海面可以調（預設 0 m），調高淹低地、調低露出海底
- [ ] 河邊拉近會切到更細的層；量拉近到河邊時的節點數與每秒張數
- [ ] 對拍：水面層的邊緣一圈都是乾的；刻河床之後台北盆地等假窪地接得到海
- [ ] 反向對照：不刻河床那一份，台北盆地仍被擋住（對拍看得出差別）
- [ ] docs/HGRID.md 寫上水面層的格式與讀數

## 任務描述

Tim 2026-11-28：「接下來 嘗試分析一下 用什麼格式去紀錄河流&湖泊吧 目前希望是跟地表高度一樣的方法 然後紀錄水面高度(甚至可以嘗試跟海洋一起處理?) 然後海水高度可以支援能變動嗎(預設0m 但之後可能可以在遊戲內模擬海洋變高淹沒低地等)」「然後不用參考現有的(整套重做)」「那河流區域加細呢(額外細分 效能上ok嗎 資料量應該還好?) 然後可以先試作台灣 完成後可以直接合併我來QA」

接在 TASK-1404 的高度格試作後面：同一套格子與編碼，多存一層水面高度；河床、湖底刻進地表高度；另算一層「海面升到幾公尺海水才到得了這一格」。河邊照河寬局部加細。驗證地球儀 hglobe.html 畫水面、海面可調。

烘焙輸入只把現有的台灣河湖紀錄（Overture 來的中線、湖形、水面、寬）當資料來源，格式不沿用。
