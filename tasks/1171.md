## 驗收標準

- [x] 收集器多記兩樣：區對區流量（起城 → 迄城 × 貨，桶與金額，照月），以及每一區的產、耗、進口、出口、區內轉運　✅ Sirius 2026-11-02
- [x] 只讀不改模擬：收集器開著跟關著，城鎮帳雜湊一樣（`sim_lab --check 1`）；原本那幾欄的 digest 跟改之前一樣　✅ Sirius 2026-11-02
- [ ] 貨源：船隊貨艙每一種貨記「在哪一座城買的」，賣的時候照比例扣。被劫、存糧這類不經過買賣的進出照比例對帳，對不上的那一截記成「不明」；一年模擬「不明」佔賣出的比例列在單上
- [ ] 守恆：流量表加總 ＝ 各城船隊賣進（fs）加總；全世界的進口總量 ＝ 出口總量
- [ ] 已知答案：手做的城與船隊（在 A 買、到 B 賣、中途被劫一部分）⇒ 流量表照答案分到 A → B 與「不明」
- [ ] 工具 `tools/trade_report.cjs`：照分組（海洋分區／勢力／時空／城）印每一區的產、耗、進口、出口、淨額，前幾名的區對區流量，流通指標（卡住的貨、跨區佔比、覆蓋面）；可以輸出 CSV
- [ ] 模擬後台多一頁「貿易」：選分組、選貨，看每一區的產銷、進出口、區對區流量
- [ ] 現況基準：起始檔＋發船一年的流通指標寫進文件、列在單上
- [ ] 文件：SIM_STATS 新增一節；TRADE_NETWORK 的 P0 標成已做

## 任務描述

## 要什麼

Tim 2026-11-02：「然後後台可以記錄每個區域的生產 消耗 以及進口 出口等(用在遊戲內報表以及輸出用來分析貿易系統運作)」「先做 P0 量具」

貿易網 v2（`docs/TRADE_NETWORK.md`，TASK-1096）的第一期。先把現在的貨怎麼流動量出來，當作後面每一期的基準。這一期只記帳、不改模擬。

## 邊界

- 遊戲內的區域報表頁、存檔裡的月帳，是 P0b，不在這張。
- 「區」先照現在的海洋分區（`regionOf`），另外可以照勢力、時空、單一城來分組；商圈（P1）做好以後，再多一種分組。
- 貨經過一座城的市場就算落地：貨源只追到上一手（在哪一座城買的），不追整條鏈。
