# TASK-1351 — 《Blocksail》自檢的 ⚠ 可以「確認不修」：一個 repo 一份確認表、每條警告帶 key、內容變了就重新報（範圍、城鎮、船的匯入）

> `feature` / `normal` / `in_review`　開單：gura　參與：gura(dev)

## 驗收標準

- [x] 共用的確認表與工具：一個 repo 一份 warn_ack.json（Blocksail tools/、Blockside src/config/）；每一筆 key、內容指紋、誰、日期、為什麼不用修；CLI 能加、列、清（加的時候照上一次跑出來的那一條取內容，不用手抄）　✅ gura 2026-11-21
- [x] 每一條 ⚠ 都帶穩定的 key（印在訊息前面）；確認過的不印 ⚠、最後一行報「已確認不修 N 條」；內容變了（數字也算）⇒ 確認失效、照樣報並附上當時的內容；確認了但不再出現 ⇒ 報「過期的確認」　✅ gura 2026-11-21
- [x] 接進 Blocksail 的自檢：areas_check（＋地球儀畫範圍面板）、town_bake、town_plan、town_report、town_check、townkit_check、flag_check、water_check　✅ gura 2026-11-21
- [x] 接進 Blockside 船的匯入：shipcheck、ladcheck（import／reimport 自動跑的那一份與報表）　✅ gura 2026-11-21
- [x] 驗過三種情況：加一筆確認 ⇒ 不再報；改資料讓內容變 ⇒ 重新報；拿掉原因 ⇒ 報過期　✅ gura 2026-11-21
- [x] 規則寫進文件：看到 ⚠ 只有兩條路 —— 修掉，或寫理由確認掉；townkit_flaw.json 與寫死在程式裡的「不報」這次不搬（列出來）　✅ gura 2026-11-21

## 任務描述

Tim 2026-11-21：「⚠ links[0]（sulfur） 有 2 個點在水上 可以修復嗎 以及其他過程中發現的warning(如果是不需要修復的 希望有工具可以關閉警告(避免下次還要再判斷一次) 可以通用這個規則到目前的自檢流程(包含船的匯入 城鎮等)」；設計回報後「照這個設計做」

**現況**（gura 2026-11-21 盤點）
- 唯一的確認機制：tools/townkit_flaw.json（城鎮模型的瑕疵／設計如此，照模型＋幾何位置記、模型改了就失效、對不上的報過期）—— 這次推廣的就是這個做法
- 其他的「不報」寫死在程式裡（town_bake 的走道對不到門洞、town_report 的渡船島、shipcheck 的憲法號、單錨的船、ladcheck 的幾條）
- ⚠ 大多是自由文字、沒有穩定 key；都不擋 exit code

**設計**
- 確認表：{ fmt, acks: { key: { sig, msg, by, at, note } } }；sig ＝ 訊息全文（含數字）的 FNV-1a 32 位元 ⇒ 內容變了就失效
- 每一支自檢：⚠ 印成「⚠ [key] 訊息」；確認過的收成最後一行；這次跑出來的 ⚠ 記進 _cache（CLI 加的時候照它取內容）
- 硫磺坑那條路的 ⚠ 已經修掉（e9a938ca2），不是確認掉
