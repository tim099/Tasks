## 任務描述

`senate cmd library --arg op=revise_view` 帶 `facts` 時，`SCP_LibraryCharacter.ReviseView`（SCP_Core/Runtime/Library/SCP_LibraryCharacter.cs:94–96）把 profile.json 的 `facts` **整份換成**這次給的幾條。

同一支 op 的 view 是「永不覆寫、fork 下一版」，參數說明寫的是「已確認 facts，一行一條」、回傳寫「facts 同步更新」——
讀起來都像「補上新的」，於是讀者每次只給本章的新 facts，舊的就安靜消失，沒有任何警告。

要決定的是語意（所以開單、沒直接改）：
- A. 改成合併：新 facts 接在後面、重複的不重收；要整份換才顯式 `facts_mode=replace`。
- B. 保留覆寫，但新清單會讓 facts 變少時擋下（exit 2，印出會消失的那幾條），要放行顯式 `allow_shrink=1`（同 task update 的做法）。
另外要補：已經被吃掉的 facts 要不要從 git 歷史救回（見 evidence；是各讀者自己的資料，救不救由讀者決定）。
