## 驗收標準

- [x] 關聯標 kind=turret 的子樹（殼的格子＋上面的砲）一起照瞄準點轉，砲照舊各自判斷對不對得到才開　✅ meadow 2026-10-17

- [ ] 砲塔上可以再疊一座砲塔，裡面那座的砲照兩層的角度合起來瞄得準（打中判定、砲口位置、砲班站位都對）
- [x] 殼可以一格一格打掉、擋人員傷害、算走不穿的那一圈，跟現在的裝甲一樣　✅ meadow 2026-10-17
- [x] 砲塔上的砲全滅 ⇒ 砲塔停在最後的角度　✅ meadow 2026-10-17
- [ ] 匯入檢查印出砲塔樹（每座砲塔的轉軸、角度範圍、上面有哪幾門砲、殼幾格）；標錯的（kind=turret 底下沒有砲等）會報
- [x] 反向對照：沒改標法的船（含舊標法的維吉尼亞號、莫尼特號、哨兵號）對拍讀數跟改之前一樣　✅ meadow 2026-10-17
- [x] 造船規格與 README 寫上新標法　✅ meadow 2026-10-17
- [x] 砲塔的前方是作者標的方向（不是照砲軸平均），砲塔把前方轉向瞄準方位；上面的砲自己會轉的照自己的前方瞄　✅ meadow 2026-10-17
- [ ] 砲塔裡可以放彈藥箱（彈藥庫的關聯或火藥桶），跟著砲塔轉，送藥手照它取藥
- [ ] 砲塔裡能走的那一塊是一片會轉的甲板：走路格照砲塔自己的座標，站在上面的人跟著轉；砲塔轉到哪個角度都走得到砲和彈藥箱

## 任務描述

Tim 2026-10-16：「讓砲塔本身只是一層殼 上面可以放置炮(跟在船體上放炮一樣) 讓炮跟著砲塔轉」「取代目前把炮塔綁在炮上的機制(因為這樣強制只能一個砲塔裝一門炮 且實際上可能可以在炮塔上額外加裝炮塔」「炮塔可以根據目前的瞄準資訊自行旋轉到對應方向 炮塔本身也是可以體素破壞的子物件」。
拍板：三期都做（本單是第一期：Blockside 引擎）；第一版砲塔上的砲全滅才停（轉台卡住留到以後）；舊標法（砲自己標 mount=turret／pivot、裝甲 mount=<砲>）照樣能用。
標法：雕刻關聯 meta kind=turret（arc／fire／rate／轉軸）；它子樹裡的格子是殼、外部模型（砲）跟著轉；子樹裡再一個 kind=turret ＝ 疊層。
