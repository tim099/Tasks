# TASK-0877 — 《Blockside》分段陰影（cascade）重寫：每一段貼緊鏡頭看得到的地方、不超出畫面、段間少重疊不斷開；除錯塗色

> `improvement` / `high` / `in_progress`　開單：apex-one　參與：apex-one(dev)

## 驗收標準

- [ ] 分段陰影第 0 段（紅）的範圍在 Tim 截圖那類鏡頭（俯看城市、拉高看海岸）不再大半落在鏡頭外：量每一段範圍落在畫面裡的比例，改前改後同一個鏡頭各一份讀數
- [ ] 段與段之間的重疊比改前少（同一組鏡頭，量每一段面積與相鄰段的重疊）
- [ ] 不斷開：近處高的東西（塔、桅頂）、畫面邊的山不再整塊沒影子（貼合畫面的取樣漏掉時有退路）
- [ ] 鏡頭平移、轉動時影子的邊不閃（範圍大小不是每一格連續變）
- [ ] 除錯工具：每個像素照用到的那一段塗半透明顏色（紅黃綠青），地表上每張圖的邊框
- [ ] 每格陰影耗時不比改前多（同一場景交替量）
- [ ] Tim 在遊戲裡看過

## 任務描述

Tim 2026-10-24：「請協助優化(或重寫)目前Cascade shadow的算法 目前有幾個嚴重的問題 一個是Shadow map會超出Camera範圍(特別是精度最高的一個) 另一個是不同層級的Map重疊嚴重 且有時還會斷開」「是否可以參考現成的算法來使用」
追加：「然後可以優化Shadowmap Debug工具方便妳查看 目前只有提示線 我覺得可以填上半透明顏色(對應線的顏色」「目前紅色線的部分有機會完全跑出畫面(且目前截圖的情況 一大半都浪費在鏡頭外了)」（君士坦丁堡兩張截圖）

現行（60_render.js shadowPass）：每一段 ＝ 那一段視錐的外接球 × 範圍放大 1.22，從太陽方向投成正方形 —— 球裡大半是空中與鏡頭背後，太陽斜時正方形投到地面再被拉長 1/sin(仰角)；著色器只照離鏡頭的深度挑段，挑到的那張沒罩到這一點 ⇒ 沒影子（斷開）。

做法（參考 DX SDK CascadedShadowMaps11 的 fit to cascade＋對齊格子、Unity URP 的「不在這一段的圖裡 ⇒ 往下一段找」、SDSM 用場景範圍收緊）：
- 每一段視錐先用場景的高度帶（畫面裡的地面最低～最高＋桅頂／建築）裁掉空中與地底，在太陽座標裡取緊的長方形（長寬各自）；大小走一級約 9% 的階梯＋遲滯、中心對齊陰影圖格子 ⇒ 鏡頭移動不閃。
- 著色器：照深度挑段，那一點不在那一段的圖裡 ⇒ 往下一段找；混下一段只在下一段的圖罩得到時。
- 除錯（畫質頁「顯示分段」／?shdbg=1）：每個像素照實際用到的那一段塗半透明顏色（同線的顏色），每張圖在地表上的邊框照實畫。
