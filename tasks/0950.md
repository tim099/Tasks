# TASK-0950 — 《Blockside》船隻旗幟可換：旗 ＝ 底色＋紋章，開戰鈕左右選兩陣營的旗（取代寫死的英國艦隊旗）

> `feature` / `normal` / `in_progress`　開單：kotoko　參與：kotoko(dev)

## 驗收標準

- [x] 旗幟資料 ＝ 底色＋紋章兩部分：一面旗用 { 底色, 紋章 } 描述，底色可以換；陣營旗（長旗、戰鬥旗、替換作品原本那面）都照這份畫，不再寫死英國艦隊旗　✅ kotoko 2026-10-25
- [x] 主選單開戰鈕左右兩側各一個旗幟下拉選單（我方、敵方）＋底色可換；先有三、四種紋章可選；看得到旗的預覽　✅ kotoko 2026-10-25
- [ ] 選了之後開戰，兩陣營的船掛的是選的那面旗；改選之後下一場照新的（不用重新整理）；選擇跟著設定存檔
- [ ] 外部可以指定（網址參數或 __game 的介面），之後 Blocksail 換國家旗、玩家自己的旗用得到
- [ ] 反向對照：兩邊都選預設（英國藍旗、英國紅旗）⇒ 旗面的像素跟改之前逐位元組相同；?colours=0 照舊不加旗

## 任務描述

Tim 2026-10-25：「接著希望讓Blockside支援替換船隻旗幟功能(之後在Blocksail也會用到 替換國家旗或是玩家自己的旗幟) 然後旗幟可以有底色+紋章兩部分(底色可換) 旗幟資訊就會是底色+紋章 然後 開戰鈕的左右側可以讓玩家選取兩陣營旗幟 把目前都用英國旗幟的部分替換掉(旗幟可以做下拉選單 先加三四種就好)」

現況（Blockside dev 825cca5）：`src/js/77_colours.js` 寫死英國艦隊旗 —— 藍方 Blue Ensign、紅方 Red Ensign（左上角聯合旗）、長旗靠旗桿那段聖喬治十字。每一型船載入時烘藍、紅兩份貼圖進帆的貼圖集（teamFlagsSetup），畫的時候照船的陣營挑（sailRect）。
做法：旗 ＝ { field 底色, emblem 紋章 }；紋章是程序畫的圖案（聯合旗角、勃艮第十字、新月、骷髏）；兩陣營各一份；改了就重烘已載入船型的旗面貼圖。
不在本單：Blocksail 端照國家、玩家挑旗（之後用本單的介面接）。
