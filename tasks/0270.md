# TASK-0270 — 央行保管費轉券政策設定與發券聯動 —— Senate BankAdminPage 央行政策參數設定轉化券種與比例，套用銀行券系統發放給帳戶下 Persona

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(pm)、gura(qa)、kaguya(dev)

## 驗收標準

- [ ] ① `bank_settings.json` 擴充錨定券種設定：包含 `voucher_type`（券種代號，如 gold/btc）、`ratio_per_token`（每 Token 兌換券數，如 20 或 1），支援缺省安全回退
- [ ] ② `Senate.Cli/Pages/BankAdminPage.cs` 央行政策參數面板新增「保管費轉化券種與比例」可視化與設定輸入，並具備二段確認（Pending 閘門）安全原子寫入
- [ ] ③ 跨日保管費結算整合：帳戶扣繳 Token 進入央行公庫時，呼叫券發券邏輯，將換算出的總券數平均發給該帳戶名下所有 Persona（依 `_registry_meta.json` 解析，人數為 $N$）
- [ ] ④ 發券結果在結算報告或酒館廣播中顯式標注（例：`🏦 Myth 扣繳保管費 141 Token → 提撥 2,820 Gold 券，均分給 gura, calli, kiara 各 940 張`）
- [ ] ⑤ 反向對照：當未設定轉化券種或比例為 0 時，僅扣繳保管費，不生成任何券，既有銀行金流行為逐字不變

## 任務描述

Tim 2026-09-22 拍板「央行保管費轉化實體資產」第一階段需求：
1. 實際運作全面套用銀行的券系統（Voucher System），儲備資產以券形態（例如 `gold`、`btc`）發給 Persona。
2. 後台設定放在 Senate 的 `BankAdminPage.cs` 央行政策參數，可以設定轉為哪種券以及比例（例如 1 Florin Token = 20 Gold 券、1 BTC Token = 1 BTC 券）。
3. 發放時平均分發給該帳戶名下的所有有效 Persona。

PM 規劃（gura）：
- 資料根設定：`Treasury/bank_settings.json`（與 `SCP_BankPolicy.cs`）。
- 後台 UI：`Senate.Cli/Pages/BankAdminPage.cs` 央行政策參數區塊。
- 服務整合：跨日保管費扣繳邏輯與券發放邏輯對齊。
