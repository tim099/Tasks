# TASK-0886 — 《Blocksail》倉庫系統：城鎮（不限量）、陸地倉庫（看桶）、船隊貨艙（看重量：壓艙物以內換掉壓艙物、超過吃水變深）同一套

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [x] 三種倉庫同一套：城鎮倉庫（市場）、陸地倉庫（一個家族在一座城）、船隊貨艙都用同一組讀寫（有多少、存、取、還放得下多少、搬過去）；生產、放不下賣進市場都改走這一套；文件寫清楚　✅ gura 2026-10-24
- [x] 城鎮倉庫不限量；反向對照：放再多都放得下　✅ gura 2026-10-24
- [x] 陸地倉庫只看桶：容量 ＝ 基礎＋那個家族在那座城的倉庫建築；搬過去只搬得進放得下的那一份，其他留在原處；反向對照：50 桶鐵礦石跟 50 桶菸草一樣滿（重量不管）　✅ gura 2026-10-24
- [x] 船隊貨艙看重量：貨重在壓艙物重量以內 ⇒ 換掉同樣重的壓艙物、吃水不變；超過 ⇒ 吃水變深，讀數印出多深；有寫貨艙幾桶就也看桶　✅ gura 2026-10-24
- [x] 船隊貨艙住在城鎮帳裡、跟著存檔走；存讀逐位元組相同　✅ gura 2026-10-24
- [x] 搬移守恆：任何搬移前後總桶數不變；反向對照：搬不進去的那一份還在原處　✅ gura 2026-10-24
- [x] 行為不變的重構：改寫前後同一份輸入，生產、家族倉庫、市場逐位元組相同；既有工具全過　✅ gura 2026-10-24

## 任務描述

## 要什麼（Tim 2026-10-24）

「可以先做倉庫系統 目前構想是所有倉儲都用同一套架構(包含城鎮 家族倉庫 船隊倉庫)
倉庫儲量分統跟重量(城鎮倉庫無限儲量 陸地倉庫只看桶(空間) 艦隊倉庫要考慮到重量(影響船隻吃水 再壓艙物重量範圍內會替換壓艙物 超過就會吃水變深))」

## 現況（Blocksail main 6d1f763）

- 城鎮的市場（world/market.js）與家族倉庫（world/prod.js 的 S.stores、storeCap）是兩套各寫各的；船隊還沒有貨艙。
- 一桶的重量已經在貨物表（goods.js 的 wt）；船的最大載重 ＝ 設計水線的壓艙物（TRADE_SIM.md §1.2、FAMILIES.md §5）。

## 順序

TASK-0884（生產鏈接上遊戲）等本單：家族倉庫優先、不夠向城鎮買 ⇒ 都是倉庫之間的搬移，先有同一套才接。
船的壓艙物、吃水面積、貨艙幾桶從哪艘船的資料來 ⇒ 接船的時候定；本單先讓貨艙吃這幾個數。
