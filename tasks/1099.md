# TASK-1099 — 《Blocksail／Blockside》脫離交戰後全員抽水（×4 照人數）、木匠用低強度補丁堵水線下的破口；補丁存進船況、下次戰鬥照樣脆

> `feature` / `normal` / `todo`　開單：ame　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 脫離交戰後（航海、城鎮模式，不是交戰）基礎抽水 ×4，再乘「站得住的人 ÷ 開局人數」；交戰中照舊
- [ ] 脫離交戰後木匠補水線下會漏的破口：水壓最大（漏得最兇）的先；要走得到洞邊、積水太深等抽水降下來再補；補一個口 4 秒＋每格 0.5 秒、1 份木材
- [ ] 補回去的格是「補丁」材質：補著不漏、硬度約橡木一成（下一發打到附近就碎、又開始漏）、顏色深褐（焦油帆布）
- [ ] 回地球儀時（不在交戰）還沒補完的漏口：木匠還在、木材夠 ⇒ 一次補成補丁；沒人、沒木材 ⇒ 照舊帶著洞
- [ ] 船況（CORE_API 戰前／戰後狀態）多存哪些格是補丁 ⇒ 下次進航海補丁照樣在、照樣脆；舊的船況（沒有這一欄）照舊讀
- [ ] 反向對照：沒有破口、或一直在交戰 ⇒ 戰局照舊；Blockside 單機海戰照舊
- [ ] 文件補上設計、史實出處與讀數
