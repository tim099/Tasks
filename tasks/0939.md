# TASK-0939 — 《Blocksail》城鎮建築的旋轉部件：風車的帆照風轉（標法同船的 spin meta）

> `feature` / `normal` / `in_progress`　開單：kotoko　參與：kotoko(dev)

## 驗收標準

- [ ] 君士坦丁堡的風車（`roman-mill`）在遊戲裡帆會轉：轉速照遊戲的風速（風越大轉越快），風速 0 就停
- [ ] 標法跟船同一套 meta（`spin`、`spin_mode`、`spin_k`、轉軸），寫進 `docs/BUILDING_SPEC.md`；沒標的建築不受影響（匯入後其他模型逐位元組相同）
- [ ] 近處畫會轉的那一件；中、遠、屋頂殼照舊畫靜態的帆。近處那一份裡，轉的那一件跟靜態的部分不重複、不缺
- [ ] 施工中的那一棟不畫轉的那一件（蓋好才裝），建造演出照舊
- [ ] 效能：同一個鏡頭，有轉、沒轉各量一次城鎮那一段的畫面耗時，差多少照實記
- [ ] 反向對照：風速設 0 ⇒ 帆停；拿掉 `spin` meta 重匯 ⇒ 跟現在一樣整塊靜態

## 任務描述

### 要什麼
Tim 2026-10-25：「另外風車可以轉動嗎(不能的話是否可以改架構 支援船上螺旋槳那種轉動方式)」⇒「先只做風車照風轉就好，開單做吧」。

### 現況
城鎮建築在匯入時整棟併成一份格子（Blocksail `tools/townmodels.py`），遊戲照實例整棟畫（Blockside `63_towns.js`）。會動的只有布旗：旗子另外有一份網格，照風算。
船的子物件靠 `26_spin.js` 照 meta 轉（造船規格 §9.8）。TASK-0927 的風車已經把風軸、輻、帆拆成獨立一件（`kotoko-grainsea-01m-mill-wind-vanes`）。

### 邊界
- 只做風車，來源參數只做風（`spin=wind`）。牛磨、水車之後再說。
- 只動畫面，不碰模擬、生產。
