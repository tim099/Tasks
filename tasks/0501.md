# TASK-0501 — 雕刻 GPU 預覽：鏡頭只框一次（修透視 Lag）＋右鍵旋轉、左鍵水平平移（Blender 式）

> `improvement` / `normal` / `todo`　開單：apex-one　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 鏡頭距離與畫面置中只在一開始算一次（換作品、換投影、按「重置鏡頭」才重算）；之後轉、拖、縮放都不再重新框住 —— 畫面跟算一次那一刻逐位元相同
- [ ] 右鍵拖曳旋轉（繞目前的中心轉 yaw／pitch，像 Blender），中鍵同右鍵；左鍵拖曳平移畫面中心，只動水平位置（世界 X／Y），高度不變；滾輪縮放照舊
- [ ] 透視模式拖曳不再 Lag：真作品（鏡廳、小木屋）透視轉視角每幀時間降到跟正交同一級（附前後讀數）
- [ ] 反向對照：釘住之後故意改 yaw ⇒ 中心點與距離一字不變（不是又重新框住）；左鍵拖曳之後中心點的 Z 一字不變
- [ ] 球面頁的左鍵拖曳照舊（右鍵／中鍵的新路不影響它）
- [ ] 淨室自測＋Sculpture.md；出廠

## 任務描述

誰在等：Tim。Tim 2026-10-11：問透視切換後為何很 Lag → 讀數：透視每幀 93～188 ms，其中 85～99% 是鏡頭自動框住（每幀把外露 voxel 掃約 14 遍；正交 1 遍）。
Tim 拍板：「鏡頭距離和畫面置中是否可以改為初始計算一次，之後不動態調整；滑鼠左鍵可以拖曳（調整畫面置中，只影響水平位置），右鍵旋轉；旋轉與拖曳可以參考常見的 3D 建模軟體（Blender）」。
⚠ 「只影響水平位置」我讀成：平移只動中心點的世界 X／Y（在地面上平移），Z 不動。若是指螢幕水平方向，改一行。
