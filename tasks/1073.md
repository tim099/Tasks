# TASK-1073 — 《Blocksail》規劃貨進貨物表（加勒比現有的城就長得出來的九種）：薑、多香果、香蕉、椰子、桃花心木、海龜、燻肉、木薯餅、焦油

> `feature` / `normal` / `todo`　開單：Sirius　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 這九種都在 `goods.js`（有名稱、類別、重量、價），RESOURCES §3 那幾列的「現況」改成 ✔；各種貨的檢查工具（resources_check、prod_ids_check、processed_goods_check）照跑、讀數列在單上
- [ ] 每一種都有配方跟建築（新的或掛在現有的建築上），生產建築能進建築選單或自動建築
- [ ] 每一種都有人要：鎮民吃、日用、船上供餐、當原料或出口，至少一條；寫明是哪一條
- [ ] 起始檔＋發船一年（`node tools/sim_lab.cjs --days 365 --fleets 1`），第 60 天之後加勒比至少一座城的產量 > 0（九種逐一列）
- [ ] 焦油：寫明松從哪裡來（古巴松補 `mast` 標籤，或焦油窯照物種直接認），跟史料一起寫在單上
- [ ] 反向對照：同一份起始檔，九種以外的貨在加勒比的產量照實列出改前、改後，有掉的要寫原因

## 要什麼

Tim 2026-10-28：「分析一下目前已經有圖片的資源還有哪些無法生產 並在加勒比海找一些合適的城市進行建造(補上這些資源缺口)」⇒ Sirius 分析（TASK-0957 留言 #1）⇒ Tim 選「1+2」：1 ＝ 把現有城已經長得出來的規劃貨登錄進 `goods.js`、接上配方；2 ＝ 坎佩切（另一張）。

## 哪幾種

RESOURCES §3 標「規劃」（圖都畫好了、還沒進 `goods.js`）、而且原料現有的加勒比城就有的（`tools/areas_cover.cjs --at` 各城中心，Blocksail main 9e393de）：

| key | 名稱 | 原料在哪 |
|---|---|---|
| `ginger` | 薑 | 物種 ginger：金斯敦、聖地牙哥、亞拉斯 |
| `pimento` | 多香果 | 物種 pimento：金斯敦、聖地牙哥、聖多明哥、亞拉斯 |
| `banana` | 香蕉 | 物種 banana：金斯敦、聖地牙哥、亞拉斯 |
| `coconut` | 椰子 | 物種 coconut_palm（離岸 2 km 內）：量過的六座城中心都有 |
| `mahogany` | 桃花心木 | 物種 mahogany：量過的六座城中心都有 |
| `turtle` | 海龜 | 海洋物種 green_turtle 等（離岸 3 km）—— 還沒逐城量 |
| `smoked-meat` | 燻肉 | 加工：肉＋木柴（boucan） |
| `cassava-bread` | 木薯餅 | 加工：木薯（目前配方 `casabe` 直接產 `bread`，TASK-0917）—— 拆不拆照 RESOURCES 那一列 |
| `tar` | 焦油 | 松：埃爾科夫雷、hierro 城區有古巴松（cuban_pine），但 species.js 沒給它 `mast` 標籤 |

## 邊界

- 蘇木 `logwood` 在坎佩切那一張做（跟城一起驗）。
- 物種表沒有的（稻米、豆子、柑橘）、要進口的（錫、鉛、煤）、加工鏈要那些料的（青銅、鉛彈……）不在這張。
- 每種貨的價、熱量、食物等級是佔位就照佔位寫，跟現有的一樣用 `tools/price_cost.cjs`、`prod_sim` 量過再定。
