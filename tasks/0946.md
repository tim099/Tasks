- [x] 盤點：城鎮規劃會出現的每一種公共、港口、軍事用途（TOWN_CORE 與地標的 as）都歸到一類 —— 公職／服務建築／港口勞力／士兵（已有，BSW.GARRISON）／不設崗位（寫原因：紀念柱、廣場、蓄水池…）；對帳工具列出沒歸類的 ⇒ 0 筆　✅ gura 2026-10-25
- [x] 公職：市政廳、總督府、長官的屋子、宮殿、港務所、過磅所、市場、魚市、監獄有公職崗位（同海關：人數照城的規模、主人的金庫付工資、付不起就少雇不欠薪）；讀數列出開場各城每一種雇幾人、一天付多少　✅ gura 2026-10-25
- [x] 服務建築：酒館、醫院、修道院套 0914 的服務建築框架；修道院照教堂算信仰、容量比教堂小　✅ gura 2026-10-25
- [x] 酒館的菜單：喝的（只要人手的基礎款、吃蘭姆酒或葡萄酒的）與吃的（供一天的飯）各給不同的滿意度、吃不同的物資；一人次的價錢 ＝（物資照當地市價 ＋ 人手的工資）÷ 招待量 × 1.5（教堂、醫院同一條式子）；讀數：同一座城每一道一天招待幾人次、收多少、吃多少　✅ gura 2026-10-25
- [x] 動態菜單：一座一天只跑一道；持有者（城鎮、每個家族）每天把自己名下的服務建築照需求（各本還有多少人想來）與物資（缺料 ⇒ 換做得出來的那一道）分配；讀數：皇家港 21 間酒館一天各跑哪一道、市場沒有蘭姆酒時換成什麼　✅ gura 2026-10-25
- [x] 港口勞力：踏輪吊車、起重架、修船灘、修船碼頭、船棚有碼頭工的崗位；讀數列出各城幾人　✅ gura 2026-10-25
- [x] 地標照它的 as 拿同一套崗位（宮殿、修道院、碉堡的地標；聖索菲亞照舊是教堂）；廢墟的地標（沒有屋頂的殘殼、只剩台地）不設崗位、寫原因　✅ gura 2026-10-25
- [x] 房租：城鎮持有的住宅向住在裡面的鎮民收房租（鎮民金庫 ⇒ 城鎮金庫）；那一天鎮民的錢不夠吃飯就不收；讀數：同一份開場跑一年，房租開 vs 關的城鎮金庫、鎮民存款、沒收房租的天數　✅ gura 2026-10-25
- [x] 不透支：同一份開場跑一年，加了新崗位＋房租之後每座城的城鎮金庫不會一路掉到付不起（讀數列出加之前、只加崗位、崗位＋房租三組的年底金庫）　✅ gura 2026-10-25
- [x] 反向對照：拆掉一座公職／服務建築 ⇒ 那一份崗位 0、工資不再出去；沒有城鎮持有的住宅 ⇒ 房租 0　✅ gura 2026-10-25
- [x] 錢守恆與重現：跑 365 天每天對帳 0 筆、全世界的錢總數不變；開場檔重算後同一份輸入跑兩次逐位元組相同；既有的檢查工具照樣全過（main 上原本就沒過的照舊）　✅ gura 2026-10-25
- [x] 城鎮介面看得到：崗位表列出新的公職、服務、碼頭工；概況有房租收入（昨天收了多少、沒收的原因）　✅ gura 2026-10-25
