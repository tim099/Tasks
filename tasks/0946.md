# TASK-0946 — 《Blocksail》公共建築的崗位：市政廳、總督府、宮殿、港務所、監獄等公職，酒館、醫院、修道院套服務建築，港口碼頭工；城鎮持有的住宅收房租（鎮民吃不起飯不收）

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [ ] 盤點：城鎮規劃會出現的每一種公共、港口、軍事用途（TOWN_CORE 與地標的 as）都歸到一類 —— 公職／服務建築／港口勞力／士兵（已有，BSW.GARRISON）／不設崗位（寫原因：紀念柱、廣場、蓄水池…）；對帳工具列出沒歸類的 ⇒ 0 筆
- [ ] 公職：市政廳、總督府、長官的屋子、宮殿、港務所、過磅所、市場、魚市、監獄有公職崗位（同海關：人數照城的規模、主人的金庫付工資、付不起就少雇不欠薪）；讀數列出開場各城每一種雇幾人、一天付多少
- [ ] 服務建築：酒館、醫院、修道院套 0914 的服務建築框架（菜單：基礎款只要人手、另一款多吃物資；招待量、滿意度、付錢或捐獻）；修道院照教堂算信仰、容量比教堂小；讀數：同一座城基礎款 vs 高級款的滿意度與吃掉的物資
- [ ] 港口勞力：踏輪吊車、起重架、修船灘、修船碼頭、船棚有碼頭工的崗位；讀數列出各城幾人
- [ ] 地標照它的 as 拿同一套崗位（宮殿、修道院、碉堡的地標；聖索菲亞照舊是教堂）；廢墟的地標（沒有屋頂的殘殼、只剩台地）不設崗位、寫原因
- [ ] 房租：城鎮持有的住宅向住在裡面的鎮民收房租（鎮民金庫 ⇒ 城鎮金庫）；那一天鎮民的錢不夠吃飯就不收；讀數：同一份開場跑一年，房租開 vs 關的城鎮金庫、鎮民存款、沒收房租的天數
- [ ] 不透支：同一份開場跑一年，加了新崗位＋房租之後每座城的城鎮金庫不會一路掉到付不起（讀數列出加之前、只加崗位、崗位＋房租三組的年底金庫）
- [ ] 反向對照：拆掉一座公職／服務建築 ⇒ 那一份崗位 0、工資不再出去；沒有城鎮持有的住宅 ⇒ 房租 0
- [ ] 錢守恆與重現：跑 365 天每天對帳 0 筆、全世界的錢總數不變；開場檔重算後同一份輸入跑兩次逐位元組相同；既有的檢查工具照樣全過（main 上原本就沒過的照舊）
- [ ] 城鎮介面看得到：崗位表列出新的公職、服務、碼頭工；概況有房租收入（昨天收了多少、沒收的原因）
- [ ] 文件（PRODUCTION、TOWN_SIM、TOWN_UI、FAMILIES）寫上規則與讀數；數字標佔位

- 分類照驗收第 1 格。提案：
  - 公職（同海關，城鎮付工資、人數照規模）：市政廳、總督府、長官的屋子、宮殿、港務所、過磅所、市場（市場管理）、魚市、監獄（獄卒）
  - 服務建築（0914 框架）：酒館（基礎款＋酒款吃蘭姆／葡萄酒）、醫院、修道院（照教堂、容量小）
  - 港口勞力：吊車、起重架、修船灘、修船碼頭、船棚
  - 不設崗位：紀念柱、廣場、蓄水池（池底菜園已經是生產）、大競技場（1453 已是廢墟）、廢墟的宮殿台地
  - 待定：海龜圍欄（照生產做要新貨「海龜」）、商人廊廳、港邊倉庫列（倉儲？還是商人的公職？）
