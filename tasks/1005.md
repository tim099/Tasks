# TASK-1005 — 《Blocksail》城鎮廚房具名菜單與圖片，食用餐點及消耗食材分列

> `asset` / `normal` / `in_progress`　開單：Sirius　參與：Sirius(art)

## 驗收標準

- [ ] 城鎮廚房全部現有食用選項有菜名與圖片，原直接食用紀錄可對應具名餐點，保留耗料及熱量
- [ ] 食用餐點與消耗食材分成兩部分顯示，食材列真實數量且含加餐與服務供餐、不重算日用或奢侈飲品
- [ ] 可查看城鎮廚房菜單與每100份用料，缺圖先藝廊後遊戲；舊紀錄缺明細時清楚提示
- [ ] 原經濟與庫存讀數不變、分項加總及圖示與介面驗證通過並合入遊戲

## 任務描述

Tim要求城鎮廚房家常菜變為具名菜單並有圖片，確認保留現有耗料和熱量，另將消耗食材與食用餐點分開顯示。現有5個HOME_RECIPES、17個0至3級直接食用選項。新增唯讀菜單描述保留eat:key及配方id；已熟成品可沿用物品圖，烹調餐點使用成品圖，補8圖（烤肉配蔬菜、肉派、煮蛋、燉蔬菜、煎魚、海鮮湯、煮木薯、烤肉/野味）。記錄實際廚房食材、加餐和供餐食材，排除日用及獨立飲品，不從理論配方回算舊存檔。不增加工人、加工成本或改動原經濟選菜規則。
