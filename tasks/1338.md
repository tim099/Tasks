# TASK-1338 — 《Blocksail》北非六種植物的樹形照現有植物重調：檉柳、阿甘樹、傘刺槐看得出是什麼樹

> `improvement` / `normal` / `in_progress`　開單：Abigail　參與：Abigail(dev)

## 驗收標準

北非六種植物（椰棗、阿甘樹、傘刺槐、檉柳、夾竹桃、細莖針茅）的樹形照現有植物（橄欖、闊葉樹、松、海葡萄、海燕麥…）的做法與水準重調，讓每一種近看、中景都認得出是那種植物。Tim 2026-11-21「是否可以先處理植物的外觀(參考目前的各種植物)」。

- [x] 檉柳看起來是羽毛似的細枝叢，不是一叢大葉片；花是枝尖一點淡粉紅　✅ Abigail 2026-11-21
- [x] 阿甘樹跟闊葉樹分得出來：矮、從低處分成幾根扭的幹、寬而密的灰綠圓頂　✅ Abigail 2026-11-21
- [x] 傘刺槐的樹冠是一整片薄的平頂傘，枝接到傘上（不是幾片浮著的厚板）　✅ Abigail 2026-11-21
- [x] 夾竹桃、細莖針茅、椰棗近看、中景都看過，該調的調　✅ Abigail 2026-11-21
- [x] 葉都接在枝上（近看樹冠，細模、低模都看）　✅ Abigail 2026-11-21
- [x] 其他 36 種植物的網格逐位元組不變（反向對照）；新六種的三角形數跟現有同類植物同一個量級　✅ Abigail 2026-11-21
