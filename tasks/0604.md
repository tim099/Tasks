# TASK-0604 — 《憲法號對轟》抽水：每型船的基礎抽水量（後台可調）＋可擺放的抽水泵（功能物件）

## 驗收標準

- [x] 抽水泵是功能物件（跟病床同一套 TASK-0568 的房間與物品）：配置頁的格子編輯器擺得進艙房、「自動擺滿」會擺；每台加多少抽水量、同一種加總有上限（buffCap），讀數看得到全船現在的抽水量　✅ ame 2026-10-21

- [x] 遊戲裡量得到：同一個破洞、同一個種子，基礎抽水量不同的兩艘（或加一台泵前後）積水曲線不一樣，數字寫在單上　✅ ame 2026-10-16
- [x] 反向對照：沒擺泵、基礎抽水量照預設 ⇒ ?demo 的 dump 跟改之前逐字相同　✅ ame 2026-10-16

## 任務描述

Tim 2026-10-15：「想確認一下目前的進水機制，是否每艘船的排水能力都一樣；之後會想加可以放置的抽水泵裝置（跟目前的病床一樣是功能物件），可以加強抽水能力，且不同船型的基礎抽水能力應該不同（後台可以調）」。

**現況（ame 查的，Blockside 9f269cd 之後）**：每艘船抽水一樣快。
- 粒子模式（33_flood.js）：每艘每秒從最低的水抽掉 FL_PUMP = 0.3 m³（≈ 每分鐘 18 噸）。
- 公式模式（32_hull.js）：每艘每秒少沉 0.004 m。
- 船隻設定的「進水速度」（cfg.flood）每型一格，但把進水與抽水一起縮放（⛔ 只縮進水 ⇒ 調慢之後抽水永遠贏、永遠不沉）⇒ 改得了快慢、改不了抽不抽得贏。
⇒ 小船（夜隼號）相對很能撐、大船（三叉戟號）相對吃虧。

**想法**：
1. cfg 加一格基礎抽水量（噸／分），預設照船的大小；跟進水速度分開。
2. 抽水泵＝功能物件（病床那一套：家具目錄 type、hold、buff；房間整合 buff、同種加總上限），配置頁擺、自動擺滿也擺。
3. 史實：鏈式抽水泵要 4–8 人搖 ⇒ 要不要派人操作等 Tim 決定；要的話跟 TASK-0568「崗位物件」（砲與家具共用的有位子、要人操作的物件）一起設計。
4. 泵被打壞、被水淹 ⇒ 停。

相關：TASK-0568（功能艙）、TASK-0569（家具模型；泵的模型也可能要雕）、TASK-0570（船隻配置頁）。
