# TASK-0891 — 《Blocksail》自動建築 v1：城鎮、家族照一區一份的市場需求自己蓋生產建築（城鎮自帶營造）＋向家族收所得稅與資產稅 —— 錢守恆

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [x] 一區一份需求表：城鎮照港口所在的海洋分區分區（地理分區；不在任何海區 ⇒ 同一個範圍檔的城一區）；到了蓋建築那一天算一次、存在城鎮帳 `regions`（每種貨理論消耗、產能、缺口、價格；糧食另算一份：人口份數 vs 產能熱量），區裡的城鎮、家族讀同一份　✅ gura 2026-10-24
- [x] 城鎮自己蓋：不缺工、有失業的大人、城鎮金庫付得起造價＋週轉 ⇒ 挑區裡缺口最值錢、這座城蓋得了的（地塊條件照城裡現有建築的 site；人手 ≤ 失業的大人）；一座城 30 天最多一座〔佔位〕、城鎮先家族後；由城鎮自帶的營造蓋（工期較長，蓋好前不開工）、造價進城鎮金庫　✅ gura 2026-10-24
- [x] 家族自己蓋：在母港、家族金庫付得起造價＋週轉 ⇒ 挑最賺的（區的價格 × 補得到的缺口 − 工資 − 原料 > 0）；玩家家族不自動蓋；造價付給城鎮金庫（自帶營造歸城鎮）　✅ gura 2026-10-24
- [x] 稅：所得稅（家族陸地倉庫賣給城鎮先扣一成〔佔位〕，跟船隊關稅分開記）、資產稅（每 30 天照家族名下建築的評價收 1%〔佔位〕，進那座城的城鎮金庫）；付不起 ⇒ 付得起多少付多少、其他記欠稅、下次先還　✅ gura 2026-10-24
- [x] 守恆與可重現：錢每天守恆（造價、稅都是金庫之間搬）、跑兩次逐位元組相同、存讀之後繼續跑相同　✅ gura 2026-10-24
- [x] 量具 `tools/auto_check.cjs`：反向對照（缺工不蓋、沒錢不蓋、區裡不缺的不蓋、玩家家族不蓋、稅率 0 ⇒ 城鎮金庫照舊見底）＋起始檔兩年讀數（每座城蓋了什麼、誰蓋的、飢荒、失業、金庫曲線）；既有工具全過　✅ gura 2026-10-24
- [ ] 自動蓋的建築擺上地圖：那座城的規劃生成或重放時擺到空的沿路建地（一筆 `src: 'auto'` 的操作），帳上補 `lot`
- [x] 文件：PRODUCTION §12.8 改成 v1 做了什麼、哪些是佔位；施工的 voxel 階段演出（25／50／75%）記成之後的細節　✅ gura 2026-10-24

## 任務描述

規格：Blocksail docs/PRODUCTION.md §12.8（Tim 2026-10-24：城鎮有錢又不缺工會自己蓋生產建築、照市場需求；需求一整區一份（含附近的城）；家族也會蓋；城鎮向家族收所得稅與資產稅；分區先照地理；造價之後由營造建築收（城鎮自帶一個容量無限、效率較差的）；之後接建材；造價、稅率、節奏實際跑過再調）。

接在 TASK-0890 移民、最低供應後面：大城的糧是產量不夠、不是錢不夠；城鎮金庫被最低供應掏空、錢沉在家族 ⇒ 多蓋生產建築把失業的大人變成崗位、稅把家族的錢收回城鎮。

第 3～6 題照推薦（Tim 2026-10-24「好 開單做 go」）：帳先決定、規劃之後擺；一座城 30 天一座、城鎮先家族後；所得稅一成、資產稅每 30 天收評價的 1%；玩家的城、玩家家族不自動蓋（玩家家族照樣繳稅）。

可以先不做的細節（Tim 同一天）：施工過程用 voxel 演出逐步成形（25%、50%、75% 的階段，預先算好）。
