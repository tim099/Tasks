# TASK-1009 — 《Blocksail》牲口飼料改成資源類別（豬吃多種食物、牛吃穀物、雞吃組合）＋基礎物價改成成本 × 1.2

> `feature` / `normal` / `in_progress`　開單：trailhead　參與：trailhead(dev)

## 驗收標準

- [x] 飼料改成資源類別（goods.js GOOD_CLASSES；換算比照熱量）：穀物（玉米、大麥、小麥）、豬飼料（穀物＋木薯、蔬菜、野果）、雞飼料（穀物＋蔬菜、野果）　✅ trailhead 2026-10-27
- [x] 養豬吃豬飼料、養牛吃穀物、養雞吃雞飼料：三種建築各一條配方（-barley 那三條合併掉，RECIPE_RENAME 讓舊存檔讀得回來）　✅ trailhead 2026-10-27
- [x] 基礎物價改成成本 × 1.2（MARKET.margin、tools/price_cost.cjs 重算整張價目表；幣照舊 ＝ 面額）　✅ trailhead 2026-10-27
- [x] 城鎮規劃重烘（指紋變了的那幾座）、開場檔只套規劃的差　✅ trailhead 2026-10-27
- [ ] 起始檔一年／兩年：飢荒、對帳、牲口產量、錢的分佈跟改之前並排對照寫進單；量只有某一種飼料時當天就吃那一種（反向對照：沒有任何一種 ⇒ 停工）
- [ ] 檢查工具全過（跟 main 原本就紅的那幾條比）
- [x] 文件：PRODUCTION（飼料、物價）、PROCESSED_GOODS／BUILDING_SPEC 牲口那幾列　✅ trailhead 2026-10-27

## 任務描述

## 要什麼

Tim 2026-10-27：「先調整一下 讓養豬 可以用糧食如何(多種食物組) 然後養牛可以用穀物(大麥 小麥 玉米等) 養雞也可以改用組合(參考醋)」「然後我在想基礎物價改為成本的120%如何」

## 現在

- world/recipes.js：養雞、養豬、養牛各兩條（玉米／大麥），換配方靠 recipeDay 重挑。
- 基礎價 ＝ 成本 × 1.5（MARKET.margin、tools/price_cost.cjs；PRODUCTION §12.9）。money_report 量到城鎮自己經營的建築照 1.5 倍賣給鎮民 ⇒ 錢往城鎮金庫集中（TASK-1007）。

## 改成

- 飼料照醋料的寫法做成類別（一份類別 ＝ 幾桶那一種，照熱量換算），配方吃類別 ⇒ 市場上哪一種便宜、有貨就吃哪一種。
- 基礎價 ＝ 成本 × 1.2。
