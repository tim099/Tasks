# TASK-0824 — 《Blockside》小艇改走平滑再減面：同色大方塊抽成方框＋surface nets＋QEM＋投影貼圖（去掉飄著的碎塊）

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 小艇不再有脫離主體、飄在空中的碎塊（船頭、船尾、船底近看）
- [ ] 同色、體積大的長方體抽成方框（不進平滑）；抽了哪些、門檻寫明
- [ ] 其餘照金屬那套平滑面再減面（QEM）；顏色烤成貼圖、跟原本的體素色對得上
- [ ] 三角形數、第一次載入的計算時間：兩種小艇改前（方塊、外殼式）／改後
- [ ] 反向對照：只改畫面 —— 戰局、匯入檢查跟改之前相同；沒有標的模型照原本的網格
- [ ] 截圖給 Tim（近看、船頭船尾、遠看）

## 任務描述

Tim 2026-10-22（TASK-0820 小艇外殼式 QA）：「小艇生成部分 是否可以移除一些脫離主體 飄在空中的碎塊」（附圖：船底尖端下面掛著幾塊）「然後我在想 是否可以先套用金屬材質的平滑算法先跑一遍 再轉成模型」→ 選「改走平滑再減面」；「另外是否可以把一些同色立方體部分 直接獨立出來 同色且體積大的立方體」。

碎塊的原因（TASK-0820 render=shell）：船頭、船尾截面變尖，射線量的殼帶沒包進殼角落的格子 ⇒ 被歸成「殼以外」照方塊畫，離平滑殼一段距離懸著（殼以外的小連通塊，憲法號 42 塊、餘燼號 42 塊）。
金屬那套平滑面（15_smooth.js surface nets）直接套：一個露出來的格面一個四邊形 ⇒ 捕鯨艇 51,624、餘燼號小艇 74,812 個三角形（比原本多 6～7 倍）⇒ 要接一道減面。

做法（通用，照 meta 選算法再加一種 / 或取代 shell）：
1. 同色、體積大的長方體（座板、收著的槳、地板）抽出來，一塊一個方框（12 個三角形），不進平滑。
2. 剩下的格子照 surface nets 出平滑面；貼著方框的那一面不出、頂點釘在格角上（跟方框接得起來）。
3. QEM（Garland–Heckbert）減面到兩千上下（焊好的平滑面減得動；不能翻面、非流形的點不動）。
4. 顏色：減完面照每個三角形朝哪個軸分片投影、攤成貼圖，貼圖每一格回原本的體素查色 ⇒ 顏色精度跟減掉多少面無關。
