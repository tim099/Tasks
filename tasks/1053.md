## 驗收標準

門檻是佔位，Tim 可以改。

- [ ] 原因寫在單上：自動建築為什麼沒跟著多蓋漁場、雞舍（附讀數）

## 任務描述

Tim 2026-10-28：「幫我把蘭姆酒鏈、加勒比硬餅乾、魚雞跟不上、小城失血這幾條開成任務單」

**誰在等**：Tim。

**讀數**（起始檔＋發船跑兩年，單一種子；同蘭姆酒那張的探針與定義）：

| | 第一年 | 第二年 | 最後半年 |
|---|---|---|---|
| 魚 供應率 | 100% | 88% | 79% |
| 魚 缺貨城·天 | 66% | 83% | 89% |
| 魚 價格 ÷ 基準 | 2.34 | 2.55 | |
| 魚 產量 | 16,359 | 16,520 | |
| 雞 供應率 | 72% | 28% | 21% |
| 雞 缺貨城·天 | 33% | 75% | 77% |
| 雞 價格 ÷ 基準 | 2.35 | 2.92 | |
| 雞 產量 | 976 | 1,989 | |

- 魚的產量兩年幾乎沒動，人口一直長（君士坦丁堡 4,987 ⇒ 5,610、聖多明哥 ≈ 4,800、小城也都在長）⇒ 供應率一路往下。每座城都缺（托爾圖加、亞拉斯、和平港 97～100% 城·天）。
- 雞的產量翻倍，需求長得更快；雞全部當原料用（菜）。
- 還不知道為什麼自動建築沒跟著多蓋（漁場、雞舍是不是被位置、資源、錢擋住）—— 先量。
- 同一類的採集品（野果、野味、海產）本來就有上限，⛔ 不在本單射程。
