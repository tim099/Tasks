# TASK-0751 — Blockside：被打飛的演出照 meta 選（預設照舊）——橫桁改成被打斷、照重力掉下去

> `feature` / `normal` / `in_progress`　開單：basecamp　參與：basecamp(dev)

## 驗收標準

Tim 2026-10-20：「是否可以讓橫桁被打掉時更符合物理(目前有點太誇張) 其他物件維持原本演出效果(例如炮被打飛)」「或是物件可以標meta設定該如何演出被打飛(預設就是目前的) 然後標記一下橫桁的演出meta」

- [x] 被打飛的演出可以照 meta 選：規格表（config/meta_kinds.json）每個 kind 一格、單件模型的 meta 可以蓋過；都沒寫 ⇒ 跟現在一模一樣　✅ basecamp 2026-10-20
- [x] 橫桁標成「被打斷、照重力掉下去」：不往上噴、只帶一點砲彈的推力、慢慢翻；掉到船上的就停在船上跟著船走、掉到海裡照舊漂　✅ basecamp 2026-10-20
- [x] 砲、舵輪等其他物件照舊被打飛（截圖或讀數對照）　✅ basecamp 2026-10-20
- [x] 反向對照：有橫桁被打掉的局 dump 跟改之前逐字相同（演出只給人看）　✅ basecamp 2026-10-20
- [x] 造船規格寫這個 meta 怎麼標　✅ basecamp 2026-10-20

Tim 2026-10-21：「掉落的桅杆在船上會穿模 且卡住一直不消失(可以想辦法讓他過一陣子消失或是滑落水嗎(可以滑一點避免卡在船上 這樣穿模就還好)」

- [x] 停在船上的帆桁不一直卡著：停一陣子之後往舷外滑、出了船舷照重力落水，落水照舊漂一陣子再拿掉；卡在滑不出去的地方就過一段時間拿掉（讀數：停、滑出、拿掉的時間）　✅ basecamp 2026-10-21
- [x] 反向對照：有帆桁被打掉的局 dump 跟改之前逐字相同（仍然只是演出）　✅ basecamp 2026-10-21
