# TASK-1110 — 《Blocksail》城鎮特產加成：照氣候、土壤、礦產自動給（每座城最多 3 種）＋手動的歷史特產額外 Buff；哈瓦那、聖多明哥照現實補河谷沖積土

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 自動特產：每座城照範圍裡的氣候、土壤（作物長得了的土地佔幾成、跟全世界比）、礦產（儲量等級）給加成，每座城最多 3 種；數字集中在一張表、可以調
- [ ] 歷史特產：手動表（城 → 貨 → 額外加成），疊在自動加成上；一種貨的總加成落在 1.1～1.5
- [ ] 加成乘在產出有這種貨的生產建築：原料、產出一起乘、人手不變 ⇒ 產量、消耗一起增加
- [ ] 哈瓦那、聖多明哥照現實補河谷沖積土（nature_extract.py PLAINS、只重抽那兩檔、其他檔逐位元組不變）⇒ 哈瓦那種得了菸草、聖多明哥種得了薑；開場檔 land 跟著更新
- [ ] A/B 讀數（4 年、有船隊）：特產關／只有自動／自動＋歷史 ⇒ 船隊買走與運來的量、特產貨的產量、價格、短缺的變化
- [ ] 反向對照：特產開關關掉 ⇒ 跟 main 逐位元組相同

## 任務描述

Tim 2026-10-30：
- 「補充一個Blocksail機制 目前想讓每個城鎮可以根據現實(歷史) 設定1~3種特產物資 會額外增加產能(相當於一個農田 工坊 可以相當於1.1~1.5棟的產出(消耗也增加)) 具體數值可以調整 測試 可以看看增加後是否會帶動貿易 & 有哪些變化」
- 「也不一定要寫死 可以讓部分城市按照歷史 其他可以根據氣候 土壤等自動判斷看看」
- 「應該說可以讓 氣候、土壤、礦產等自動根據數據給予特產加成 然後手動設定的歷史加成是額外的Buff」
- 「哈瓦那種不了菸草、聖多明哥也沒薑 是否可以調整物種表」⇒「那如果讓兩座城按照現實 有部分土地不是石灰岩呢 手動局部修改土壤」

## 兩層加成
1. 自動（每座城都有）：照範圍層的數據 —— 作物照「這種作物長得了的土地佔這座城陸地幾成，跟全世界平均比」（比較優勢），礦照資源分布區的儲量等級。
2. 歷史（手動表）：照史實寫的城 → 特產貨 → 額外加成，疊在自動那一層上面。

加成乘在「產出裡有這種貨」的生產建築上：原料、產出一起乘、人手不變（同工坊效率 TASK-1064 的乘法）⇒ 產量、消耗一起增加。

## 土壤
量到（每 250 m 一點，同 tools/land_start.cjs）：哈瓦那 100% 石灰岩、聖多明哥 100% 石灰岩 ⇒ 菸草（沖積土／沙土／黏土）、薑（沖積土／火山土／黏土）都長不了。
⇒ 照現實補河谷的沖積土：tools/nature_extract.py 的 PLAINS（已知的大河平原）加阿門達雷斯河谷（哈瓦那）、奧薩馬—伊莎貝拉、海納河谷（聖多明哥），只重抽那兩檔；物種表不動。
