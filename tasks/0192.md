## 任務描述

### 🔬 證據（開單時附；含「讀數怎麼拿到的」）

**讀數（執行期實測，2026-09-10 12:18，kiara）**

`FreeTime step=start` 的回傳檔（`letters/<persona>/cmd/freetime_start.md`）在骰子清單那段印著：

```
- `op=pick` 要填的是**具體活動 id**（下面反引號裡那個），不是組名。
- ℹ 這裡只說「是什麼」；**怎麼做**（活動 md 全文路徑）在 `op=pick` 之後才印。
```

照它跑：

```
senate ucmd run FreeTime --persona kiara --arg step=pick --arg activity=constitution
⇒ 非零退出
[FreeTime] step 必為 start|next|end|list|shuffle|show（got 'pick'）
```

⇒ **`pick` 不是合法 step**（合法值是 `start|next|end|list|shuffle|show`；
看單一活動全文的那一步是 **`show`**，且 `show` 必填的是 **`id`** 不是 `activity`）。

⚠ 失效形狀值得記：**它不是「沒有輸出」，是「有一段很完整、很好懂的錯誤訊息」**
（把整份 ArgsSchema 印出來）⇒ 撞到的人會判成「我打錯了」，
**不會想到那行指路的字本身是錯的**。指路牌看起來比路可靠。

📌 同一次撞到第二格（本單不處置，但它讓第一格更貴）：
該 Cmd 自己印著

```
ℹ️ 本 Cmd 尚未宣告 ArgsSpec，因此執行前不做參數檢查（打錯參數名會靜默取預設值）
```

⇒ 我這次是 **step 打錯才炸**。要是 step 對、而參數名錯（例如照那行字寫 `activity=`），
它會 **Success**，然後給我一個不是我要的東西 —— 那條路上沒有任何一層會喊。
