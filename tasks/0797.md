# TASK-0797 — 模擬步長①：每一小步的位移上限 —— 帆布、碎木、掉落物、船對船碰撞、擱淺、進水粒子（不管步長多長都不穿透）

> `subtask` / `normal` / `in_progress`　開單：erina　參與：erina(dev)

## 驗收標準

- [ ] 共用的「每一小步最多走多遠」：帆布、碎木、掉落物、船對船碰撞、擱淺、進水粒子都走它（每個系統的上限寫在一處、註明為什麼是這個數）
- [ ] 60 Hz 時交戰對拍（`?demo` dump、擬真沙盒 60 Hz）逐位元相同 —— 上限在 1/60 秒一步時不切
- [ ] 反向對照：步長 0.1 s、關掉上限 ⇒ 量得到東西穿過一格甲板（或帆布炸開）；開著 ⇒ 0
- [ ] 讀數：步長 0.1 s 時各系統平均切幾小步、每模擬秒多花幾 ms

## 任務描述

TASK-0796 第 3 節。Tim 2026-10-21：「步長風險可以限制上限(無視模擬步時長 限制每步上限位移)」。

不管一步多長，會移動、會撞東西的系統每一小步最多走固定距離 ⇒ 快的自己切小步（砲彈 21_gunnery.js stepBall 的「5 cm 一小步」就是這個；切步的花費跟走了多遠成正比、跟步長無關）。做成共用的一支（每系統一個上限），套到：
- 帆布（30_rig_physics.js）：Verlet，`RIG_FAR_HC = 0.1 s` 是上限，但 `evk = every × max(1, …)` 只會放大 ⇒ DT 0.1、兩步一次就是 0.2 s。照時間上限／位移上限切小步。
- 碎木（22_pieces.js stepPiece：繞斷口倒的角度 |ω|·dt、自由落體）、掉落物（21_gunnery.js stepFly：落到甲板只看終點）。
- 船對船碰撞（31_sailing.js collide／collideFine）、擱淺（32_ground.js）。
- 進水粒子（33_flood.js）：航行不管進水（Tim），但上限照樣套上去（之後交戰也要粗步長）；進水換演算法另見研究單。
