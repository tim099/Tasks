# TASK-1199 — 《Blocksail》沼澤鹽、鹽岩：特殊地形（資源分布區）＋鹽田變體（參考金礦坑、銀礦坑）

> `feature` / `normal` / `in_progress`　開單：ridge-two　參與：ridge-two(dev)

## 驗收標準

- [ ] 範圍層多兩種資源分布區：沼澤鹽、鹽岩（`BSW.RESOURCES` 有 key、地球儀「畫範圍」選得到、`tools/areas_check.cjs` 照檔案跑過）
- [ ] 鹽田變體：沼澤鹽田（`need.res` 沼澤鹽）、鹽岩礦（`need.res` 鹽岩，蓋在礦坑）—— 只在那種分布區裡蓋得了、不看氣候；建築模式在區外蓋 ⇒ 擋下並說原因
- [ ] 拉羅歇爾範圍內畫一塊沼澤鹽區（位置、儲量等級附史料出處或標〔佔位〕）；開場檔 land／自動建築蓋得出沼澤鹽田
- [ ] 起始檔兩年：拉羅歇爾鹽產出 > 0、挨餓 0；`statsDay` 不帶船隊帳差 0
- [ ] 對照組：其他城的規劃雜湊、開場檔、原本鹽田的城（雅拉斯等）鹽產量跟 main 一樣
- [ ] 文件：WORLD_FORMAT（資源分布區種類）、RESOURCES／PRODUCTION 的配方表、鹽田的 note 寫上變體與規則出處

## 任務描述

## 起因

Tim 2026-11-02（TASK-1162 拉羅歇爾施工時）：「沼澤的鹽 是否可以讓城鎮能有特殊規則(讓某些建築可以無視氣候等因素建造) 或是標記特殊地形(沼澤鹽 鹽岩) 並新增對應的鹽田變體(參考金礦坑 銀礦坑)」

史料上拉羅歇爾（聖通日、布魯阿日、雷島一帶）出沼澤的鹽〔轉，docs/TOWNS_1660S_EUROPE.md E3〕，塞圖巴爾的鹽也是荷蘭船來裝的大宗（同檔 E2 附近）。但現在的鹽田進不了溫帶：

- 適地表 `world/areas.js` SUITS `salt`：`env: { climate: ['dry', 'savanna'], soil: ['sand', 'swamp'], hMax: 0, coast: 3000 }` ⇒ 法國、葡萄牙的海岸一律蓋不了。
- 鹽田建築 `world/buildings/saltpan.json`（配方 `salt` 曬鹽，3 人、一天 3 桶，site 海邊 30 m、低於 3 m）。

## 建議做法（ridge-two 推薦，Tim 已同意開單）

不加「城鎮特殊規則」旗標，改成**資源分布區**，跟金礦、銀礦同一套：

1. `BSW.RESOURCES` 多兩種：沼澤鹽（`marsh-salt`，where land）、鹽岩（`rock-salt`，where land）。範圍層畫成 `type: resource` 的一筆，有儲量等級 `grade`。
2. 鹽田的變體配方，照 `gold-ore`／`silver-ore` 那樣帶 `need: { res: ... }`、`cap: 'reserve'`、`show`：
   - 沼澤鹽田：產 `salt`，只准蓋在沼澤鹽區裡 —— **區域本身就是「無視氣候」的那一條規則**，不看 SUITS 的 climate。
   - 鹽岩礦：產 `salt`（或另一種貨，要不要分岩鹽由做的人提、Tim 定），蓋在 `mine`（同金銀礦坑），只准在鹽岩區裡。
3. 原本的鹽田（半乾旱、熱帶乾濕季）不動。

這樣「某些建築無視氣候」被收斂成「在那種分布區裡才能蓋的變體」，不用另開一套城鎮層級的例外表；之後有別的特殊地形（例：泥炭、溫泉）也走同一條路。

## 範圍與不做的

- 先畫拉羅歇爾（必做）；塞圖巴爾／里斯本、加的斯有沒有要畫，看那幾座城在不在、史料查得到多少，查不到就照實寫。
- 價、產量、人手是佔位，寫清楚出處或標〔佔位〕。
- 白蘭地（聖通日）不在這張。
