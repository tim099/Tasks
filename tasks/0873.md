# TASK-0873 — 《Blocksail》存檔：一份 JSON 格式（時鐘、船、船型、改過的城、城鎮帳），先做編輯器存檔（%APPDATA%\Blocksail\saves），之後遊戲內用同一個格式

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 存檔格式一份（`blocksail-save` v1，JSON）：世界時鐘、船（位置、航向、航線）、選的船型、每座城玩家的操作（`townApplyOps` 那一串 road／build）、城鎮帳（同起始檔那一份）；讀的時候驗格式名與版本、不認得的版本報錯不亂讀
- [ ] 編輯器存檔：地球儀（`tools/world_serve.py`）把這一份寫到 `%APPDATA%\Blocksail\saves\editor.json`（跟之後 PC 版 Electron 的 userData 同一個資料夾）；先寫暫存檔再換上、舊的留 `.bak`
- [ ] 地球儀開頁讀這一份接回來（船、時鐘、船型、改過的城、城鎮帳）；改了就自動存（不用按）
- [ ] 沒有 world_serve（單純的靜態伺服器）⇒ 同一份 JSON 存在瀏覽器裡，照樣讀得回來
- [ ] 第一次：舊的 localStorage（船、時鐘、船型、城的操作）搬進存檔，一樣都不掉
- [ ] 同一個格式之後給遊戲內存檔用：存讀走同一支（`world/save.js`），遊戲內只差存放的地方（Electron 主行程、手機 App 私有資料夾）
- [ ] 量：工具驗格式（存→讀→存逐位元組相同、壞格式／舊版本報錯）；伺服器寫讀、`.bak`、檔名過濾；地球儀裡改船位置、撥時鐘、改城 ⇒ 重開頁全部接回來；反向對照：刪掉存檔 ⇒ 回到開場
- [ ] 文件：存檔格式、放在哪、各平台的位置寫進權威文件（`PACKAGING.md` 存檔那一節）；`ARCHITECTURE.md` 加存檔這張卡
- [ ] 兩種存檔（Tim 2026-10-24「編輯器可以有一個路徑參數控制會存到哪裡 Editor版本(修改會影響到打包出去的遊戲) 一個是遊戲版本(存在存檔內) 可以在存檔時根據路徑存(且遊戲存檔可以有多個)」）：Editor 版本 ＝ repo 裡的 `world/start.json`（打包進遊戲、新遊戲從它開始；起始檔 `townstate_start.json` 併進它的 `town` 那一欄）；遊戲版本 ＝ 存檔資料夾裡的 `<名字>.json`，可以有很多份
- [ ] 路徑參數：地球儀網址 `?save=editor`（預設）讀寫 Editor 版本、`?save=<名字>` 讀寫那一份遊戲存檔（沒有 ⇒ 從 `world/start.json` 開新遊戲）；Tim「目前在編輯器內的編輯(非打包版本) 按下存檔後都是存到編輯器內」「都是存到Editor版本」⇒ 編輯器裡按存檔一律寫 Editor 版本；沒有 world_serve（打包版）⇒ 只有遊戲存檔
- [ ] 按了才存（💾、Ctrl+S），畫面上看得到存到哪、有沒有沒存的改動；拿掉每 2 秒自動存
- [ ] 存讀檔的畫面（Tim 2026-10-24「存讀檔幫我加一個按鈕吧 會挑出讀檔選單 下拉選單選取後 還要按下讀檔鈕才讀檔 存檔則是會有預設名稱(輸入文字欄位) 然後只要按下存檔鈕就根據名稱存檔(不需要存成按鈕)」）：存檔名欄位有預設名稱，按 💾 照欄位裡的名字存（`editor` ＝ Editor 版本、其他 ＝ 遊戲存檔），沒有「存成…」；按 📂 讀檔跳出選單，選了不會馬上讀、要再按「讀檔」才讀；反向對照：只在選單裡換選項，頁面不重開
- [ ] 存成 Editor 版本是另一顆按鈕、分區存（Tim 2026-10-24「存成Editor版本請用另一個按鈕(並且應該要有分區 例如我只想改世界時間 或某一座城鎮) 城鎮編輯模式下存檔應該就只存該城鎮的改動」）：勾「世界」（時鐘、船、船型、照時鐘推到那一天的城鎮帳）、勾哪幾座城（那座城玩家鋪的路、蓋的建築）；只勾一座城 ⇒ `world/start/` 只有那座城的檔變、其他檔一個字都不動；💾 存檔只存遊戲存檔
- [ ] 城鎮編輯模式（城鎮模式的建築模式）裡存檔 ⇒ 只存那一座城的改動（Editor 版本 ⇒ 寫進 Editor 版本那一座城；Build 版本 ⇒ 存遊戲存檔）；反向對照：在 A 城存，B 城改過的路沒進 Editor 版本

## 現況（ame 查的）
- 地球儀的狀態散在 localStorage：船 `blocksail.globe.ship`、時鐘 `blocksail.globe.clock`、船型 `blocksail.globe.boat`、每座城的操作 `blocksail_townops_<id>`（globe.html 自己寫著「暫時的存法……正式存檔系統出來之後搬過去」）。
- 城鎮帳開場讀 `world/townstate_start.json`（TASK-0871），存讀 `townSave`／`townLoad`。
- 設計紀錄 ⑦（TOWN_BUILD）：存檔凍結規劃、之後只存玩家的操作（`townApplyOps`）。
- PACKAGING.md §3.4 已經寫了：JSON 檔到 `app.getPath('userData')/saves/`，Steam Auto-Cloud 同步；不同步 IndexedDB 快取與畫質設定。

## 範圍
- 只做編輯器（地球儀＋world_serve）的存檔；遊戲內的存檔欄位、Electron／Capacitor 的存放只保證格式相同，不做。
- 只存已經有雛型的系統；艦隊、船員、家族這些做好再加欄位。
- 畫面的偏好（摺疊、作者名）照舊放 localStorage（跟機器有關，不進存檔）。
