# TASK-1274 — 《Blocksail》城鎮規劃的指紋不看整份物種表 —— 只算那座城用得到的物種（改一種北非的物種，41 份規劃全部過期）

> `improvement` / `normal` / `in_progress`　開單：Abigail　參與：Abigail(dev)

## 驗收標準

- [ ] 改一種跟某座城無關的物種（例：只在北非出現的那幾種）⇒ `node tools/town_bake.cjs --check` 那座城不過期
- [ ] 反向對照：改一種那座城範圍裡長得出的物種（分布或環境條件）⇒ 那座城過期；只改物種的名字、note、註解 ⇒ 都不過期
- [ ] 地球儀（world/town_store.js 的 Worker）與 town_bake 算出同一個指紋：`town_bake --verify` 全過、進城照樣用烘好的那一份
- [ ] 指紋的算法換了那一次用 `--restamp`：現有的規劃一個位元組都不動，只換指紋

## 任務描述

Tim 2026-11-11：「物種表在城鎮規劃的指紋裡（TOWN_SAMPLE_CODE 有 species.js），改一個字，32 座城的規劃就全部過期　這個可以開單處理 不應該影響城鎮指紋」

現況（Blocksail main c4ba5592）：world/town_store.js `BSW.TOWN_SAMPLE_CODE = ['world.js', 'terrain.js', 'areas.js', 'species.js', 'town_sample.js']` ⇒ species.js 去註解後整份雜湊。
2026-11-11 TASK-1253 替三種美洲物種加 noRegions（只影響歐洲、北非、黎凡特、安納托利亞）⇒ `town_bake --check` 41 份規劃全部「換了：species.js」，要整批重烘（約 70～90 分鐘）。

規劃真的會讀物種（取樣的適地：開場的農莊照「長得了的作物」各種一座）⇒ 不能整份拿掉，要像 `#tables`（TASK-0994）那樣只算「這座城用得到的那幾格」：
例如照城範圍（townBox）裡的分區與環境，挑出分布對得上的物種，只把那幾種的 regions／noRegions／env／alt 算進指紋。
⚠ 這段判斷本身要跟取樣用同一支（speciesWhy／inRegions），不然指紋與規劃會對不上。
