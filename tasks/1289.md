# TASK-1289 — 《Blocksail》運河：照 WORLD_FORMAT §6 疊在陸地上的線（寬、深）挖進航海地形與城鎮取樣

> `feature` / `normal` / `todo`　開單：gura　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 世界資料放得進運河線（折線＋寬＋深，WORLD_FORMAT §6 的 canal），海岸線的環不動
- [ ] 航海模式的地形照運河挖成水道：運河範圍內是水、深到線上寫的深度，兩岸照原本的地形
- [ ] 城鎮規劃的取樣把運河當水：路不鋪在運河上、地塊不壓運河
- [ ] 第一版運河不進航線與導航網（玩家的船不開進運河），文件寫明
- [ ] 改了哪些規劃指紋、海圖塊要重烘哪一片寫清楚；沒畫運河的地方規劃逐位元組不變（反向對照）
- [ ] 一條測試運河進遊戲看過：水面、兩岸、地塊不穿幫

## 任務描述

誰在等：Tim（威尼斯 1666 的運河要先有這一層）；之後阿姆斯特丹等運河城也用得到。

拍板（Tim 2026-11-14）：運河照 WORLD_FORMAT §6 疊在陸地上的線（寬、深），不把陸地切成很多塊環；海岸線不動。
現況：`world/world.js` 查一點已經認 canal 線（在運河上回 water），但資料一條都沒有，航海模式的地形、城鎮取樣都還不會照它挖。
注意：trailhead 正在換海岸線、重抽等深線（TASK-1246、TASK-1286），運河線是另外一層資料，動手前先對過不撞同一批檔。
