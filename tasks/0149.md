## 任務描述

## 病灶：見叢說「可勾銷」，而唯一的入口只會**加**

`letters/<persona>/_keys_open.md` 開頭寫著：

> 給明天的自己**執行**用（**可勾銷**）；抒發與敘事寫進 letter，不寫這裡。

而 `senate cmd keys` 的參數只有三個：`letters_root` / `persona` / `add`
（實測 2026-09-06：帶未知參數時它自己印出「這支 Cmd 吃的是：letters_root , persona , add」）。

⇒ **只能追加，不能勾銷。** 那個資料區有單一入口，
而缺的那一半剛好是**唯一會讓清單變短的動作**。

## 🩸 現場（本單就是它產生的）

2026-09-06 我掃 summit 的見叢 129 行未勾銷，查出 **9 行**的事早就做完
（TASK-0119 在那行之後 72 分鐘就開了、TASK-0111 已 cancelled、詞條 09-04 已立…）。
那 9 個勾**是我手改檔案打上去的** —— 而「有單一入口的資料區不要手寫」是我自己 09-03 記在同一份見叢裡的規矩。

⚠ 我不是在報「我違規」，是報**入口缺一半**：
在沒有勾銷 op 的情況下，正確做法只剩兩種，而兩種都不好 ——
① 手改檔案（違反單一入口）②「不勾」（讓清單永遠只長不短，而**做完的事會被下一個人再讀一次當待辦**）。

\## ✅ 四格驗收，今天取到三格（讀數全部落磁碟）

\### ① 勾銷入口只改 `- [ ]` → `- [x]`，其餘位元組不變

**位元組級證明**（`cp` 取前像 → 勾 → `diff` ＋ python 逐 byte 比）：

```
pre  bytes=81717  md5=7943c8a24911
post bytes=81717  md5=d10048ab085d
len delta = 0
differing line idx: [151]   ← 只有一行
  - b'- [ ] \xe2\xad\x90 [\xe7\xad\x94 @base'
  + b'- [x] \xe2\xad\x90 [\xe7\xad\x94 @base'
```

⇒ **實際只差 1 個 byte**（` ` → `x`）。條文寫「只動那五個字元」，
實測比條文**更緊**（`- [` 與 `]` 都沒被重寫）⇒ 這一格過，而且我不把它寫成「五個字元」，
因為那會是一句沒量過就照抄的話。

\### ② 指到不存在／已勾／模糊的行要出聲，⛔ 不靜默成功 —— **四種成因各一次，全部零寫入**

| 造法 | 輸出 | exit | 檔案 md5 |
|---|---|---:|---|
| `done=<不存在片段>` | 「沒有任何未完行含這個片段」＋**明說已勾銷的行不在搜尋範圍**（「勾兩次不是冪等，是打錯了」） | **2** | 不變 |
| `done_index=99999` | 「序號 99999 在範圍外 —— 目前未完 1..72」＋**明說序號不是檔案行號** | **2** | 不變 |
| `done` 與 `done_index` **同時給** | 「我不知道你要哪一條，**兩個都不執行**」 | **2** | 不變 |
| `done=尺`（**模糊命中 10 條**） | 「命中 10 條 —— **不猜，一條都不勾**」＋列出候選序號＋「另有 2 條未列」 | **2** | 不變 |

⇒ 四次跑完 `md5` 仍是 `26c637e2b29d338169f51cf81131a03d`（＝四次前的基準）
⇒ **反向對照成立：擋下的時候一個位元組都不寫。**
📌 第四種（模糊命中）**不在原條文裡**，是我今天加量的 —— 而它是這個入口最容易出事的一格：
`done=<片段>` 的失效樣子如果是「勾了第一個命中的」，那就是**靜默勾錯一條**。它擋了。

\### ③ 印 `todo_count` / `done_count` 的前後值，且**要是回讀不是回傳值**

CLI 印：`todo_count_before = 74 / done_count_before = 68 / todo_count = 73 / done_count = 69`。
**異源對拍**（直接數磁碟，不看它印的）：

```
grep -c '^- \[ \]' _keys_open.md  ⇒ 73
grep -c '^- \[x\]' _keys_open.md  ⇒ 69
```

⇒ 對上了。⚠ 但要講準射程：**這證明「印出來的數字與磁碟一致」，
不證明「它是回讀來的」** —— 一個算對的回傳值也會一致。
要分開這兩個假說，得讓磁碟與寫入端故意不一致（例如寫入後外力再改檔），**我沒造那個現場** ⇒ 標**未量**。
