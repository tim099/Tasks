# TASK-0507 — 雕刻：外部模型（obj 匯入、作品當模型、繩綁模型）＋網格建構提到共用層

> `feature` / `normal` / `done`　開單：basecamp　參與：basecamp(dev)

## 驗收標準

Tim 2026-10-12：雕刻作品可以匯入外部模型（先只支援 obj），支援旋轉、縮放等基礎變換；繩可以綁在外部模型上（用模型自己的座標，模型移動繩跟著動）；也可以指定另一件作品當外部模型（不匯入 voxel，而是輸出成模型後匯入，模型快取在本地）。同時整理架構，把渲染的共用部分提到 SCP_Core。測試部件：憲法號的舵輪（0.02 m／格的子作品）。

- [x] 作品可以匯入一個 obj 檔當外部模型：檔案收進作品、可設位置／轉軸點／任意角度旋轉／縮放／鏡像；改變換不必重新匯入；拿掉之後作品的 voxel 一格不變　✅ basecamp 2026-10-12
- [x] 讀不了、空的、面索引越界的 obj ⇒ 擋下並說原因，作品一個檔都沒寫　✅ basecamp 2026-10-12
- [x] 可以指定另一件作品當外部模型：輸出成模型快取在本地（不入版控）；來源作品改了，下一次觀測自動重出；比例照兩件作品的一格幾公尺自動換算　✅ basecamp 2026-10-12
- [x] 模型來源成環（A 用 B、B 又用 A，含隔層與經過關聯）⇒ 擋下　✅ basecamp 2026-10-12
- [x] 繩的端點可以綁在外部模型上（模型自己的座標；作品來源的模型也可以用那件作品的固定點名）；移動、旋轉、縮放模型之後，繩端讀數跟著變到對的位置　✅ basecamp 2026-10-12
- [x] 模型跟著關聯走（被關聯進來的作品自己的模型照那條關聯換座標）；所在那一層沒畫 ⇒ 模型跟著不畫並照列；綁定壞了照列、不靜默消失　✅ basecamp 2026-10-12
- [x] view 出圖與觀測頁的 GPU 預覽畫得出模型（同一組燈與影子）；觀測頁有模型開關；export obj 把模型接在後面輸出　✅ basecamp 2026-10-12
- [x] 反向對照：沒有模型的作品 —— view 的網格讀數與 export obj 逐位元不變　✅ basecamp 2026-10-12
- [x] 網格建構（voxel 外露面＋AO＋合併、繩、帆、模型）搬到 SCP_Core 共用層；搬家前後同一份場景的網格 digest 逐位元相同　✅ basecamp 2026-10-12
- [x] 雕刻文件寫上外部模型的用法與限制　✅ basecamp 2026-10-12
- [x] 憲法號舵輪測試：0.02 m／格的舵輪子作品，以作品來源的模型掛上船、出一張圖給 Tim 看　✅ basecamp 2026-10-12
