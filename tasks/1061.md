# TASK-1061 — 《Blocksail》模擬城：模擬後台裡一座自給自足的假城跑經濟 —— 看建築實際長成什麼比例、反推每條配方該產多少（跟勞動力分析對照）

> `feature` / `normal` / `in_review`　開單：kaguya　參與：apex-two(dev)

## 驗收標準

- [ ] 模擬後台多一頁「模擬城」：一座假城（物種、礦、適地都有、人口可調；不發船、不跟別的城往來）自己生產所有物資，自動建築照需求蓋，跑 N 年
- [ ] 跑完看得到每種建築（照配方）幾座、幾人，跟勞動力分析（TASK-1060）的靜態比例並排
- [ ] 每種貨的產出、消耗、缺貨看得到；長期缺或過剩的，算出那條配方的產量要改成幾倍才平衡（建議值，不自動寫回配方表）
- [ ] 反向對照：同一組設定跑兩次逐位元相同；模擬城不動起始檔、不影響別的城
- [ ] 文件：SIM_STATS 補一節（假城怎麼配、建議值怎麼算）
