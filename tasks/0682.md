## 驗收標準

- [x] 造船規格寫明 `deco` 這個 meta：意思、能標在哪（外部模型；關聯標了遊戲不拿）、什麼不能標（帶功能 kind 的、別的部件掛在它上面的）　✅ kotoko 2026-10-17

- [x] 畫質不改戰局：同一場開／關裝飾，戰局讀數（重量、傷害、進水）一樣　✅ kotoko 2026-10-17

- [x] 反向對照：沒標任何 deco 的船，開／關前後網格三角形數一樣　✅ kotoko 2026-10-17
