# TASK-1226 — 《Blocksail》航線轉角改成弧線：貿易航線（航線網、入港航線）與玩家船的局部尋路用同一套 —— 弧照水深能放多大放多大

> `improvement` / `normal` / `in_progress`　開單：summit　參與：summit(dev)

## 驗收標準

- [ ] 共用的 BSW.roundPath：每個轉角試最大的弧、呼叫端的尺核、不過就縮；netRound 改叫它且舊行為逐點相同（反向對照）
- [ ] 航線網的邊在烘的時候圓：弧上不比原本那兩段淺，改前改後比最淺、長度、轉角的 t
- [ ] 入港航線在烘的時候圓：不碰棧橋、碼頭，最淺不變淺
- [ ] 玩家船的局部尋路圓：弧不碰擋格（含船半徑），改前改後同一批航段比長度、時間
- [ ] 地球儀上看過：貿易航線、玩家船的航線轉彎是弧
- [ ] Tim 看過一次

## 任務描述

## 要什麼

Tim 2026-11-05：「另外希望能讓航線轉彎變成弧線(目前轉角太銳利)」「弧線轉角還沒動工 開工吧 不只貿易航線 玩家船隻的導航希望也用一樣算法」

## 現況（量的，2026-11-05，TASK-1196 #8 之後）

- 圓弧本來就有（world/navgraph.js netRound，Tim 2026-10-26「航線轉角過於銳利(希望用曲線轉彎)」）：切線長 t ＝ min(寬度 × 0.9、前後段 × 0.45、1.5 km)
- 航線網 world/nav/net.js 轉 15° 以上的轉角 313 個：t 中位 0.60 km、最多 0.90 km；199 個被寬度限住（nav_net 量寬度封頂 W_CAP 1,000 m）
- 只有 61／313 個在深海層裡 ⇒ 光放寬上限只救 45 個；多數銳角在近岸短段（較短那段中位 2.3 km）
- 玩家船的局部尋路（world/legplan.js）拉直之後就交出折線，沒有圓

## 做法

- 一支共用的 BSW.roundPath（world/navgraph.js）：每個轉角先試最大的弧（前後段各 45%、上限），交給呼叫的那一邊的尺核，不過就對半縮、縮到下限還不過就留轉角
- 三處各帶自己的尺：航線網的邊（tools/nav_net.cjs：導航網＋深海層，弧上不比原本那兩段淺）、入港航線（tools/nav_ports.cjs：導航網格子、棧橋當陸）、玩家船（world/legplan.js：照船半徑外擴過的擋格）
- 執行時的 netRound（接縫：入口點、節點）照舊照寬度限，改成叫同一支
