# TASK-0909 — 《Blocksail》城鎮模式點選建築：沒開建造選單時點建築，跳出建築資訊（名稱、居民容量、工人容量、產物）與操作選單（購買、拆除、演出建造過程）

> `feature` / `normal` / `in_progress`　開單：kotoko　參與：kotoko(dev)

## 驗收標準

- [x] 城鎮模式沒開建造選單時點一棟建築，跳出資訊面板：建築名稱、居民容量、工人容量、產物　✅ kotoko 2026-10-25
- [ ] 面板上有操作：購買、拆除（規則照當時經濟系統的定案）
- [x] 面板上有「演出建造過程」按鈕，按下去那一棟從 0 演到完工　✅ kotoko 2026-10-25
- [ ] 反向對照：開著建造選單時點建築，行為跟現在一樣；點到空地或沒有建築的地方，不跳面板

## 任務描述

Tim 2026-10-25：「另外目前構想在城鎮模式 沒有開啟建造選單時 點選建築可以出現建築資訊&該建築操作選單（包含購買 拆除 以及顯示建築名稱 功能（居民容量 工人容量 產物等）以及演出建造過程的按鈕） 這個可以先記錄成task」

先記錄，還沒有人認領。「演出建造過程」那顆按鈕接建造演出 TASK-0908。購買、拆除的規則（誰能買、價格、拆了居民與工人去哪）跟經濟、自動建築（TASK-0891）、都市更新（TASK-0895）有關，動工前要先對。

### 💬 #1 kotoko 2026-10-24T22:33:55.886Z
**判定**：資訊面板與演出鈕做好了，合進遊戲（同 TASK-0912 那一批：Blockside dev edf2ae8、Blocksail main 20713d5／0f7fdf0）。購買、拆除還沒做（第 2 格）。

**做了什麼**（Tim 2026-10-25：「城鎮中直接點選房子會跳出房屋資訊…資訊包含住宅人口/容量 工人/崗位 產出/消耗等 然後有個額外按鈕可以演出該房屋建造過程」）
- Blockside 新檔 `89_townbld.js`：建築模式沒開時點一棟，左邊跳出面板 `#tbiP`，選著的那一棟畫黃框。再點同一棟、點空地、按 ✕ 或 Esc 都會關掉。
- 內容來自地球儀 townUI `'bld'`（Blocksail `world/site.js townBld`）：
  - 名稱、種類、主人、等級；
  - 住宅：住的人／容量（容量照佔地 × 密度級，住的人照全城人口按容量分，帳上沒有每一戶）；
  - 生產建築：工人／崗位、每天產出／消耗（昨天的帳，桶），停工時寫原因（市場價賣不回成本、沒有人手、缺原料、主人付不起工資）；
  - 施工中：進度條、工地幾人。
- 「▶ 演出建造過程」：從 0 演到完工（24 秒），演完停 1.5 秒自己換回帳上的樣子（還在蓋就照帳的進度）；播放中按鈕變「■ 停止演出」。

**憑據**（和平港，地球儀進城鎮模式）
- 點住宅 B：面板「住宅／🏠 住的人／容量 5／6」。
- 點甘蔗園：「種植園　主人：馬爾尚家／👷 工人／崗位 0／8」。帳上那一天真的 0 人上工（市場價卡開工率），之後補了停工原因那一行。
- 按演出：p 0.09 → 0.31 → 0.53 → 0.75 → 0.97，播完工地收掉、按鈕換回來。
