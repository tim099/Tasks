# TASK-0911 — 《Blocksail》簡易船隊系統：家族、城鎮的船隊自己訂航線貿易（母港需求、價差、航程），集散地（每區自動挑、可手動指定）

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [x] 船隊屬於家族或城鎮（國家）：城鎮帳 fleets 的主人可以是家族或城鎮，買賣、開銷從主人的金庫出入；開場照城鎮規模、家族發船隊（數量〔佔位〕、照種子可重現）；玩家的船隊不歸 AI 管　✅ gura 2026-10-25
- [x] 每支船隊自己訂航線：停港時照「母港缺什麼、這裡什麼便宜、哪裡賣得高、航程幾天」挑下一站與貨；航行天數 ＝ 距離 ÷ 航速；到港先賣、再買下一趟；沒有划算的就留在港裡　✅ gura 2026-10-25
- [x] 集散地：每一區自動挑一個以上（照人口與市場量）、可以手動指定（覆寫自動）；非集散地的船隊偏向跑本區集散地與母港，集散地的船隊跑跨區　✅ gura 2026-10-25
- [x] 只跟同一個時空的城貿易（君士坦丁堡、加拉塔自己一圈）　✅ gura 2026-10-25
- [x] 檢查腳本：手做的小城（A 便宜 B 貴 ⇒ 運過去；沒價差 ⇒ 不動；同價差遠的排後面；母港缺貨優先；集散地自動挑與手動指定）；錢、貨總數不變（路上的貨算進去）；起始檔一年讀數（航次、運量、各城同一種貨的價差 vs 沒有船隊的對照）　✅ gura 2026-10-25
- [x] 接地球儀：城鎮帳每天跑船隊；查詢接口與報表印得出每支船隊（在哪、去哪、載什麼、賺多少）；城鎮介面概況列停在港裡的船隊　✅ gura 2026-10-25
- [x] 文件：TRADE_SIM 新一節（簡易船隊；概略層追價差那一條改寫）、TOWN_UI 補船隊　✅ gura 2026-10-25

### 第二段：玩家所在的海域真實模擬（Tim 2026-10-25）

Tim：「繼續優化船隊系統吧 讓玩家所在海域會真實模擬船隊運行(例如整個加勒比海)」；挑了「航海模式看得到船」「精細區跟著玩家走」「港口進出與船隊規模」三塊；
「非精細模擬區的船隊可以凍結」——「凍船隊 但是會根據船隊有虛擬貿易額度 且仍然可以建造新船隊以及維修 遭遇海盜等 只是船隊變成粗略模擬(不實際模擬航行 而是直接假設在某條航線上的某個位置 海盜變成機率計算遭遇 損失等)」；
「航線可以一開始就計算好 在幾個月週期才調整一次(或是完整航行完幾輪後 根據貿易報表調整營運路線)」。

- [x] 營運路線：每支船隊有一條排好的營運路線（停哪幾個港、每一段大致載什麼），照它一輪一輪跑，不再每次停港重挑；每隔幾個月或跑完幾輪，照這條路線的貿易報表（每一段賺多少）調整或換路線；讀數：起始檔一年重排幾次、每次為什麼換　✅ gura 2026-10-25

- [x] 精細區跟著玩家：玩家的船（航行中或停靠）在哪一個海區，那一個海區的船隊就走精細層；離開（過了緩衝帶）就收回。海區是設定出來的（先：加勒比海一帶、馬爾馬拉海）；在邊界來回不會讓船隊一下出現一下消失　✅ gura 2026-10-25
- [x] 精細區外的船隊凍結成粗略模擬：不跑航行，假設停在某條航線上的某個位置；照船隊的載量給虛擬貿易額度（每天在航線兩端照市場價買賣）；海盜照機率遭遇與損失；照樣會造新船、維修　✅ gura 2026-10-25
- [x] 交接：展開（照假設的位置生出、帶上那一趟的貨）、收回（剩下的貨、照位置換成粗略的那一段）錢與貨總數不變；海盜風險不重複算；反向對照：玩家一直在加勒比 ⇒ 君士坦丁堡那一圈全程粗略、加勒比全程精細　✅ gura 2026-10-25
- [x] 港口進出照小時：精細區的船隊在一天裡不同的時刻出港、照導航圖的小時數到港賣貨（不再整天跳）；城鎮模式看得到停在港裡的船隊　✅ gura 2026-10-25
- [x] 船隊規模：船型照載量挑；船況會因航行與被劫變差、回母港花錢修；主人有錢、航線賺錢 ⇒ 造新船隊（錢付給造船的那座城），一直虧 ⇒ 賣掉；讀數：起始檔三年各城的船隊數與船型　✅ gura 2026-10-25
- [x] 航海模式看得到船：玩家在航海模式時，附近的精細層商船、海盜船真的出現在海面上、照位置與航向航行；開遠了或回地球儀就收回；量多幾艘的幀數成本　✅ gura 2026-10-25
- [x] 錢、貨守恆與重現：起始檔三年每天錢、貨總數不變；兩次跑、存讀逐位元組相同；效能：node 一年多久、地球儀每幀多久　✅ gura 2026-10-25
- [x] 文件：TRADE_SIM 新一節（精細區跟著玩家、凍結的粗略層、港口進出、船隊規模、航海模式的船）　✅ gura 2026-10-25

## 任務描述

## 要什麼（Tim 2026-10-25）
「然後可以先嘗試做簡易的船隊系統（串接各城市的航線）艦隊屬於家族或城鎮（國家） 會根據判斷自己制定航線進行貿易（看母港需求的資源 以及生產的資源賣到哪裡收益高 航行距離等判斷） 然後有些港口可能成為集散地（例如 君士坦丁堡）各城市貨物可能會傾向在集散地買賣（每個區域可以根據判斷選取一個以上集散地 可以手動指定）」

## 跟舊規格的關係
- TRADE_SIM §2.2 寫「概略層不跑追價差的商人」（2026-10-19）⇒ 這次 Tim 要的是概略層就有自己挑航線的船隊 ⇒ 以這次為準，文件改寫並標日期。
- 導航圖（§1.1、TASK-0724）還沒做 ⇒ v1 航程 ＝ 兩港的大圓距離 × 繞行係數〔佔位〕；導航圖做好再換成真的海路距離。
- 買賣走現成的 world/stores.js（價格曲線、關稅、金庫）；城鎮帳的 flow／hist（TASK-0910）照記。

## 做法（v1）
- world/fleet.js：船隊的主人、開場發船、每天一步（航行、到港賣買、挑下一站）、集散地（自動＋手動）、查詢與報表。
- townDay 裡跑（有載才跑）；地球儀照範圍層給港口座標與分區。
