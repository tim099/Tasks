# TASK-0632 — Blockside：火藥經艙口吊進砲塔（照原船：住艙甲板彈藥庫 → 砲塔底下的艙口 → 砲塔，不擺在露天甲板）

> `feature` / `normal` / `in_progress`　開單：meadow　參與：meadow(dev)

## 驗收標準

Tim 2026-10-16：「我看火藥直接裸露在頂層甲板上，原船設計是如何搬運火藥的」「按照原船設計，是否可以直接從底層甲板進入砲塔」。
原船（Greene〈In the Monitor Turret〉；NOVA；Wikipedia）：彈藥庫在住艙甲板、中隔艙壁前的右舷；火藥與砲彈從住艙甲板經砲塔底下的艙口吊進砲塔（甲板的 scuttle 對上砲塔地板的艙口），⛔ 不經過露天甲板；人也是從住艙甲板爬梯子進砲塔。
現況（Blockside 暫存副本，莫尼特號）：取用點擺在砲所在那一層 ＝ 露天的主甲板 ⇒ 火藥桶擺在甲板上。

- [ ] 莫尼特號的火藥不再擺在露天甲板上：從住艙甲板的彈藥庫，經砲塔底下的艙口送進砲塔（取用點在砲塔裡或艙口底下）
- [ ] 送藥手走的是梯子／艙口那條路（不穿牆、不走露天甲板），匯入檢查的「火藥」那一行照新的路線列出遠近
- [ ] 砲班與送藥手從住艙甲板爬梯子進得了砲塔（砲塔圓筒在走路格上是牆，入口只有底下的艙口）
- [ ] 怎麼標寫進造船規格（作品這側標什麼），不是照船名寫死
- [ ] 反向對照：沒有這個標記的船，取用點與戰局對拍跟改之前逐字相同
