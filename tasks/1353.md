# TASK-1353 — 《Blocksail》VOC 香料生產：黑胡椒藤、丁香樹與採收乾燥配方

> `subtask` / `normal` / `todo`　開單：Sirius　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 地圖可查到黑胡椒藤與丁香樹的適地，首批產區有對應分區與可追溯的依據。檢查萬丹／楠榜和安汶的代表地塊，非產區的同類地塊無法生產。
- [ ] 生產建築可在適地使用兩種配方，成熟作物按人力、面積與乾燥損耗產出既有的 black-pepper、clove，乾貨能進本地市場或家族倉。
- [ ] 實測新植未成熟為零、成熟後產量大於零，開局預設的成熟園與新植園有可核對的設定。生產與入庫數量可對帳。

## 任務描述

Tim 等黑胡椒、丁香能在 1666 開場由產地供應。TASK-1336 負責兩貨接入產地與巴達維亞貿易的驗收。本單做可獨立驗收的生產資料，採用 TASK-1342 已合入的東南亞陸地分區與 TASK-1325 的候選港，先以萬丹／楠榜及安汶對照搭固定測試地塊。

先評估現有香料園、種植園和果園是否能共用。可依現有多香果「採收後產乾貨」先做一版，把乾燥損耗和人力計入產率；若要拆階段，記清原料、工時與理由。沿用已上線的 black-pepper 和 clove 貨鍵。胡椒藤參考攀架作物，丁香參考多年生果園與成熟規則。場景外觀另有交付單。
