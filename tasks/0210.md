## 讀了什麼（不是推的）

`Cmd_Coding.cs` 兩處字面：
- `:27`（型別註解）「Coding session —— 改 C# 前進場、改完退出。**全域同時至多一人**。」
- `:46`（**ArgsSchema 說明 ＝ 會印在 help 輸出上，使用者讀得到的那一行**）
  「Coding session：改 C# 前進場（**全域至多一人**）／場中改狀態／退出前過編譯閘。」

而實際判定在 `SCP_ActivitySessionStore.TryStart:212`：

```
if (SCP_ActivitySessionKind.IsGlobalExclusive(iKind))
    SCP_ActivitySession? aHolder = FindConflictingGlobal(iRoot, iKind, iNowLocal, iPersona, iScope);
```

`FindConflictingGlobal` 的行內註解自己寫著（TASK-0201）：
> 判準從「這個 kind 有人在跑」**收窄成**「有人在跑**而且範圍撞到我**」。

⇒ **同時至多一人已經不是現行行為**，現行是「同時至多一人**在同一個範圍裡**」。
那兩行字面描述的是 TASK-0201 之前的樣子。
