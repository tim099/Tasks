# TASK-0884 — 《Blocksail》生產鏈接上遊戲：城裡的生產建築照 id 串到建築表／配方／貨物，城鎮帳每天推進（家族倉庫優先、不夠向城鎮買、買不到照比例減產、要有勞動力）

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [ ] id 對帳工具：城鎮規劃會出現的每一種工坊、生產建築都對得到建築表的一種；建築表的每一條配方都在配方表；配方吃的、產的每一種貨都在貨物表與資源表上；全對 exit 0、有差指出是哪一筆
- [ ] 現在對不上的補齊：城鎮規劃與建築表兩套名字合成一套；牧場、鹽田、漁場、伐木場、蒸餾坊、製革坊、織布坊、鋸木坊等城裡有的工坊、生產建築各有建築種類、配方、貨物；補了哪些、哪些先不做，清單與 Tim 的取捨記在單上
- [ ] 城鎮規劃裡的生產建築（開場的農莊、玩家蓋的）都進城鎮帳的建築清單，帶配方、田的面積、主人；拆掉就從清單拿掉；反向對照：住宅、教堂不進生產清單
- [ ] 遊戲裡每過一天，每座城的城鎮帳推進一次（以城鎮為單位）；同一份輸入跑兩次逐位元組相同
- [ ] 家族的建築：產出進那個家族在那座城的倉庫，放不下的當天強制賣給城鎮；原料先從倉庫拿，不夠的向城鎮市場買（錢從家族資金出）；城鎮的建築原料、產出都直接走市場
- [ ] 買不到原料（市場沒貨、或家族沒錢）⇒ 照拿到的原料比例減產，一點都沒拿到就停產；反向對照：原料全有 ⇒ 照配方滿產
- [ ] 勞動力：崗位從城鎮的勞動人口分，同一個人不算兩次；人手不夠照到崗比例減產；看得到哪幾座缺工、缺多少
- [ ] 一座城跑 365 天的讀數：每種貨的產出、消耗、買進、賣出、家族資金；總量守恆（期初＋產出＋買進 − 消耗 − 賣出 ＝ 期末）

## 任務描述

## 要什麼（Tim 2026-10-24）

「接下來想把城鎮生產鏈實際串上產出 目前已經有農田跟其他生產建築了 需要確保對應產出資源都有設定(根據id串接) 然後可以開始規劃資源產出模擬了(目前設想是一天計算一次 以城鎮為單位 家族的建築產出進入到該城該家族倉庫 溢出的強制賣給城鎮 然後生產需要的資源優先從倉庫拿 不夠的部分從城鎮購買(買不到原料就降低產量或停產(產出根據消耗原料算)) 以及要有勞動力滿足生產需求」

## 缺的（2026-10-24 量的，Blocksail main 1dbcb48）

1. **城鎮帳裡沒有建築**：起始城鎮帳（world/start/）的建築清單 0 筆；開場的農莊（PRODUCTION.md §12.3，town.js ⑬ 的 farm-<配方>）只在城鎮規劃裡，沒進城鎮帳 ⇒ 生產一天都沒跑在它們身上。
2. **遊戲裡沒人推進**：townDay／townRunTo 只有工具在叫，遊戲的時鐘沒接。
3. **兩套名字**：城鎮規劃的建築用途（town.js CORE.cat）有 sugar-works、tobacco-farm、indigo-works、cacao-farm、ranch、lumber-camp、saltpan、fishery、carpenter、smithy、cooper、distillery、tannery、weaver、sawmill、ropewalk…；生產建築表（world/buildings.js）只有 farm、plantation、mine、woodcutter、henhouse、mill、bakery、sugar-mill、warehouse ⇒ 糖莊對糖廠、伐木場對 woodcutter 是兩個名字，牧場、鹽田、漁場與第七批工坊在表裡沒有種類、配方。
4. **向城鎮買原料**：FAMILIES.md §4 寫「家族從市場買原料：之後（v0 只有放不下 ⇒ 賣）」⇒ Tim 這次要：倉庫優先、不夠向城鎮買、買不到照比例減產。
