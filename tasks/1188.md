# TASK-1188 — 《Blocksail》鎮民消耗照價格陡伸縮：原料低於門檻才吃、非糧食日用品便宜多吃貴少吃，先留生產鏈的料（鐵件撐不到 60 天、進口鐵礦被吃光）

> `improvement` / `normal` / `in_progress`　開單：ridge-001　參與：ridge-001(dev)

## 驗收標準

- [ ] 原料（中間貨：礦、錠、生鐵、熟鐵這一類）鎮民只在價格低於門檻才消費、高於門檻幾乎不消費：幾種原料的「現價 ÷ 基準價 vs 鎮民一天吃多少」讀數列在單上
- [ ] 原料消化太慢時價格不再一路跌破成本：一年模擬裡，有生產、沒人用的原料（例：沒有煉鐵場的城進口的鐵礦）最低價不低於門檻那一帶（讀數）
- [ ] 非糧食的日用品（鐵件、工具…）價格低吃得多、價格高掉得快，並且先保留生產鏈 N 天份：開場給船具行的鐵件撐得到設計的天數（改前第 6～36 天就見底）
- [ ] 糧食不受影響：反向對照糧食那幾種的消耗與改前相同
- [x] 一年模擬：沒有一種貨因為這次改動變成全世界一年產量 0，或一路堆積不降；開關關掉 ⇒ 收集器 digest ＝ 改前　✅ ridge-001 2026-11-06

## 任務描述

## 要什麼

Tim 2026-11-02（排查船具停產之後）：
- 「目前想法是 當價格夠低時才提升鐵件需求(其他關鍵原料也是) 可以調整消耗曲線(大部分商品其實都可以參考 除了糧食) 也就是消耗量會隨著價格降低而顯著上升(讓價格容易維持在回本線上) 但又能保留作為原料的輛」
- 「2 希望是當原料價格低於一定程度時 鎮民才會消費原料(價格高於一定程度消費會非常低) 主要是避免原料消耗過慢時價格迅速低於成本」
- 「然後可以先記錄到單上 先不動工」

⇒ 鎮民對非糧食的貨，消耗量照價格陡一點地伸縮：便宜 ⇒ 吃得多（把價格撐回回本線）、貴 ⇒ 幾乎不吃（把料留給生產鏈）。原料只在價格低於門檻時才吃。**還沒動工**。

## 現況（ridge-001 2026-11-02 讀的，`world/food.js` CONSUME.needs；TASK-1108 的設計）

- 需要表 ④：量 ×（基準價 ÷ 現價）^eps，改善那一級 eps 0.8、最多 2.5 倍。鐵件在需要表裡（hardware，改善），價格漲到上限（約 3 倍）時鎮民照吃約四成 ⇒ 開場給船具行的 60 天份（GOODS_BASE，只照建築的需要算、沒算鎮民）第 6～36 天就被吃光，船具行跟著停（鎮民一年每城吃鐵件 5～13 桶，比船具行自己吃的還多）。
- 撿便宜 ⑤（原料、半成品）：現價 < 基準價 0.9 倍才買，只買超過「理論每天消耗 × 60 天」的那一截。理論消耗 0 的城（沒有加工廠）⇒ 保留 0 ⇒ 進口來的原料全被吃掉（哈瓦那：船隊賣進鐵礦 41.9、鎮民吃 41.9）。
- 門檻照的是基準價，不是回本線（PROD_MKT：產出值 ÷（工資＋原料）＜ 0.4 停工、≥ 0.8 滿產）。

## 方向（〔設計〕，等拍板再動）

- 原料：門檻改照回本線（或基準價的某一倍），門檻以上幾乎 0、以下隨深度陡升；保留量照「本城＋本商圈」的生產鏈要的算（接 TASK-1187 的商圈需求），不是只看本城。
- 非糧食日用品：eps 調陡、上下限放寬；先保留生產鏈 N 天份，鎮民只買多出來那一截。
- 糧食那幾條照舊。
