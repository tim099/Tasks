# TASK-1404 — 《Blocksail》地形改存高度格（立方球面四分樹）試作：驗證用地球儀＋台灣資料

> `feature` / `normal` / `in_progress`　開單：summit　參與：summit(dev)

## 驗收標準

- [ ] 高度格的格式文件寫進 Blocksail docs：分檔、數值範圍 −20,000～20,000 m、編碼、粗細交界的規則
- [ ] 烘焙工具產出全球粗層＋台灣細層；Python 寫出的檔由 JS 讀回，逐格相同
- [ ] 接縫讀數：跨立方體的面、跨檔、粗細交界三種各量一次，高度的跳動不超過量化步距
- [ ] 反向對照：把細層邊界的漸變關掉 ⇒ 同一支檢查量得到跳動
- [ ] 驗證用地球儀（新架構，不沿用 globe.html 的畫法）在瀏覽器開得起來：台灣有高低起伏、顏色照土質／植被／冰蓋，截圖給 Tim
- [ ] 本體改用 C#、UI 嵌網頁的可行性分析給 Tim

## 任務描述

Tim 2026-11-28：等高線地形「地形資料來源轉等高線過程中會出現很多瑕疵&效能問題」⇒ 分析改用其他方式保存地形高度（儘量做到球表面積上資料平均）；之後追加：沒有接縫、精度可更高（10 GB 內）、分多檔保存、不用考慮城鎮風險（之後重新處理）、格式方便地形編輯器（遊戲內建工具可以調整並輸出）、高度範圍 −20000～20000 公尺（等高等深一起、含海溝）、地球儀渲染整個重做（實際模型、顏色照土質／植被／冰蓋）。

本單：做「一個驗證用的地球儀（新架構）然後填入台灣的資訊測試看看」，並分析「本體改用c# 嵌入網頁做UI的可行性」。試作，全部是新檔，不動現有的地形鏈、globe.html、城鎮。
