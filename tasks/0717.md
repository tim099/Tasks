# TASK-0717 — Blockside：著火 —— 希臘火點燃木材、照材質易燃性延燒、船員滅火（含演出）

> `feature` / `normal` / `in_progress`　開單：kaguya　參與：kaguya(dev)、Tim(qa)

## 驗收標準

- [ ] 希臘火打到木船殼／甲板 ⇒ 潑開範圍裡易燃的格起火；鐵甲、銅皮、鍋爐（flammable 0）不起火
- [ ] 火照鄰格材質的 flammable 延燒；燒夠久的格被燒掉（體素破壞），吃水線以下燒穿會進水
- [ ] 帆也會燒（Tim：「可以嘗試真的燒掉帆的演出 出現邊緣焦黑以及逐漸燒掉」）：起火點往外燒、燒過的地方破洞、洞的邊緣焦黑，帆的血量跟著掉
- [ ] 船員會去滅火：有人被派到火邊、火勢因此變小／熄滅；熄掉的格留下焦痕
- [ ] 看得到：火焰、黑煙、火光；HUD 新聞報起火／撲滅
- [ ] 決定性：同一個種子同一局；沒有希臘火的對局（seed 3 預設對局、ship=napoleon,virginia）dump 跟改之前一位元不差
- [ ] 參數在 config/game.json fire 那一節（validate 過）；匯入檢查／srccheck／build 全綠
- [ ] Tim 實機看過（含持火號 vs 木船）

## 任務描述

Tim 2026-10-18：「可以趁現在空檔 加一下著火效果(希臘火可以讓木材起火) 火會延燒 然後船員會去滅火」「著火效果直接做在Blockside專案」「這個要展示出來」（放進 kaguya 的宣傳影片）。

現況（dev c0c3b71）：28_fire.js 的希臘火只直接燒人、燒帆與細繩，⛔ 不留燃燒點、不延燒（檔頭：Tim「點燃機制我也還要想(還要搭配滅火) 可以先直接給予傷害就好」）。
材質表 config/game.json materials 已有 flammable（橡木 0.5、松木 0.8、柚木 0.3、鐵／銅皮／鍋爐 0）—— TASK-0616 留的欄位，還沒有人讀它。

這一張做：
1. 點燃：希臘火潑開的範圍裡，易燃的格（照那一格的材質 flammable）起火。
2. 延燒：燒著的格照鄰格材質的 flammable 往外燒；燒久了那一格燒掉（體素破壞，照既有的去格路徑 ⇒ 吃水線以下照樣進水）。
3. 滅火：船員去滅火（照木匠／抽水那一套派工：走到火邊、打水），撲滅的格留下焦痕。
4. 演出：火焰、黑煙、火光；HUD 新聞與詳細資訊。
5. 決定性：一律走 rngMake；同一個種子同一局（反向對照：沒有希臘火的對局 dump 一位元不差）。
6. 參數進 config（fire 那一節）＋後台滑桿慣例。
