# TASK-1325 — 《Blocksail》1666 特許公司母港選址：VOC 總行、各港分公司與遠洋補給候選

> `subtask` / `normal` / `in_progress`　開單：Sirius　參與：ridge-001(dev)

## 驗收標準

- [ ] 交付 1666 年母港候選表：公司、港名、總行／商會／區域分公司角色、史料或取捨、開場城鎮 id（若存在）。
- [ ] VOC 確認第一批母港與分公司順序，另外列出首條東印度航線所需的補給港和亞洲交易節點；每一站有可核對的角色。
- [ ] 核對候選城的城鎮範圍、勢力與年代、開場、港口及必要航段雙向可達性，將可用和缺資料的分開，排出最小補齊批次。
- [ ] EIC、WIC 至少各列一個總公司母港與一個分支候選；列清西班牙貿易局與護航船隊的港口角色，候選與已拍板分開。
- [ ] 反向對照：只有歷史據點、沒有實際城港或遠洋航段的候選在表上明確標為待補，不能列入可啟用母港。

## 任務描述

Tim 2026-11-19：「城鎮資料可以先開單(選擇要做為公司母港的城鎮)」。母單 TASK-1096，供 P5（TASK-1206）選擇各公司可放入 1666 開場的母港和分公司港。Tim 等選址與補資料順序。本單先選址、讀資料、確認航線需求，城鎮繪製、烘焙與公司實裝由相應交付另外安排。

第一優先 VOC：阿姆斯特丹是總公司母港候選，已有城、港與集散地；米德爾堡是澤蘭商會母港候選；巴達維亞是亞洲營運中心的分公司母港候選。核對開普補給站和至少一個亞洲交易節點（如馬六甲或依史料選更合適的港）。補給站與交易節點各自有理由才升為分公司，首輪不追齊六個荷蘭商會。

第二順位：為 EIC 核對倫敦與一個 1666 年適合的亞洲分支候選；為 WIC 核對歐洲及大西洋分支候選。西班牙貿易局及王室船隊另標塞維亞、加的斯的管理／出港角色及哈瓦那的集結角色。未定分支保留史據與地圖缺口，不預設啟用。

讀數入口：Blocksail docs/CHARTERED_COMPANIES.md、docs/TRADE_NETWORK.md §13、node tools/charter_ports.cjs。現開場有阿姆斯特丹和倫敦，米德爾堡、巴達維亞、開普站、馬六甲、埃爾米納及威廉斯塔德尚未進開場。區分城鎮母港、貿易節點、普通交易港與補給港。逐段航程取實際烘焙導航，缺軌就直接記缺軌。
