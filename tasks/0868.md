# TASK-0868 — 《Blockside》碰撞與觸礁音效：更沉悶、木頭與金屬兩種合成音、照撞擊力道變

> `improvement` / `normal` / `in_progress`　開單：summit　參與：summit(dev)

## 驗收標準

- [ ] 船撞船、觸礁、擱淺的聲音照撞到的材質分兩種：木頭一種、金屬（鐵甲、黃銅這種硬金屬）一種；兩艘不同材質相撞兩種都聽得到
- [ ] 比現在沉悶：低頻為主、高頻少（試聽集的頻譜重心與 1 kHz 以上能量佔比，改前改後並列）
- [ ] 照撞擊力道變：撞船照撞擊動能、觸礁照速度與海底硬度 —— 輕碰是悶悶一聲、重撞比較大聲、比較長、比較低（試聽集分好幾檔）
- [ ] 全部現場合成（Web Audio），不用音檔
- [ ] 只是聲音：不抽模擬的亂數、無頭 dump 跟改之前逐位元組相同
- [ ] Tim 在遊戲裡聽過

## 任務描述

Tim 2026-10-23：
- 「接下來想優化一下船隻碰撞音效 希望可以更沉悶一些 另外木頭跟金屬材質可以用兩種音效(都用合成音)」
- 「不直接用音檔 且根據撞擊力道變化音效」
- 「觸礁也是」

現況（summit 讀 Blockside dev 06cdd71）：
- 碰撞（31_sailing.js collidePair／collideFine 的「兩艘擦撞」、ramHit 撞擊事件開頭）、觸礁（32_ground.js groundHit／groundPunch）都放 sfx('crack')。
- crack ＝ 雜音過 900～1800 Hz 帶通、0.35 秒（02_audio.js），跟砲彈打中木頭同一個聲音，所以很脆；音量只差固定的 1／1.2／1.6，跟力道、材質無關。
- 材質表（config materials）kind：wood（oak、pine、teak）／metal（iron 硬度 32、brass 20、copper_sheath 1.1、boiler 1.5）／other（glass）。銅包皮是木船底下的一層薄皮。
