# TASK-0908 — 《Blocksail》建築建造演出（獨立功能，之後再串施工進度）：照雕刻的施工階段 meta 逐件長出建築；沒有 meta 的照自動算法（由低到高＋子模組順序）；演出中搭腳手架、堆建材、打地基

> `feature` / `normal` / `in_progress`　開單：kotoko　參與：kotoko(dev)

## 驗收標準

- [x] 帶施工階段 meta 的建築：給進度 0～1，每一件照 meta 出現；10／25／50／75／100% 各一張圖看得出順序（先地基、牆身由下往上、屋頂、門窗與小物最後）　✅ kotoko 2026-10-25
- [x] 沒有 meta 的建築：自動算法照高度由低到高，有子模組（關聯、層名、kind 這類 meta）的照它排先後；現有 townkit 每一棟都演得出來，不報錯　✅ kotoko 2026-10-25
- [x] 演出中有施工裝飾：地基（開挖或墊層）、腳手架、建材堆（磚、木材等），跟著進度出現、移動、撤掉　✅ kotoko 2026-10-25
- [x] 不接經濟系統也能看：有一個獨立入口能挑一棟、拉進度或播放　✅ kotoko 2026-10-25
- [ ] 反向對照：進度 1.0 時跟現在的成品逐格相同、施工裝飾 0 格；不開演出時城鎮模式的畫面與效能跟改之前一樣
- [x] 文件：施工階段 meta 怎麼寫、沒有 meta 時自動算法怎麼排、施工裝飾的規則　✅ kotoko 2026-10-25

## 任務描述

Tim 2026-10-25：「可以嘗試給目前的建築加上建造演出（先做獨立功能 之後在串接上去）動畫概念是在雕刻作品中標記meta（表示建造%數多少時蓋好該部分）然後也可以有一套自動算法去演出完全沒有meta的建築建造過程（從低到高 以及一些子模組meta來判斷順序） 演出過程中可以搭腳手架或其他裝飾（磚頭 木材等建材堆積 打地基等）」

已有的：
- 施工階段 meta 的格式 crest-001 在 TASK-0893 #2 設計過、寫進 TOWN_BUILD（關聯帶 build0／build1、sweep: z；數字〔設計〕：牆身 0～0.6、屋頂 0.6～0.9…），程式這側一行都還沒有。fr、carib、roman 中高密度住宅已經帶這組 meta。
- 施工進度本身（工量、建材、缺料停工）在 TASK-0891（gura）、TASK-0894 —— 本單先不接，做成給一個進度 0～1 就能演的獨立功能，之後再串。

範圍：照 meta 的演出、沒有 meta 的自動算法、腳手架／建材堆／地基這些施工裝飾、一個不靠經濟系統也能看的入口。點選建築的選單另一張單（演出按鈕在那邊接）。
