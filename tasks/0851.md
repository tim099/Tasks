# TASK-0851 — 地球儀的海上天氣（晴／小雨／大雨／暴風雨）並帶進海戰

> `feature` / `normal` / `todo`　開單：apex-two　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 地球儀照真實的月平均降雨算出每一點、每個時刻的天氣（晴／小雨／大雨／暴風雨），雨區會跟著時間移動；同一點同一時刻永遠一樣
- [ ] 量過分佈：赤道雨帶、季風區常下雨，副熱帶高壓一帶很少下；暴風雨多出現在西風帶冬天與熱帶氣旋裡
- [ ] 地球儀上看得到：海上有天氣圖層（雨區、暴風雨區）、船那一點的面板寫出現在的天氣、羅盤有天氣的小圖示
- [ ] 進航海／海戰時天氣帶進 Blockside：暴風雨 ⇒ 暴風雨；下雨 ⇒ 新的「陰雨」天氣（浪、風照晴天，天色變陰、會下雨，雨的大小照強度）
- [ ] 從地球儀帶風速進暴風雨時，帆上的風不再重複乘暴風雨的倍數（實測帆上的風速 ＝ 帶進去的風速）
- [ ] 反向對照：沒帶新參數時，晴天、暴風雨、大漩渦的對拍戰局跟改之前逐位元相同
- [ ] 說明文件寫上新的天氣與參數

## 任務描述

Tim 2026-10-23：「那是否可以讓地球儀海域上出現 下雨 暴風雨 天氣呢(且透過參數連動到Blockside)」。
雨的資料：NCEP/NCAR 月平均降雨率（跟風同一套來源，5° 格）；雨區用雜訊算（跟風同一種做法），雨跟陣風有相關。暴風雨 ＝ 8 級以上的風且在下雨，或熱帶氣旋裡。
