# TASK-0867 — 《Blocksail》遊戲裡換玩法的架構：不重載就能在航海、城鎮（之後海戰）之間換；第一個用例 航海靠近城鎮 ⇒ 停靠 ⇒ 城鎮模式、城鎮 ⇒ 出航

> `feature` / `normal` / `in_progress`　開單：summit　參與：Tim(qa)、summit(dev)、apex-two(dev)

## 驗收標準

- [ ] 遊戲裡換玩法不用重載頁面、不回地球儀：海圖塊、城鎮、我艦（位置、船頭、速度、損傷、船員）照舊，只換玩法規則；換之前、換之後各自的規則都對（每一格讀的規則、開局才讀的規則都照新玩法）
- [ ] 每種玩法可以宣告「進來時做什麼、離開時做什麼」，換玩法的入口只有一個；加一種可以換進來的玩法只要寫那兩件事，不用改入口
- [ ] 哪幾種玩法之間可以換、要什麼條件是一張表；不准換的說得出原因（例：離城太遠、船在動、正在開戰）
- [ ] 航海 ↔ 城鎮（第一個用例）：航海靠近有停靠處的城 ⇒ 多一顆「停靠」鈕 ⇒ 船自己停進停靠處、兩錨都下、換成城鎮模式（建築模式可以開）；城鎮模式按「出航」⇒ 起錨、換回航海、從停靠處開得出去
- [ ] 回地球儀時地球儀知道現在是什麼玩法、停在哪座城（從城鎮模式回去 ⇒ 地球儀上是停靠狀態；從航海回去 ⇒ 船在實際開到的位置）
- [ ] 之後接海戰用得上：寫下航海 → 海戰要多做哪幾件（生敵艦、判勝負、海戰的鍵），本單不做海戰
- [ ] 反向對照：不換玩法的對局（舊網址直接開 pve／sail／town）dump 跟改之前逐位元組相同；換過一輪再換回來的城，規劃與存檔的操作跟沒換過一樣
- [ ] Tim 在遊戲裡從航海停靠進城、再出航一輪

## 現況（summit 2026-10-23 讀 Blockside dev 150500c）

玩法（MODE，04_state.js）在載入時照網址 ?mode= 定下來，一場裡不會變。地球儀的「航海」「進入城鎮」是兩次不同的網址（globe.html battleIn ⇒ iframe 重載 battle.html），換玩法 ＝ 回地球儀再進一次。

玩法規則（04_modes.js MODE_RULES）的 22 個讀取點分三類：

| 類別 | 規則 | 換玩法時 |
|---|---|---|
| 每一格都讀 | ui（61_layout uiLayoutName）、battleKeys（71_ctrl）、stopOwn（31_sailing sailShip）、othersAct（50_sim、40_crew、41_crew_art）、judge（61_hud checkEnd）、chart（63_chart chartReady）、fpLock（81_fps）、town（87_townbuild twbOk／twbKey／twbFrame） | 換掉 MODE 就跟著變 |
| 開一場時讀一次 | fleet（52_fleet fleetSpec）、origin（spawnSteps）、autoFire（70_flow resetSteps）、hint（startSteps）、myReload（10_ship makeShip、52_fleet playerTake）、build（82_build bldEnter）、observe（86_inspect inspEnter） | 要變成「進這個玩法時做的事」 |
| 載入時讀一次 | 87_townbuild 的 🔨 綁定與選單（底部那個立即執行的區塊，只有載入時是 town 才綁）、TWB.town（只從網址 ?town= 拿）、prefs 存的 MODE（69_prefs） | 要能在遊戲裡打開／關掉 |

缺的資料與回報：
- 航海模式下 Blockside 不知道每座城的玩家停靠處（位置、船頭、進港航道）—— 那份在地球儀的範圍層（areas 的 dock，TOWN_BUILD §3.3），要從外面那一頁給（新的一則 host 訊息，或照城鎮那樣按需要問）。
- 回地球儀（hostBack／battleOut）只回報船在哪，沒有「現在是什麼玩法、停在哪座城」。

## 做法的方向（動工前再跟 Tim 對）

1. 換玩法只有一個入口（例：modeSwitch(到哪一種, 理由)）：檢查表上准不准 ⇒ 舊玩法的「離開」⇒ 換 MODE ⇒ 新玩法的「進來」⇒ 重算介面配置 ⇒ 通知外面那一頁。
2. 每種玩法一份「進來／離開」：城鎮 = 下錨、鏡頭框城、🔨 可用、跟外面要這座城的規劃；航海 = 起錨、鏡頭跟船、小地圖；海戰（之後）= 生敵艦、判勝負、海戰的鍵。開局才讀的那幾條（上表第二類）搬進「進來」，第三類改成在「進來」時綁、「離開」時拆。
3. 准換表：航海 → 城鎮（離某座城的停靠處夠近、船慢到某個速度以下）；城鎮 → 航海（隨時）；其他先不准，說原因。
4. 停靠怎麼「自己停進去」⇒ 待 Tim 定（見下）。

## 動工前要 Tim 定的

- 「船會自動停靠」：(a) 照進港航道自動開進去（看得到船開過去，要幾十秒）／(b) 短暫淡出淡入、直接擺到停靠處 ／(c) 其他。
- 「靠近城市」多近算：停靠處幾公尺內、或城鎮範圍裡。
- 海戰之後怎麼接：航海裡遇到敵艦換成海戰、打完換回航海，是不是同一個方向（本單只留接口）。
