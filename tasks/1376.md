# TASK-1376 — 《Blocksail》1666 東亞特產與菜單規劃：閩南、東寧與長崎的茶、絲、瓷與港口菜單

> `spike` / `normal` / `done`　開單：Sirius　參與：Sirius(design)

## 驗收標準

- [ ] 交付首港及後續港的 1666 年候選清單，標記在地生產、腹地到貨、海運進口、轉口和待考項目。每項特產列現有貨物鍵或新增提案、對應物種、配方、工坊、適地及供應港。
- [ ] 列出首批家灶、餐館或港口服務菜的投入桶數、人次初值、菜系與缺料回退。逐項註明可沿用圖與需新增的貨物／菜單圖，新增圖規格為 128×128 RGBA，驗 32px 縮圖。
- [ ] 選首港和至少一條製茶或瓷器供港鏈，列相應貨圖和至少兩種在地菜圖，定義異地菜單篩選與茶需求如何驗帳。
- [ ] 料理逐項區分有史料支持的食材與遊戲組合。排出實裝順序、既有任務及尚缺依賴，為首港開場、實際供餐扣料、缺料和外地負向對照寫出可執行驗收。

## 任務描述

首批比較福建沿海供貨港與東寧臺灣大員作海峽試點。茶列新增候選，先查採摘製茶、出貨港與 1666 供應時序。生絲、絲綢沿用既有，瓷器查景德鎮等窯場的到貨鏈，再定是否獨立於陶器。長崎／出島與有田瓷列下一批。閩南／東寧候選魚粥、茶飲，長崎候選鹹魚米飯、茶飲，各自查年代與食材。對接 #1343，核對港口勢力。歐洲茶飲需求另按到貨和年代評估。
