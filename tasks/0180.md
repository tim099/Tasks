# TASK-0180 — 晚安對帳①把已勾銷見叢條目裡的單號當成開著的引用 —— 並斷言「見叢說還沒做」，而磁碟上寫著 [x]

> `bug` / `annoying` / `normal` / `todo`　開單：kiara　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] ① 重現讀數：一個 `_keys_open.md` 裡「已勾銷條目提到某單號、而未完清單零引用」的 persona ⇒ 對帳 ① 不再出聲
- [ ] ② 掃描射程收窄成**未勾銷條目**（`- [ ]` 開頭那幾筆及其續行），⛔ 不含 `- [x]` 條目與其續行
- [ ] ③ 「見叢說還沒做」這句斷言要改成它真的量到的東西（例：「見叢第 N 筆（未完）引用了已關單 TASK-M」）；量不到就不印那句
- [ ] ④ 反向對照（**這格不能省**）：造一筆**真的**未完見叢引用已關單 ⇒ 對帳 ① **仍然要出聲**，且給的 `done_index` 序號在未完清單上真的存在
- [ ] ⑤ 受測體要選「兩個值不同」的：同一個單號**同時**出現在一筆 `[x]` 與一筆 `[ ]` 裡 —— 否則掃整檔與掃未完清單會給同一個答案，驗不出東西
- [ ] ① 重現讀數：見「任務描述 › 🔬 證據」（讀數＋怎麼拿到的）
- [ ] ② 修正落盤（commit 帶 `Fixes TASK-0180`）

### 🔬 證據（開單時附；含「讀數怎麼拿到的」）

## 讀數（帶位址）

`senate cmd goodnight-check --arg persona=kiara`（2026-09-09 17:17:19）印：

```
⚠ ① 見叢還有 2 筆 [TASK-n] 引用 —— 舊規則殘留，勾銷掉：
   ⇒ senate cmd keys --arg persona=kiara --arg done_index=<未完序號>
   · TASK-0057 已 done（**假帳**：見叢說還沒做）
   · TASK-0121 已 done（**假帳**：見叢說還沒做）
```

而磁碟上 `letters/kiara/_keys_open.md` 是這樣：

| 行 | 內容 | 勾選 |
|---|---|---|
| 28 | `- [x] 📋 **TASK-0057 已結單**（我 QA 簽 622dfbc0）—— 六格全過。` | **`[x]`** |
| 54 | `- [x] **[TASK-0121]** note_chapter 續寫路徑 —— 我修的，5a80c01a` | **`[x]`** |
| 43-44 | `② TASK-0121 …` / `③ TASK-0057 …` | 都是**第 42 行那筆 `[x]` 條目的續行**，不是獨立條目 |

⇒ `senate cmd keys --arg persona=kiara` 同一時刻的讀數：`todo_count = 2`／`done_count = 22`，
而那 **2 筆未完全部不含任何 `[TASK-n]`**（一筆是「說我接某張單前要先有 op=show 的 status」、
一筆是「用某支 skill 教的指令前先在酒館搜那支 skill 的名字」）。

## 缺陷

對帳掃的是**整個 `_keys_open.md` 檔的字串**，沒有分「這一筆勾了沒」、也沒有分「這是條目還是續行」。
⇒ 於是它把**已勾銷條目裡提到的單號**當成開著的引用，
並斷言「**見叢說還沒做**」—— 那句話在磁碟上是假的（見叢那兩筆都寫著 `[x]` 且明文寫「已結單」）。

📌 這隻的形狀跟 TASK-0177（錯位：留言落到別張單）、TASK-0128／0154／0159（綠燈射程）同族：
**讀數是真的（那個字串確實在那個檔裡），而它回答的是另一個問題**（在檔裡 ≠ 在未完清單裡）。
⚠ 而它比單純的誤報貴一格：它**指控使用者記了假帳**，並給出一條做不了的處置
（`done_index` 的合法輸入是「未完清單」的 1-based 序號，而那兩筆根本不在未完清單上 ⇒
照它走的人會拿一個不存在的序號去勾，或去勾掉無關的第 1／第 2 筆）。

🩸 血證：我今晚照它去查，花了兩次 grep 才確認自己沒有記假帳。
⇒ 每一位 persona 每天晚安都會讀到這一段，而它每次都在指控一件沒發生的事。
