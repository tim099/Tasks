# TASK-0803 — 模擬步長⑦：海圖模式 —— 跨洋高倍數航行用簡化模型（照 sb_sim.js），遇敵切回真實航行

> `feature` / `normal` / `todo`　開單：erina　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 海圖模式的航行模型：照真實航行量回來的帆速曲線、轉向、加減速（數字附量法與讀數，像 sb_sim.js 那樣）
- [ ] 海圖模式 ⇄ 真實航行切換：位置、航向、航速、船況照實帶過去（走 TASK-0709 的狀態進出）
- [ ] 反向對照：同一段航線（同風、同洋流）真實航行 ×1 跑一次、海圖模式跑一次，終點、時間差在寫明的容許範圍內
- [ ] 讀數：海圖模式每模擬小時幾 ms、跨洋一趟（例 4 週）要幾秒真實時間

## 任務描述

TASK-0796 建議 ⑥；Blocksail docs/ROADMAP.md §2.3「尺寸與航行」：地球照真實尺寸、航行時間壓縮；航行兩種模式 ——「真實航行」（就是核心在跑、可以加速）與「海圖模式」（純航行，只看風向、天氣、洋流，時間壓縮得很快）；海圖模式遇到要打的 ⇒ 先切回真實航行、再無縫進入戰鬥。

真實航行做完 TASK-0797～0802 估到約 ×60（TASK-0796 第 4 節，推的）；跨洋（真實 3～5 週）要再高好幾個數量級 ⇒ 這一層不跑格子、不跑船員：
- 前例：Blockside 的 2D 策略沙盒（sb_sim.js，TASK-0551）—— 一步 0.1 秒、照抄遊戲的帆速曲線、逆風、加減速、轉向，數字從遊戲量回來。
- 交接：TASK-0709（核心 API spike：戰前狀態注入、戰後狀態輸出）已經做過「狀態進出」；海圖模式 ⇄ 真實航行要用同一套。
- 風、洋流的資料是 ROADMAP §2.4（季節的風、洋流與天氣）。
動工前跟 Tim 確認：倍數範圍、海圖模式畫面長什麼樣、遇敵的判定距離。
