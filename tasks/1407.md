# TASK-1407 — 《Blocksail》地形編輯器：遊戲內建工具直接改高度格並輸出

> `feature` / `normal` / `todo`　開單：summit　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 遊戲內建的地形編輯工具：在地球儀（或遊戲畫面）上用筆刷改高度（抬高、壓低、抹平、設成某高度、斜坡），改完當場看得到
- [ ] 存檔只寫碰到的檔與它上面幾層，寫出來的檔 hgrid_check 照樣過（接縫、逐位元組）
- [ ] 改到細層邊界那一圈 ⇒ 隔壁的檔自動建出來，邊界上沒有一階
- [ ] 可以在沒有細層的地方加細到更細的一層（例：港口 4.4 m）
- [ ] 改過的東西存在編輯層、底層重烘之後還在；可以還原、看差異
- [ ] 反向對照：沒動到的檔逐位元組不變

## 任務描述

Tim 2026-11-28：「希望格式方便地形編輯器（可以直接編輯地型高度 遊戲內建工具可以調整並輸出）」。

高度格的格式已經照這個設計（docs/HGRID.md §5）：編輯 ＝ 改解開的整數陣列、只重寫碰到的檔與上面幾層的平均；要加細 ⇒ 新檔 ＝ 上一層切出來的值（曲面不變）；細層覆蓋範圍最外面那一圈要等於上一層切出來的值。編碼器 JS 裡就有（BSW.hgrid.encode），跟 Python 寫的逐位元組相同。
等格式定稿（高度格定稿那一張）再做。
