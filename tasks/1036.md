# TASK-1036 — 《Blocksail》家族變成統治者階級：綁定社會階層，有人口、有消耗

> `feature` / `normal` / `backlog`　開單：trailhead　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 每一家 NPC 家族在母港有一層「統治者」人口，算進那座城的人口
- [ ] 統治者照那一層的消費等級吃飯、用日用品、買奢侈品，錢從家族金庫出、付給城鎮（同其他階層）
- [ ] 城鎮介面的社會階層看得到統治者那一層（人口、吃了什麼、收入）
- [ ] tools/money_report.cjs 起始檔兩年對帳全過；跟現在比讀數（家族存款、城鎮金庫、物價與缺貨）寫在單上
- [ ] 反向對照：統治者階層關掉 ⇒ 兩年模擬跟改之前逐位元組相同

## 任務描述

Tim 2026-10-27：「目前我在想讓家族變成統治者階級(綁定階級 因此也會有人口與消耗)」—— 先開單，還沒動工、規格等 Tim 想好。

現況（Blocksail 試驗分支 trailhead/money-tax，TASK-1007 那一串）：
- NPC 家族（kind npc）只是一個金庫＋名下的建築，沒有人口、不吃飯；錢只靠「家族花錢」（FAM_SPEND：存款超過 20,000 那一截每天 1% 買奢侈品、佳餚，買不到付給鎮民當家僕）和投資、造船流回城裡。
- 社會階層（STRATA：受薪勞動、富裕商業、教士）有人口、照那一層的消費等級吃飯與買奢侈品；富裕商業、教士那一池當家族經營建築（kind strata）。
- 量過的問題：錢會堆在家族與富裕商業手上（加拉塔兩年：朱斯蒂尼亞尼家 29,044、富裕商業 33,043，城鎮金庫才兩萬）。

想法：家族綁成一個社會階層「統治者」—— 家族成員是母港的一層人口，照那一層的消費等級吃、用、買奢侈品，錢從家族金庫出；家族的錢自然花回城裡，不用另外抽一筆。

要 Tim 決定的：統治者一家幾人（固定、照名下建築、照財富）；吃哪幾級、奢侈品一籃多少；家族花錢那一條留不留；統治者要不要有自己的建築需求（宅邸、僕役）。
