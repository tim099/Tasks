# TASK-0315 — 每日結算（結帳／保管費／轉券／匯率）的觸發搬到 Senate Server —— 不再依賴 Unity Editor 開著

> `feature` / `normal` / `done`　開單：gura　參與：gura(dev)

## 驗收標準

- [x] ① Senate Server 在 UTC 跨日之後自己跑一次每日結算（結帳 → 保管費扣繳 → 轉券 → 匯率每日版本），**Unity Editor 沒開也照跑**　✅ gura 2026-09-28
- [x] ② 一天只跑一次：跑過的日子落盤，Server 重啟不重跑；那天 Unity 已經跑過（過渡期）也不重跑　✅ gura 2026-09-28
- [x] ③ 結算公告照舊貼上酒館（同一則，含扣繳／轉券／匯率），寄件人仍是酒保　✅ gura 2026-09-28
- [x] ④ Unity 那側不再觸發每日結算 —— 兩邊不會各扣一次、各貼一則　✅ gura 2026-09-28
- [x] ⑤ 反向對照：扣繳那一步失敗 ⇒ 不記成「跑過了」、稍後再試；公告失敗 ⇒ 錢照上表已發生、不重跑扣繳　✅ gura 2026-09-28

## 任務描述

Tim 2026-09-28：「觸發直接綁定在 Senate 端（不要透過 Unity）」＋ 選「搬扣繳觸發到 Senate（另開單）」。
TASK-0278 ⑧ 當初把扣繳的計算搬到 Senate，但**觸發**（判跨日＋派一次＋貼公告）留在 Unity daemon，並寫明「觸發搬走是下一張單」——就是這張。

現況（2026-09-28 量）：今天的保管費公告 00:46 UTC 才發（Editor 開了才跑）；酒館寫入端已是 `server`，所以「貼公告只能在 Editor」那個理由已不成立。
⚠ 已知邊界：Senate 這條發文路**沒有 Discord 轉發**（Editor 的 AppendMessage 才有），搬過來之後保管費公告不再轉 Discord。

誰在等：Tim（TASK-0272 ② 的每日匯率版本也掛在這一趟上）。
