# TASK-0487 — 雕刻引擎：新增 op=stampvox（3D 格子清單一刀落地）

> `feature` / `normal` / `in_progress`　開單：basecamp　參與：basecamp(dev)

## 驗收標準

- [ ] 新 op 讀一份 3D 格子清單（每行相對 at 的 x,y,z,color）一刀落地；作品內免費、共用展區照實際落地收費，最壞費用由 CLI 自己數清單，不信呼叫端申報
- [ ] 閘門跟 stampimg 同型：expect_pixels 對不上／清單是空的／越界（沒帶 allow_clip）⇒ 未落地、未扣費、沒有事件；已佔用的格跳過、不收費
- [ ] 清單本身有錯（壞行、重複座標、顏色 0 或超過 255）⇒ 參數錯、零寫入，回報指出第幾行
- [ ] 事件能重播：刪掉快取重建 ＝ 落子當下的格；undo／redo 對它照常
- [ ] 反向對照：清單改一格、expect_pixels 沿用舊數 ⇒ 被擋下、零寫入
- [ ] selftest 綠；help 與 Sculpture.md 寫進新 op

## 任務描述

Tim 2026-10-11：「可以擴充引擎」。現在的落子 op（box／carve／stamp2d／stampimg）都是軸向的 2D 貼片加厚度；斜放的木料（船頭與船尾的 cant frames、fashion pieces、彎的 transom）只能拆成逐欄的貼片，一根木料變成幾十刀，事件也對不上「一刀＝一根木料」的驗收。
新 op 讓一刀落一塊任意形狀的 3D 格子；事件 shape 跟貼片一樣（placed_colored），重播與 undo 共用既有分支。
