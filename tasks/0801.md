# TASK-0801 — 模擬步長⑤：航行時的固定開銷 —— 局勢檢查沒受損就跳過結構那幾項、閒著的船員不逐步走

> `subtask` / `normal` / `todo`　開單：erina　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 局勢檢查：沒有格子被打掉時跳過結構那幾項；照時間的 tick 照舊
- [ ] 閒著的船員不逐步走、事件喚醒
- [ ] 戰局不變：交戰對拍（60 Hz）逐位元相同；航行 120 秒的狀態雜湊前後相同
- [ ] 反向對照：在航行中打掉一格（`__game.dig` 之類），下一次局勢檢查照樣做結構那幾項、該掉的模型照掉
- [ ] 讀數：航行每模擬秒局勢、船員各幾 ms，前後對照

## 任務描述

TASK-0796 建議 ③④。航行時照秒數跑、不會因為降步長變便宜的固定開銷：

- **局勢檢查**（32_hull.js survey，每半秒一次、一次約 3 ms／艘）：模型腳下、桅、繩與帆的錨、浮空的繩、船員腳下這幾項只跟「格子被打掉」有關 ⇒ 上次之後沒有格子被打掉（`sh.rbin` 空、格數沒變、沒有新的 blow）就跳過；吃飯、抽水、木匠、效率這些照時間的 tick 照舊。
- **閒著的船員**（40_crew.js stepCrew，每艘 357 人每步都走一遍）：沒在走、沒在做事的不逐步走，事件喚醒（被叫去補位、開火、落水…）。

倍數越高，這兩塊越顯眼（照秒數跑 ⇒ 每真實秒跑的次數 × 倍數）。
