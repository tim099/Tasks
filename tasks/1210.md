- [x] 手動試過幾種策略（照舊、城鎮只跑集貨、混合的幾種門檻），讀數寫進文件，最後的算法照讀數定　✅ Sirius 2026-11-05
- [x] 已知答案：沒跑夠不換、虧本的幹線退回集貨、同一個主人留一支集貨（若採用）、錢與貨守恆　✅ Sirius 2026-11-05
- [x] 反向對照：開關關掉 ⇒ 收集器 digest ＝ 改之前　✅ Sirius 2026-11-05
- [x] 兩年讀數配雙胞胎：TRADE_NETWORK §9.3 指標、城鎮金庫、巴拉科阿的可可、一年換幾次方針、船隊每天花的計算時間　✅ Sirius 2026-11-05
- [ ] 補缺口方針取代原本的運糧（food）：糧食、生產原料（例如鑄幣廠缺銅）缺到門檻 ⇒ 城鎮的船照「保供價」（不照賺不賺）去附近買、補到上限，同一趟照跑別的貿易；關掉 ⇒ 照舊運糧
- [x] 造船的試算照主人錯開（不擠在同一天）；量單日最多花幾毫秒　✅ Sirius 2026-11-05
