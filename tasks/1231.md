# TASK-1231 — 《Blocksail》海圖「跟海斷開的低地不畫水」：河、湖一律當水體（塞維亞港口那段河一陣有水一陣沒有）

> `improvement` / `normal` / `todo`　開單：summit　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 河（挖回水的河道、內陸水的河）與湖在遊戲裡一律畫水，不被「跟海斷開的低地」遮掉：塞維亞港口那段河，船停在港口、鏡頭沿河往下游拉 3 km，水一直都在（含遮罩重建之後）
- [ ] 原本要遮的照樣遮：恩里基約湖那一帶（低於海平面的乾地）海面照舊不蓋上去
- [ ] 反向對照：拿掉水體標記 ⇒ 塞維亞那段照舊會被遮掉（證明是這次改的讓它有水）
- [ ] 沒有河、湖的海域畫面逐位元組不變（托爾圖加進場截圖對照）

## 任務描述

Tim 2026-11-06：「Blockside 判斷「跟海斷開的低地不畫水」時 是否可以讓河流是特例(河流應該都要有水) 且湖泊也一樣(等於直接標記為水體)」「可以先開成task」

**現況**（Blockside `src/js/63_bed_gl.js` `bedDryCalc`，TASK-0768、2026-10-21 起）：船周圍那個窗裡，8 m 一格照地面（城鎮整過地的那一份）判水格 h < 0，從「碰到窗外、沒有陸地的塊」的水格往裡淹；淹不到的低地 ⇒ 遮罩 ⇒ 海的著色器不畫 0 m 海面。原意是恩里基約湖那種低於海平面的乾地、水坑不被海面蓋住。

**咬到的**（TASK-1230 查到）：塞維亞港口那段瓜達基維爾河，遊戲裡一陣有水、一陣沒有（Tim：「河道上的水我有看過出現過一會 然後又消失」）。資料層有水（港口一排河寬約 120 m、h −10 m；遊戲 twbProbe 停泊點 −10 m）。河的上游是死路（挖到 37.40 為止）⇒ 港口那段只能從下游接到窗邊，窗裡下游只要有一格被判成陸（粗的遠景塊取樣、城鎮整地壓到河上……還沒查是哪一格）⇒ 整段變成跟海斷開的水坑、被遮掉。

**要注意的前提**：塞維亞、倫敦、阿姆斯特丹那幾段河不是內陸水（world/water/ 那一種），是 `tools/bathy_edits.json` 的 coast 切口（guadalquivir-*、thames-*、zuiderzee-*）挖回來、跟海同一個 0 m 水面的水 ⇒ Blockside 現在分不出「這裡是河」。⇒ 要嘛 Blocksail 產海圖塊時多帶一個「水體」標記（coast 切口裡、內陸水），要嘛 Blockside 照別的輸入判；湖（內陸水）照 Tim 的話一樣直接當水體。
