# TASK-0892 — 《Blocksail》模擬統計系統：每天收挨餓比例、人口、庫存、金庫與錢的流向 ⇒ 曲線＋圖表＋自己對帳（檢查經濟模擬用）

> `feature` / `normal` / `todo`　開單：gura　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 統計模組 `world/stats.js`：每天從城鎮帳＋那一天的讀數收一列（不改模擬本身）—— 每座城：挨餓比例（‰：沒吃飽的份數 ÷ 要吃的份數）、城鎮補的比例、人口、大人、失業、缺工、碼頭上、去碼頭／吸收回來、建築數／還在蓋的／今天蓋的、市場每種貨的庫存；錢：城鎮金庫、鎮民金庫、家族金庫（母港在這座城的）的餘額，與今天的流向（工資、鎮民買飯、家族賣貨、所得稅、資產稅、造價、鑄幣）；全世界：人口＋碼頭＋船上、錢的總數、鑄過多少
- [ ] 曲線查詢：照天數分桶（例 30 天）取平均／最後一天／加總，給工具與之後的介面用
- [ ] `tools/sim_stats.cjs`：起始檔照範圍層分區跑 N 天 ⇒ 印每座城的挨餓比例曲線（每月平均＋小走勢圖）、人口、金庫曲線、庫存變化最大的幾種貨；輸出一頁圖表（HTML，自己畫的 SVG，不靠外部套件）與 JSON
- [ ] 統計自己對帳：錢的流向加起來 ＝ 金庫的變化（每座城、每天）、全世界的錢 − 鑄的 不變、人 ＋ 碼頭 ＋ 船上 ＝ 前一天 ＋ 出生 − 死亡、庫存的變化 ＝ 產出 − 消耗 ± 買賣（市場那一格）；有一筆對不上就 ✗
- [ ] `tools/auto_check.cjs` 起始檔那一段改用統計模組（挨餓比例曲線取代「飢荒幾天」）
- [ ] 文件：統計有哪些欄、怎麼跑、圖怎麼看（docs 新一節）

## 任務描述

Tim 2026-10-24：「另外可以改成統計飢餓人口曲線（每天有多少%挨餓）」「可以做一套統計系統來檢查模擬功能」「包含貨物庫存量 金錢變化等」

起因：調節奏時拿「有幾天飢荒」比，一個人沒吃飽也算一天，會誤導（皇家港其實第 84 天就降到一天 1～2 人，卻被算成 362 天）；而且四年才看得到的問題（人口縮、錢沉進鎮民金庫）要看曲線才看得出來。

接在 TASK-0889／0890／0891（經濟循環、移民、自動建築）後面：統計只讀、不改模擬；工具與之後的地球儀介面都用同一套。
