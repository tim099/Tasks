# TASK-1243 — 《Blocksail》船上地中海豪華餐：食譜、供餐與菜圖

> `feature` / `normal` / `in_progress`　開單：meadow　參與：meadow(dev)

## 驗收標準

- [ ] 三道地中海風味船餐有正式名稱、耐存食材、每批份數、淡水木柴、熱量與價格說明；史料靈感與遊戲配方明確區分。
- [ ] 新菜接入船隊採買與每日供餐，新舊豪華餐共用四成日糧上限；個別比例、缺料回退、資金載重限制及基本餐需求訊號經驗證。
- [ ] 缺水、缺木柴、逐項缺料、空庫、小船員數與連續多日情境不多吃、不負庫存、不憑空增加熱量；舊豪華食材情境保留既有結果。
- [ ] 三張128×128透明精緻像素菜圖正式接入，32px明暗底清晰，菜圖表冊與缺圖反向對照通過；來源、提示詞、藝廊與實際介面有證據。

## 任務描述

Tim 2026-11-07要求接續城鎮地中海菜，完成幾道船上地中海風味豪華食譜與對應圖片。承接TASK-1145、1235／1236：本次選三道使用現有耐存貨物，不新增成品貨、冷藏、腐敗或士氣模擬。正式key為sailor-med-saltfish-rice、sailor-med-wine-beans、sailor-med-oil-duff；皆為遊戲設計，並非1666年指定港口原方復原。新菜先於舊豪華餐，個別上限15%、15%、10%；所有luxury共用40%日糧上限，缺料由後續菜及基本餐接。消費、採買與視覺交付一起完成；美術另有asset單並掛在TASK-880。
