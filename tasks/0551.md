# TASK-0551 — 《憲法號對轟》艦隊指揮官 AI（全局策略）＋ 2D 策略沙盒

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

範圍（Tim 2026-10-14「1～3 GO」）：第一段 ＝ 指揮官介面＋三種策略（一對一配對、集火、戰列）＋ 2D 沙盒（含批次勝率表）。我方友艦也聽我方指揮官；玩家對友艦下令之後再說（不在本單）。

- [ ] 每一方有一個指揮官，每隔幾秒照抽象的局勢（位置、航向、航速、血量、風、候補）替自己那一方每艘電腦的船下命令（打哪艘、站哪裡／航向、隊形、用哪一舷）；船照命令開船開砲。量得到每艘現在的命令
- [ ] 指揮官是一份獨立的程式，遊戲與沙盒載入同一份（不是兩份各寫一套）
- [ ] 三種策略各自做得出來、讀數上分得出來：一對一配對（不會三艘圍一艘、另一艘沒人管）、集火（全隊打同一艘，打掉再換）、戰列（排成縱隊跟著旗艦、全隊用同一舷）
- [ ] 主選單或細節設定選得到每一方用哪種策略（存檔、網址吃同一組）；我方友艦聽我方的，玩家自己那艘照舊自己開
- [ ] 2D 沙盒（一頁 HTML，放在遊戲同一個資料夾、不在展區顯示）：俯視畫出船、風、命令線（誰打誰、隊形位置）、射界；可以單場看、也可以批次跑同一組對手 N 個種子出勝率表（勝率、平均剩幾艘、打多久）
- [ ] 沙盒的數字從遊戲量出來（各船型的航速與轉向、齊射在不同距離的命中與傷害、多少傷害會降旗或沉），量法與讀數寫在單上
- [ ] 對拍：沙盒排出的策略名次，拿完整的遊戲跑幾場對照（同樣的對手組合），名次對得上；對不上的寫出差在哪
- [ ] 反向對照：沒有友艦的一對一（指揮官只有一艘船可管）縮圖 ?demo=75&still=1&cam=deck 跟改之前逐位元組相同

Tim 2026-10-14：「可以加一個艦隊指揮官 AI 用來制定全局策略；另外可以用一個更簡易的測試沙盒來模擬 AI 策略（不用真實物理模擬，只要知道如何指揮船移動、哪艘船對付哪艘敵艦、甚至組成戰列對轟等，沙盒可以純 2D 模擬指揮官會如何指揮）」⇒「1～3 GO；3 聽指揮官的，之後再想玩家是否能給指令（先不用）」。誰在等：Tim。

## 設計（ame 2026-10-14，開工前的分析）

### 指揮官只下命令，船照命令執行
- 指揮官（每一方一個）：每 2–5 秒想一次，讀抽象的局勢 —— 每艘的位置、航向、航速、血量（船殼、砲剩幾門、人剩多少）、風向、候補；輸出每艘一道命令：打哪艘、站到哪裡／朝哪個航向、隊形（自由交戰／戰列／撤退）、用哪一舷。
- 船（現在的電腦，ArtGallery js/50_sim.js、31_sailing.js、52_fleet.js）：目標從「最近的敵艦」換成命令指定的那艘；操舵多一種「保持在隊形的位置」。開砲、裝填、兩舷齊射、讓友船、讓開砲線照舊。
- 指揮官是一個獨立的 js 檔，遊戲與沙盒載入同一份；遊戲那側多一層轉接，把真的船翻成抽象的局勢。

### 第一段的策略
1. 一對一配對：照戰力把敵我配成對（避免三艘圍一艘、另一艘沒人管）。
2. 集火：全隊打同一艘（最弱的或旗艦），打掉再換。
3. 戰列：排成縱隊跟著旗艦，全隊用同一舷對轟。
（第二段：搶上風、橫切對方戰列、保護旗艦／傷艦撤退、玩家對友艦下令。）

### 2D 沙盒
- 一頁 HTML，放遊戲同一個資料夾、不在展區顯示（跟設定後台 TASK-0542 一樣）。
- 俯視 2D：船是有方向的長方形，畫命令線、射界、風向。
- 簡化的模擬：航速照風向的帆速曲線、轉向上限；射界兩舷正橫 ±26°；命中率照距離；船殼與砲數兩條血；降旗、沉沒、候補照遊戲的規則。
- 批次：例如「戰列 vs 配對」跑 200 個種子出勝率表。
- 校準是關鍵：數字從遊戲量（各船型航速轉向、每輪齊射在不同距離的命中與傷害、多少傷害降旗或沉）；最後拿幾場完整的遊戲對照名次。
