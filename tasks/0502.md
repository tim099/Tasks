# TASK-0502 — 雕刻：纜索（繩索）—— 綁在固定點之間、受重力下垂、可設顏色與粗細

> `feature` / `normal` / `done`　開單：basecamp　參與：kaguya(dev)

## 驗收標準

- [x] 作品可以定義有名字的固定點（名字 → 格座標），CLI 可以加／列出／刪；子作品的固定點從組裝件看得到（用關聯路徑指名，例 `主桅/main-yard-arm-port`），跟著那條關聯的 at／turn／mirror 換座標　✅ kaguya 2026-10-11
- [x] 繩索：兩端各是一個固定點（或直接給座標），可設顏色（palette index 或 #RRGGBB）、粗細、鬆緊；存在作品裡、不是 voxel，⛔ 不改任何 voxel　✅ kaguya 2026-10-11
- [x] 形狀受重力：拉緊的是直線；有鬆度的往下垂（中段 z 比兩端連線低）；同樣的輸入每次算出同樣的形狀；CLI 印得出每條的長度與最大下垂量（讀數，不只畫圖）　✅ kaguya 2026-10-11
- [x] 觀測：op=view 與觀測頁（SculptureViewerPage）畫得出繩索，顏色、粗細照設定；觀測頁可以開關繩索（跟關聯 toggle 同一種用法）　✅ kaguya 2026-10-11
- [x] 匯出：export obj 可以把繩索輸出成管狀網格（Tim 會匯進 Unity 看）　✅ kaguya 2026-10-11
- [x] 跟著部件走：把一條關聯的 at 移動（或關掉那條關聯）⇒ 綁在它固定點上的繩子端點跟著移動（或跟著不畫）；鏡像關聯裡的固定點翻到另一舷　✅ kaguya 2026-10-11
- [x] 反向對照：刪掉一個有繩子綁著的固定點（或改名）⇒ 那條繩子被報出來（壞掉的綁定），⛔ 不靜默消失　✅ kaguya 2026-10-11
- [x] 文件（Sculpture.md）寫用法；之後「綁帆」的端點型別留得出位置（本單不做帆）　✅ kaguya 2026-10-11

## 任務描述

Tim 2026-10-11（看憲法號 TASK-0478 時）：帆與索具不用 voxel 雕，另外做 ——
- 「繩索目前的想法是可以設定綁定點，然後本身受重力以及一定的物理影響彎曲，可以設定顏色與粗細」
- 「繩索可以綁帆 & Voxel 固定點」
- 帆之後另開（布料模擬：綁在幾個 voxel 上固定、可以跟線綁定、風＋重力；帆可以設定顏色甚至指定貼圖）
- 「可以先把纜索開成 task（相對簡單一些）」⇒ 本單只做繩索；綁帆等帆那張單。

用在哪：憲法號的 shrouds、stays、backstays（從船殼的 channels／船頭拉到桅頂）、yards 的 lifts／braces、bowsprit 的 bobstays 等 —— 兩頭常常在**不同的子作品**上（例：shroud 一頭在船殼的 channel、一頭在主桅的 masthead），所以綁定點要能跨關聯指名，部件換位置時繩子跟著走。

basecamp 這邊會配合的：之後做 yards、channels、cleats、bitts 這類部件時，plan.json 會多一份「固定點清單」（每點一個名字＋座標）；本單的固定點格式定下來之後，basecamp 照那個格式把點寫進各子作品。

設計建議（實作者可以改，改了寫理由）：
- 固定點是作品的資料（例：work 資料夾裡 anchors.json：名字 → 格座標），不是 voxel；從組裝件看時用關聯路徑指名（例：`主桅/main-yard-arm-port`），照那條關聯的 at／turn／mirror 換到組裝件座標。
- 繩索也是資料（例：ropes.json：兩端〔固定點名字或座標〕、顏色、粗細、鬆緊〔長度比或下垂量〕），掛在哪一件作品都可以（通常掛在組裝件）。
- 形狀：只受重力的話是懸鏈線，一般解析解就夠；「一定的物理影響」先做重力，風等帆那張單一起。
- 中間經過滑車／導索孔的多段繩（一條繩過幾個點）可以之後再做；先做兩端。
