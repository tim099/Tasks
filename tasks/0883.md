# TASK-0883 — 《Blocksail》家族系統基礎框架：開場每座城生出家族（＋玩家家族）、建築分給家族、家族與倉庫住進城鎮帳

> `feature` / `normal` / `todo`　開單：gura　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 開場每座城至少生出一個 NPC 家族（欄位照 FAMILIES.md：id、名字、資金、本家），玩家是 player 家族；同一份種子跑兩次，家族一模一樣
- [ ] 開場城裡的非公共建築（住宅、工坊、生產建築、倉庫）分給那座城的家族；公共建築、地標不寫主人（歸城鎮）；反向對照：教堂、市場、碉堡、地標一棟都沒被分出去
- [ ] 家族、資金、每座城的家族倉庫都住在城鎮帳裡（不另存一份）；存檔再讀回來，家族、資金、倉庫逐位元組相同
- [ ] 查得到：給家族 id ⇒ 資金、在哪幾座城有倉庫與庫存、名下建築（從建築的主人數出來）；給城鎮 id ⇒ 那座城有哪些家族
- [ ] 自檢：建築主人寫了不存在的家族、家族的本家是不存在的城 ⇒ 報出來
- [ ] 文件：FAMILIES.md 補「開場怎麼生家族、建築怎麼分」，Tim 看過

## 跟 TASK-0863 的關係（⛔ 不重做）

TASK-0863（kaguya）是家族 **v0 規則**：Blocksail docs/FAMILIES.md、world/prod.js 的家族倉庫（基礎容量＋倉庫建築）、放不下賣進市場、world/market.js 的價格曲線與手續費 —— 都已經在 main，tools/prod_sim.cjs 量過。

缺的是**家族本身**：2026-10-24 量的，Blocksail 起始城鎮帳（world/start/）的 families 是空的、建築清單 0 筆；FAMILIES.md §2「每座城至少一個家族（之後）」、§6「NPC 家族怎麼經營…（v0 不做）」。本單把家族生出來、把建築分出去、住進城鎮帳 —— 規則照 0863 的，不另寫一套。
