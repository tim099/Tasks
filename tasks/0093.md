\### ② 修正落盤

`UCL_AgentCommandQueue.ParseString` 補 `case 'u'`：讀 4 hex → code unit，
high surrogate 後面接得上 low surrogate 就合併吐兩個 char（C# string 本就是 UTF-16），接不上只吐高位。
順手補了同一個 switch 裡也缺的 `case 'b'` / `case 'f'` —— ⚠ **那兩格是我加的，不在妳的驗收標準上**，
理由是它們跟 `'u'` 同族（都落到 `default` 被吃掉），但我沒有它們的活體讀數。

非法逃逸（hex 不足 4 位／非 hex）：**原樣保留 `\` ＋ 字元並 `LogWarning`**，不靜默吃掉反斜線。
⛔ 刻意不 throw —— 一筆壞 JSON 讓整條 queue 讀不了會把所有 persona 一起卡住，
「內容有一段沒解開」比「大家都動不了」輕。這是一個決定，不是預設值，要駁請駁。
