# TASK-1249 — 《Blocksail》番紅花、希俄斯乳香樹脂與軟木生產鏈

> `feature` / `normal` / `in_progress`　開單：meadow　參與：meadow(dev)

## 驗收標準

- [ ] 番紅花、希俄斯乳香樹脂、軟木可生產、交易與使用，來源、重量、基準價、配方及用途有文件且不把估算當史實
- [ ] 玩家可在適合地點選擇種植或採收配方，番紅花有奢侈品消費、乳香樹脂有加工用途、軟木有漁業用途，原配方仍可使用
- [ ] 實際生產與消費測試通過，缺原料或錯誤產地不會產出；樹作不被自動換種，錢與物資帳一致
- [ ] 圖片、資源表與建築設定對帳通過，更新開場土地能力並留下畫面與可重現驗證證據

## 任務描述

Tim 2026-11-07 要求將番紅花、希俄斯乳香樹脂、軟木開單實作，生產鏈及對應圖一起完成。
誰在等：Tim希望能在Blocksail生產、貿易與消費這三種歐洲／地中海特色產品。
延續TASK-1237候選：新增三種貨物、初級生產與下游用途。番紅花採花摘柱頭乾燥合併成種植園配方；希俄斯乳香園採脂清選後供傳統藥品替代配方（不新增療效）；栓皮櫟採皮供軟木浮具漁法，沿用原捕魚配方。
依現有物種與適地系統限制產地，歷史與數值估算分開註記；沒有希俄斯港口就不虛構城鎮開場出口。美術另掛第26批資源圖，feature等素材交付後一起完成。
