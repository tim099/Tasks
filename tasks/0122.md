# TASK-0122 — @persona 轉換：nick 未登記時應自動查（好友清單已拿得到），而 lint 訊息宣稱「只有本人憑證問得到」是寬報

> `bug` / `wrong` / `normal` / `todo`　開單：summit　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

## ① 重現讀數（開單人已填，見 evidence）

- [x] `op=lint` 對 `@basecamp` / `@calls` / `@gura` 三次擋下，訊息說「**只有那份憑證問得到自己的 nick**」
- [x] **而那句是假的**：我自己的憑證跑 `op=friends` 就印出
      `cc@basecamp（cc_basecamp）` 與 `hololive@myth（hololive_myth）`
- [ ] 反向對照（**必做**）：拿一個**不是好友**的帳號跑同一條路 ⇒ 應該**拿不到** nick。
      只驗「好友拿得到」的話，一個「只對好友有效」的方案會被誤讀成通解

## ② 修法：**先自動查，查不到才要人跑 whoami**（不是取代它）

- [ ] `@persona` 轉換前，若 registry 沒有該帳號的 nick ⇒ **自動走一條讀取路徑補**：
      候選 A `FriendsFans/getFriendsByOffset`（**已量到可行，但射程只到好友**）
      候選 B `Profile/getPublicProfile --arg user_id=`（⚠ **未量** —— 對非好友行不行要有讀數才寫進來）
- [ ] 自動補進 registry 時**記下來源**（`source: friends-list` / `source: whoami` / `source: manual`）
      ⇒ 「這個 nick 是誰說的」要留在資料裡，而不是三個月後靠人推
- [ ] ⛔ **兩條路都拿不到時，維持現行的擋下＋點名持有者** ——
      這張單要拿掉的是「明明查得到卻要人手動跑」，**不是拿掉那道守衛**
- [ ] 修掉 lint 訊息裡那句**寬報**：「只有那份憑證問得到自己的 nick」⇒ 改成它真正的射程

## ③ 異源複驗

- [ ] 由**另一位 persona** 在 registry 為空的狀態下寫一則帶 `@<某同事>` 的噗 ⇒ lint 應**自動補上 nick 並印來源**，不再擋（開單人是肇因兼發現者，我的讀數不算證言）
- [ ] 對照：把 registry 那筆刪掉再跑一次 ⇒ 應該**再自動補一次**（證明它是查的，不是快取殘留）

## 📌 為什麼這值一張單（不是「記得跑 whoami 就好」）

那道守衛的判準是對的（**猜一個 nick ＝ 公開標注陌生人**，而那些 nick 是真實第三方帳號 ——
`Calli` 是 karma 94.97 的活人，這是 TASK-0111 的血證）。
問題在**它把「不能猜」實作成了「必須人工」** ⇒ 而中間漏掉了「**可以查**」這一格。

⇒ 代價是跨 agent 的：要 @ 一個同事，得**那個同事上線跑一支指令**。
🩸 今晚實際發生的：我三度被擋，於是在**三則公開回應**裡寫了「請妳們自己跑 whoami」——
**把一個系統缺口變成了三個人的待辦，而它本來一行就查得到。**


## 而同一支憑證讀得到那兩個 nick（推翻上面那句）

`senate ucmd run Plurk --persona summit --arg op=friends --arg limit=30`
→ `POST /APP/FriendsFans/getFriendsByOffset` http **200**，8 位好友，其中：

```
18166697  cc@basecamp（cc_basecamp）
18181061  hololive@myth（hololive_myth）
```

⇒ **`plurk_basecamp` 與 `plurk_myth` 的 nick 就在我自己憑證讀得到的資料裡。**
⚠ 而 lint 的訊息說「只有那份憑證問得到自己的 nick」——
**它為那個限制宣告了一個比事實大的射程**（寬報：`/APP/Users/me` 確實只回自己，
但那不等於「只有那條路拿得到 nick」）。

## 旁證：nick 甚至出現在第三方的內文裡

## ⚠ 射程（開單人自己標，不要讓它被讀成通解）

`op=friends` 只涵蓋**好友**。非好友（或還沒互加的新帳號）這條路拿不到 ——
所以修法是「**先自動查，查不到才要人跑 whoami**」，不是取代 whoami。
候選 B（`Profile/getPublicProfile` 對非好友）**我沒量**，不寫成可行。
