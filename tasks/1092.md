# TASK-1092 — 蒸汽船的司爐：每座鍋爐 2 位、蒸汽照司爐在崗比例（同槳手）、倒下由預備水手補（Tim「讓蒸汽船加上額外的燒煤工」）

> `feature` / `normal` / `in_progress`　開單：calli　參與：calli(dev)

## 驗收標準

- [ ] 有鍋爐的蒸汽船每座鍋爐（鍋爐那一組的每一點 boiler-n）配司爐，預設 2 位、船隻配置頁可以調（另外加在船員上，不從別的職位扣）；開戰時站在那座鍋爐旁（機艙那一層走得到的地方），shipcheck 列出每艘幾位、站不下照實報
- [ ] 蒸汽照司爐：每座鍋爐的出力 ×（那座的司爐在崗 ÷ 該有的，最多 1）—— 同槳手；開戰時站滿 ⇒ 一開始的航速跟現在一樣（量給看）
- [ ] 司爐倒下 ⇒ 預備水手補上去（同槳手）；鍋爐壞了、淹水熄火 ⇒ 照舊（不派人去顧壞的）
- [ ] 圖先用別的船員圖暫代（TASK-1091 交圖之後換）；新聞、HUD、船員配置頁的職位名寫「司爐」
- [ ] 反向對照：司爐設 0 ⇒ 戰局跟 dev 逐位元相同；帆船（沒有鍋爐）不管設多少都逐位元相同
- [ ] demo 對拍照實記：蒸汽船改前改後哪裡不同（機艙被打、司爐倒下 ⇒ 掉速），不要求逐位相同
- [ ] Tim 開一場確認

## 任務描述

Tim 2026-10-28：「是否可以讓蒸汽船加上額外的燒煤工(不確定具體職位名稱) 同時開船員素材需求task 然後先用其他船員圖暫代」；問了兩格，Tim 選：
- 玩法 ＝ 管蒸汽（照槳手那一套：每座鍋爐的蒸汽 × 那座的司爐在崗比例；司爐倒下 ⇒ 預備水手補上去；開戰時站滿 ⇒ 一開始跟現在一樣）
- 人數 ＝ 每座鍋爐 2 位（定遠、光榮、拿破崙 16；松島 12；蘇士奎哈納、維吉尼亞 8；莫尼特、哨兵 4），船隻配置頁可以調
