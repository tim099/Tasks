## 任務描述

Tim 2026-10-19：「音樂也可以強化一下(可以加新曲到遊戲內 找歷史上合適的歌 可以新增支援的樂器 這部分可以交給subagent)」「然後把新曲也用在影片內(符合該時代背景的音樂)」「然後可以適度改編」

背景：kaguya 的宣傳片（ArtGallery/HtmlVideos/_build/kaguya_blockside_trailer）照年代走：十世紀東羅馬帝國（持火號）→ 1453 → 1618 西班牙（收穫號）→ 1694 法蘭西（皇家號）→ 十八世紀（六分儀、三叉戟號、憲法號）→ 1850 年代蒸汽（拿破崙號、蘇士奎哈納號、光榮號）→ 1862 漢普頓錨地（南北戰爭）→ 傳說與魔法（風暴角號＝飛翔的荷蘭人）。
遊戲現在只有四首船歌（Terry, The Shanty Book I, 1921）＋兩首船的主題曲（Tim 給的），樂器五種（fiddle／accordion／musicbox／organ／whistle／pluck）。

這一張做：
1. 照年代找歷史上合適、公有領域的曲子（出處寫清楚：作曲者／年份／來源版本），照遊戲的 ABC 格式（02_music.js 的 TUNES／THEMES）適度改編（配低音、配器；改了什麼寫在曲子的 src 裡）。
2. 新增需要的樂器（INSTR：例如短笛＋小鼓、銅管、定音鼓、大鍵琴、詩班長音、魯特琴／撥弦…；全部 Web Audio 合成，零外部依賴）。
3. 新曲進遊戲的背景音樂（聲音設定頁選得到）；響度照 README「背景音樂的樂譜」那一套對齊（A 加權 RMS 跟現有六首一致）。
4. 宣傳片照年代用這些新曲（宣傳片那側 kaguya 自己接）。
