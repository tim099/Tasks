# TASK-1234 — 《Blocksail》河流源頭的湧水演出：泉眼水面一圈一圈湧動＋白沫水花（海圖塊帶泉眼位置）

> `feature` / `normal` / `todo`　開單：basecamp　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 泉眼的位置由 Blocksail 海圖塊帶給遊戲（從泉水開始的河的第一點；湖的出口不算），沒有泉眼的塊逐位元組不變
- [ ] 第一層：泉眼周圍的水面一圈一圈往外湧、中心偏清澈的藍綠 —— 鄧斯河源頭在遊戲裡看得到
- [ ] 第二層：泉眼持續冒白沫往下游漂，岩縫那種多一點水花；畫質的「船邊水花」關掉 ⇒ 不冒
- [ ] 反向對照：海圖塊沒有泉眼那一段 ⇒ 畫面跟改之前一樣；只給人看 ⇒ 同一個種子的戰局逐字相同

## 任務描述

Tim 2026-11-06：「河流源頭是否有辦法做一些水湧出的演出(參考現實河流源頭)」；看過方案「先做第一、二層」。

方案（TASK-1231 之後的分析）：第一層水面湧動（內陸水著色器照附近幾個泉眼畫一圈一圈的湧動、中心偏藍綠）、第二層水滴與白沫（沿用 13_water.js 的 WS／WF）；第三層泉潭地形不在本單。
泉眼種類：泉眼湧出（石灰岩泉）／岩縫流出（山裡、第一段很陡）；濕地滲出不演出。
注意：源頭的河窄（6～15 m），遠景會斷成一顆一顆（TASK-1231 留言 #2 的 ③）⇒ 本單只保證船附近看得到。
