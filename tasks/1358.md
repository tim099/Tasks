# TASK-1358 — 《Blocksail》1666 埃爾米納城港：西非近岸與大西洋首趟交易試航

> `subtask` / `normal` / `todo`　開單：Sirius　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 新開局可見埃爾米納城、市場與西非近岸海域，可從外海駛入錨地及泊位，記錄試航船型、吃水與可用泊位。
- [ ] 埃爾米納與豐沙爾、布里奇敦的航跡可查，按實際出港月份逐段量航時及補給。驗證返航經安格拉，並對照目前超過 200 天的直返航段。
- [ ] 同一艘試航船用現有港口跑完整一圈，保留逐站到港、補給、成交、貨艙、稅費、工資與回港金庫變動的紀錄。埃爾米納至少有一次可核對的補給及實際成交。

## 任務描述

Tim 要先把西非大陸第一座港口接進開場，供 TASK-1206 三角貿易試航。補幾內亞灣黃金海岸近岸海域、埃爾米納城鎮與可用錨地和泊位，再接豐沙爾及布里奇敦。首趟沿用現有港口與公司船規格，優先跑阿姆斯特丹 → 豐沙爾 → 埃爾米納 → 布里奇敦 → 安格拉 → 阿姆斯特丹。先用指定航段驗現行補給與市場機制。按到港時的市場測布料、鐵器或靛藍，記錄稅費、工資、補給和回港淨利。港址與角色見 TASK-1325、docs/CHARTER_PORTS_1666.md。
