# TASK-1235 — 《Blocksail》地中海特色食譜與對應精緻像素菜圖

> `feature` / `normal` / `in_progress`　開單：meadow　參與：meadow(dev)

## 驗收標準

- [ ] 整理第一波5至8道地中海特色菜的名稱、key、食材、食物等級與供應建築；1666年前後史實與遊戲設計明確區分，附可核對來源。
- [ ] 配方優先使用TASK-1214啟用的橄欖、橄欖油、稻米、豆子、柑橘及現有食材，接進餐館／酒館等適合的菜單；產量、工時、售價與熱量按既有規則驗算。
- [ ] 每道菜有對應精緻像素圖：128×128透明PNG、32px可辨識，延續既有菜圖風格；食物等級由介面右下羅馬數字呈現，圖片不加底圖、邊框或文字。
- [ ] 菜圖asset單、img/dishes、RESOURCES菜單圖表與dishes_check機械對帳一致，原稿、提示詞、ArtGallery總覽及作品卡可追溯。
- [ ] 實際介面驗證菜單圖片、等級、食材消耗與供餐結果；缺料不產出、熱量不憑空增加。不要求既有城鎮的經濟讀數維持相同。

## 任務描述

Tim 2026-11-06在TASK-1214施工時要求開衍生單：「地中海地區的特色食譜 & 對應圖片」。本單承接TASK-1214新增及啟用的食材，掛在地中海港口母單TASK-1211下。

先做第一波5至8道，城鎮餐館、酒館為主；依菜式用途安排建築及食物等級，不新增一堆只為一道菜使用的實體貨物。菜是SERVE_RECIPES等菜單，不當成市場貨物；圖放img/dishes。

候選方向（設計草案，史實待查，尚未拍板）：橄欖油豆湯、煎魚佐柑橘、橄欖與麵包拼盤、米飯海鮮燉鍋、柑橘蜜餞。先查證並取捨，再固定菜名與key。歷史範圍參照docs/TOWNS_1660S_MEDITERRANEAN.md及GOODS_REF；不要將後世著名菜名直接冒充1666年五港特產。

對應圖片需由內建image_gen繪製，沿用精緻像素、透明背景、128px及32px辨識規格；羅馬數字等級由介面疊字，圖中不畫文字、框或等級底圖。另開asset單承接本單確認後的菜單key與美術交付。

Tim同時取消TASK-1214「舊城讀數不變」要求；本衍生單同樣以功能、供餐、熱量、消耗及素材驗證為準。這次先開單，不視為已授權立即繪製所有候選菜。
