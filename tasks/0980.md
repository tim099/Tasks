# TASK-0980 — 《Blocksail／Blockside》城鎮模式：往來的船進出港時暫時降回 ×1，做好出港、進港演出（Tim 發現快轉時船離港會卡住）

> `feature` / `normal` / `in_progress`　開單：erina　參與：erina(dev)

## 驗收標準

- [x] 城鎮模式快轉（比 ×1 快）時，附近有往來的船要出港或進港 ⇒ 時間面板自動降回 ×1，面板上看得出是自動降的；那幾艘進出港演完 ⇒ 自動回到玩家原本選的倍率　✅ erina 2026-10-26
- [x] 出港演出：船從泊位起錨、離開棧橋、開到外海（或開出往來船的範圍）一路不卡住、不撞棧橋與旁邊停著的船、不噴整片浪花；Tim 截圖那種兩艘擠在棧橋邊動不了的情形重現不出來　✅ erina 2026-10-26
- [x] 進港演出：船從外海沿入港航線開到泊位、停好（下錨、繫泊），一路不卡、不撞　✅ erina 2026-10-26
- [x] 演完之後 3D 裡的船跟地球儀精細層的船對得上（不會同一艘在兩個地方、也不會演完又跳回時刻表上的位置）　✅ erina 2026-10-26
- [x] 反向對照：附近沒有船進出港 ⇒ 照玩家選的倍率走、不降速；本來就是 ×1 ⇒ 什麼都不變　✅ erina 2026-10-26
- [ ] Tim 進城鎮看一次

## 任務描述

Tim 2026-10-26（測試城鎮時間面板之後）：「測試ok 然後我發現船要離港時會卡住 目前想法是有船進出港時是否可以暫時改回1倍速 並處理好船的進出港演出 先開task先不用動工」

**症狀**（Tim 的截圖，夜裡的城鎮模式）：一艘三桅船要離港，跟停在棧橋邊的另一艘疊在一起動不了，兩艘四周噴出一大片白色浪花。截圖沒寫當時是哪一檔倍率。

**現在的做法**（Blockside 58_traffic.js、Blocksail globe.html trafficFor；2026-10-26 Blockside 5d85a84、Blocksail 5112fa3）：
- ×1：往來的船照帆沿航道開（trafficHelm），停港的兩錨都下、繫在泊位上；出港 ⇒ 起錨、放開繫泊、張戰鬥帆照航道開。
- 比 ×1 快：照時刻表滑（trafficGlide）—— 直接擺在精細層的位置上，不照帆走；停港 → 出港那一下從泊位跳到時刻表上的位置。
- 兩種都還會被碰撞（collide）推；滑的船不擱淺、棧橋不推。
- 精細層的時刻表是平均推進速度（逆風一段約 0.26 m/s），不是船真的開得出來的速度 ⇒ 照帆開的船會跑在時刻表前後。

**Tim 的想法**：有船進出港時暫時改回 1 倍速，把進出港的演出做好（解纜、離開棧橋、出港航道、靠泊）。

**還沒查**：截圖那一次卡住的原因（照帆開被棧橋或旁邊的船擋住、滑的船跟碰撞互推，還是起錨、繫泊沒放開）—— 動工時先重現、量讀數再改。

相關：TASK-0911（簡易船隊）、0931（精細層）、0949（航線快取、入港航線到泊位）、0951（停靠的船固定在泊位上）、0913（航行與貿易後續）。
