\## 做法

比照 SubmoduleSyncPage：草稿欄位 `autocommit/root` → 「✓ 套用並重新掃描」才寫進 session 生效值 `autocommit/root/applied`（跨 process）→ 「儲存本頁設定」寫 `senate.pages.local.json` 的 `auto-commit.Root`。另有「↩ 改回資料根」（點了立即生效）與「⇣ 貼上」（只填草稿）。
掃描根＝引擎 Discover 的父層那一格；信件庫只在 letters 根落在掃描根底下時一起掃，否則本輪不掃並明說。
引擎（SCP_Core）一行沒動；AutoCommitJob 的 letters 根改成可空（引擎本來就吃可空）。

\## 讀數（`senate ui --local --page auto-commit`，沙盒 repo 在 scratchpad：sbA、sbB 各 1 commit、各 1 個 ChatTavern/rooms/ 檔）

- ② 預設：session 清空後印「掃描根目錄：D:/Unity/Valhalla —— 由預設＝資料根（手填）決定」。
- ④ 反向：`D:/no/such/dir` ⇒「沒有套用：這個路徑不存在」；一個存在但沒有 .git 的目錄 ⇒「沒有套用：這不是 git repo 的根」。兩次之後生效根仍是 Valhalla、`senate.pages.local.json` md5 前後相同（7369ee56…）、sbA 仍 1 commit。
- ③ 作廢：在 sbA 按「Commit 勾選群組」進待確認 → 換到 sbB 套用 ⇒ 印「之前的勾選與待確認的提交已作廢」，`--click autocommit/confirm` 回「畫面上沒有這個 id」；sbA／sbB 都還是 1 commit、staged 0。
  勾選：在 sbB 把 chat 群取消（0 筆）→ 換回 sbA ⇒ sbA 的 chat 群是 [x]（預設），勾選 id 的戳記從 8df276a48313ef1 換成 8df276a4f29dd84。
- ① 持久：sbA 時按儲存 ⇒ 檔內 `"Root": "…/sbA"`；清 session 重開 ⇒「由存檔值（…senate.pages.local.json）決定」。改回資料根再存 ⇒ `"Root": ""`，清 session 重開 ⇒「由預設＝資料根」；與備份比對只多這一行。
- 真視窗（`--local --screenshot`）：欄位與「由誰決定」那行畫得出來（第一幀掃描中，執行中照設計不畫操作鈕）。
