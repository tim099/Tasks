# TASK-1077 — 《Blocksail》建築模式：鋪路分直線、曲線、自由曲線（＋自動繞路）；道路類別多棧橋（木、石堤、長碼頭）與海堤

> `feature` / `normal` / `in_progress`　開單：pinnacle　參與：pinnacle(dev)

## 驗收標準

- [ ] 道路類別有四種鋪法可以切：直線（兩點）、曲線（起點、彎的那一點、終點）、自由曲線（一段接一段，接頭照上一段的方向圓滑接上）、自動繞路（現在那一種）；預覽照那一種畫，擋到的地方說得出原因
- [ ] 直線、曲線、自由曲線鋪完，終點自動變下一段的起點（接到別條路上就收），右鍵或 Esc 收手
- [x] 道路類別多木棧橋、石堤、長碼頭三種：從路、碼頭線（海堤）、棧橋接出去伸進水裡；遊戲照那一種畫（木板＋樁／實心石砌），規劃裡跟生成的棧橋同一種格式（有路的號碼、兩側長格子帶、水上建築蓋得上去）　✅ pinnacle 2026-10-28
- [x] 道路類別多海堤：沿岸邊（一邊陸、一邊水）、從路或棧橋接出去；不填海、不改地形　✅ pinnacle 2026-10-28
- [x] 棧橋、海堤不壓地塊、城牆、別的棧橋、碼頭線、現有的泊位、錨地、玩家停靠處與外海泊位的航道；壓到的說得出原因（不另外加泊位 —— Tim 2026-10-28 拍板先不加）　✅ pinnacle 2026-10-28
- [x] 遊戲裡蓋過：一條直線路、一條曲線路、一段自由曲線、木棧橋、石堤、長碼頭、海堤各一，存檔讀回來還在；復原（undo）退得回去　✅ pinnacle 2026-10-28
- [x] 反向對照：沒動到鋪法的時候（自動繞路）鋪出來的路跟改之前逐位元組相同；六座城生成的規劃雜湊不變　✅ pinnacle 2026-10-28
- [ ] Tim 遊戲裡看過一次

## 任務描述

Tim 2026-10-28：「城鎮建設模式下 是否可以在道路類別加上 棧橋 & 海堤 以及棧橋是否可以加上石頭類型」「另外道路建設是否可以參考Cityskyline 可以設定不同模式(直線 取線 取線線段)」

拍板（2026-10-28，四題）：
- 鋪路模式：直線、曲線、自由曲線三種（照 Cities: Skylines 的 Straight／Curved／Freeform），現在的自動繞路保留當第四種。
- 石頭棧橋：石堤（mole：實心到海床、面 2.0 m、寬 12 m）、長碼頭（wharf：實心、面 1.0 m、寬 16 m）兩種都要 ⇒ 選單：木棧橋、石堤、長碼頭。
- 玩家鋪的棧橋先不加泊位：只當路走、旁邊能蓋水上建築；不能壓到現有的泊位、錨地、航道。泊位照它重排之後另開一張。
- 海堤沿著岸邊（一邊陸、一邊水，同生成的碼頭線）、從路或棧橋接出去；不填海、不改地形。

規則在 Blocksail world/town.js（townRoutePlan、townAddRoad、seaLines、townEditCtx），建築模式的介面與預覽在 Blockside src/js/87_townbuild.js；碼頭線、棧橋本來就是路（TOWN_BUILD §5.18），遊戲照規劃的 piers／quay 畫（63_towns.js）。
