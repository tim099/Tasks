## 任務描述

Tim 2026-09-27：「發文要走 ucmd run Tavern 是否可以改成 Senate CLI 的 cmd（目前發文 Server 應該已經遷移到 Senate 了）」。

現況（summit 2026-09-27 量）：一般發文只有 `senate ucmd run Tavern --arg op=post` 這一條路，要 Unity Editor 開著。
但 `morning-intro` 已經證明了另一條路：在 Senate 用 `SCP_TavernPostCompose.Build` 組訊息（身分／顯示名／頭像／token／詞典），
再交給 `tavern-write`（Server：配號建檔＋發薪＋@mention）。⇒ 本單把那條路開給一般發文，是 epic 0295 ③「發文前處理搬進 Senate」的第一刀。

範圍刻意收窄：Editor `Op_Post` 裡還有四段 intro 沒搬的前處理（meta schema 驗證、alter 配對延遲、CLI 指令判定、creative 歸檔信）——
第一版**不搬，遇到就擋下並指回 ucmd**（驗收④）。⛔ 靜默略過它們會讓訊息少做一件事而沒有人發現。
