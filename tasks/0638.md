# TASK-0638 — Blockside：艙門子模型 —— 人經過才開（演出、可關）、走路當通道、擋水、打得壞；莫尼特號甲板出入口先用

> `feature` / `normal` / `done`　開單：meadow　參與：meadow(dev)

## 驗收標準

Tim 2026-10-16：「另外目前還想加一個艙門機制 有人經過才打開 且打開只是演出效果(畫質設定可以關閉門的開關演出)(且炮門也可以套用類似概念)」「門要另外建子模型 且可被破壞(類似目前的一些裝飾元件 但是有實際功能) 可以讓人員進出(直接視為通道)」「但是會阻擋水流入 可以用在莫尼特號 甲板出入口試試(門可以有上下開 & 左右開 純粹演出)」

- [ ] 門是作品裡另外建的子模型（標一個門的 meta），開法可以標上下開或左右開；造船規格寫了怎麼標，匯入檢查有對應的那一行（標錯 ⇒ 報出來）
- [ ] 人員走路把門當通道：門關著也走得過去，不繞路、不卡住
- [ ] 有人經過時門打開、人走過去之後關上；這只是畫面演出，畫質設定有一格可以關掉（關掉 ⇒ 門一直關著的樣子，人照樣通過）
- [ ] 門還在時擋水：水不會從門那一格流進去；門被打掉之後那個開口照常進水
- [ ] 門打得壞（跟現在的裝飾元件一樣吃砲彈），壞了之後那個開口變成一般的洞
- [ ] 莫尼特號甲板的出入口裝上門，在遊戲裡看得到開關、擋得住甲板上的水
- [ ] 砲門用同一套演出（有人在砲旁裝填／開砲時打開）—— 先做艙門，砲門那一格看完莫尼特號再決定要不要同一張做
- [ ] 反向對照：沒有門的船戰局對拍跟改之前逐字相同

## 任務描述

船上的艙門做成子模型：人經過時開門（純演出、畫質設定可關），走路當通道，門在時擋水、打壞了變成洞；開法有上下開與左右開。先裝在莫尼特號的甲板出入口；砲門之後套同一套。
