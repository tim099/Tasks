# TASK-0875 — 《Blocksail》版本旗標：Build（打包出來的）／Editor（開發者用），主選單可以切去測 Build；介面與城鎮建造的權限照它

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 一個旗標分兩種版本：Build（打包出來的）／Editor（開發者編輯用）；打包流程把它定成 Build，打包版切不回 Editor
- [ ] Editor 版本在主選單可以切到 Build 版本測試（記在這台電腦上，也能切回來）；地球儀、主選單看得到現在是哪一種
- [ ] 只在 Editor 版本出現（Build 版本藏起來）：島嶼預覽、城鎮規劃的連結；存到 Editor 版本（Build 版本只有遊戲存檔，網址帶 `?save=editor` 也不行）；畫了幾環、查點那一行統計
- [ ] 城鎮的建築模式兩種版本都打得開同一個建造選單；能做哪些操作照一張權限表（照版本、照那一棟是誰的）判斷，地球儀那一頁擋（不只藏按鈕）：Editor ＝ 全部（改的是城鎮預設、可以拆所有建築與道路、改生產配方、不用買）；Build ＝ 之後要花錢、資源，只能動自己的
- [ ] 反向對照：Build 版本叫一個 Editor 才能做的操作 ⇒ 擋下並說原因；Editor 版本同一個操作 ⇒ 照做
- [ ] 文件：權威文件寫清楚旗標怎麼定、怎麼切、哪些介面看它、權限表；`ARCHITECTURE.md` 加這張卡

## 任務描述

## 要什麼（Tim 2026-10-24）
- 「另外是否可以用一個Flag來區分當前遊戲是Build出來的版本 或是Editor版本(開發者編輯用) 且Editor版本在主選單可以切換到Build出來的版本(用來測試) 這個Flag會影響介面該顯示哪些內容 例如城鎮編輯就只能在開發者版本編輯(玩家需要走建造模式 花費錢跟資源建造 且只能控制自己擁有的建築)」
- 問了兩題：
  - Build 版本的 🔨：「一樣打開建造選單 之後才根據Flag影響該模式下能做的操作 區別在於Editor存檔會是改動城鎮預設 且可以拆除所有建築與道路 修改生產配方等 不需要購買或其他操作來擁有建築」
  - 只給開發者的介面：島嶼預覽、城鎮規劃連結；存到 Editor 版本；統計那一行（畫範圍沒選 ⇒ 兩種版本都留著）

## 現況（ame 查的）
- 打包：packaging/electron/build.sh ⇒ tools/copy_game.cjs 把 index.html、globe.html、battle.html、presets.js、world/、船檔複製進 game/。
- 建築模式（Blockside 87_townbuild.js）只問地球儀那一頁（world/mapgen.js townEdit ⇒ mapgen_worker.js），規則全在 Blocksail world/town.js；現在能做的只有鋪路（road）、蓋房子／生產建築（build）。
- 拆除、改生產配方、花錢買、建築歸誰：都還沒有。
