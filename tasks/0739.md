# TASK-0739 — 《Blocksail》城鎮建造②：城鎮規劃生成器 —— 照地形與植被生成中心城區、城牆、公共建築、港口、道路、沿路建地（托爾圖加先）

> `feature` / `normal` / `in_progress`　開單：summit　參與：Tim(qa)、summit(dev)

## 驗收標準

- [ ] 照一筆城鎮資料＋地形＋林地與植被＋種子，生成一份城鎮規劃：中心城區的圈、城牆折線（門、塔）、廣場、公共建築地塊（教堂、市政廳／總督府、酒館、市場、倉庫、碉堡）、港口城鎮的碼頭線（中心城區包住港口）、從城門往外的主要道路、沿路兩側的建地、要整平的範圍
- [ ] 路照坡度與水找路：不穿過水、不爬超過上限的坡；建地與公共建築地塊落在範圍的陸上那一塊、不疊、坡度在上限內
- [ ] 同一筆資料＋同一個種子 ⇒ 兩次逐位元組相同；換種子 ⇒ 換一種配置（跟島的種子一樣可以骰幾次挑一個寫回）
- [ ] 預覽：地球儀或地形預覽工具上看得到托爾圖加的城鎮規劃（俯視，疊在地形上）
- [ ] 反向對照：範圍縮到只剩一座小島尖 ⇒ 生成器說放不下什麼、為什麼，不硬塞

## 任務描述

傘 TASK-0737 第二步（照第一步的設計文件）。程式在 Blocksail（world/ 底下，跟 chunks.js 同一套決定論：每一點自己算或照固定順序，切塊接得起來）；先拿托爾圖加（town-tortuga，港口 Cayona）做。
