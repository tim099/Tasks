# TASK-0910 — 《Blocksail》城鎮介面與貿易：停靠後 🏛 城鎮（概況、每日產出與消耗、庫存與價格、統計報表）＋ 💰 貿易（只列雙方有的貨）

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [ ] 城鎮模式（停靠後）按鈕列：🔨 旁邊多「💰 貿易」（常用、放外側）和「🏛 城鎮」（開城鎮介面）兩顆、各有快捷鍵；航海、海戰模式看不到
- [ ] 🏛 城鎮介面：上方城名、年份（另一個時空有標示）、勢力、人口、城鎮金庫；子選單四頁：概況／每日產出與消耗／庫存與價格／統計報表；資料一律跟 Blocksail 那一頁的城鎮帳問（Blockside 不自己算）
- [ ] 每日產出與消耗：城鎮帳每天記每座城每種貨產出多少、用掉多少（生產建築、採集、工地、鎮民吃）；檢查腳本對帳：各城產出、原料加總 ＝ 總帳 led 當天的差，0 筆對不上
- [ ] 統計報表：城鎮帳記歷史（每天：人口、勞動、失業、碼頭上、城鎮金庫、鎮民金庫；每 7 天：每種貨的庫存、價格、產出、消耗；各留一年），存得成讀得回；畫人口、金庫、選一種貨的庫存與價格
- [ ] 💰 貿易：只列船隊上有、或城鎮庫存 > 0 的貨（聯集；人不列）；每一列：城鎮庫存、買一桶／賣一桶的價格（含關稅）、船上有幾桶；買賣走 storeBuy／storeSell（價格曲線、關稅進城鎮金庫、玩家金庫付）；付不起、放不下、市場不夠 ⇒ 只成交做得到的那一份並說原因；底下顯示玩家金庫與載重（貨重 vs 壓艙物、多吃幾公尺水）
- [ ] 玩家船隊貨艙：第一次交易時照玩家開的那艘船開一個（那一型的壓艙物）；存檔存得成讀得回（fleets/player.json）
- [ ] 檢查腳本：買賣後錢總數、貨總數不變；反向對照（玩家金庫 0 買不到、貨艙放不下、城鎮庫存 0 而且船上沒有 ⇒ 清單上沒有）
- [ ] 遊戲內實測：停靠金斯敦 ⇒ 城鎮介面四頁、貿易買一種賣一種，數字跟城鎮帳一致（截圖）
- [ ] 文件：docs/TOWN_UI.md（新）、TRADE_SIM §3.2 指過去；Blockside 新檔檔頭寫協定

## 任務描述

## 要什麼（Tim 2026-10-25）
「接著準備做城鎮資訊&貿易頁面吧　希望城鎮模式下（停靠後）有按鈕可以開啟介面 可以顯示城鎮資訊&跟城鎮互動（子選單）　貿易按鈕很常用可以放在外側（建築按鈕旁）　子選單可以放城鎮的一些詳細資訊鈕（例如 查看城鎮每日產出資源&消耗資源 目前庫存等 以及統計報表（人口 資源變化圖等） 然後貿易按照之前文件規格 只顯示雙方有的貨物（因為貨物之後種類會很多）」

## 現況（gura 查的，Blocksail main 841d8b9）
- 買賣已經有：world/stores.js storeBuy／storeSell（船隊貨艙 ref、價格曲線積分、關稅 10% 進城鎮金庫、付不起／放不下只成交一部分）；船隊貨艙存檔 fleets/<船隊>.json。
- 沒有的：城鎮帳裡沒有玩家的船隊；每座城每天的產出／消耗沒有分城記（led 是全世界的累計）；沒有歷史；Blockside 城鎮模式只有 🔨。
- 城鎮資訊查詢 townInfo（TASK-0871，ame）照用，只加欄位。

## 做法
- Blocksail：townstate.js townDay 記每座城昨天的 flow（made／used）＋歷史 hist；globe.html／world/mapgen.js 加兩條協定（townInfo、trade）；玩家船隊第一次交易時開。
- Blockside：新檔（城鎮介面＋貿易），按鈕放 #keys 🔨 旁。
