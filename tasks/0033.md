# TASK-0033 — Cmd_Task 兩格「行為對但讀的人看不到」：重複 sha 訊息落錯層 ＋ link 不可解

> `improvement` / `normal` / `done`　開單：basecamp　參與：summit(dev)、basecamp(qa)

## 驗收標準

TASK-0023 補簽過程中量到的兩格，都是「行為對、但讀的人看不到」。
兩格都**不會叫**，所以只會被剛好在做同一件事的人撞見。

## ① `op=commit` 重複 sha：訊息落在單檔時間線，不在回傳檔

`Cmd_Task.cs:672`：
```csharp
UCL_TaskIO.Save(e, "", "", $"…commit `{aSha}`（{aMode}）by {iActor}"
    + (aShaNew ? "" : "（這個 sha 本來就在，沒重複加）"));
```
那句進的是**單檔時間線**，而下面 `ioR.AppendLine(...)` 那四行**沒有用 `aShaNew`**。

實測（探針 TASK-0031，同一顆 sha 打兩次）⇒ **兩次回傳檔逐字相同。**

- [x] `ioR` 也要能分辨：新加 vs 本來就在（9503c5f8；♻ 行＋「本次 0 新增」）（形狀不同，不是只有字不同）
- [x] 讀數：同一顆 sha 對同一張單打兩次，**兩次回傳檔內容必須不同**（08-26 實跑：第二次多 ♻ 行）
- [x] ⚠ 別把時間線那句刪掉 —— 稽核紀錄要留，這是**補**不是搬

📌 「有印」與「印在被讀的地方」是兩件事。

## ② `link` 只能建、不能解

`Cmd_Task` 的 op 清單只有 `"link"`，沒有 `"unlink"`。
⇒ 掛錯或探針用的關聯**永久留在對方單子上**。

現場：我為了驗「有未解 blocker 時 commit 不推進」，把探針 TASK-0032 掛成 TASK-0017 的 blocker，
現在 **TASK-0017 的 `blocks: [16, 32]`**，而 32 是已作廢探針。

⚠ 這會累積：「探針用完當場標記」是這桌的慣例，而**每一張有掛關聯的探針都會留一行拆不掉的殘骸**。
（blocker 閘只認未關的單 ⇒ **不影響判定**，只影響讀的人看到什麼。所以是可讀性不是正確性。）

- [x] 加 `op=link --arg remove=1`，**雙向對稱移除**（UCL_TaskIO.Unlink，五種 kind 全對稱）
- [x] 讀數：33↔31 建→解，兩邊回讀 related_to=—；再解一次印「本來就不存在」（08-26 實跑）
- [x] ⚠ 解除要不要留時間線紀錄：**要**（兩張單各一筆 `unlink`）。移除關聯是一個決定，不是打掃
- [x] 收尾：把 TASK-0017 的 `blocks` 清掉 32（回讀 blocks: [16]）（我留下的殘骸，我報上來）

## 為什麼不塞進 TASK-0026

0026 是併發寫檔（回傳檔分格／單檔鎖／index 原子化），跟這兩格是不同的關注點。
📌 塞在一起會讓 0026 的驗收標準變成一張雜貨清單，**而雜貨清單裡沒過的那格不會有人發現**。
## 第三格（Tim 2026-08-25 收斂機制上線時撞到，併入本單不另開）

**`op=update --arg criteria=` 只給它是靜默 no-op** —— `OpUpdate` 沒把 `criteria` 放進
`aChanges`，於是走「沒有任何變更 ⇒ 什麼都沒寫」那條路，單子一個字都不變。

⚠ 而它直接卡住收斂機制：**「擴充當前 Task 的驗收細項」是那套流程的主要出口**，
而那個出口目前需要一個 workaround（同時帶 `--arg title="<原標題>"` 逼它計入變更）才會寫。

- [x] `criteria`（與 `description`）要計入 `aChanges`，只給它也要能寫入（本次更新就是讀數：只帶 criteria）
- [x] 「沒有任何變更」那句的欄位清單要**列全**：原寫
      `（status / priority / title / milestone）` ⇒ 漏了 `memory_topic` /
      `memory_archived_commit` / `criteria` / `description`
      📌 **錯誤訊息自己在低報** —— 讀的人分不出「這不是欄位」與「這是欄位但沒被計入」
- [x] 讀數：只給 `--arg criteria=` ⇒ `updated_at` 推進、單檔內容真的變（＝本筆）
- [x] 反向對照：**什麼欄位都不給**（08-26 實跑：八欄全列） ⇒ 仍要走「沒有任何變更」那條，且清單要是全的
