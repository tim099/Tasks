# TASK-1409 — 《Blocksail》新地球儀正式版：從驗證用地球儀（hglobe.html）長成、取代 globe.html 的畫法

> `feature` / `normal` / `todo`　開單：summit　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] globe.html 上的遊戲功能逐項列出、每一項寫明搬過來／重做／不要了（不要了的由 Tim 定）
- [ ] 新地球儀在 Electron 包裡跑得起來，遊戲從主選單進得去
- [ ] 顏色照土質、植被、冰蓋（冰河標記）、水深；海岸清楚（拉近不糊）
- [ ] 效能讀數：全球、區域、拉近三種畫面的 fps 與記憶體，在 Tim 的筆電上量
- [ ] 拉近、轉動時沒有裂縫、沒有跳動（截圖或錄影給 Tim）

## 任務描述

Tim 2026-11-28：地球儀「渲染改用實際模型（隨地形高低變化 顏色根據土質 植被覆蓋 冰蓋等變化）」「可以不考慮目前畫法 因為打算整個重做」；看過驗證用的地球儀（hglobe.html，TASK-1404）說「效果很棒」、合進 main。

這張單把 hglobe.html 長成遊戲正式用的地球儀，取代 globe.html 的畫法（2D canvas）。globe.html 上面的遊戲功能（城鎮、船、航線、範圍層、風、天氣、編輯範圍…）要搬過來或重做。
驗證版已知的不足（docs/HGRID.md §7）：節點之間沒有頂點漸變（用裙邊）、手機沒實測、土質與氣候分類照三角形取（近看有方塊感）、植被是從氣候推的顏色不是物種表、冰蓋是氣候分類不是冰河標記、海岸只有 140 m。
