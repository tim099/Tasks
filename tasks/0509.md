- [x] 觀測頁 GPU 預覽：主作品只建自己的格；每個關聯節點、每個外部模型各自一份 mesh 畫出來（各自完整，不剔除貼合面）　✅ erina 2026-10-12

## 任務描述

誰在等：Tim（2026-10-12）。

## 需求
觀測頁 GPU 預覽裡，子模型（**關聯 links** 與 **外部模型 sub=model** 兩種）各自是一份獨立 mesh，不合併進主模型；
多個同樣的子模型**共用一份 mesh**（每份只帶自己的變換）；頁面上的子模型開關**只切那份 mesh 的顯示**，不重建 mesh。

## 拍板（Tim 2026-10-12）
- 兩種都算：關聯（現在逐格併進主作品 voxel）、外部模型（現在已是獨立 mesh，但每份各烘一次世界座標頂點）。
- 範圍：先做觀測頁 GPU 預覽；`export`（obj／vox／list）與 CLI `view` 維持現狀（obj 格式本身不能共用 mesh）。
- 重疊：各自完整顯示 —— 子模型畫自己的全部格子，跟主作品貼合處不互相剔除、重疊處兩份都在（同一件才真的能共用 mesh）。

## 現況（調查讀數）
- 關聯：`SCP_SculptLinkComposer.Compose／Place` 在建 mesh 前逐格併進同一個 voxel 空間（自己的格優先、先到的贏、出界丟掉）⇒ 一整塊 mesh；頁面切關聯開關 ⇒ voxel 簽章變 ⇒ 重新組合＋重建整塊。
- 外部模型：`BuildGeom` 把每份的變換烘進世界座標頂點，`SCP_SculptMeshBuilder.Models` 全部串成一批上傳；N 份 ＝ N 份頂點。
- 渲染器沒有 model 矩陣 uniform、每個 VAO 一次 DrawElements。
