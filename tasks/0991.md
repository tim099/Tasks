# TASK-0991 — 《Blocksail》現有配方加副產品：鋸木坊、伐木場多出木柴，養雞場多出肉（淘汰的老母雞）—— 架構本來就支援主產品＋副產品

> `improvement` / `normal` / `in_progress`　開單：trailhead　參與：trailhead(dev)

## 驗收標準

Tim 2026-10-26：「分析一下目前生產架構 是否支援菜單生產多種產品(主產品+副產品) 例如養雞場可以產 雞+雞蛋」「如果不支援 可以先優化架構支援 然後先調整目前生產 讓一些建築可以產出多種資源」。

判定（trailhead 讀 world/prod.js、world/auto.js、tools/price_cost.cjs）：架構已經支援 —— 配方的 out 是一張表，煮糖（糖＋糖蜜）、養豬（肉＋牛油）、養牛（肉＋牛皮＋牛油）早就在跑：產量照同一個開工率一起出、開工照全部產出的市值比（mktRate）、自動建築把每一種產出的缺口都算進去、基礎價照產出的價值比例分成本。這張單只調整現有配方、加副產品。

- [ ] 鋸木坊、伐木場、養雞場（玉米、大麥兩條）多一種副產品，數字與理由寫在配方旁與文件
- [ ] 養雞多產的肉沒有讓熱量變多（飼料熱量 ≥ 蛋＋肉的熱量）
- [ ] 起始檔跑一年：每座城的人口、主糧、木柴與木板的產量跟改之前比，變化寫成讀數；沒有城因此缺糧或停產
- [ ] 既有的生產檢查工具都過（日用加工鏈、熱量、開場檔）
- [ ] 反向對照：把副產品拿掉，讀數回到改之前那一份
