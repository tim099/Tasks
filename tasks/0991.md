# TASK-0991 — 《Blocksail》牲口與屠宰場：養雞場產雞蛋＋活雞、牧場產活牛＋牛奶，屠宰場出肉、羽毛、牛皮、牛油（架構本來就支援主產品＋副產品）

> `improvement` / `normal` / `in_progress`　開單：trailhead　參與：trailhead(dev)

## 驗收標準

Tim 2026-10-26：「分析一下目前生產架構 是否支援菜單生產多種產品(主產品+副產品) 例如養雞場可以產 雞+雞蛋」「如果不支援 可以先優化架構支援 然後先調整目前生產 讓一些建築可以產出多種資源」⇒「看起來已經支援了」⇒「那我想調整一下 養雞場改成產出 雞 & 雞蛋 牧場產出牛 牛奶 然後屠宰場可以消耗雞 產出 肉 羽毛 消耗牛 產出肉 牛皮 牛油」。

判定（trailhead 讀 world/prod.js、world/auto.js、tools/price_cost.cjs）：架構已經支援 —— 配方的 out 是一張表，煮糖（糖＋糖蜜）、養豬（肉＋牛油）早就在跑：產量照同一個開工率一起出、開工照全部產出的市值比（mktRate）、自動建築把每一種產出的缺口都算進去、基礎價照產出的價值比例分成本。這張單照 Tim 的設計改牲口這一段：活雞、活牛、牛奶、羽毛四種新貨＋屠宰場。

- [ ] 養雞場產雞蛋＋活雞、牧場產活牛＋牛奶、屠宰場吃活雞 ⇒ 肉＋羽毛、吃活牛 ⇒ 肉＋牛皮＋牛油；新貨進貨物表與資源表、屠宰場進建築選單（共用模型、崗位立繪有男有女）
- [ ] 熱量沒有變多：飼料 ≥ 雞蛋＋活雞、≥ 活牛＋牛奶；屠宰出來的肉 ≤ 活雞、活牛的熱量帳
- [ ] 起始檔兩年：每座城的挨餓、救濟、短缺跟改之前比，變化寫成讀數；沒有城因此缺糧；肉、活牛不無限囤
- [ ] 既有的生產檢查工具都過（日用加工鏈改成屠宰場出牛油、熱量、建築崗位、資源表對帳）
- [ ] 反向對照：拿掉這一段，讀數回到改之前那一份
- [ ] Tim 遊戲內確認（建築選單有屠宰場、蓋得起來、資訊面板看得到兩條菜單的產出）
