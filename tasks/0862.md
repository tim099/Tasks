# TASK-0862 — 《Blocksail》生產建築規格：產出物資、要勞動力、消耗原料（糖廠吃甘蔗產糖）；地標裡的田兼任生產建築；農作物照生成式樹木生成、也會野生

> `feature` / `normal` / `in_progress`　開單：kaguya　參與：Tim(qa)、kaguya(dev)

## 驗收標準

- [ ] 生產建築的規格寫進 Blocksail 文件，Tim 看過拍板：每一種寫產出什麼、要幾個工人、消耗什麼原料、蓋的條件（適地、資源分布區）、帶哪一種附屬
- [ ] 種類、貨物、配方三張都是設定表：新增一種生產建築或配方只改表，不改程式
- [ ] 一座生產建築有工人、有原料 ⇒ 照配方產出；讀數：甘蔗園產甘蔗、糖廠吃甘蔗產糖，數字跟配方表對得上
- [ ] 反向對照：缺原料 ⇒ 停工、一顆都不憑空產出；缺工人 ⇒ 照到崗的比例減產；兩個都缺的讀數也印出來
- [ ] 勞動力從城鎮人口來：同一個人不會同時算在兩座建築；崗位比勞動人口多 ⇒ 看得到哪幾座缺工
- [ ] 一條兩段的鏈跑 365 天（例：甘蔗園 ⇒ 糖廠）：庫存曲線合理；總量守恆（期初＋產出 − 消耗 ＝ 期末）
- [ ] 特殊建築可以兼任一種生產建築：地標裡的田算那一種的附屬、照格數產出，地標模型不變；反向對照：沒登記兼任的地標不產出
- [ ] 已經雕進地標的田都登記成兼任（三座蓄水池池底、奧古斯都廣場東南角、大皇宮台地的菜畦）
- [ ] 同一份輸入跑兩次，產出與庫存逐位元組相同
- [ ] 田裡的農作物照生成式樹木那一套生成（照物種長相、遠近分級）：附屬鋪幾格就長幾格，拆掉就不見
- [ ] 農作物也會野生：野外照物種表的條件（氣候、土壤、海拔）長出來，跟野生的樹同一套；反向對照：條件不合的地方一株都不長

- [ ] 田是附屬：一定綁一座主生產建築，不雕刻，用建地的格子劃範圍（同沿路建地那一套格子），不必臨路、只要跟主建築相連；反向對照：沒綁主建築、跟主建築不相連、疊到路或別的地塊的田都蓋不了

- [ ] 產出進主人在那座城的倉庫、原料也從那裡拿；屬於城鎮的建築（還沒有家族的都是、地標兼任也是）原料直接從市場拿、產出直接進市場；反向對照：市場裡沒有原料 ⇒ 城鎮的工坊一樣停工

## 任務描述

Tim 2026-10-23：
- 「田野可以先不做 之後打算做成生產建築」「之後會有生產建築的規格(產出物資)」
- 「目前規劃是生產建築會生產資源 需要勞動力人口 且可能消耗資源(例如 糖廠消耗甘蔗 生產糖)」
- 「地標裡的田(按照妳的建議 可以兼任)」

**這張管什麼**：生產建築是什麼 —— 產出、勞動力、消耗、蓋的條件，以及一座城每天怎麼照這些推進。
**不管**：在哪裡蓋、附屬怎麼鋪、建築模式的操作，這些在 TASK-0742（summit）。這張定下來的種類表與配方，0742 的「產量跟著附屬走」直接查它。

**已經有的設計（照這些接，不重寫）**：
- 能不能蓋看地區、產多少看建築：`TOWN_SIM.md` §2.2，適地表 `BSW.SUITS`、物種表 `world/species.js`。
- 生產鏈、配方表（數字是佔位）：`TOWN_SIM.md` §3、§4；兩層模擬見 §6。
- 主建築＋附屬：`TOWN_BUILD.md` §7（1 m 一格、產量 ＝ 每格產量 × 附屬格數、等級決定附屬上限）。
- 種類表與實例的格式：`TOWN_BUILD.md` §7.1（`cat`、`need`、`annex`、`levels[]` 的 jobs、recipe、cost）。
- 加勒比海那一套的史料：`TOWN_BUILD.md` §1.1.6。

**這次新加的**：
- 消耗原料的生產建築（例：糖廠吃甘蔗）跟產原料的同一套格式。
- 勞動力從城鎮人口來（`TOWN_SIM.md` §5）。
- 特殊建築可以兼任一種生產建築（照 fort-roche 的 `as` 那條路）：地標裡已經雕好的田就是附屬，模型不變。
- 地區分套：加勒比海那一套跟 1453 年君士坦丁堡的不一樣（例：菜園 bostan、葡萄園、漁場、磨坊）。史料表裡的 `garden-field` 區（城牆裡沒有房子的園地）是現成的地方。
- 之後的田不雕進地標模型（`TOWN_BUILD.md` §5.14「田野先不做」）。

Tim 2026-10-23（同一段）：「然後田地我希望參考目前生成式樹木方法 去生成農作物(且農作物也可能作為野生作物長在野外)」
- 田裡的作物不雕，走生成式樹木那一套（Blockside `16_treegen.js`、模型 meta `kind=tree` 換成生成式的那條路）；田本身是附屬的格子。
- 作物是物種（`SPECIES.md`）⇒ 野外照同一張物種表的條件長，跟野生的樹一樣。
