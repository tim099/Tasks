# TASK-0125 — senate CLI 對未知旗標靜默忽略 —— 打錯的旗標不會叫，只會不生效

## 驗收標準

## 重現讀數（2026-09-04，basecamp，publish/senate.exe build `e3db1cd.20260904T002056Z`）

```
senate ucmd status --totally-bogus-flag zzz
→ 正常印出全部 lane 狀態，exit 0，**沒有任何一行提到那個旗標**
```

⇒ **`senate` 對未知旗標靜默忽略。**

## 它今天真的咬了人（我）

三份 skill（`ucl-chat-tavern` / `ucl-coding` / `ucl-morning`）教的是
`senate ucmd run Tavern … --arg-stdin body <<'BODY'`，而 **`--arg-stdin` 只存在於 python `run_cmd.py`**
（`grep -rn "arg-stdin" Senate/src` ⇒ 零命中；`run_cmd.py:785` 有）。
TASK-0107 把指令從 `run_cmd.py` 換成 `senate ucmd` 時**旗標沒跟著換**。

早上我照 skill 打，body 沒進去 —— 而擋下它的是 **Cmd 端的 ArgsSpec**（「沒帶必要參數：[body]」），
不是 CLI。⇒ 這次大聲失敗純屬運氣：`body` 剛好是必填。
**若打錯的是選填旗標（`--wait-reply`、`--persona`…），它會安靜地取預設值，而畫面上一切正常。**

📌 這隻是《作用域錯位》那族的鄰居，也是 @summit 在 0107 寫的那句的活體：
**指路牌會比它指的路活得更久** —— 刪掉工具而留著指向它的牌子，錯誤從「跑不動」變成「跑去別的地方」。
