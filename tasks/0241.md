# TASK-0241 — BTC 區（Bar 專案）切換金流權威到 Senate 新銀行 —— 承 TASK-0216 ⑪

## 驗收標準

- [ ] ① **先確認 Bar 那棵樹的 code 到位**：`Assets/Plugins/UCL_Core` 的 checkout 含 `8950a496`（權威切換本體）。讀數＝該 checkout 裡 `UCL_TreasuryAuthority.cs` 存在且 `git log -1` 的 sha 是它或它的後代。⛔ 這格**不到位就不准設旗標**（見任務描述的「最貴的那一格」）
- [ ] ② **切換前的同步讀數**：在 **Bar 的 Editor** 跑 `Treasury op=bank_diff`，逐戶零差額（相符 N／不同 0／未預期缺戶 0／只有新的有 0），並把**射程逐 id 那一行**抄進留言。⛔ 不是總額零差額，也不是「沒有人回報問題」
- [ ] ③ **切旗標**：`<Bar 資料根>/Treasury/bank_settings.json` 的 `money_authority` 設 `senate_bank`。反向對照：設成一個**認不得的值**（例如 `senate-bank`）⇒ Editor Console 要出聲並當 `legacy`，⛔ 不是靜默切換
- [ ] ④ **判別讀數**（⛔ 不可用「兩邊數字相同」那種同形的對照）：挑一個**兩本帳不同值**的帳號查餘額，答案要等於新銀行那邊。LY 當時用的是 `codex`（舊 249／新 0）；BTC 要自己找一個，並把「為什麼它兩邊不同」寫在留言
- [ ] ⑤ **寫入端實跑**（`Template` persona，真扣款）：credit +1 之後，**舊 `Treasury/ledger/<今日>` 的檔數不變**、新銀行 `Bank/ledger/<今日>` +1。兩個數字都抄進留言
- [ ] ⑥ **反向對照**：把 `senate_path` 指到一個不存在的檔 ⇒ 寫錢**整筆失敗**，且**兩本帳各自 0 新分錄**（⛔ 不降級寫舊帳本）。做完記得 `senate_path=clear`
- [ ] ⑦ **鏡像確認停了**：`Treasury op=bank_mirror` 印「開關 關」。⛔ 這格是**推導**的（權威＝新銀行就自動停），所以要驗的是「它真的推導對了」，不是「我有沒有去關」
- [ ] ⑧ **明著宣布**：酒館公告權威切換，射程寫明是 `BTC` 那一區，並列出**沒做到的格**（⛔ 不留白）

## 任務描述

## 🩸 最貴的那一格（先讀這段再動手）

**旗標是資料，切換的行為是 code —— 兩者在不同的 repo 裡，而它們不同步時沒有任何一層會喊。**

`money_authority=senate_bank` 只是 `bank_settings.json` 裡的一個字串。
真正讓錢改道的是 `UCL_TreasuryAuthority` ＋ `UCL_TreasuryLedger` 的路由（`UCL_Core 8950a496`）。
⇒ 如果 Bar 那棵樹的 `UCL_Core` checkout **還沒拉到那顆 commit**：
- 旗標設了 ⇒ 帳面上「這棵樹已經切了」
- 而 code 不存在 ⇒ 錢**照舊寫進舊 `Treasury/`**
- ⛔ **兩邊都不會報錯**，而且各自都自圓其說

⇒ 所以驗收 ① 排在最前面，且它的讀數是「那個檔案存不存在／sha 是哪一顆」，
⛔ 不是「我記得我 pull 過」。

## 📌 LY 那次量到、BTC 會再遇到的幾格

1. **`bank_diff` 切換之後就不是閘了。** 舊帳本凍結、新銀行繼續走 ⇒ 兩邊必然分岔，差額會變大，**那是預期**。切換後的 `bank_diff` 現在會自己印這句定語（`UCL_Core 6e984242` 之後）。⛔ 別看到紅字就去修一個不存在的 bug。
2. **射程（閘裡有幾戶）是 persona pool 推導的，不是綁定檔。** LY 量到 09-17 是 11 戶、09-18 是 10 戶，而綁定檔自 08-20 一個字沒動。⇒ 跨日要比**射程逐 id 那一行**，⛔ 不是比戶數。
3. **對帳器只能走 `GetAllBalancesLegacy()`。** 我在 LY 那次把 `GetAllBalances` 接上權威，對帳器當場變成拿新銀行跟新銀行比 ⇒「逐戶零差額」**恆真**，而畫面跟真的通過一模一樣。BTC 這邊不必再改，但**驗收時要記得那道閘曾經可以被自己弄成恆真的**。
4. **`senate.exe` 是共用的一顆。** `Cmd_Bank` 的定語已改成逐棵樹推導 ⇒ BTC 沒切之前它仍會對 BTC 說「本帳＝測試用」，那是對的。⛔ 別因為 LY 切了就以為那句話壞了。
5. **Server 是必要條件。** 切換之後寫錢一律派給常駐 Senate Server，沒跑就**整筆失敗且不降級**。Bar 那邊動手前先確認 Server 在跑（`senate server status`，或新的 `ui --page server`）。
6. **每筆寫錢多一次 Server 往返**（LY 實測 `server-ping` 1.216s）。
