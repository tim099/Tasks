# TASK-0491 — 雕刻作品的時間標記：標記某一刻／某一段，觀測時還原那一刻、撤掉或只看那一段

> `feature` / `normal` / `done`　開單：basecamp　參與：basecamp(dev)

## 驗收標準

- [x] 標記：作品可以加「某一刻」的標記（名字＋單點／區間開始／區間結束＋備註），預設標在現在；也能指定過去的某個事件補標；同名同類重複時擋下（要覆蓋得顯式給）　✅ basecamp 2026-10-11
- [x] 標記列得出來：單獨列一張表，作品歷史那一頁也看得到　✅ basecamp 2026-10-11
- [x] 還原外觀：view／slice／section／stats／export 給一個標記，就畫出（匯出）那一刻的樣子 —— 作品本身、快取、事件一格都不動　✅ basecamp 2026-10-11
- [x] 區間：可以「把某一段的改動撤掉再看」（例：拿掉外板看裡面）與「只看某一段改動到的格」　✅ basecamp 2026-10-11
- [x] 寫入類的 op（落子、刻、貼、編輯）不受標記影響　✅ basecamp 2026-10-11
- [x] 反向對照：標記指到不存在的事件、名字不存在、同名有開始／結束卻沒說哪一個 ⇒ 擋下、零寫入；undo 之前的標記仍畫得出 undo 之前的樣子　✅ basecamp 2026-10-11
- [x] 舊版重播器讀得懂作品（標記不寫進 events）；selftest 與 Sculpture 文件補上　✅ basecamp 2026-10-11

## 任務描述

Tim 2026-10-11：「加炮門前是否可以給雕刻引擎加一個功能，標記某個雕刻區間（例如標記哪一段是在雕刻炮門），用來在之後可以還原某個歷史時刻的外觀（例如還原炮門雕刻前的船殼樣子）」「船殼其實也可以標記一下」「然後也可以用在標記之後船的內裝、桅杆、每層甲板等」。誰在等：Tim；憲法號階段八（TASK-0490，開砲門）等這張先做完。

設計（basecamp）：標記存在作品自己的 marks.json（不進 events ⇒ 舊版 senate.exe 照常重播）；一個標記 ＝「重播到某個事件（含）為止」的那一刻。觀測類 op 給標記就從頭重播到那裡（不讀不寫主快取）；區間的「撤掉」＝ 那一段改過、之後沒再改的格回到區間開始時的值；「只看」＝ 那一段改過的格。
