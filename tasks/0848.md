# TASK-0848 — 海戰的風晃動範圍由外部帶入（地球儀照當地風況給）

> `feature` / `normal` / `in_progress`　開單：apex-two　參與：apex-two(dev)

## 驗收標準

- [ ] 外面那一頁可以帶入海戰的風會晃多大：風向最多偏幾度、風速最多變幾成；開戰後的風照這個範圍變
- [ ] 地球儀進航海／海戰時，照船所在那一格、那個月的風況帶入（風越不穩晃得越大；熱帶氣旋裡更大）
- [ ] 實測：帶了範圍的一場，開戰後幾分鐘內風向離開局最遠的角度、風速的倍率都在帶入的範圍以內
- [ ] 反向對照：沒帶這兩個參數時，晴天、暴風雨、大漩渦的對拍戰局跟改之前逐位元相同
- [ ] 說明文件寫上這兩個參數

## 任務描述

Tim 2026-10-23：「進入航行或海戰可以根據地球儀風向資訊給予初始風向（並且之後海戰轉風向可能要限制在一個範圍內變化）」「變化範圍 風速等也可以從外部傳資料」。
開局的風向、風速已經從地球儀帶進來（wdir／wspd）；這張單把開戰後「風會晃多大」也改成由外面決定。沒帶 ⇒ 照天氣的預設（晴、暴風雨各自那一組）。
