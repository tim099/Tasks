# TASK-0933 — 《Blocksail》動物用 2D 圖片演出（同鎮民：會走、會晃）：養殖場的動物換掉、城外的野生動物

> `feature` / `normal` / `in_progress`　開單：basecamp　參與：basecamp(dev)

## 驗收標準

- [ ] 動物用 2D 圖片演出，跟鎮民同一種畫法：會走、會停、走路時晃動；只在鏡頭附近畫、畫面外的不算（效能比照鎮民）
- [ ] 養殖場的動物換成 2D：養雞場、豬圈、牧場模型裡雕的方塊動物拿掉，動物在圈裡、雞場裡走動，不走出圍欄、不穿過牆和槽
- [ ] 野生動物：照 `world/species.js` 的動物物種與分布，在城外的地上出現（同一套演出）；地球儀「物種」查得到的地方，遊戲裡看得到那一種
- [ ] 遊戲裡截圖看過：一座城的養殖場（三種）、城外一處野生動物
- [ ] 反向對照：動物的開關關掉 ⇒ 不載、不畫；開或關，戰局與城鎮帳逐位元組相同（動物只給人看）
- [ ] 文件：動物的素材格式、模型怎麼標動物活動的範圍、野生動物怎麼挑物種

## 任務描述

## 要什麼
Tim 2026-10-25：「目前的想法是 動物可以跟鎮民一樣用2D圖片演出(會移動 晃動) 且可以有野生動物(用一樣的演出)」「可以先開成task(之後把養殖場動物替換成2D動物演出)」

## 現況
- 鎮民：Blockside `src/js/63_townfolk.js`（看板、照畫面時間算位置、只畫鏡頭附近），素材 Blocksail `world/townkit/_folk.js`＋`_people.js`（`docs/TOWNFOLK_ART.md`）。
- 養殖場：TASK-0926 的養雞場、豬圈、牧場（`BUILDING_SPEC.md` §6.22）裡的雞、豬、牛是雕在牆身的方塊擺設，等這張換掉。
- 野生動物：`world/species.js` 已經有 `kind: 'animal'` 的物種與分布區（野化的牛與豬、硬毛鼠、刺鼠、野豬…；`docs/SPECIES.md`）。

## 邊界
- 只給人看：不進模擬、不碰模擬亂數。
- 動物的圖另開美術單（type asset），這張等圖。
- 狩獵、捕捉、動物數量照生產或族群變動：不在這張。
