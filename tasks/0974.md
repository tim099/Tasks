# TASK-0974 — 《Blockside／Blocksail》往來的船掛自己那一國的旗：城鎮的勢力 ⇒ 船的旗（每艘船自己的旗）

> `feature` / `normal` / `in_progress`　開單：basecamp　參與：basecamp(dev)

## 驗收標準

- [ ] Blockside：每艘船可以掛自己的旗（sh.flag ＝ 預設旗的 key）—— 那一型的貼圖集照需要多烘一份（陣營旗每一面、替換掉的作品旗），沒給的照陣營（藍、紅）；換旗後同型的船都重做帆的緩衝（物理關著的也要）
- [ ] Blockside：補國旗的預設旗：法國（1660 年代商船旗：藍底白十字）、荷蘭（紅白藍三橫條）、丹麥（紅底白色北歐十字）、熱那亞（白底紅十字）；英國商船用紅旗（gb-red）、西班牙用勃艮第十字、海盜用骷髏
- [ ] Blockside：往來的船（58_traffic.js）照清單的 flag 掛旗；清單裡的 flag 換了（城轉手）⇒ 跟著換
- [ ] Blocksail：範圍層的勢力表加 flag；地球儀 trafficFor 每艘帶 flag —— 船隊主人是城鎮 ⇒ 那座城現在的擁有者；是家族 ⇒ 家族母港那座城；海盜 ⇒ 海盜旗；沒有對應的（原住民、逃亡者、東羅馬、玩家）不帶 ⇒ 照陣營旗
- [ ] 驗：同一型兩艘掛不同的旗、先畫一艘再加旗的那一艘不錯位（反向：拿掉換旗後重做帆的那一行 ⇒ 看得出錯）；無頭海戰 tick hash 不變（沒有 flag 的船逐位元組照舊）；遊戲裡聖地牙哥、金斯敦、和平港的港口截圖

## 任務描述

Tim 2026-10-26：「港裡的船都掛英國旗 目前支援陣營旗了 可以給不同國家的城鎮加上對應旗幟替換」（聖地牙哥進城截圖：西班牙城的港裡全是英國旗）。

現況：TASK-0950 的旗是陣營層級（藍方、紅方各一面；預設都是英國旗角），每個船型的貼圖集只烘這兩份，船照 team 挑；往來的船（58_traffic.js）都是藍隊 ⇒ 全掛藍方那面。
