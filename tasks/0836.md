# TASK-0836 — 《Blockside》砲身與砲座拆兩件：後座只退砲身、座跟著砲塔轉、固定式的座不動；大型砲塔的砲上下轉（只是演出）—— 先做松島號

> `improvement` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 松島號的砲（主砲 32 cm、12 cm、57 mm、47 mm）砲身與砲座拆成兩件：雕刻外觀逐格相同（split 引擎比對 mismatch 0）；每個擺放都有座、座的 meta 指到自己那門砲（匯入檢查 ✗ 0）
- [ ] 遊戲裡開火只有砲身往後退，砲座不動；砲塔、迴旋砲轉的時候座跟著轉；固定式的砲（沒標 mount、不在砲塔上）座固定在船上
- [ ] 大型砲塔的砲（模型 meta pitch，先標松島號主砲）照瞄準的距離上下轉，只是畫面：戰局一個值都不讀它
- [ ] 沒拆的船戰局不變：10 組對拍跟改之前逐位元組相同；松島號換了合起來的網格，戰局有變就寫新值與原因
- [ ] 反向對照：拿掉座的配對 ⇒ 座不畫／整門照舊一起退；拿掉 pitch ⇒ 砲身不抬
- [ ] 造船規格補上「砲身與砲座拆兩件」「固定式的砲」「pitch」三段，§10 檢查表多一行

## 任務描述

## 為什麼開（Tim 2026-10-23）
「接著是遊戲相關的船隻meta調整 是否可以把一些炮跟炮身拆開(在雕刻中維持原外貌) 讓炮的後座力只讓炮身移動 目前最明顯的就是松島號的主炮跟甲板內的炮(炮座應該是固定在船上的)」
「這個屬於遊戲相關調整 確保雕刻外觀接近即可」
「然後更新相關文件到造船文件 炮如果是固定式的話要額外處理(另外目前架構支援嗎 需要的話可以調整架構) 同時可以考慮支援炮可以上下轉動」
「上下轉動只要大型砲塔的炮支援就好 松島號主炮這種的」「然後轉動只是演出 不影響任何遊戲運算」

## 現況（ame 量的，Blockside dev 2ca1707）
- 後座（62_ports.js recoilPose）寫的是整個砲模型的 m.vsl ⇒ 砲座跟著退；架構上「一門砲 ＝ 一個模型」，沒有分件。
- 松島號的砲元件是一件作品雕砲身＋座：Canet 32 cm（液壓搖架、斜滑座）、Armstrong 12 cm（中心樞軸座、砲盾）、哈乞開斯 57／47 mm（立柱座）；顏色分得開（砲身 GUN_BLACK／BRASS、座 GUN_IRON 與盾）。

## 做法
- 雕刻：work split（§9.4.12，不限作者、引擎證明外觀不變）把座拆成子作品，每個擺放自動補雙生「座」，meta kind=gunmount、mount_of=<砲的 id>。
- 遊戲：座是裝飾件（不算重量、不擋彈）、一律畫；載入時砲的模擬網格 ＝ 砲身＋座合起來（外框、砲班站位、命中範圍照舊），畫面分兩件 ——
  砲身吃後座（＋ pitch 的仰角），座跟著砲的擺法（砲塔、迴旋砲）、不吃後座。
- pitch：照瞄準點用 shotEl 算、扣掉船身傾斜、限速；只寫畫面的欄位。
