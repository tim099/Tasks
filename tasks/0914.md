# TASK-0914 — 《Blocksail》城鎮建築的崗位：海關（公職人員）、船具行（生產船具）、教堂（服務建築：菜單、信仰滿意度、捐獻）

> `feature` / `normal` / `in_progress`　開單：gura　參與：gura(dev)

## 驗收標準

- [ ] 公職崗位：海關有公職人員的崗位，工資從主人（城鎮）的金庫付，人數照城的規模；讀數列出開場各城雇了幾人、一天付多少工資
- [ ] 反向對照：拆掉海關 ⇒ 公職人員 0、那份工資不再從城鎮金庫出去；關稅照舊（跟海關無關）
- [ ] 船具行真的生產：新貨「船具」，配方吃木板、繩、鐵件；讀數列出一座船具行一天吃多少、產多少；原料不夠 ⇒ 照夠的比例少產
- [ ] 船具有人用：船廠吃船具（船隻先不消耗）；讀數列出一天用多少；市場沒有船具 ⇒ 船廠停工、不付工資
- [ ] 教堂菜單：基礎款只要人手；另一款多吃物資（麵包、葡萄酒）、滿意度更高；讀數：同一座城掛基礎款 vs 掛高級款，信仰滿意度與吃掉的物資
- [ ] 地標教堂（聖索菲亞等）也是教堂，容量更大、效果更好；一座城有一般教堂也有大教堂 ⇒ 人先往大教堂去
- [ ] 捐獻：鎮民照參加的人次付捐獻，進教堂主人的金庫，算在鎮民的消費預算裡；跑 365 天，每天對帳 0 筆、全世界的錢總數不變
- [ ] 反向對照：沒有教堂 ⇒ 信仰滿意度 0、捐獻 0；高級款的物資沒了 ⇒ 那一份換成基礎款
- [ ] 供的飯先算：彌撒吃掉的麵包、葡萄酒算成那一級的飯，鎮民吃飯先扣掉、不足的才由家裡的灶煮
- [ ] 讓錢流動：城鎮金庫不夠 ⇒ 鎮民花快一點；鎮民的存款也收資產稅；讀數：同一份開場跑一年，規則開 vs 關的城鎮金庫、鎮民存款
- [ ] 開場的存量：船具行、船廠、教堂吃的料（產品與原料）開場有一定的量
- [ ] 自動建築不再一直蓋缺料停工的補料（反向對照：關掉 ⇒ 磚窯一直蓋）
- [ ] 教堂用的「服務建築」寫成通用的一套（招待量、菜單、捐獻／付錢、滿意度、供的飯），之後餐館、酒館只要填表；PRODUCTION §13 標出哪些做了、餐館酒館還差什麼
- [ ] 城鎮介面看得到：崗位表有公職人員、教堂的人；概況有信仰滿意度、昨天的捐獻、鎮民吃各種食物的比例（有圖）；貿易頁有商品圖（有的話）
- [ ] 開場檔重算後，規劃裡有海關、教堂、船具行、船廠的城，帳上都有那幾座；同一份輸入跑兩次逐位元組相同；既有的檢查工具照樣全過（main 上原本就沒過的照舊）
- [ ] 文件（PRODUCTION、STORES、TOWN_UI、RESOURCES）寫上規則與讀數；數字標佔位


## 任務描述

## 要什麼
Tim 2026-10-25：「城鎮建築加上崗位 例如海關(公職人員) 船具行(真的生產船具) 教堂(類似餐館 酒館 提供居民滿意度(虛擬商品) 然後收取捐獻(相當於鎮民消費)」

拍板（同日，問答）：
- 範圍：海關、船具行、教堂三棟，外加教堂用的服務建築框架做成通用的（餐館、酒館之後套上去）。
- 海關：只是雇人 —— 公職人員佔崗位、領城鎮的薪水；關稅照舊固定 10%，跟海關無關。
- 船具：新增一種貨「船具」（滑車、索具配件），配方吃木板＋繩＋鐵件。
- 教堂：「參考餐館可以有菜單機制 可以有基礎款(只有人手) 以及有額外消耗的菜單(更多滿意度)」。

## 現況（2026-10-25 查的）
- 規劃裡已經有 customs（海關）、chandlery（船具行）、church／chapel（教堂、小教堂）這些用途，但 `world/buildings.js` 沒有它們 ⇒ 不進城鎮帳、沒有崗位。
- 餐館、酒館只有設計稿（Blocksail `docs/PRODUCTION.md` §13），程式還沒有；滿足度目前只有讀數。
- 崗位已有的模式：生產建築（`world/prod.js`）、營造廠的菜單（§14.2）、士兵與採集（`world/townstate.js`）。

## 邊界
- 餐館、酒館本身不在這張（只把框架做好）。
- 滿意度先出讀數、進城鎮介面；拿它影響人口或移民，等 Tim 另外決定。
- 新貨的圖示走美術素材單，不在這張。
