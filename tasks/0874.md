# TASK-0874 — 《Blocksail》地形編輯：範圍層的等深線（平滑的天然水深；之後越過岸線改海岸線）—— 不重抽世界地圖；金斯敦先試

> `feature` / `normal` / `todo`　開單：kaguya　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 地形編輯的規格寫進 Blocksail 文件（WORLD_FORMAT 範圍層那一節＋TOWN_TOOLS「改地形」，scp-blocksail-town 讀得到）：等深線怎麼畫、怎麼內插、什麼時候用人工挖（dredge）、怎麼檢查
- [ ] 範圍層多一種「等深線」：一圈＋水深，同一組一圈套一圈；最外圈不寫水深 ＝ 跟原本的海床接起來；圈與圈之間照距離內插（不是一階一階、不是長方形的牆）
- [ ] 平滑：同一組裡沒有一道比上限陡的坡（讀數印最陡的坡）；反向對照：最外圈寫了水深（外面一圈跳一階）⇒ areas_check 擋下
- [ ] 沒有任何等深線的海域：海圖塊、六座城的規劃、town_check 跟改之前逐位元組相同（對照組）
- [ ] 金斯敦：拿掉長方形的 dredge-kingston-wharf，改用等深線把港口畫成平滑的天然水深；玩家停靠處照樣停得進去、泊位照樣通外海（town_check、town_report、town_dock）
- [ ] 遊戲裡看金斯敦港口的海床（Blockside 海圖塊）：沒有長方形的坑
- [ ] 人工挖的（史料寫著挖過的港池、航道）照舊用 dredge；文件寫清楚兩種怎麼選
- [ ] 第二步（另一輪）：等深線越過岸線 ⇒ 陸地挖成水，海岸線、等高線在 world.js 載入時跟著改（布科勒昂港）

## 任務描述

Tim 2026-10-24：
- 「世界地圖要重抽才挖得出來 是否可以修改架構 為何無法局部改變地形(直接在世界地圖上挖港池呢?)」
- 「我的意思是 不動烘好的 而是跟細化地圖一樣 改等高線(還是目前不支援設定水深 那需要改為支援)」
- 「開單動工 不過這個我想先規格化且用金斯敦先測試 先把金斯敦挖出來的港池移除 改用等深線處理港口水深 且必須要平滑(除非是人工挖的港) 目前挖一塊長方形很突兀 這個規格要進到 /scp-blocksail-town」

**為什麼要做**：
- 海岸線、等高線是抽取工具烘好的向量（world/tiles）；地球儀、航線、地形格、城鎮都直接讀 ⇒ 改一小塊岸要整份世界重抽（10-23 之後還要 Sirius 的擴充那一段）。
- 水深只有兩種來源：圖磚（博斯普魯斯那一框海一律 0 m ⇒ 照離岸距離的預設坡）、範圍層 dredge（一圈壓到一個深度，圈邊 edge 公尺漸深）。dredge 拿來修天然水深 ⇒ 一塊平底的坑、四邊一道牆（金斯敦 13 m、edge 10）。

**做法**（範圍層、不動烘好的圖磚、世界重抽也不會蓋掉）：
1. 第一步（這一輪）：等深線 ⇒ 海床的高度照一組一圈套一圈的等深線內插；先在金斯敦試。
2. 第二步：等深線（或等高線）越過岸線 ⇒ 陸地變水／水變陸地，world.js 載入時改海岸線與等高線；布科勒昂港用它挖。
