# TASK-0371 — 交易所投資報酬率：交易事件簿＋開帳快照＋persona 持倉頁＋法幣報價（TWD/JPY/EUR…）

> `feature` / `normal` / `in_review`　開單：gura　參與：gura(dev)

## 驗收標準

- [ ] ① 交易紀錄：兌換（兩個入口都走 SCP_VoucherSwap）、發券（demurrage 轉券）、voucher op=grant／consume／migrate 每筆寫一個不可覆寫的事件檔到 `Market/portfolio/events/`；只記有報價的券。寫事件失敗不讓已成立的券異動失敗，但回傳要明說
- [ ] ② 開帳快照：`senate cmd portfolio --arg op=open --arg confirm=1` 只能跑一次（第二次拒絕），用當下報價把所有可估值持倉寫進 `Market/portfolio/opening.json`，現值＝成本
- [ ] ③ 報酬率：加權平均成本；賣出計已實現損益；成本來源分「實際成本／上線時估值／混合」標示；帳上數量與紀錄不符的差額單獨列出、不計入報酬（⛔ 不當成 0 成本）
- [ ] ④ 新頁 `portfolio`（銀行群組）：工具列選 persona 與顯示幣別，只顯示該 persona 的可估值持倉（數量／成本／均價／現價／現值／未實現損益／報酬率／已實現）、無報價持倉、最近交易
- [ ] ⑤ 法幣：新增來源種類 `fx_rates_per_usd`（讀「1 USD 兌多少」的匯率表並取倒數）；LY 加入 TWD／JPY／EUR／GBP／CNY／KRW／HKD 報價並能 `rate op=sync` 刷新
- [ ] ⑥ 兌換結果若讓目標券簿永久券超出 int 上限 ⇒ 拒絕並說明（法幣單位小，173 BTC 換 KRW 就會溢位）
- [ ] ⑦ `rate op=set` 與匯率頁手動存報價時保留既有的抓取端點設定（現況會把它清掉、自動刷新靜默停止）
- [ ] ⑧ selftest：解析器（含反向對照：格式不符／缺幣別要失敗）、平均成本重算、開帳不可重跑、溢位守衛
- [ ] ⑨ 反向對照：沒有報價的券（Florin／canvas／tavern）不產生事件、不出現在報酬率表；未開帳時頁面明說「尚未開帳」而不是顯示 0

## 任務描述

Tim 2026-10-01：「RateAdminPage 以及整個交易所系統是否可以支援查看投資報酬率（參考購入價格＆現值）；開新頁面顯示（TopBar 選 persona，只顯示該 persona 的投資＆持有的類型）；擴充支援更多貨幣（新台幣、日圓、歐元等主流貨幣）。」
拍板（同日）：「如果沒有紀錄的話可以在系統層上增加紀錄（不管舊的資料）」「既有持倉可以根據新系統上線時的現值計算（假如無法推算原成本）」。

現況（讀碼確認）：券簿只存狀態不存事件（2026-09-18 拍板「券不記歷史」），兌換只改兩個券檔、成交率不落盤 ⇒ 現有資料推不出成本。報價只有 USD／BTC／GOLD（Binance）；報價模型本身支援任意幣別，但自動刷新的解析器只有 Binance bookTicker 與單一 price 兩種。
⇒ 本單在券本之外另加一本只增不改的交易事件簿（不改券簿 schema），並以開帳快照當既有持倉的成本。
