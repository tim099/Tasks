# TASK-0724 — 《Blocksail》貿易模擬 spike：導航圖（只存直航）＋概略層 365 天對帳

> `spike` / `normal` / `todo`　開單：gura　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 導航圖：托爾圖加海峽附近至少 4 個港口、它們之間的直航（折線避開陸地與淺灘、兩個季節各自的雙向航速）；任兩港之間都找得到路，讀數列出每一對的路徑與航行時間
- [ ] 直航判準：有港口離航路太近的那一段會拆成經過它的兩段；門檻與拆了哪幾段寫進讀數
- [ ] 封鎖一段直航 ⇒ 經過它的路徑改走別段、時間變長；反向對照：解除封鎖 ⇒ 回到原本的路徑與時間
- [ ] 概略層：3 個港口、3 種貨、2 條貿易路線、一塊海盜活動區域，跑 365 天；各港庫存與價格的曲線看起來合理（不爆掉、不歸零），每種貨一年的總量誤差有讀數（不要求 0 —— Tim 2026-10-19：以遊戲體驗與效能為主）
- [ ] 效能：跑 365 天要多久（同一台機器）寫進讀數
- [ ] 同一個種子跑兩次結果相同（除錯用）；換種子結果不同
- [ ] 反向對照：關掉海盜活動區域 ⇒ 被劫的貨歸零、海盜據點的庫存不再增加
- [ ] 程式與讀數放 Blocksail repo；TRADE_SIM.md 補上量到的數字

## 任務描述

## 要什麼
Tim 2026-10-19：「開一張 spike 單掛在 0706 底下：先做導航圖（托爾圖加海峡附近幾個港口的直航）＋概略層（3 港 3 貨 2 路線跑 365 天對帳）」。
設計在 Blocksail repo（私有）`docs/TRADE_SIM.md`：第 1.1 節導航圖（只存直航，其他用組合的）、第 2.1 節概略層、第 2.3 節交接規矩、第 7 節從哪裡開始。

## 邊界
- 只做導航圖與概略層；精細層（真的船隊、海盜船隊開打）不在這張。
- 不用畫面；程式與讀數放 Blocksail repo，⛔ 不改 Blockside。
- 港口、貨物、數值先用假的也可以，重點是結構與對帳；史實資料之後再填。
