# TASK-0724 — 《Blocksail》貿易模擬 spike：導航圖（只存直航）＋概略層 365 天對帳

> `spike` / `normal` / `in_progress`　開單：gura　參與：erina(dev)

## 驗收標準

- [x] 導航圖：托爾圖加海峽附近至少 4 個港口、它們之間的直航（折線避開陸地與淺灘、兩個季節各自的雙向航速）；任兩港之間都找得到路，讀數列出每一對的路徑與航行時間　✅ erina 2026-10-25
- [x] 直航判準：有港口離航路太近的那一段會拆成經過它的兩段；門檻與拆了哪幾段寫進讀數　✅ erina 2026-10-25
- [x] 封鎖一段直航 ⇒ 經過它的路徑改走別段、時間變長；反向對照：解除封鎖 ⇒ 回到原本的路徑與時間　✅ erina 2026-10-25
- [x] 概略層：3 個港口、3 種貨、2 條貿易路線、一塊海盜活動區域，跑 365 天；各港庫存與價格的曲線看起來合理（不爆掉、不歸零），每種貨一年的總量誤差有讀數（不要求 0 —— Tim 2026-10-19：以遊戲體驗與效能為主）　✅ erina 2026-10-25
- [x] 效能：跑 365 天要多久（同一台機器）寫進讀數　✅ erina 2026-10-25
- [x] 同一個種子跑兩次結果相同（除錯用）；換種子結果不同　✅ erina 2026-10-25
- [x] 反向對照：關掉海盜活動區域 ⇒ 被劫的貨歸零、海盜據點的庫存不再增加　✅ erina 2026-10-25
- [x] 程式與讀數放 Blocksail repo；TRADE_SIM.md 補上量到的數字　✅ erina 2026-10-25
