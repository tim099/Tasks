# TASK-1301 — 《Blocksail》首批地中海船⑤ 突尼斯湖淺水轉運划艇

> `feature` / `normal` / `in_progress`　開單：meadow　參與：kiara(dev)

## 驗收標準

- [ ] 步驟 1 查突尼斯湖與拉古萊特的同期水域與小艇紀錄，分列直接證據、近區類比和設計值。
- [ ] 步驟 2 依史料做淺水槳艇，能沿用相符小艇船殼時採改型，對帳比例、水線與貨位。
- [ ] 步驟 3 量實際湖口、近岸吃水及轉運停泊位置。加貝斯版本作獨立場景測試，記錄兩地的史料限度。
- [ ] 步驟 1 開單、列步驟：照船的種類挑好步驟、貼成驗收標準（讀：Ship_Steps）
- [ ] 步驟 2 開工前：座標與比例、作品怎麼拆、查 sub=components 能用的現有元件、建船殼（任務作品）與組裝件、都記 meters_per_voxel（讀：Ship_Setup §0–§2.1；委託與收費看 scp-sculpture）
- [ ] 步驟 3 找資料與新圖紙：主尺寸、線形（龍骨、艏艉柱、剖面）、甲板高度、桅帆表，每個數字標出處或設計決定；產生程式重跑逐位元組相同（讀：Sculpture_Blueprint_Build §1–§4、Ship_Setup §3）
- [ ] 步驟 4 船殼落格、塗裝：結果帳缺 0／多 0／色差 0、1 元件、空腔 0、鏡像差 0、反向對照（讀：Sculpture_Blueprint_Build §5–§8）
- [ ] 步驟 5 甲板、梯子、艙房：每層甲板子作品＋meta（kind=deck、level、floor、thick）、走路格與貨位平台對帳（讀：Ship_Decks）
- [ ] 步驟 6 裝飾：船首、船尾、繫纜樁與護舷等裝飾；能隱藏的裝飾做成模型標 deco=1（讀：Ship_Fittings §9.9）
- [ ] 步驟 7 桅與帆桁：每根桅一件子作品、下桅的關聯標 meta kind=mast＋mast（帆桁的 mast 一字不差對到它）、每根帆桁一件子作品＋外部模型（pivot、meta kind=yard）、`yard` 的值照遊戲怎麼轉挑、三角帆桁 rig=lateen（讀：Ship_Masts）
- [ ] 步驟 8 索具、帆、旗：靜索、帆角綁帆桁模型、帆／旗／帆自己的繩標 meta；帆裝三段各張哪幾面排成表（收帆、戰鬥帆都至少一面；單帆 set 1）；ropes_broken 0、sails_broken 0（讀：Ship_Rigging）
- [ ] 步驟 10 甲板物件：貨位（貨箱／酒桶）／繫纜與燈具／門與艙蓋（如有）（讀：Ship_Fittings §9.7／§9.13／§9.14）
- [ ] 步驟 11 舵、舵輪、錨：舵是模型（kind=rudder＋stock-top＋spin）、舵柄、錨用共用元件、錨鏈孔固定點（讀：Ship_Helm；錨看 Ship_Game §9 表的 anchor 那一列）
- [ ] 步驟 13 動力與材質：槳（每舷槳位、划手與槳支點，掃掠與靠泊對帳）、木質與少量鐵件材質（讀：Ship_Oars、Ship_Materials）
- [ ] 步驟 14 給遊戲的 meta 與匯入：kind=ship waterline_z、ropecheck、匯出 vxk、匯進 Blockside（暫存副本或自己的 worktree）、admin.py ids、shipcheck ✗ 0、樓梯自檢 ✗ 0；新做的桶、槳、舵輪這類元件要不要標 render（讀：Ship_Game §9／§9.4／§12、Ship_Render）
- [ ] 步驟 15 交船：換一艘船時的檢查表逐條看過、notes 寫下給遊戲那側填 geo 的高度、跟遊戲那側對 checksum（讀：Ship_Game §10）

首批補一艘北非湖內小船。用途是拉古萊特－突尼斯湖岸的短程轉運，並作加貝斯淺水場景的候選。轉運路線有史料，具體船名與船線尚未確定。誰在等：Tim 和 TASK-1288 北非城鎮。
