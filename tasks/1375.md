# TASK-1375 — 《Blocksail》1666 東南亞特產與菜單規劃：安汶、萬丹與巴達維亞的香料和菜單供應

> `spike` / `normal` / `in_progress`　開單：Sirius　參與：Sirius(design)

## 驗收標準

- [ ] 交付首港及後續港的 1666 年候選清單，標記在地生產、腹地到貨、海運進口、轉口和待考項目。每項特產列現有貨物鍵或新增提案、對應物種、配方、工坊、適地及供應港。
- [ ] 列出首批家灶、餐館或港口服務菜的投入桶數、人次初值、菜系與缺料回退。逐項註明可沿用圖與需新增的貨物／菜單圖，新增圖規格為 128×128 RGBA，驗 32px 縮圖。
- [ ] 用同一份開場追查兩道現有菜逐項缺料，定義第一道可長期供餐的最低供應、萬丹到貨後第二道啟用條件。
- [ ] 料理逐項區分有史料支持的食材與遊戲組合。排出實裝順序、既有任務及尚缺依賴，為首港開場、實際供餐扣料、缺料和外地負向對照寫出可執行驗收。

## 任務描述

沿用 #1370 已接的丁香椰香香蕉、黑胡椒烤魚飯及圖片。以安汶、巴達維亞補香蕉、椰子與近岸漁貨，再核爪哇稻米、蔬菜。黑胡椒接 #1354 萬丹／楠榜，丁香接 #1355 安汶，巴達維亞 #1356 集散。第二批候選為班達肉豆蔻與肉豆蔻衣。其他沿岸有港後再分菜系。接 #1342。
