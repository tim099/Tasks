# TASK-0503 — 雕刻：帆（布料模擬）—— 綁在固定點與繩索上、風＋重力、可設顏色或貼圖

> `feature` / `normal` / `todo`　開單：basecamp　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 作品可以定義帆：形狀（至少四邊形與三角形）、每個角（或一整條邊）綁在哪些固定點上（固定點格式跟 TASK-0502 共用，可用關聯路徑跨子作品指名）；存在作品裡、不是 voxel，⛔ 不改任何 voxel
- [ ] 一整條邊綁在兩個固定點之間（方帆上緣沿 yard）：那條邊全程固定在線段上，不是只固定兩個角
- [ ] 布料模擬：重力＋風（方向、強度可設），算到靜止；同樣的輸入每次同樣的形狀；CLI 印得出讀數（例：每面帆最鼓的那一點離綁點平面多遠、模擬步數、是否收斂）
- [ ] 風向反過來 ⇒ 帆往另一邊鼓（反向對照）；沒有風 ⇒ 只受重力往下垂
- [ ] 顏色（palette index 或 #RRGGBB）與貼圖（圖檔路徑；貼圖不歪、方向寫在文件）
- [ ] 帆的角可以當繩索（TASK-0502）的端點：拉動繩子的另一頭（或改它的鬆緊）⇒ 帆的形狀跟著變
- [ ] 跟著部件走：關聯的 at／turn／mirror 改了、或關掉那條關聯 ⇒ 綁在上面的帆跟著移動／不畫；綁點不見了 ⇒ 那面帆被報出來，⛔ 不靜默消失
- [ ] 觀測：op=view 與觀測頁（SculptureViewerPage）畫得出帆（顏色／貼圖），可以開關；整艘船二十幾面帆時觀測頁不明顯變慢（寫出讀數）
- [ ] 匯出：export obj 輸出帆的網格（含 UV 與貼圖），Tim 匯進 Unity 看得到
- [ ] 文件（Sculpture.md）寫用法；收帆、縮帆留位置（本單可以不做）

## 任務描述

Tim 2026-10-11（看憲法號 TASK-0478 時）：帆不用 voxel 雕，另外做 ——
- 「帆可以另外用布料模擬方式，設置綁定的位置（綁在幾個 voxel 上固定，然後可以跟線綁定），最後透過風＋重力模擬布料」
- 「帆也可以設定顏色（甚至指定貼圖）」
- 「繩索可以綁帆 & Voxel 固定點」（繩索是 TASK-0502）
- 「帆也可以開一張 task」

用在哪：憲法號三根桅的方帆（course、topsail、topgallant、royal —— 上緣綁在 yard 上、下面兩個角〔clews〕由繩子拉住）、後桅的 spanker（gaff 與 boom 之間的縱帆）、bowsprit 前面的三角帆（jibs、staysails —— 一邊沿著 stay）。yards 會做進各桅杆子作品（Tim 的決定），basecamp 會在 plan.json 記下每一面帆的綁點（固定點名字＋座標）。

跟 TASK-0502（繩索）的關係：固定點（有名字的格座標、跨關聯指名）是兩張單共用的 —— 先做 0502 定格式，或兩張一起定；帆的角可以當繩索的端點（例：clew 綁 sheet，sheet 另一頭綁甲板上的 cleat）。

設計建議（實作者可以改，改了寫理由）：
- 帆是作品的資料（例：sails.json：形狀〔四邊形／三角形／梯形〕、每個角或每一邊綁在哪些固定點或繩索端點上、布料解析度、顏色或貼圖），不是 voxel。
- 一邊整條綁在 yard 上（方帆的上緣）＝ 那一邊沿著兩個固定點之間的線段全部固定，不是只綁兩個角。
- 模擬：重力＋風（方向、強度），算到靜止為止；同樣的輸入每次算出同樣的形狀（可重現）；之後可以只換風再算。
- 收帆（furled，捲在 yard 上）與縮帆（reef）可以之後再做。
