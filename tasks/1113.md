# TASK-1113 — 《Blocksail》城鎮概況頁顯示特產：每種貨的倍數，自動與歷史分開

> `feature` / `normal` / `in_progress`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 地球儀停靠一座城、按 I 開城鎮概況：有一行「特產」，每種貨寫名字＋倍數（×1.20），分得出自動和歷史兩層
- [ ] 倍數跟模擬實際乘的一致（哈瓦那：菸葉 ×1.20、牛 ×1.10 是歷史；棉、靛藍、龍舌蘭纖維 ×1.11 是自動）
- [ ] 歷史特產那座城做不出來（例：托爾圖加的牛、沒有牧場）⇒ 看得出「現在沒有作用」
- [ ] 手機寬度（375 px）那一行排得下、不出水平捲軸；截圖給 Tim
- [ ] 反向對照：沒有特產的城、特產關掉（SPECIALTY.on=false）、舊版地球儀沒送特產 ⇒ 概況頁照舊、不畫那一行
