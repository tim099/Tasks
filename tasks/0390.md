## 驗收標準

- [ ] A、B 兩欄每一項都有判定（換／並存／不換）與一句理由，標「未測」的先實測再判

## 任務描述

Tim 2026-10-03「接著開 task，把可能可以改走 Unity CLI 的部分記錄一下」。誰在等：Tim。
背景與實測讀數：`ucl_core:Docs~/zh-Hant/Plan/Plan_Unity_CLI_Evaluation.md`（§5）。本機已裝 CLI `1.0.0-beta.12`（winget）與 `com.unity.pipeline 0.8.0-exp.1`（Bar `25b8750`）；安裝入口是 Editor 工具集 →「🧰 環境安裝」→ 套件安裝（UCL_Core `26c2a5cd`／`668f0949`）。

⚠ 先講射程：CLI **一樣要 Editor 開著**（它經 Pipeline 套件的 7800 埠問正在跑的 Editor）。換過去省掉的是「我們自己的 AgentCommand 佇列＋Cmd handler」那一層，⛔ 不是 Editor 依賴。
⚠ CLI 一律帶 `--project-path <Unity 專案根>`；每次呼叫約 1.5 s 啟動成本（實測），⛔ 不放進每次刷新都跑的路徑。

## A. 同一件事、可以換（ucmd → CLI）

| 我們的 | CLI | 讀數／狀態 |
|---|---|---|
| `Cmd_Recompile`＋`senate cmd unity-recompile`（觸發＋等那一趟） | `unity command recompile` → 輪詢 `recompile_status`（idle／triggered／compiling／completed／up_to_date） | ✅ **已實測**：Editor 失焦、檔案有變動 ⇒ 兩次都真的編（5.7 s／15.9 s）；故意放 `#error` ⇒ `failed=true`＋檔案行號錯誤碼。⛔ 頂層 `unity recompile` 失焦時回 `up_to_date` 沒編，不能用。📌 我們的 UCL_Core 編不過時 CLI 照樣回得出錯誤（實測放錯那次） |
| `Cmd_Invoke`（反射呼叫，**回傳值只進 Editor.log**） | `eval`／`eval_file`（Roslyn 跑任意 C#）、`run_script`（專案 .cs 的靜態入口，不 domain reload） | 未測。若回傳值直接在 CLI 輸出，就省掉「去 Editor.log 撈」那一步。⚠ 任意程式碼執行，官方有 capability gate |
| `Cmd_TypeInspect`（反射查型別） | `eval` | 未測；同上 |
| `Cmd_ReadHierarchy`（場景階層 → `_last_op.md`） | `get_scene_hierarchy`、`find_gameobjects`、`list_open_scenes` | 未測；輸出是 JSON |
| `Cmd_BuildPlayerCheck`（`BuildScriptsOnly` 只驗 player 腳本編譯） | `build`＋`build_status` | 未測；⚠ CLI 的是完整 Player build，**不一定等價**，要先查它能不能只編腳本 |

## C. 不換（我們自己的業務或 UCL_Asset 專屬，CLI 沒有對應）

- UCL_Asset 系列：`Cmd_FindAssetUsages`、`Cmd_AssetDump`、`Cmd_ResolveAssetReferences`、`Cmd_ValidateAssetFormat`、`Cmd_DiagnoseAssetReflection`、`Cmd_MigrateAssetToTemplate` —— CLI 的 `find_assets` 是 AssetDatabase 層，不懂 UCL_Asset 的 id／連動。
- `Cmd_BuildAddressable` —— CLI 沒有 Addressables 指令（要的話只能走 `run_script`）。
- 業務 Cmd：Tavern／Treasury／Library／StreamWatch／FreeTime／GoodMorning／Task／Coding／SessionClose／Books／Bartender／HelpUrlCheck／ExportCmdSchema／ExportCommandCatalog／SchemaSelfTest —— 這些的去向是搬 Senate（TASK-0324），不是 Unity CLI。

## D. 前提與風險

1. **每台機器都要裝 CLI＋每個專案都要裝 Pipeline**：LY 那台目前兩個都沒有 ⇒ A 欄每一項都要**保留現行路徑當退路**（CLI 找不到／exit 7 ⇒ 走 ucmd）。
2. Pipeline 是官方**實驗版**（`-exp`），CLI 是 beta；9 月中才修過「剛編完誤報連不上」。
3. Pipeline 讓 Editor 常駐開 7800 埠（同事 pull Bar 之後也會開）。
4. `eval`／`run_script` 是任意程式碼執行 —— 換掉 `Cmd_Invoke` 前先確認權限閘怎麼設。
