# TASK-0552 — 《憲法號對轟》艦名機制＋上方資訊面板可折疊（圓形按鈕：船體／進水圓環、側面投影、艦名）

> `feature` / `normal` / `done`　開單：ame　參與：ame(dev)

## 驗收標準

- [ ] 艦名：每種船型有自己的艦名池（憲法號 ＝ 同級的 44 砲巡防艦），另有一個公共艦名池；場上第一艘用原名，同型的下一艘照池子的順序拿，池子用完從公共池拿；同一場不重名
- [ ] 艦名在同一個種子、同一組編成下固定（重開同一場名字不變）；候補進場的船也有名字
- [ ] 上方資訊預設折疊：場上每一艘船各一個看起來可以點的圓形按鈕（我方在左、敵方在右）—— 外面兩圈圓環是船體與進水，中間是那一型的側面投影與艦名；沉了、降旗的看得出來
- [ ] 上方一列：我方的圓形按鈕在左、敵方在右、中間一塊詳細資訊（跟現在的面板同一份內容）；同時最多展開一艘 —— 點另一艘換成那一艘，點同一艘或資訊本身收回折疊；每一場開局都是全折疊
- [ ] 手機直拿（375×812）折疊時不擋到畫面中間、展開時不超出畫面；電腦 1600×900 也量一次
- [ ] 廣播：我艦照舊寫「我艦」，其他每艘船都用艦名（多船時分得出是哪一艘）
- [ ] 反向對照：只改畫面與廣播文字 ⇒ 同一個 ?demo dump 的戰局讀數逐字不變（命名不抽 rnd()）
