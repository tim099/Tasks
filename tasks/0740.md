## 驗收標準

- [ ] 城鎮規劃匯出到 Blockside（海圖塊新的一段或海域的城鎮檔；格式寫進 Blockside src/MAP_CHUNK.md），舊的解碼器讀到照舊能用
- [ ] Blockside 照規劃整地（建築地塊、路）、清掉路與建地上的樹，照用途擺建築模型；城牆照規模 × 繁榮度換一套（沒有／木柵／石牆…；繁榮度先用網址參數或除錯函式給）

- [ ] 跨海圖塊的路、牆、建築接得起來，載入順序不同結果一樣
- [ ] 建築照樹的做法分遠近畫：近處原模型（實例化）、中距離低模、遠處貼圖、更遠屋頂與城牆的殼；交接沒有一刀切的線；托爾圖加整座城載進來的三角形數與一格幾 ms 有讀數
- [ ] 低模與貼圖在匯入建築時就算好、存進成品，遊戲開局不現算；同一份輸入兩次逐位元組相同
- [ ] 反向對照：沒有城鎮的海域（例：舊的 maps）海圖塊與對局 dump 跟改之前逐位元組相同
- [ ] Tim 在遊戲裡看過托爾圖加

\### 做法的重點
- **只給人看**：整地只寫進給畫面的那一份高度（`C.hv`），模擬查的 `C.h` 不動 ⇒ 城什麼時候到都不影響戰局（就地生成的城要好幾秒才到，不擋開戰）；無頭不載城。這一點跟 TOWN_BUILD §5 原文「畫面與 bedHgt 同一份」不同，理由寫進文件了。
- 清樹：規劃的 `clear` 每 2 m 一格遮罩，樹與小植物都跳過；空建地照長。
- 建築：地塊照用途挑，同用途照 `城 id:地塊 id` 雜湊挑變化；模型比地塊小 ⇒ 臨路對齊、沿路置中；底下墊石基。長官的屋子用住宅代；砲台、碉堡還沒有模型 ⇒ 不擺（讀數 `skip`）。風格目前只有 fr 一套，英、西的城也用它。
- 城牆一級：門、塔照位置、兩頭收尾，中間照斷面沿曲線一節一節拉（節數 round(L/len)、沿 x 補滿），牆外朝離城心遠的那邊。
- 遠近四級（原模型 < 160 m、低模 < 800 m、貼圖 < 3 km、屋頂殼），低模（4³ 併一格）、八個方向的側面照、屋頂高與色都在 `townmodels.py` 匯入時算好；交接抖動互補。
- 路：照規劃的 `z` 鋪貼地的帶子（主要道路土色、街石板色）；廣場、碼頭、棧橋同一份網格。
