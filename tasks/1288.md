# TASK-1288 — 《Blocksail》北非首批三座城：突尼斯（＋拉古萊特）、阿加迪爾、加貝斯 —— 等 TASK-1273 補完非洲地圖資料才動工

> `feature` / `normal` / `todo`　開單：Abigail　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

照 TASK-1253 的規劃（Blocksail `docs/TOWNS_1660S_NORTH_AFRICA.md` §3～5）蓋北非首批三座城：突尼斯（拉古萊特當市中心、突尼斯城當遠城區，`ottoman`）、阿加迪爾（新勢力 `morocco`）、加貝斯（椰棗乾的產地港）。內陸綠洲不做陸路（Tim 2026-11-13 選 A）。

**物種、貨與配方**
- [ ] 阿甘樹只在蘇斯：阿加迪爾範圍裡有、突尼斯沒有
- [ ] 椰棗乾、阿甘油是可交易的貨，有從產地做出來的配方，貨物圖示接上

**海床與海岸**
- [ ] 拉古萊特沙洲補上：突尼斯湖跟海灣分開，只留拉古萊特一條水道；突尼斯城下停不了大船（反向對照：補之前那幾點讀到海，補之後是陸）
- [ ] 突尼斯湖畫淺（小船可行），大船泊位在拉古萊特外側
- [ ] 阿加迪爾灣的 5／10／20 m 線照海圖補，錨地有水深
- [ ] 三座港：預設船從鄰港開進來停得到泊位，停港後開得出去，城鎮模式進出正常

**開場經濟（一年模擬，起始檔＋發船，配雙胞胎）**
- [ ] 三座城都不餓（糧食自給或有船運進來）
- [ ] 工坊吃本地原料：阿加迪爾壓阿甘油、加貝斯曬椰棗、織坊吃羊毛
- [ ] 船隊實際買賣：阿甘油、椰棗乾離開產地港
- [ ] 市場只列實物
- [ ] 反向對照：拿掉椰棗的「有水」條件 ⇒ 撒哈拉長出椰棗；換錯氣候 ⇒ 不長
