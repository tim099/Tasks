# TASK-0860 — 雕刻預覽認混合材質（外觀照第一個成分）、材質表 smooth 旗標自動平滑 —— 跟遊戲一樣看得到金屬

> `improvement` / `normal` / `in_progress`　開單：ridge-001　參與：ridge-001(dev)

## 驗收標準

- [ ] 雕刻預覽（CLI view、觀測頁）認得混合材質 `<材質>*<比例>+…`：外觀照第一個成分（同 Blockside 05_material.js matMix）；成分不在表裡、比例不在 0～1、加起來 > 1、第一個是 air ⇒ 照「材質表沒有」報、不反光
- [ ] 材質表 `Sculpture/materials.json` 的材質可標 `smooth: true`（照遊戲：iron、boiler）⇒ 關聯只寫 material、沒寫 render 也畫平滑＋反光；明寫 `render=voxel` 的照方塊
- [ ] 松島號組裝件在 CLI view 上，船殼（iron*0.15）、上層建築、桅（iron*0.1）看得到金屬反光（截圖）；欄杆、梯子、艙壁（render=voxel）照方塊
- [ ] 沒寫 material 的作品，預覽結果逐位元不變（selftest 對拍）
- [ ] selftest 涵蓋混合寫法與 smooth 旗標；造船規格 §9.5「雕刻預覽不認混合寫法」「只有遊戲自動平滑」那幾行改成新規則

## 任務描述

Tim 2026-10-23：「同時也處理 /scp-sculpture Senate中預覽雕刻 混合材質無法顯示為金屬的問題吧」（跟 TASK-0859 一起做）。

兩個原因（ridge-001 讀 SCP_Core/Runtime/Sculpture/SCP_SculptSmooth.cs）：
1. SCP_SculptMaterials.TryGet 只認完整 ID ⇒ `iron*0.15` 被當成「材質表沒有」、不反光。
2. 預覽只照 render=smooth 平滑，反光只畫在平滑面；遊戲的材質表把 iron／boiler 標 smooth ⇒ 只寫 material 的關聯在遊戲裡平滑反光、預覽是方塊（松島號船殼、上層建築、桅）。
