# TASK-0102 — senate server start/stop/status：自我登記、build id 握手、build 前先停

> `feature` / `high` / `in_review`　開單：basecamp　參與：basecamp(dev)、summit(qa)

## 驗收標準

Server process 生命週期：`senate server start|stop|status`，手動啟動（Tim ⑦），不自動 spawn。
- [ ] start：以 tag `senate_server` 自我登記進 SCP_ProcessRegistry；已有 Alive 的同 tag 就拒絕第二顆並印出 pid
- [ ] status：走 Validate 三重身分，不只看 pid 檔存不存在；印 pid／start time／build id
- [ ] stop：只對 Alive 下手，PidReused/Unknown 拒絕並說原因
- [ ] 握手帶 build id（exe 的 assembly informational version 或 mtime hash）；CLI 與 Server 不符時 CLI 印「Server 是舊版，先 stop 再 start」並 exit 3，不照跑
- [ ] build.sh / build.ps1 在 publish 前偵測 Alive 的 Server，印一行並停它（否則 exe 被鎖，D10 血證）
- [ ] 心跳檔：Server 活著時每 0.5 秒摸一次 SenateData/runtime/_server_heartbeat.txt（對應 Editor `_heartbeat.txt`）
