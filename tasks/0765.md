# TASK-0765 — 地球儀水體層：湖、河流（支流、高低差、瀑布），再拿加勒比海的湖與河驗

> `feature` / `normal` / `in_progress`　開單：kiara　參與：kiara(dev)

## 驗收標準

Tim 2026-10-20：「湖也補上吧 可以下載(需要先擴充架構支援湖跟河流(海平面上的水體))」「河流可以跟湖 海連接 然後可以有高低差(太大就形成瀑布)」「然後河流可以有支流」「目前應該還沒有相關機制」。
現況：地球儀每格只有一個 RGB 顏色、沒有高度；目前的湖是塗成藍色的陸地（summit 的 #3B7FC4），程式分不出它是水。

### 架構
- [ ] 地球儀有一層獨立於格子顏色的水體層：湖（外環＋湖中島，水面海拔公尺，可以是負的）與河（上游到下游的點列，每點有水面海拔與寬度）；寫入只追加、可以 Undo，跟格子的 Undo 互不干擾
- [ ] 河的兩端能接：源頭（泉）或某個湖的出口；河口接海、接湖，或接另一條河（支流），一條河可以有多條支流
- [ ] 往上游流的河、接到不存在的湖或河、繞成環的水系 ⇒ 整筆拒絕、零寫入，訊息說是哪一點、為什麼
- [ ] 落差大到門檻以上就判成瀑布（河身上的一段、支流匯入、入湖、入海都算），門檻放在設定裡；查得到每一座瀑布在哪、落差多少
- [ ] CLI 能新增、修改、刪除、列出、查看水體，查一格時告訴你那裡是哪個湖或哪條河；整個水系檢查一次印出讀數（湖幾個、河幾條、支流幾處、瀑布幾座、有問題的幾處）
- [ ] render（CLI 與後台頁）把湖、河畫在格子顏色上面，瀑布有記號；水體層是空的時候，輸出的圖跟改之前逐像素相同
- [ ] 舊版程式讀到有水體的球不會靜默算錯（要嘛照舊只看格子、要嘛大聲拒絕），寫在文件裡
- [ ] selftest 覆蓋：寫入／重播／Undo、支流與瀑布判定、拒絕的幾種情形；反向對照：不合法的水系一筆都沒落盤
- [ ] 文件（Globe）補水體層一節

### 拿加勒比海驗
- [ ] 下載 Natural Earth 10m 湖泊與河流，補進加勒比海施工區（含恩里基約湖這類低於海平面的），水面海拔有出處；summit 在美國／墨西哥／中美洲塗的藍色湖不在本單射程
- [ ] 看圖驗收：湖、河、支流、瀑布在 render 上位置對得上，附讀數
