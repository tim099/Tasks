# TASK-0154 — check_compile.py --watch 在編譯還沒開始時就返回上一次快照 —— 而且不印 STALE（綠燈沒有可疑跡象）

> `bug` / `wrong` / `high` / `done`　開單：summit　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

## 病灶：`--watch` 的結束條件是 `in_progress=false`，而**編譯還沒開始時它就已經是 false**

`check_compile.py --watch` 的語意是「等到編譯結束再印」，而它的判準只有一個布林。
問題是 `senate ucmd run Recompile` 只保證 **Cmd 送達**，Unity 那邊要幾秒後才進編譯 ——
在那個空窗裡 `in_progress` 仍是上一次編譯留下的 `false`，
⇒ **watch 立刻返回，印出上一次的快照**，而那份快照格式完整、Errors: 0、看起來完全正常。

## 🩸 現場讀數（2026-09-07，summit）

我改完四個 `.cs` 之後跑：

```
senate ucmd run Recompile --persona summit ; python check_compile.py --watch --errors-only
```

| 讀數 | 值 |
|---|---|
| watch 印出的 Timestamp | **`2026-09-04T17:14:07`**（三天前） |
| 同一刻 `.compile_status.json` 的真值 | `2026-09-07T08:57:10`，duration 13.7s |
| watch 那次有沒有印 STALE 橫幅 | **沒有** |
| 前一次不帶 `--watch` 的同一支工具 | **有**印 STALE（「早於你的改動 229349.8 秒」） |

⇒ **加上 `--watch` 之後，那道唯一會叫的守衛反而不叫了。**
而它報的是「Errors: 0」—— 一個綠燈。

## 為什麼這隻特別貴

這支工具是「改完 `.cs` 的唯一可信來源」（CLAUDE.md 寫著），
而 `--watch` 正是**教給趕時間的人**的那條路（工具自己在 STALE 段落裡推薦它）。
⇒ 它在最需要它的那一刻給出綠燈，且**不留任何可疑跡象**。


- [ ] 重現讀數（開單人已填，見上表）：recompile 送出後立刻 watch ⇒ 印出早於改動的快照且無 STALE
- [ ] 修正落盤：`--watch` 的結束條件要**同時**要求「狀態的 timestamp 晚於基準」（基準沿用既有的
      `--since-file` / git mtime 那套），而不是只看 `in_progress`
- [ ] 反向對照：編譯**真的**跑完之後再跑 watch ⇒ 立刻返回（不能因為多一個條件就變成永遠等）
- [ ] watch 逾時的那條路要出聲說「等不到晚於基準的編譯」，⛔ 不可以退回印舊快照
- [ ] 異源複驗：由另一個人在自己那台跑一次「改檔 → recompile → watch」，確認拿到的是自己那次的讀數
- [ ] ① 重現讀數：見「任務描述 › 🔬 證據」（讀數＋怎麼拿到的）
- [ ] ② 修正落盤（commit 帶 `Fixes TASK-0154`）

## 結單說明

關單理由：**不是修好了，是那個 bug 的載體整支退場了**（Tim 2026-09-10 拍板，隨 TASK-0155）。

`check_compile.py` 今天改成指路 stub —— 跑它只印一段指路並 **exit 2**，`--watch` 這條路不存在了。
⇒ 本單的症狀（`--watch` 在編譯還沒開始時返回上一次快照、且不印 STALE）**沒有修法，它連同入口一起消失**。

📌 而真正把這個洞填掉的是結構不是修補：`senate cmd unity-recompile` **送出觸發的那一刻天生就是基準**，
所以「回上一輪的快照」在新結構裡**表達不出來** —— 它不是被防住，是不成立。
（本單原字面的成因是「python 那側必須**猜**新鮮度基準」，而猜的地方就是洞的位置。）

⚠ 照實記兩格，免得未來的人以為換入口什麼都沒少：
- `--fallback-log`（狀態檔不存在時解 Editor.log）與 `--editor-alive`（心跳）**沒有搬過去，也沒有替代品**。
- 血證行在 skill 與四語系文件裡**都留著**（⛔ 沒有跟著刪）—— 因為這個形狀會換一個工具重來：
  「沒發生的事看起來像綠燈」不是那支 python 的性格，是那一族 bug 的形狀。

驗收：`python <UCL_Core>/Tools~/AgentCommands/check_compile.py` ⇒ 印指路、`exit_code=2`（今天實跑過）。
