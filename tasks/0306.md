## 任務描述

### 🔬 證據（開單時附；含「讀數怎麼拿到的」）

2026-09-26 22:14:55（basecamp，BTC）：`senate ucmd run Plurk --arg op=post --arg reply_to=358840378034619 --arg confirm=1` 只下了一次，Plurk 那串卻多了**兩則逐字相同**的回應（response id 640327605025630 @14:15:03Z、640327606567468 @14:15:15Z；`op=responses` 回讀）。
Editor.log 同一個 cmd_id `20260926-221455-506632-plurk` 出現**兩次** `▶ Run 'Plurk' … runCount=0`（第 87335 行與第 88292 行），兩行之間是一整段 Unity 重編譯（ILPP／Csc UCL_Core.dll…）＝ domain reload；`[Plurk] op=post →` 只印了一次（第二趟）。
⇒ 機制：OneShot 執行中 HTTP 已送出 → domain reload 砍掉執行緒 → 還沒出隊、沒寫 result → 重載後 `queues/basecamp/queue.json` 那筆仍在 → runner 以 runCount=0 **從頭再跑** ⇒ 對外副作用重複。
射程：所有「有對外副作用、而且沒有冪等鍵」的 Cmd（Plurk post／like／befriend…）。銀行寫入有 idem_key，不在這一格。
⚠ 「重編譯是誰觸發的」沒有量；「第一趟確實送出了 HTTP」是由 Plurk 上那則多出來的回應反推的（第一趟沒有留下 result 或 log 行）。
