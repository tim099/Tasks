# TASK-0542 — 《憲法號對轟》設定後台：遊戲設定初始值、船隻設定（船員配置）、匯入新船與重新匯入

> `feature` / `normal` / `todo`　開單：ame　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

範圍：《憲法號對轟》的設定後台（一頁 HTML）—— 各項設定的初始值、每艘船的設定（含船員配置與數量）、匯入新船與重新匯入舊船。玩家在遊戲裡改的（存檔）照舊。

- [ ] 開工前拍板：後台頁的形式與存法、匯入船要不要從頁面直接跑（描述裡的三題）
- [ ] 後台頁改得了遊戲各項設定的初始值（滑桿的預設與上下限、砲種表、娛樂加成、畫質／物理預設…），存成一份設定檔；遊戲建置時讀它（不再寫死在 js）
- [ ] 每艘船的設定：航速／靈活／逆風／硬度等、船型的高度與範圍、船員配置與數量（各職位人數、砲班、預備水手…）
- [ ] 匯入新船：給雕刻作品 ID ⇒ 匯出 .vxk、登記進船型清單（名字、預設設定）、重建後主選單選得到
- [ ] 重新匯入舊船：同一艘換新的 .vxk，顯示格數、checksum 與上一版的差別
- [ ] 反向對照：設定檔是預設值時，縮圖 ?demo=75&still=1&cam=deck 跟改之前逐位元組相同
- [ ] 後台改得了多船的上限（一場最多幾艘、船艙遮罩最多幾艘；Tim 2026-10-13「上限可以直接放在管理後台頁面調整」）：改成 N ⇒ 重建後主選單最多編得到 N 艘、畫質設定的「陰影船數」上限跟著 N

Tim 2026-10-13：「另外是否可以加另一個後台 html，讓我可以設定遊戲中各項設定的初始值，以及一些船隻相關設定（船員配置、數量等）；另外也要可以匯入新船的資料（以及重新匯入舊船）。先開成 task」。誰在等：Tim。

## 現況（ame，讀 ArtGallery/HtmlGames/_build/ame_constitution_broadside）
- 各項設定的初始值寫死在 js：`LIM`（滑桿上下限與預設，04_state.js）、`HULL_CFG0`（每型的航速／靈活／逆風／硬度）、`GUNS`（砲種：初速、裝填、砲班滿編／最少、重量）、
  `GEO0`／`HULL_KNOWN.geo`（船型的高度與範圍、預備水手倍率）、`DMG`、`AMMO_K0`（彈種倍率）、`FUN`（娛樂加成）、畫質／物理預設…；玩家改的存在瀏覽器 localStorage（69_prefs.js），只蓋過自己那台。
- 船：`template.html` 一個 `x-vxk` 標籤＋`HULL_KNOWN` 一行；.vxk 由 `senate cmd sculpture op=export format=vxk` 匯出到 `ArtGallery/VoxelKit/_cache/`，`vxk_inline.py` 內嵌進單檔成品。
- 船員配置：砲班照砲種表、送藥手一對砲一個、軍官 4、舵手 2、陸戰隊照舷牆、桅頂每根 4、預備水手 HANDS×handsK（40_crew.js、42_hands.js）。

## 要決定的（開工前問 Tim）
- 後台頁住哪、怎麼存：(a) 單獨一頁 HTML（畫廊外）改完下載一份設定 JSON，建置時內嵌進遊戲；(b) 走 senate 後台（`senate ui`）一頁，直接寫 repo 的設定檔並重建；(c) 其他。
- 「匯入新船／重新匯入」要不要從頁面直接叫 senate 匯出＋重建（要本機有 senate 與 Python），還是頁面只產生指令。
- 船員配置要細到什麼程度（每種職位的人數、每門砲砲班、送藥手比例、陸戰隊上限…）。
