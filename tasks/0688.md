# TASK-0688 — 艦隊指揮官 AI ②：對戰中往前推演（2D 沙盒對齊遊戲＋rollout 選戰術）

> `feature` / `normal` / `todo`　開單：basecamp　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 精簡推演模型（類似下棋）：只考慮風向風速、各船位置航向航速、帆的狀況、兩舷火力等；時間刻度粗（預設 3 秒一步，可調參數）、往前跑幾步（可調）
- [ ] 指揮官在決策點把候選戰術各推演幾步、挑預測最好的；有預算上限（每次決策幾毫秒）
- [ ] 不追求跟遊戲完全對齊（Tim：現實海戰指揮官的資訊更少）；但量一次預測與實際的落差當參考
- [ ] 用自動調參那張的評測尺比較：推演版對規則版勝率
- [ ] 戰鬥報表記下推演的理由（各候選的預測分數）


## 任務描述

指揮官要選戰術時（戰列／配對／集火、交戰那一舷、要不要搶上風），把每個候選用 2D 沙盒（sb_sim.js）往前模擬 60–120 秒，挑結果最好的那個（類似 MCTS／rollout 規劃）。容量 0，代價是決策時的 CPU。

前置：2D 沙盒要先跟遊戲對齊 —— 現在戰列照舊跟前一艘船尾（遊戲已改成照排頭航跡）、沒有頂風扇區／順風繞、加減速模型不同。對齊的尺 ＝ 同一場景遊戲與沙盒的軌跡、勝負對照。
