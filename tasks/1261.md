# TASK-1261 — 《Blocksail》船廠造船：每型船一張造船菜單（自動算法＋手調、特殊材料、大船只在大船廠），造好的船殼進庫存等人買

> `subtask` / `normal` / `todo`　開單：basecamp　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 每一型船有一張造船菜單（料、工天），預設照自動算法算、手調表寫了的格子蓋過算法；工具印得出每一型的整張菜單，並標出哪幾格是手調的
- [ ] 菜單寫了特殊材料的船型：城裡沒有那種料 ⇒ 不開工；有 ⇒ 照吃
- [ ] 大船只在大船廠開工；小船廠開不了大船
- [ ] 船廠開工造船：照菜單吃料、照工天做完，造好的船（沒有砲）進那座船廠的庫存；沒有鐵砲照樣造得完
- [ ] 主人造船改成買船廠庫存裡的船（錢付給船廠的主人）；庫存沒有 ⇒ 下訂單給船廠排工；⛔ 不再憑空生船
- [ ] 玩家在地球儀上看得到船廠庫存、買得到一艘
- [ ] 起始檔＋發船一年、配雙胞胎：船隊規模、新造幾艘、跨商圈佔比、木板／帆布／繩／焦油的缺口，改前改後並排照實列
- [ ] 反向對照：開關關掉 ⇒ 一年的城鎮帳逐位元組同改前
- [ ] 文件寫明菜單的自動算法、手調表在哪、船廠庫存與訂單規則

## 任務描述

母單拆法的 ①②（Tim 2026-11-10「開單，先做①②」）。

- 每一型船一張造船菜單：吃哪些料、幾個工天。預設由一套自動算法照船型（噸位、帆、船員、軍艦與否）算出來，手調表寫了的那幾格蓋過算法（比照營造的建材菜單）。
- 特殊材料：菜單可以寫任何貨（潮木、鐵甲艦的鐵、特殊木材）；那種貨不在貨物表或城裡買不到 ⇒ 那一型造不了。⚠ 潮木現在還不是貨（只有圖示，TASK-1012），鐵甲艦不在 Blocksail 的船型表 —— 本單只要菜單吃得下，不新增貨。
- 小船廠只造小船、大船廠什麼都造（照船型分級）。
- 造好的船沒有砲（Tim：造船不吃砲，武裝時才買砲 ⇒ 母單 ③）。
- 買的人：城鎮、NPC 家族、富裕商業那一池、商行、玩家；國家在母單 ⑦ 接。
