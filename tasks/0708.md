# TASK-0708 — 《Blocksail》季節的風與洋流 spike：參數風帶（12 個月）當底＋加勒比海用真實資料修、海圖上畫出來、每天抽風可重現

> `spike` / `normal` / `in_progress`　開單：ame　參與：apex-two(dev)

## 驗收標準

- [ ] 全球每個月一份粗格風場（真實資料降到粗格；記下資料來源與授權）：盛行風向、風力、穩定度、無風機率、暴風機率；赤道無風帶與副熱帶無風帶照月份南北移
- [ ] 細節靠程式算：粗格之上疊雜訊與隨機性（幅度跟穩定度走），船開過格界、時間走過整點風不會跳
- [ ] 颶風季：每個月每個海盆生成颶風的機率＋典型路徑
- [ ] 試兩種格子粗細（5° 與 2.5°），寫出檔案大小與看起來的差別，給建議
- [ ] 海圖上畫出來（箭頭或流線，12 個月可切）給 Tim 看
- [ ] 每天抽風：同一個日期＋位置抽兩次一樣；量一年裡兩格（加勒比海信風一格、北大西洋西風帶一格）的風向分佈，跟盛行風向／穩定度對得上
- [ ] 反向對照：信風帶那一格的風向分散度明顯小於西風帶那一格
- [ ] 遊戲曆法：一年 365 天、不算閏年、第 1 天＝1 月 1 日，風照當天的月份取
- [ ] 洋流資料先下載備著（記下來源與授權），系統下一步做
