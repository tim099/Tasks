# TASK-0494 — 雕刻作品：關聯匯入 —— 只記關聯不複製 voxel，被關聯的作品改了跟著變，每個關聯可開關

> `feature` / `normal` / `done`　開單：basecamp　參與：basecamp(dev)

## 驗收標準

- [x] 作品可以「關聯匯入」另一件作品（位置＋轉向，同 assemble 的寫法）：只記關聯 —— 父作品的 events 一筆都不多、一格 voxel 都不複製　✅ basecamp 2026-10-11
- [x] 觀測父作品（view／slice／section／stats／export）看到的是「父＋所有開著的子」；子作品改了，父作品下一次觀測就是新樣子，不必重新匯入　✅ basecamp 2026-10-11
- [x] 每個關聯可以開關：長期設定（存在父作品）＋觀測時一次性指定（例：拿掉甲板看裡面的房間、只看某一層甲板）　✅ basecamp 2026-10-11
- [x] 巢狀：被關聯的作品自己也有關聯（例：甲板 → 甲板上的房間 → 房間裡的物品）⇒ 一路組進來；開關可以指到任一層（例：只拿掉「甲板2/船長室」）；成環（含隔好幾層才繞回來）擋下　✅ basecamp 2026-10-11
- [x] 父與子（或子與子）重疊的格：誰蓋誰寫明在文件，回報重疊幾格、附位置；⛔ 不靜默吃掉　✅ basecamp 2026-10-11
- [x] 子作品的格子讀不入 git 的快取（子作品沒變就不重播）；快取刪掉，組出來的結果逐格相同　✅ basecamp 2026-10-11
- [x] 落子／刻／undo 父作品，子作品一格不動；關聯成環（A→B→A）、子作品不存在 ⇒ 擋下、零寫入　✅ basecamp 2026-10-11
- [x] 匯入展區或對外匯出時攤平成實際 voxel，並記下每件子作品當時的版本　✅ basecamp 2026-10-11
- [x] 反向對照：子作品改一格 ⇒ 父作品觀測差 1 格；關掉關聯 ⇒ 那些格消失、開回來又出現；刪快取結果相同；成環擋下；巢狀第二層改一格 ⇒ 最上層也差 1 格、只關掉那一層的那一件 ⇒ 只少那一件　✅ basecamp 2026-10-11
- [x] selftest 與 Sculpture 文件補上　✅ basecamp 2026-10-11

## 任務描述

Tim 2026-10-11（/scp-task 493 時追加）：「也可以採用子作品方式去切割區域（目前想用在甲板），子作品可以用關聯方式匯入（而非直接把 voxel 匯入）。這樣在子作品有修改時，關聯匯入的作品也會同步這些修改，且可以開關匯入的部分（這樣就能觀察到甲板內部、房間等）」「關聯匯入可以用緩存的 voxel 資訊（不入 git 的緩存）優化效率」。誰在等：Tim。第一個用處：憲法號（TASK-0478）的每層甲板各做一件子作品。

Tim 同日補充：「子作品其實跟獨立作品一樣，只是創作時切分出來的作品」⇒ 關聯匯入對**任何作品**都成立，子作品不另設規則；別人的作品也能關聯（Credit 照 assemble 的規矩記）。

這裡已經有的：子作品（work create parent_work=，同作者免費）、assemble（把零件的 voxel 複製進來＋Credit＋轉向）、每件作品自己的 sculpt_cache.json（已在 .gitignore）。本單是 assemble 的「不複製」版本（同樣對任何作品都成立）：只記關聯，觀測時現組。
跟 TASK-0493（草稿層）相關不併：草稿是「還沒落進作品的刀」，本單是「作品由哪幾件組成」—— 修法不同。

⛔ 不在本單（Tim：非必要）：回溯去改更早的區域（例：開完砲門才發現船殼要調，把調整歸回船殼那一段，等於每個區域獨立可改）。想得到的方向先記著：落子時標「屬於哪一區」，hide／only 照區而不是照時間區間 —— 事件只追加、不改歷史。要做再開單。另外，用子作品切區（本單）本身就讓那些區域可以獨立修改。
