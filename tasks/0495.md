# TASK-0495 — 雕刻引擎：噴漆 —— 沿射線／曲線打出去，碰到的格換成噴漆的顏色（只換色、不放不刻）

> `feature` / `normal` / `todo`　開單：basecamp　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 一道射線（起點＋方向，或起點＋終點）打出去，碰到的第一格換成噴漆的顏色；什麼都沒碰到 ⇒ 回報 0、零事件
- [ ] 一次打一束：沿一條線或一個面等距平行掃過（例：從船外側往內噴整片船殼塗裝），回報打中幾格、落空幾道
- [ ] 曲線：給一串控制點（折線或平滑曲線），沿著走、碰到的第一格換色
- [ ] 只換色、不放不刻：空格一格都不多、一格都不少；可以限制只噴哪些原色（例：只噴木色的格）、噴幾層深
- [ ] 先預覽（會換哪幾格、幾格、分原色列），確認才落刀；可以落在草稿裡（TASK-0493）
- [ ] 重播得出來（沒更新的 senate.exe 也行），undo 照常
- [ ] 反向對照：射線剛好打在兩格之間的接縫要有寫明的規則；方向反過來要打到另一面；限制的原色之外一格不動；預覽與實際落刀的格逐格相同
- [ ] selftest 與 Sculpture 文件補上

## 任務描述

Tim 2026-10-11：「噴漆功能 —— 可以用 CLI 打出射線（也可以是曲線），把碰到的 voxel 替換為噴漆的顏色，可以用來噴塗船殼塗裝等」。誰在等：Tim。
來源：憲法號（TASK-0478）的塗裝（銅底、黑身、白帶、露在外面的結構上色）現在是 python 端算「船外看得到的那一層」再產 stampvox overwrite 清單（draft_planking.py 的 paint／paint_struct、draft_ports_touchup.py）；那一層的判斷綁著作品的設計，噴漆是把「從外面打過去、碰到哪格就漆哪格」這件通用的事搬進引擎。
相關：TASK-0493（草稿：噴之前先在草稿裡噴、看、undo）；TASK-0492（carvevox 是照清單、噴漆是照幾何）。
