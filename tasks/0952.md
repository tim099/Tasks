# TASK-0952 — 《Blocksail》漁場、鹽田的臨水規則：要蓋在水邊才放行（建築模式與自動建築同一條），補進建築選單

> `feature` / `normal` / `in_progress`　開單：kotoko　參與：kotoko(dev)

## 驗收標準

- [x] 漁場要臨水：地塊外框往外一小段（〔佔位〕20 m）內碰得到海，或貼在碼頭線、棧橋靠陸地那一側；不臨水的地方試放是紅的，說得出原因（離海幾公尺、要 ≤ 幾公尺）　✅ kotoko 2026-10-26
- [x] 鹽田要在海邊低平地：外框附近（〔佔位〕30 m）有海、地面高度低於〔佔位〕3 m、坡度小；不合的地方試放是紅的、說得出原因　✅ kotoko 2026-10-26
- [x] 建築模式和城鎮、家族自動蓋的走同一條規則：自動蓋的漁場、鹽田不再擺到不臨水的地方（加拉塔讀數：改之前有、改之後 0）　✅ kotoko 2026-10-26
- [x] 漁場、鹽田的設定檔補上選單分類 ⇒ 建築選單自己出現，遊戲裡蓋得下去、畫面是漁場、鹽田的模型　✅ kotoko 2026-10-26
- [x] 反向對照：規則關掉（或距離放到很大）⇒ 跟現在一樣哪裡都能蓋；六座城生成的規劃逐位元組不變　✅ kotoko 2026-10-26

## 任務描述

Tim 2026-10-25：「那927 魚場 鹽田可以蓋了嗎」⇒ 還不能（設定檔沒寫 ui、也沒有臨水的規則）⇒「好先開單 然後先不動工」

現況（Blocksail main fd32c0a 之後）：
- 漁場 `world/buildings/fishery.json`、鹽田 `saltpan.json` 沒寫 ui ⇒ 不在建築選單（TASK-0944 刻意留的）。模型是 TASK-0927 的 common-fishery、common-saltpan。
- 自動建築（town.js townAutoBuild）不看臨水 ⇒ 加拉塔自動蓋的漁場落在不臨水的街邊（TASK-0927、0938 那時量到的）。

做法（提案，Tim 還沒逐條拍板）：試放（town.js townBuildTry ／ townTryPlace）多一道地塊條件 —— 建築模式與自動建築同一支 ⇒ 一起修；
規則寫在設定檔（例：`place: { sea: 20 }`、`place: { sea: 30, hMax: 3, slopeMax: … }`，數字〔佔位〕）⇒ 之後後台頁也改得到；量各城蓋得下幾處再調數字。
⚠ town.js、buildings.js 在規劃指紋裡 ⇒ 改完重烘。
