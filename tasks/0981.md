# TASK-0981 — 《Blocksail》停在小棧橋（魚骨式）泊位的船，船尾有時跟棧橋重疊（穿模）—— 停靠位置照船長、朝向重算

> `feature` / `normal` / `in_progress`　開單：erina　參與：erina(dev)

## 驗收標準

- [ ] 停在小棧橋（魚骨式支棧橋）泊位的船，船身（含船尾、船艏斜桅）不跟棧橋、支棧橋重疊：每一座有魚骨泊位的城、每一型會停魚骨泊位的船都量過，重疊 0
- [ ] 我艦停靠（地球儀停靠 ⇒ 進入城鎮）與停港的往來船都照同一套停靠位置
- [ ] 反向對照：大船以上的泊位停靠位置不變（那邊是 TASK-0962 的事）；泊位數、各城規劃雜湊不變
- [ ] TOWN_BUILD 寫清楚魚骨泊位的停靠點怎麼算
- [ ] Tim 進城鎮看一次

## 任務描述

Tim 2026-10-26：「以及船停靠在小棧橋(魚骨)時 有時船尾跟棧橋本身重疊了(穿模) 停靠位置算法可能要調整」（同一輪先開單、先不動工；另一件進出港演出是 TASK-0980）

**症狀**：船停在小棧橋（魚骨式支棧橋）的泊位時，有時候船尾跟棧橋本身重疊（穿模）。「有時」⇒ 可能跟哪一型船（船長）、哪一座城、哪一個泊位有關，還沒量。

**還沒查**：停靠點是照泊位中心擺、船長沒算進去，還是船頭朝向（停靠的 hdg）跟支棧橋不平行、船尾甩進棧橋；我艦與停港的往來船是不是同一套。動工時先把每座城、每型船的重疊量出來再改。

相關：TASK-0962（大船以上的泊位貼平台；它的驗收寫「小艇、小船（魚骨式）照舊」⇒ 魚骨不在那張的射程）、0906（泊位建築，已結）、0951（停靠的船固定在泊位上）、TOWN_BUILD §5.19、支棧橋那一節。
