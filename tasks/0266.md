## 成因（讀 code，不是猜）

`Senate/src/Senate.Cli/SelfTest.cs:4546`：

```csharp
sealed class TavernLaneProbe : Senate.Core.Cmd_TavernWrite
{
    public string Peek(SCP_CmdArgs iArgs) => Lane(iArgs);
}
```

它是 selftest 為了讀 `protected Lane()` 而開的子類（註解逐字：「`Cmd_TavernWrite` 因此**不加 sealed**，
理由就是這一格」）—— 而它**連指令名一起繼承**，於是註冊表裡出現兩支同名，而掃描順序讓探針贏。

📌 ⇒ 這不是有人打錯字，是**一個測試用的子類意外變成了產品指令**。
