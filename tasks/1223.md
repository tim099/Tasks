# TASK-1223 — 《Blocksail》囤原料：生產建築的主人把原料囤在自己的倉庫（60 天份，照倉庫空間調整）—— 倉庫建築有實際用途

> `feature` / `normal` / `in_progress`　開單：Sirius　參與：Sirius(dev)

## 驗收標準

- [ ] 有生產建築的主人（NPC 家族、富裕商業）把自己建築吃的原料囤在自己的倉庫：目標 60 天份（照名下建築滿產一天的用量），照倉庫空間調整（不另外替產品留空間：產品照倉庫管理人照常賣，倉庫快滿本來就先賣產品）
- [x] 便宜才囤滿 60 天；不到 30 天不管價錢先補到 30 天（Tim 2026-11-06「太貴不買可以改為30天以上才觸發」）；留得住幾天的工資才買　✅ Sirius 2026-11-06
- [x] 倉庫管理人留料照囤料的目標（不把剛囤的料賣掉）；倉庫建築的容量決定囤得了多少　✅ Sirius 2026-11-06
- [x] 已知答案：倉庫夠 ⇒ 囤到 60 天份、倉庫小 ⇒ 囤到放得下的、很貴只補到 30 天、錢不夠不買、錢與貨守恆　✅ Sirius 2026-11-06
- [x] 反向對照：開關關掉 ⇒ 收集器 digest ＝ 改之前　✅ Sirius 2026-11-06
- [ ] 兩年讀數配雙胞胎：生產建築缺料停工、缺貨率、供給、價格波動、家族的現金與工資、跨商圈流量

## 任務描述

貿易網 v2 的缺料問題（docs/TRADE_NETWORK.md §8、§12-11；TASK-1210 量到：原料買不到、存貨又少、附近有人存著的城·天約七成，城鎮的船補缺口補不完）。

Tim 2026-11-05：「然後缺料問題 目前有個想法是讓商人(或產業建築經營者) 囤原料(同時可以讓目前的倉庫建築有真實功能)」「可能可以屯60天份的原料(視倉庫空間調整)」「開單吧」

現在：家族的生產建築先拿自己倉庫的料、產品先進倉庫（world/prod.js）；倉庫容量 ＝ 基礎 ＋ 名下的倉庫建築（storeCap）；倉庫管理人（FAM_SELL）賣貨時留 10 天份自己要用的料。可是沒有人先把料買進來囤著 —— 料都是當天要用才買，市場那天沒貨就停工。

第二步（另議）：自動建築照「囤料目標被倉庫卡住」多蓋倉庫；商行倉庫（§5.2 v2）借同一套。
