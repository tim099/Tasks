# TASK-0899 — 《Blocksail》水上建築：港口的建築跨在碼頭、棧橋邊（陸上一半＋水上木樁平台、船台伸進水）—— 船廠、起重機、船棚先做

> `feature` / `normal` / `in_progress`　開單：crest-001　參與：crest-001(dev)

## 驗收標準

- [ ] 規格寫進 TOWN_BUILD（新的一節，接 §7.3 綁路、§3.3 港口），附參考的機制與 Tim 的參考圖。
- [ ] 碼頭線、棧橋都當成一種特殊的路（參考廣場，§5.15）：都有路的號碼，兩側長格子帶（陸那一側照舊、水那一側新長）；綁定照舊 `{ road, side, c0, cw, cd }`，`road` ＝ 碼頭線或棧橋的號碼。開場的規劃雜湊照舊（只多格子帶、不多地塊）。
- [ ] 碼頭線、棧橋都要跟道路接通（參考廣場接附近的路，§5.15）：路網連得到；碼頭面、棧橋面跟路面有高低差 ⇒ 自動加樓梯或梯子（同 §5.16 路接地塊的樓梯）；放不下 ⇒ 城市報表標出要手動調整的地方。
- [ ] 當成道路顯示與載入：小地圖照道路一樣畫碼頭線、棧橋；城鎮載入時跟道路一樣優先（大城分區載入 TASK-0817 那一層「城牆、道路一次到」也帶上碼頭、棧橋）。
- [ ] 水上的格子：一格量水深（不是「落水就不能用」）；每一種建築寫自己要的水深範圍。整地不碰水（遊戲不把海床填成陸）。
- [ ] 建築分陸、水兩段（`water: { d0, deck, slip? }`）：陸上那一段照舊整地；水上那一段是木樁平台，平台面 ＝ 碼頭面高、樁到海床；船台從平台斜進水裡，尾端要到那一種要的水深。
- [ ] 航行安全：水上建築擺在泊位之前，泊位、錨地、玩家停靠處的航道避開它；town_check 多驗「水上建築壓到泊位、航道」「船台尾端水深」。
- [x] 第一批：修船碼頭、小船廠、大船廠、船棚、起重架**另做水上版、跟陸上版並存**（陸上版照舊給沒有碼頭線的城；有些可以拿現有的模型改）；生成器 ⑦b 照新的擺法、建築模式也能蓋。　✅ crest-001 2026-10-31
- [x] 建築的繩索（參考船）：雕刻作品的 `rig.ropes` 照船那一套匯進 townkit（`townmodels.py` 匯出本來就帶 `rig`）；匯入時算好兩端綁在哪（同 Blockside `admin.py ropebind` ⇒ `.vxk` 的 `rig.ropes[i].bind`），遊戲照它畫（同 `10_ship.js` `linkRopes`）、不現場猜。先用在起重架、踏輪吊車、船台的絞盤，之後其他建築也能用。　✅ crest-001 2026-10-31
- [ ] Blockside：水上那一段的地形不整平；木樁照模型的 meta 伸到海床（同棧橋的樁）；水照樣畫在平台底下。
- [ ] 反向對照（`--mutate`）：水太淺、太深、壓到泊位、船台到不了水深、離碼頭太遠，都說得出原因。

## 任務描述

Tim 2026-10-24：
- 「另外之後會需要支援在海上(港口海堤旁 棧橋旁)建造一些建築(例如造船廠 起重機) 可以先分析一下方案 開成task」
- 參考圖（「類似這種感覺」，加勒比海的港口）：
  - 木造船棚踩在水上的木樁，後半在石碼頭上；裡面一條木板船台斜進水裡，船台上有一艘小船。
  - 兩層磚樓站在伸出碼頭的木樁平台上；樁看得到，伸到淺灘；平台面跟碼頭頂一樣高。
  - 石碼頭一階一階，有往水邊的樓梯；轉角一座圓石塔。
  - 淺水邊一條低的木棧，沿著碼頭走。

**已經有的**
- 碼頭線、棧橋、泊位、錨地、玩家停靠處（TOWN_BUILD §3.2、§3.3）。碼頭線有路的號碼（`seq`）；路網已經把碼頭面當成一種路。
- 港口建築（修船灘、修船碼頭、小、大船廠、船棚、起重架…）沿碼頭線擺，往**陸上**退；船廠那四種背面貼碼頭、船台朝水。
- 棧橋的樁、長碼頭與石堤的實心石砌，遊戲都會畫到海床。

**卡住的地方**
- 每一塊地塊每 1 m 一點都要在陸上（生成器、試放、格子帶都是「落水 ⇒ 不能用」）⇒ 船台只能停在碼頭邊，伸不進水。
- 格子帶只沿路長；碼頭線、棧橋在格子帶裡是障礙。
- 遊戲整地不看是不是水：地塊伸進水裡會把海床填成陸。
- 泊位只避開棧橋、碼頭線、別的泊位，不看地塊（今天地塊都在陸上，不需要）。

**方案**

A（推薦）—— 跨在碼頭邊：陸上一段＋水上木樁平台，綁在碼頭線上
- 碼頭線當成路（§7.3 早就定了「碼頭是路的一種」），兩側長格子帶：陸那一側照舊；水那一側的格量水深。
- 建築佔「碼頭線某一側」的格：陸上的（倉庫、海關）照舊；跨的（船廠、船棚、起重架）綁在**水那一側**，模型的 y 0 在碼頭邊，往水裡伸 `water.d0` 公尺以上是平台。
- 平台面 ＝ 碼頭面高（遊戲已經有碼頭面的高度）；樁照棧橋那一套伸到海床；水上那一段不整地。
- 船台（slipway）：從平台斜進水裡，尾端要到那一種的水深（小船廠約 2.5 m、大船廠約 4 m〔佔位〕）；試放時量尾端。
- 長在棧橋旁：棧橋現在沒有號碼、也不算路 ⇒ 給它號碼、當成路（Tim 拍板），棧橋旁的起重架第一批就做。
- 好處：建築模式、存檔、分配器（TASK-0895）全部照舊，只多一種路與一條水深規則。

B —— 自由擺：建築帶一塊「水上的範圍」，不綁路
- 照手擺地塊那一套（at、rot）擺；水上範圍要整塊夠深、外框要碰到碼頭或岸。
- 好處：棧橋旁、斜的岸也擺得進去。壞處：建築模式沒有格子可以吸、存檔另一套、玩家擺起來比較難對齊。

C —— 填海：水上那一段也整地，用石基墊到海床
- 最省事（現在的石基、整地加一個「可以填海」的旗標）。壞處：跟參考圖不像（看不到樁、水會被填掉）、會改到海岸線與泊位的水深。
- 只適合長碼頭、石堤那種實心的；可以當 A 的一個選項（`water.fill`）。

推薦 A，C 當成 A 的一種（實心的那幾種）。

**規則**〔數字全是佔位〕
- 每一種建築：`water: { d0（從臨碼頭邊算起，幾公尺以外是水上）, min（平台底下最淺）, max（樁最深）, slip?: { len, depth（尾端要的水深） } }`。
- 水上那一段離泊位、錨地的圈至少 `BERTH_GAP`；不壓玩家停靠處的航道（`docks.player.path` 船寬一半內）。
- 擺的順序：⑦b 港口建築 ⇒ 泊位（泊位多避開水上建築）⇒ 玩家停靠處。
- 船廠要不要自己長泊位（造好的船停哪）：先不要，修好、造好的船走一般的泊位。

**模型規格**（BUILDING_SPEC 加一節）
- 最外層 meta：`water=<d0>`（第幾格起是水上）、`deck=<平台面在模型裡的高>`、`piles=<間距>`（照柱子畫樁，或模型自己雕樁到某個深度、遊戲補到海床）、`slip=<船台尾端的格>`。
- 樁、船台下半段標成會伸到海床的件（同棧橋的樁；遊戲照海床補長）。
- 施工演出（TASK-0893 的 build0／build1）：樁先、平台、再上面的房子。

**Blockside**
- 地塊帶 `water` ⇒ 整地只整陸上那一段；水上那一段的地形不動，模型的樁補到海床。
- 遠景：低模、屋頂殼照舊；水照海水遮罩畫在平台底下。

**存檔**：照舊 `{ build: { on, use } }`，`road` 是碼頭線的號碼；碼頭線被切（之後玩家能蓋碼頭）照路那一套換號碼。

**參考**（只取機制）
- Anno：港口建築要貼著岸，一半在水上；水的那一邊朝開闊的水。
- Cities: Skylines：港口只能沿岸擺，一段在水裡、一段在陸上接路。
- Port Royale、Patrician：船廠、倉庫沿碼頭排，船廠有船台伸進水。
- 17 世紀港口：船台從船廠斜進水；起重架、踏輪吊車站在碼頭邊；木樁平台、樁上的棚屋伸出碼頭。
