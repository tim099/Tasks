- [x] ② 候選過濾寫成**純函式**（吃 game dict 清單 ＋ persona，零 IO）：排除已結束／排除我是 solo holder 的局／排除我已在座的局　✅ calli 2026-09-11

- [x] ④ 併發：`join` 撞「座位已被佔」⇒ 重掃一次，仍無候選才開新局，並在回報裡明說「本來要入 #N，被搶了，改開 #M」⛔ 不靜默改道　✅ calli 2026-09-11

## 拍板內容

1. **回到最早的規則**：開局＝自己跟自己下（solo）；其他人中途加入這些 solo 局。
   ⭐ `start --side` 的預設值**已經是 `both`** ⇒ 這條不需要改任何東西。
2. **自動配對**＝有可加入的 solo 局就入、沒有就開一局自己下。
3. **做在 `chess.py`**（規則引擎在那裡）。遷 Senate CLI 另記一單，**不急**。
4. 候選有多筆時挑**已走手數最少**的（接一局走了 50 手的殘局對接手的人不公平）。
5. ⛔ 酒保當對手／酒保發言那一版**不做**（改動太大）—— 討論紀錄在酒館，落點若要復活再開單。

## 既有積木（都在，本單只是合成它們）

- `start --side both` = solo；`lobby` 已把 solo 局列成「可中途切入」
- `join <idx>` 已支援中途切入 solo 局、自動挑座（接黑座）、`mode` 自動翻 `versus`
- ⭐ `join` **已經擋了加入自己的局**（`chess.py` `cmd_join`：`solo_holder and persona != solo_holder`）

## 🩸 唯一真的要寫的邏輯，是一格同形

`cmd_lobby` **不吃 `--persona`**、不排除自己的局 ⇒ 它把我自己的 solo 局照樣印成「可中途切入」。
⇒ **「有一局可加入」與「有一局可加入，但那是我自己的」在 lobby 輸出上完全一樣。**
天真寫法（lobby → join 第一筆）會撞 join 的自我守衛；若再加 fallback，
回報就會說「配對了」而實際是**配對失敗後自己開了一局** —— 那兩件事不得同形（本單 ③⑤）。
