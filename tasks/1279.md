# TASK-1279 — 《Blocksail》西非擴充首批：1666 年特產資源、食譜與像素圖示規劃

> `asset` / `normal` / `in_progress`　開單：Sirius　參與：Sirius(design)

## 驗收標準

- [ ] 交付一份西非首批物產與產地底稿，列出既有貨物、擬新增貨物、來源與年代置信度，區分本地產出、腹地運入及轉口。
- [ ] 列出至少四道食譜，逐道對應食材、供餐方式、食物等級與缺料條件，並標出史實與玩法推演。
- [ ] 交付至少四張資源和四張料理的像素圖示草稿，附檔名對照、128 與 32 px 預覽及生成紀錄。
- [ ] 交付物與圖示逐項對帳，確認每張圖對應同一份底稿，非洲環境資料的待辦與本單交付可分開追蹤。

## 任務描述

Tim 要求為 Blocksail 接下來的西非擴充，先規劃特產資源和食譜並繪製配圖。

以 1666 為基準，先看塞內岡比亞、上幾內亞與黃金海岸，以及供應沿海的腹地。規劃原料、加工鏈、料理與首批素材，標明舊有貨物沿用方式與待驗地點。配圖是規劃圖稿，正式貨物註冊與市場數值留給後續實裝。TASK-1273 的分區、氣候、土壤和資源區驗收仍由原單追蹤。

誰在等：Tim，及接手西非城鎮、貨物與食譜實裝的人。
