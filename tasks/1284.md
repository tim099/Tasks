# TASK-1284 — 《Blocksail》田放大之後重算開局建造清單（open_list）：Tim 的田分法搬上 main、清單照新的農莊大小重取

## 驗收標準

- [ ] 第二階段的田（density、精耕農莊等新種類）＋ Tim 的分法（農莊 2,400 m²／12 人、精耕農莊 1,200 m²／12 人）搬到當時的 main 上，城鎮規劃重烘、開場檔套規劃差異
- [ ] 每座城的開局建造清單用 tools/open_list.cjs 重算寫回（不是照面積換算）；清單裡的菜田換成精耕農莊
- [ ] open_list 加快（Tim「不用很精確的分布 只要大致能運轉就好」）：全部城重算的時間改前改後並排；快的那一版取出來的清單，兩年經濟面（同下一格的指標）跟慢的那一版在雙胞胎的差距內，或照實列出差在哪
- [ ] tools/town_start.cjs 的 ✗ 跟當時的 main 一樣（沒有新的 ✗）

- [ ] 文件寫明：改了建築的大小或人數 ⇒ 開局清單要重算（清單只記座數）

## 任務描述

起因（TASK-1266 第二階段，basecamp 2026-11-13 量的；讀數在 TASK-1266 留言 #4、#5）：
Tim 的田分法把一座農莊放大一倍（1,200 m²／6 人 ⇒ 2,400 m²／12 人），可是開局建造清單（world/start/towns/<城>/state.json 的 opening，tools/open_list.cjs 照舊的建築大小跑模擬取的）只寫座數、沒跟著重算 ⇒ 第 14 天開局那一批多吃一倍人手（聖多明哥農莊 51 座：306 ⇒ 612 人；全部城農莊 593 座）⇒ 自動建築每一輪的空人手少 ⇒ 排在中段的可可田輪不到 ⇒ 加勒比兩年可可 40,884（拆之前）⇒ 27,349 桶。
反向對照：同一份 Tim 的分法、只把清單的農莊減半（593 ⇒ 302 座）⇒ 43,416 桶（單跑、沒配雙胞胎）。

Tim 2026-11-13 選 A（用 open_list 重算，不是照面積減半），「那A先不做 先開單吧」。
Tim 同一天補：「同時可以看是否能優化算法 加快效率(因為其實不用很精確的分布 只要大致能運轉就好)」
⇒ open_list 現在是整個起始檔跑經濟模擬、每 30 天看一次，等每一座城的開場崗位都到大人的 target 成才停（聖多明哥 1,232 天）。可以考慮的方向（都還沒量）：只跑要算的那幾座城、到 target 的城先停掉、用較粗的步長或簡化的估法直接照缺口配座數 —— 要求是「大致能運轉」，驗收看結果（城跑得起來、可可等鏈不斷），不看清單跟慢的那一版逐座相同。

現況：
- Tim 的分法在分支 basecamp/1266-fields-tim（b7a5db97），底是舊的 587b1ab5（main 之後走了 92 筆）；第二階段的程式（4ef230dd：田寫 density、拆出精耕農莊、香料園、果林等種類，annex.js、town.js、townstate.js、townkit 等）也還沒進 main。
- 現在的清單只寫 farm；Tim 的分法裡 farm 只種穀物、菜改由精耕農莊（intensive-farm）種 ⇒ 舊清單裡的菜田等於不見了，重算時一起換。

做法（照順序）：
1. 從當時的 main 開 worktree，把第二階段的程式、建築表（4ef230dd 的非 start 部分＋b7a5db97 的 farm.json／intensive-farm.json／buildings.js）搬上去。
2. 重烘全部城鎮規劃；開場檔只套規劃差異（照 fields-split 那一場的做法：plan_delta）、補主糧。
3. node tools/open_list.cjs --town all --write 1（跑之前它會自己拿掉舊清單；聖多明哥 main c141dfb 量的是 1,232 天才到 target ⇒ 排晚上、背景、白天一次一個模擬）。
4. node tools/town_start.cjs 檢查；起始檔＋發船兩年配雙胞胎（MARKET.ema=0.3001），跟當時的 main 並排。

⚠ 已知還開著的另一格（不在本單）：城鎮生成器照熱量蓋田（world/annex.js townFarms）⇒ 規劃裡的菜田少（745 ⇒ 542 座）—— TASK-1266 留言裡等 Tim 定。
⚠ 量可可、自動建築要在發船的那一場量：不發船的 tools/auto_trace.cjs 兩版都蓋 8 座可可田，量不到這一格。探針在 basecamp session 3136688e 的 scratchpad cocoa/cocoa_probe.cjs（--trace <城>、--halfFarm 1；--out 給絕對路徑，它會 chdir）。
