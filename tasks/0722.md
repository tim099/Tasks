# TASK-0722 — Blockside：閒著的砲班轉成預備水手 —— 射界外再寬一圈、射程幾倍內都沒有敵艦的那一舷，砲手去補另一舷能開火的砲

> `feature` / `normal` / `done`　開單：erina　參與：erina(dev)

## 驗收標準

- [x] 每一層每一舷的砲：射界外再寬一圈、射程的幾倍內都沒有敵艦，連續幾秒 ⇒ 那一組砲手變成預備水手（判斷頻率低：幾秒一次、每艘錯開）；範圍與秒數在設定檔　✅ erina 2026-10-19
- [x] 放出來的預備水手照點名去補另一舷能開火、缺人的砲（也能派去救火、抽水、搬傷員、修破口）　✅ erina 2026-10-19
- [x] 敵艦進到那一組的範圍 ⇒ 那一組照點名補回砲班，而且排在一般補位前面　✅ erina 2026-10-19
- [x] 沒有著火、敵艦一直在兩舷射界裡的對局：每門砲照樣有人（放出去的組數 0）　✅ erina 2026-10-19
- [x] 實測：一舷接敵的單挑、艦隊戰各幾個種子，跟改之前比那一舷的開火數與人手（不只看一個種子）　✅ erina 2026-10-19
- [x] 反向對照：設定關掉（範圍 0 或開關）⇒ 戰局跟改之前逐字相同　✅ erina 2026-10-19

## 任務描述

Tim 2026-10-19：「炮在檢查射程範圍(檢查範圍會比射程寬 例如炮射角度45度 射程100m 檢查範圍可能是90度 200m 內沒有合適目標時 炮手轉為候補水手(先找看看是否已經有開單)」
「這樣候補水手就可以去補位另一邊能開火的炮」。

現況：救火那一版（Blockside 014a6db，TASK-0717）已經有閒置判定（射界外 +15°、射程 ×2、每 2 秒、連續 4 秒），
但只在船著火時啟動、只放出去救火（49_burn.js burnIdle）。本單把它變成通用的：跟著火無關，閒著的砲班就是預備水手，點名照缺額派（補另一舷的砲最優先）。
