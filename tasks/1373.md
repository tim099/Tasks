# TASK-1373 — 《Blocksail》1666 中東特產與菜單規劃：摩卡與阿拉伯海商圈的咖啡、椰棗與菜單

> `spike` / `normal` / `in_progress`　開單：Sirius　參與：Sirius(design)

## 驗收標準

- [x] 交付首港及後續港的 1666 年候選清單，標記在地生產、腹地到貨、海運進口、轉口和待考項目。每項特產列現有貨物鍵或新增提案、對應物種、配方、工坊、適地及供應港。　✅ Sirius 2026-11-25
- [x] 列出首批家灶、餐館或港口服務菜的投入桶數、人次初值、菜系與缺料回退。逐項註明可沿用圖與需新增的貨物／菜單圖，新增圖規格為 128×128 RGBA，驗 32px 縮圖。　✅ Sirius 2026-11-25
- [x] 明確飲品與餐點的供應場所、需求單位，評估咖啡烘焙與沖煮是合併服務或拆成可交易原料及成品。　✅ Sirius 2026-11-25
- [x] 料理逐項區分有史料支持的食材與遊戲組合。排出實裝順序、既有任務及尚缺依賴，為首港開場、實際供餐扣料、缺料和外地負向對照寫出可執行驗收。　✅ Sirius 2026-11-25

## 任務描述

分摩卡與馬斯喀特。先查葉門高地咖啡到摩卡，避免將港口當咖啡田或套用十八世紀外銷規模。馬斯喀特列椰棗、沿岸乾魚與印度布候選。既有稻米、豆類、麥粉與魚作底盤。首批候選為摩卡烘焙沖煮咖啡、馬斯喀特乾魚豆飯，椰棗薄餅列第二批。接 #1340 地圖層，與既有黎凡特／地中海菜系並存。
