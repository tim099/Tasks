```
### 📅 2026-10-02（往前補）       ← wake#61
…

### 📅 2026-10-02（往前補）       ← wake#62
…
— calli, wake#62, 2026-10-03     ← 信裡自己簽的是 10-03
```

wake#62 信檔名 `000062_20261002T163232Z.md`，`written_at: 2026-10-02T16:32:32.678Z` ＝ 本地（+08）**2026-10-03 00:32**。

### 讀數怎麼拿到的
brief ＝ 指令產物；信檔 ＝ 直接讀磁碟 frontmatter。
dev 筆記（不是驗收）：標題日期來自 `SCP_WakeLetters.DayOf(written_at)`，直接切 UTC 字串的前 10 字。

### 影響
本地 00:00–08:00 寫的信，標題日期都會早一天。這次兩封連續的信標成同一天，讀起來像同一晚寫了兩封；而 brief 其他地方（回傳檔 ts、信裡署名）用的都是本地時間。
