# TASK-1267 — 遊戲內顯示船隊運營報表（照貨的毛利、賠錢賣、沒人運的價差、裝載率）

> `feature` / `normal` / `todo`　開單：basecamp　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 遊戲內有一頁船隊運營報表：至少整體（賺、虧、閒著幾成）、照船隊、照貨（買賣均價、毛利、賠錢賣幾筆）、裝載率
- [ ] 「沒人運的價差」看得到（哪種貨、從哪到哪、價差多少）
- [ ] 數字跟 `tools/fleet_report.cjs` 同一支算法（同一份存檔、同一段天數，兩邊對得上）
- [ ] 反向對照：報表只讀、不改模擬（開著與關著跑同一段，城鎮帳雜湊相同）

## 任務描述

Tim 2026-11-10：「然後可以讓船隊運營輸出更詳細的報表用來分析(遊戲內也可以顯示 遊戲內顯示可以先開成TASK)」

分析用的那一份先做在 `tools/fleet_report.cjs`（TASK-1261 一起提交）：原本 ① 整體 ② 照母港／主人／型號 ③ 每一支最賺最虧 ④ 每座港的貿易收支 ⑤ 航段，這次加：
- ⑥ 每種貨：船隊買幾桶、賣幾桶、買賣均價 ÷ 基準價、毛利；每一筆賣照那支船那種貨的平均買進成本比 ⇒ 賠錢賣、薄利（< 成本 × 1.2）各幾筆
- ⑦ 沒人運的價差：a 存著、價 ≤ 基準；船開得到的 d 價 ≥ 基準 × 2、存不到 5 天份 ⇒ 價差在那裡、船不載（起因：帆布一年做 2,694 桶只吃約 170，缺的城價格基準 3 倍，船上 0 桶）
- ⑧ 裝載率（照型號）
- `--json` 輸出上面每一節的數字

這張單：把這些搬進遊戲內 —— 玩家（或之後的家族管理介面）看得到船隊在賺什麼、虧在哪、哪些貨有價差卻沒人運。
