# TASK-1334 — 《Blocksail》路切段不改名：送給 Blockside 的路段照原本的 id、帶弧長 sub，橋照原本的路找（根治「#k」改名斷橋）

> `improvement` / `normal` / `todo`　開單：ame　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 送給 Blockside 的路段 id 跟規劃一樣（沒有「#k」），每一段帶 sub；沒切到的路逐位元組不變
- [ ] 橋原樣送（不跟著換段名）；Blockside 照 id＋sub 找得到每一座橋：威尼斯每一座橋都找得到（district_reach 0 ✗），反向對照：Blockside 不看 sub ⇒ 量得到錯
- [ ] tools/district_reach.cjs 全部城 ✓（一段 ≤ 250 m、一段只在一區、橋找得到路）
- [ ] 文件（WORLD_FORMAT 長路切段、TOWN_BUILD）照新的寫；Blockside 檔頭說明照新的寫
- [ ] 遊戲裡進威尼斯：兵工廠兩座橋、里亞托都在，換城區之後橋還在

## 任務描述

Tim 2026-11-21「路切成「#k」的長期根治 開工吧 GO」（接 TASK-1331；Tim 11-20 問「跨界的路被切成原名#1、#2 … 實際應該只要標記使用的建築模型就好 為何切換城區會影響?」）

現況：town_export.js townRoadPieces 把送給 Blockside 的路在城區界上切、再每 250 m 等分，段名改成「<路>#k」（of ＝ 原本的 id）。
城鎮模式一區一建、地面只載焦點 ±2 km 的窗 ⇒ 長路一定要切，不然整條建、窗外那一段浮在霧上。
但 Blockside 有東西照路 id（＋弧長）找路 —— 橋（townBridgeList、townPrep 的 brOf）。改名 ⇒ 找不到 ⇒ 橋沒畫、路面平鋪在水上（TASK-1331 量到 7 座）。
1331 的補法是 bridgePieces 把橋的 road／s 跟著換成段名 ⇒ 治標：以後任何照路 id 找的東西都要記得跟著換。

做法：切還是照切（一段只在一區、≤ 250 m、不切在橋上），但 ⛔ 不改名 —— 每一段的 id 照原本那條路，多帶 sub: [s0, s1]（這一段在原本那條路上的弧長）。
- Blocksail：拿掉 of、bridgePieces；橋原樣送（road、s 照原本的路）。
- Blockside：照 id＋弧長找的地方改看 sub（townBridgeList：那一座橋落在哪一段、那一段有沒有建；townPrep 的路面挖橋：s 減 sub[0]；townDiff 照 id＋sub[0] 比）。
- tools/district_reach.cjs：「橋找得到路」改量 sub。
