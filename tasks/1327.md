# TASK-1327 — 《Blocksail》城鎮規劃分層烘：骨架（牆、路、公共建築）不受氣候與物種影響、田另一層；田只換種什麼不重烘

> `improvement` / `normal` / `todo`　開單：ame　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準


- [ ] 量（至少小、中、大三座城）：烘一座城的時間拆成地形取樣、適地遮罩、骨架、田各幾秒 —— 先量再決定拆到哪一層
- [ ] 改一個物種的適地、或換氣候格子 ⇒ 骨架那一份不過期、只重算田那一層；城牆、路、公共建築、住宅地塊跟改之前逐位元組相同
- [ ] 田只換種什麼的情況不重烘：載入時照現在的適地挑配方；田的地塊什麼都種不了時才重算田那一層（讀數：改一種作物的適地，幾座城不用烘、幾座要烘田那一層）
- [ ] 反向對照：改骨架讀的東西（地形、範圍、生成器骨架那一段）⇒ 骨架過期、田跟著重算
- [ ] 地球儀現場算的跟烘好的逐位元組相同（town_bake --verify）
- [ ] 分層那一次的全部重烘做完；開場清單照新規劃對過（路網變了的城列出來、田的配方跟載入時挑的同一套）

- [ ] 海圖塊的植被（段 2）另外一層（Tim 2026-11-19「植被那一段也拆成另外一層吧」）：改物種、氣候 ⇒ 地形、海床那幾段不過期，只重算植被（或改成用到時才算、不烘）
- [ ] placeAt 不再每一點掃整份範圍層（空間索引；土壤改格子後 TASK-1324 再少一大半）—— 讀數：烘一座城、一塊海圖塊的時間 修前／修後，結果逐位元組相同


## 任務描述

Tim 2026-11-19：「另外城市不受氣候&植物影響的建築 是否可以在自動建造 烘焙中跟農田等會受影響的建築分離 進而加速烘焙(這樣改動植物分部等不影響其他建築)」「開單 另外我在想 田是否也能在部份情況下不重烘(單純替換田的種植配方)」

**現在**（ame 查的，main e86f6cb87）
- 一座城的規劃一個指紋（world/town_store.js townInputs）：規劃讀的適地（'#planareatables'、'#species'，TASK-1282）＋氣候格子（'#climate'，TASK-1323 336bfdba5）都在裡面 ⇒ 改物種的分布、適地表、換氣候格子 ⇒ 那座城整份規劃重算（城牆、路、公共建築、港口、住宅一起），取樣也一起（取樣的指紋同樣有物種、氣候）
- 規劃讀適地的地方（world/town.js）：
  - 取樣：整座城的適地遮罩（town_sample.js townSuitPut）—— 取樣是烘一座城最貴的那一段（bake log「取樣 現場」10～60 s）
  - ④ 主要道路挑終點：往 FARM 那幾種適地的方向（TOWN_ROAD_SUITS：甘蔗、菸草、可可、靛藍、棉花、牧場）
  - ⑬ 開場的農莊（annex.js townFarms）：放哪、種什麼
  - plot 地塊記那一點的適地（o.suit）；手動配置檢查「這裡長不了」
- 遊戲裡的自動建造（auto.js）是執行時照 site 的適地算，不烘 ⇒ 本來就不受影響

**做法（提案，數字待量）**
1. 取樣拆兩層：地形取樣（貴、不看物種氣候）／適地遮罩（便宜、看物種氣候），各自一個指紋
2. 規劃拆兩層：骨架（城牆、路、公共建築、港口、碼頭、住宅地塊）不讀適地／田（⑬ 開場農莊、plot）疊在骨架上、讀適地 —— 各自一個指紋、各自一份烘好的檔
   ⇒ 改物種、適地、氣候：只重算適地遮罩＋田那一層；骨架（還有建築網格、海圖塊裡的建築）不動
   ⚠ 代價：④ 的路現在照農地挑終點 ⇒ 要分層，路就不能看適地（改看地形／平地、或固定）⇒ 生成器改一次 ⇒ 全部城的路網變一次、全部重烘一次、開場清單照新規劃對一次
3. 田只換種什麼（Tim 的第二個點子）：田的地塊（形狀、位置、通路）留在烘好的檔，「種什麼」不烘 —— 載入時照現在的適地挑配方（跟開場清單、自動建造同一把尺）
   ⇒ 只有某一塊田什麼都種不了（或該多一塊田）時才重算田那一層；多數的物種微調連田那一層都不用烘
   ⚠ 開場清單（world/start）的田是照規劃的配方記的 ⇒ 配方改成載入時挑，開場清單那一欄要跟著改成同一套（不然兩邊對不上）
