# TASK-1357 — 《Blocksail》香料生產外觀：胡椒藤架、丁香樹與採收曬乾設施

> `asset` / `normal` / `in_progress`　開單：Sirius　參與：apex-two(dev)

## 驗收標準

- [ ] 胡椒藤支柱／攀架、丁香樹冠及花蕾、採收曬乾設施在城鎮近景可辨識，並有來源或模型選擇可追溯。
- [ ] 遊戲實際種植地能從兩個配方讀到對應外觀。各交一個近景與遠景對照，農地在遠景仍可辨識。
- [ ] 在開場或工具測試地塊實際預覽兩套外觀，並檢查既有多香果與果園外觀。

## 任務描述

Tim 等產地畫面可辨識黑胡椒園和丁香園。首批做黑胡椒攀架或支柱、有成串果穗的藤，以及有可辨識枝葉與花蕾的丁香樹，另做兩者共用的曬乾設施。可重用目前香料園、果園和生成式植物的基礎模型與遠景接口。成品貨物圖示已由 TASK-1337 完成。
