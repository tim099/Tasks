# TASK-1060 — 《Blocksail》勞動力分析：一名工人一天的消耗（分食物等級）要幾名工人做得出來 —— 每種貨的勞動量、工人的消耗與產出比（模擬後台一頁）

> `feature` / `normal` / `in_progress`　開單：kaguya　參與：kaguya(dev)

## 驗收標準

- [ ] 每種貨一桶要幾個工人·天：沿配方往回推（原料也算進去、聯產品照價值分、幾條路取最省的、野外採集也算一條），看得到走哪一條
- [ ] 一名工人一天的消耗（一份飯分 1／2／3 級、日用、奢侈品）要幾名工人才做得出來 ⇒ 一名工人養得起幾人；分「最省的那一道」與「照現在吃的花樣」
- [ ] 模擬後台多一頁看得到（同一份表、拆到每一種貨與每一道菜），node 也印得出來、兩邊數字一樣
- [ ] 反向對照：手算兩條鏈（例：麵包 ⇐ 麵粉 ⇐ 小麥、肉 ⇐ 屠宰 ⇐ 養牛）跟工具算的一樣
- [ ] 文件：寫明怎麼算、沒算進去的（服務、兵、營造、造船、戰爭的損耗；各地區種不種得出來）

## 任務描述

Tim 2026-10-28：「另外可以加一個 分析 每名工人的理論物資消耗 要多少名工人才能完全滿足(且可以分食物等級) 理論上最優情況下市場要能滿足所有需求(因為會有額外損耗) 之後可能會有一些生成力buff讓後期經營得好的話可以滿足供需」
「因為人口並非全都是工人階級(但產出全靠工人)」「然後建材 造船 以及戰爭都會有額外損耗」「應該說 目前希望單純化 指分析工人自己的消耗 & 產出比」

**誰在等**：Tim（調配方、消費量時看「一名工人養不養得起自己、還剩多少給其他人與損耗」）。

**做什麼**：模擬後台（sim.html，TASK-1059）多一頁「勞動力」＋ node 工具：照配方表（world/recipes.js、建築的一級、prodFull）推每種貨一桶的勞動量（工人·天），再算一名工人一天的消耗籃要幾名工人。比值 < 1 才有餘裕養不工作的人、營造、造船、戰爭。
