# TASK-1007 — 《Blocksail》鎮民分社會階層（可擴充的階層表）：城鎮生產建築的收益歸商人階層、教堂歸教士，各階層分池吃飯消費與課稅；家族不再賠錢生產

> `feature` / `normal` / `in_progress`　開單：trailhead　參與：trailhead(dev)

## 驗收標準

- [ ] 階層表 BSW.STRATA（資料驅動、可擴充）：每一筆 share（佔人口幾成）、wage（收不收工資）、owns（持有哪幾類城鎮建築：cat／type）、消費等級（2、3 級上限、日用、奢侈品倍數、reserve／spread）、tax（照哪一張分級稅表；null 免稅）；先放三筆：受薪勞動、富裕商業（城鎮生產建築）、教士（教堂、修院）；加一筆不用改程式
- [ ] 鎮民金庫照階層分池：ref { folk: 城, cls }；舊存檔的 { folk: 城 }／towns.<城>.folk 照讀成第一層；全世界的錢照舊對得上
- [ ] 沒寫 owner 的城鎮建築照 STRATA.owns 找主人階層：生產建築的工資、原料錢由那一池出，收工時城鎮照市場曲線收購產出、錢進那一池（分紅）；服務建築的收入進那一池、雇人的工資由那一池出
- [ ] 吃飯、日用、奢侈品、服務建築消費、房租照階層各算一次（人數 ＝ 人口 × share，錢 ＝ 那一池，消費等級照那一層）
- [ ] 分級資產稅照階層：一人平均 ＝ 那一池 ÷ 那一層人數，照那一層的稅表；教士免稅
- [ ] 家族不再賠錢生產（E）：家族建築的市場開工率把所得稅算進產出值
- [ ] 開關：BSW.STRATA_ON ＝ false ⇒ 逐位元組照舊（反向對照）
- [ ] tools/money_report.cjs 照階層列鎮民的收支、儲蓄與分佈；起始檔跑兩年，跟改之前並排對照（城鎮、各階層、家族的錢佔比）寫進單
- [ ] 統計照階層列食物消費（Tim 2026-10-26「然後統計資訊可以加上 不同階層的食物消費(吃了甚麼菜單)」）：money_report 每一層吃了哪幾道菜、每一級幾成；城鎮資訊 strata ＋ 城鎮介面「📋 概況」的「👥 社會階層」（Blockside 89_townui.js）每一層昨天吃了什麼
- [ ] 檢查工具全過（跟 main 原本就紅的那幾條比）；重跑兩次逐位元組相同
- [ ] 文件：STORES §6.1（鎮民金庫分池）、TOWN_SIM 社會階層、PRODUCTION 吃飯與服務建築那幾節


## 任務描述

## 要什麼

Tim 2026-10-26（看完 money_report：錢八成五躺在城鎮金庫、NPC 家族一年燒光）：
「那我想了一下 生產建築的收益屬於鎮民如何(相當於擁有者是分散的鎮民)」
「然後鎮民可以分階層(持有生產建築的商人階層)」「然後會根據階層有不同消費等級」「階層可以保持擴充性」
「例如教士(教堂歸教士階層持有)」

## 現在（main 5955120，tools/money_report.cjs 起始檔一年）

- 城鎮擁有八成的生產建築：生產工資 944k 由城鎮付、221k 由家族付；產出直接進城鎮市場（不花錢），照基準價（成本 × 1.5）賣給鎮民 ⇒ 鎮民的收入只有工資，買不起自己做出來的東西。
- 城鎮一年 +209k ≈ 鎮民 −78k ＋ 家族 −111k ＋ 鑄 +28k；第 365 天城鎮 88.5%、鎮民 10.3%、家族 1.2%。
- 家族賣貨 178k ＜ 工資 221k（再加原料 54k、稅 26k）：prod.js mktRate 產出值 ≥ 成本 0.8 倍就滿產，沒算三成所得稅。

## 改成

- 階層表 BSW.STRATA（見驗收標準），程式照表繞；城鎮變成市場與政府（收房租、稅、鑄幣，付士兵、免費補糧）。
- 之後（這張單不做）：五個社會階層、建築種類對應持有階層（農莊名門、工坊工匠、攤位小本自營）、階層流動、商人池出自動建築的造價。
