# TASK-0531 — 《憲法號對轟》大量破壞時的慢動作（破壞與物理分散到多幀，避免卡頓）

> `feature` / `normal` / `done`　開單：ame　參與：ame(dev)

## 驗收標準

- [x] 彈藥庫殉爆時自動進入慢動作（慢多少照爆炸大小：大的慢很多），畫面看得出變慢、之後平順回到正常速度　✅ ame 2026-10-13
- [x] 殉爆的破壞與物理（挖彈坑、重新網格化、碎片、斷開的一團）分散到多幀處理：同一場殉爆，最慢的那一幀比現在的版本短（讀數寫在單上：最慢一幀的毫秒數，前後對照）　✅ ame 2026-10-13
- [x] 慢動作與特寫可以在設定裡各自關掉；關掉時沒有慢動作與特寫（彈坑照樣分步挖 —— 那是分散工作量，不是慢動作）　✅ ame 2026-10-13
- [x] 反向對照：慢動作只改「模擬時間跟真實時間的比例」與每幀的工作量分配，不改戰局 —— 同一個種子跑同樣的模擬秒數，開與關的戰局讀數逐項相同　✅ ame 2026-10-13
- [x] 觀戰、對戰電腦、沙盒都適用；?demo 縮圖不受影響　✅ ame 2026-10-13
- [x] 彈藥庫殉爆：自動切特寫鏡頭（對準爆心、看得到火球與船斷開）＋慢動作，結束後鏡頭回到原本的模式；可以在設定裡關掉特寫　✅ ame 2026-10-13
- [x] 開戰第一輪對砲不卡（Tim：平常 60 FPS、第一輪對砲掉到 15 以下）：最慢一格的毫秒數前後對照，判定不變（同一個種子的戰局讀數逐字相同）　✅ ame 2026-10-13

## 任務描述

Tim 2026-10-13：「當大量破壞發生時可以做慢動作（同時避免 Lag），讓破壞、物理模擬分散到更多幀（同時也能更好地欣賞破壞效果）。」先開單、不動工。

現況：模擬固定步長 1/60 秒；彈藥庫殉爆、斷船時一步裡打掉幾十萬格、重新網格化很多區塊，那一幀會卡。
方向（開工時再定）：偵測到大破壞 ⇒ 時間倍率降到例如 0.3×、幾秒後回到 1×；同時把重網格化／碎片生成排進佇列，每幀做固定預算。
關聯：TASK-0514（總單）、TASK-0526（物理效果分級）。
