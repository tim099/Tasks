# TASK-0621 — 《憲法號對轟》金屬的物理：鐵甲打不穿會凹陷、太斜會跳彈、能量夠才擊穿（跟木頭分開算）

> `feature` / `normal` / `done`　開單：ame　參與：ame(dev)

## 驗收標準

- [x] 砲種表有彈重（kg，照史料）；每一發帶能量 E ＝ ½ × 彈重 × 速度²；打木頭每咬一口照打掉的格數扣能量（取代照格數扣速度），扣完就停 ⇒ 大口徑鑽得深、小口徑淺；24 磅長砲打橡木的深度跟以前差不多（校準點）　✅ ame 2026-10-16
- [x] 入射角：打中點周圍的格子估表面法線，θ ＝ 砲彈方向跟法線的夾角；有效能量 ＝ E × cos²θ；θ 超過門檻（預設 65°，設定檔）⇒ 彈開（照反射方向飛走、帶著剩下的速度），不掉格　✅ ame 2026-10-16
- [x] 鐵甲（材質 kind=metal）的門檻：需要的能量 ＝ 材質表的 pen（每格板厚幾 kJ）× 沿法線量的板厚 × 船殼硬度比；比值 ＝ 有效能量 ÷ 需要的能量 ⇒ 擊穿機率照曲線：低於 lo ⇒ 0（小口徑完全打不動，1000 發也不穿）、lo～hi 之間隨機（例：24 磅正面約 5%）、高於 hi ⇒ 必穿；曲線參數在設定檔　✅ ame 2026-10-16
- [x] 沒穿 ⇒ 不掉格、不噴碎木（讀數記凹痕）；穿了 ⇒ 照原本的咬法打洞，能量扣掉門檻再往裡　✅ ame 2026-10-16
- [x] 碎片傷人照這一口實際用掉的能量；爆裂彈的爆炸半徑照彈重　✅ ame 2026-10-16
- [x] 讀數：每種砲打維吉尼亞號砲廓、莫尼特號砲塔（各 100 發）：穿／凹／彈各幾發；打憲法號橡木的深度與掉格；戰鬥報表改前改後（維吉尼亞號對憲法號、莫尼特號對維吉尼亞號、憲法號對餘燼號，各 3 個種子）　✅ ame 2026-10-16
- [x] 三組對拍換新值並寫在提交裡；Tim 在遊戲裡開過　✅ ame 2026-10-16
