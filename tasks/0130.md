## 留言

### 💬 #1 summit 2026-09-05T11:58:19.809Z
\## 追加一格 —— 而它比原單重：`senate ucmd` **沒有**未知參數預檢，而文件說有

開這張單的時候我 dogfood 自己寫的那招（`--arg <不存在的名字>=1` 換 ArgSpec），
在 `senate ucmd` 上**它不動** —— 不是被擋下沒印，是**根本沒擋**。

\### 對照組（變因單一：同一個 `--arg bogus=1`）

| 路 | 結果 |
|---|---|
| `senate ucmd run Tavern --arg op=catchup --arg bogus=1` | ✓ **Success**，catchup 照跑（游標真的推進了） |
| `senate ucmd run Task --arg op=show --arg index=64 --arg bogus=1` | ✓ **Success** |
| `senate cmd tasks --arg data_root=… --arg bogus=1` | ✗ exit 2 ＋ 列出合法參數 |

⇒ **`senate cmd`（SCP_CMD 本地）有預檢，`senate ucmd`（Editor 派遣）沒有。**

⭐ 而 ArgsSchema 在 ucmd 上是**半邊生效**，這個區分是重點：
- 缺**必填** → 會擋（`senate ucmd run Tavern` 不給 op ⇒ `缺少 op 參數。請參考 ArgsSchema。`）
- **未知參數** → 靜默吃掉，Success

（Cmd_Tavern **有** ArgsSchema —— 昨天 `1a6bc460` 才給它補了 `expect_from`/`waiter` ——
所以這不是「那支沒宣告」，是**那條路不跑未知參數這一檢**。）

\### 🩸 而 4 份 skill 寫著它會擋

`ucl-morning` / `ucl-goodnight` 的「為什麼有兩條路」一節都寫：
> - CLI 端有 **ArgSpec 預檢**（未宣告的參數名會被擋，不會靜默取預設值）

那句話對 `senate cmd` 成立、對 `senate ucmd` **不成立**，而它沒有分 ——
**是寬報**（憲法⑤：射程說大，而過度信任不會炸，所以它永遠不會被推翻）。
⚠ 而失效樣子最貴：**你相信打錯會被擋，所以不去檢查 ⇒ 靜默取預設值。**
兩份 skill 同時也在教 `senate ucmd run GoodMorning --arg step=wake …` 那條底層直派 ——
也就是說，它**教了 ucmd，然後保證了一個 ucmd 沒有的東西**。

\### 已修（字面止血，不是設計決定 ⇒ 我沒等拍板）

改 `Skills~/` 兩份**源**檔，跑 `install_skills.py --include ucl-morning,ucl-goodnight`
同步三個 target（claude / antigravity / codex）。新字面把射程寫死並附對照組讀數。

驗收（正反兩面）：舊字面殘留 **0** 檔／新字面 **8** 檔（1 源＋3 複本 × 2 skill）。
⭐ 反向對照：`git status` 只有那 8 個檔動了 —— **同步器沒有順手改到別的 skill**
（我顯式帶了 `--include`，沒有讓它走預設全裝）。

📌 而找到那 8 個檔本身也踩了一次憲法⑦：我第一次 grep 只給了 `.claude` 與 `Skills~` 兩個路徑，

**缺的那兩份不會出現在我自己列的路徑清單上。**

在 `senate ucmd` 上連那條路都沒有：**沒有任何方法能從 CLI 問出一支 ucmd 吃什麼參數。**
