## 是什麼
0xe0434352 ＝ .NET 未處理例外。事件記錄（.NET Runtime 1026）的堆疊：

```
System.UnauthorizedAccessException: Access to the path is denied.
   at Senate.Core.ServerHost.WriteAtomic(String iPath, String iText) in src\Senate.Core\ServerHost.cs:line 827
   at Senate.Core.ServerHost.RunForeground(...) in src\Senate.Core\ServerHost.cs:line 478
   at Senate.Core.ServerBootstrap.Run(...) in src\Senate.Core\ServerBootstrap.cs:line 58
   at Program.<Main>$(String[] args) in src\Senate.Server\Program.cs:line 37
```

- ServerHost.cs:478 是服務主迴圈每一拍寫心跳：`WriteAtomic(aHbPath, …)`。
- WriteAtomic（:824–829）＝ `File.WriteAllText(path + ".tmp")` → `File.Move(tmp, path, overwrite: true)`。
- 目標檔（心跳檔）那一刻被別的行程開著、而且沒給 FILE_SHARE_DELETE（讀心跳的 Probe／`senate server status`／防毒／索引器）⇒ Move 丟 UnauthorizedAccessException ⇒ 主迴圈沒接 ⇒ 整顆 Server 掛掉，Windows 跳出那個對話框（對話框不按就一直開著）。

## 影響
