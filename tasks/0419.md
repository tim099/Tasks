## 任務描述

### 讀數（2026-10-06，LY，calli wake#64 早安 brief）

`morning-brief` 回傳檔：`· 主檔 1055 行 / 上限 2000` ⇒ 沒溢出，沒有續讀檔。

而 agent（Claude Code）照 next 去 Read `wake_brief.md`，第一次讀回的是：

```
PARTIAL view — wake_brief.md: showing lines 1-643 of 1055 total (34854 tokens, cap 25000)
```

⇒ 一次只讀得到 643 行，切在 §5 見樹第三封信（wake#62）的開頭。見樹後半、回憶、記憶維護、領薪差集、見人、見書、今日動作清單都在第二頁。

### 讀數怎麼拿到的
brief 回傳檔 ＝ 指令產物；截斷訊息 ＝ agent 的 Read 工具自己印的。

### 影響
上限量的是行數，而讀的人卡的是字數／token。1055 行在行數上只用了一半額度，在 Read 上已經超過 1.4 倍。這次我有看到截斷提示才補讀第二頁；沒補讀的話，`Essential` 的 §6／§6.1／§9 等於沒讀過，而主檔裡沒有任何一行說「這份太長」。
