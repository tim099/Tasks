# TASK-1059 — 《Blocksail》模擬後台：瀏覽器直接跑起始檔＋發船的經濟模擬，看每種貨的庫存、產出、消耗、價格曲線（sim.html／sim.sh）

> `feature` / `normal` / `in_progress`　開單：kaguya　參與：kaguya(dev)

## 驗收標準

- [ ] 一支 `sim.sh`（或伺服器在跑時直接開 `sim.html`）就能從起始檔＋發船跑 N 天的經濟模擬；跑的是遊戲自己的 `world/*.js`，不另寫一套
- [ ] 每種貨看得到庫存、產出、消耗（吃掉、當原料、船隊買走／賣進）、價格 ÷ 基準、供應率、缺貨城·天；可以切全世界、分區、每座城；曲線 1／7／30 天一格
- [ ] 貨物總表可以排序，找得到長期短缺的貨；城鎮那一頁看得到人口、挨餓、三種金庫
- [ ] 同一頁改設定再跑一次，兩次可以疊在一起比
- [ ] 讀數跟 node 跑同一份起始檔、同樣天數的結果逐筆相同（換一條路徑對帳）
- [ ] 反向對照：收集只讀不改模擬 —— 收集開著跟關著，一年的城鎮帳雜湊相同
- [ ] 文件：SIM_STATS 補一節（怎麼開、看什麼、怎麼比）

## 任務描述

Tim 2026-10-28：「是否可以先加一個數據模擬後台(底層直接用目前的數據模擬) 然後可以查看各項數據(包含貨物庫存 產出 消耗 取線 價格等)」「然後可以直接是html或是靠.sh啟動」

**誰在等**：Tim（調經濟要看曲線，例如 TASK-1053 魚、雞的兩種改法要並排比）。

**現在有的**：`world/stats.js`＋`tools/sim_stats.cjs --html`（TASK-0892）—— node 跑起始檔（不發船）、產一份靜態報表；庫存只畫變化最大的六種，沒有價格、產出、消耗、供應率（SIM_STATS §5「之後」那一條）。各人的探針（trailhead 的 xtown.cjs 等）都在 scratchpad。

**做什麼**：`sim.html`＋`sim.sh`（照 globe.sh：起 `tools/world_serve.py`、開網頁）；模擬在 Web Worker 裡跑遊戲的 `world/*.js`（起始檔＋發船，同 `money_report --fleets 1`），每天收每座城每種貨的讀數，頁面畫表與曲線。
