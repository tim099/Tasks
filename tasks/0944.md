# TASK-0944 — 《Blocksail》每種建築一份設定檔：種類表與建築模式選單從它組、照設定檔＋模型自動進選單、後台頁改參數

> `feature` / `normal` / `in_progress`　開單：kotoko　參與：kotoko(dev)

## 驗收標準

- [ ] 建築模式選單裡的每一種、生產建築種類表裡的每一種，各有一份自己的設定檔（名字、分類、選單放哪一類、佔地、營造等級、配方、等級、擺放規則）；種類表與選單都從這些檔組出來
- [ ] 選單自動長：設定檔寫了選單分類、而且城鎮模型套件裡至少有一件那個用途的模型 ⇒ 出現在那一類；磨坊因此進「工坊」
- [ ] 反向對照：設定檔沒寫選單分類、或套件裡沒有那個用途的模型 ⇒ 不出現；搬家前後五座城的規劃逐位元組相同、選單的項目與順序相同（除了新進來的）
- [ ] 後台頁：Editor 版本開得到一頁，挑一種建築、改參數、存 ⇒ 只改那一份設定檔；重新整理後遊戲讀到新值；不合法的值（負數、不認得的配方）擋下並說原因
- [ ] 遊戲裡（Port de Paix 或托爾圖加）建築模式「工坊」看得到磨坊、蓋得下去、畫面是磨坊的模型

## 任務描述

Tim 2026-10-25：「927 我找不到磨坊 而且建築選單好像也沒有 另外是否能讓建築根據meta與config檔案(目前有嗎?希望每棟建築有一份自己的配置檔案 之後後台可以改參數)自動進入建築選單」「開兩張單，先做每棟建築一份設定檔自動進選單，再做住宅種類 GO」

現況（2026-10-25 讀 Blocksail main 548ba37）：一棟建築的資料散在四處 ——
- `world/buildings.js` 一張大表 `BSW.BUILDINGS`（生產、工坊、倉庫：名字、cat、grade、lot、recipes、levels）；住宅、公共建築沒搬進來。
- `world/town.js`：`PUB`（公共建築大小）、`CORE.name`、`WATER`（水上版大小）、寫死的 `BUILD_MENU`（今天糖廠進選單就是手加一行）。
- 模型 meta（Sculpture ⇒ `world/townkit` 索引：style、use、lot、lvl、recipes、water、spin）。
- 沒有後台；Blocksail 的本機伺服器 `tools/world_serve.py` 已經有寫回檔案的 API（attrs、areas、save）。

磨坊、漁場、鹽田沒進選單（TASK-0927 時刻意留下：生產鏈 0917 還在動；漁場、鹽田要臨水的試放規則）⇒ 遊戲裡只有城鎮或家族照需求自己蓋才會出現。

做法（第一版）：設定檔一種一份、Blocksail 讀進來組 `BSW.BUILDINGS` 與選單；選單照「設定檔有選單分類 ∧ 套件有模型」自動長；後台頁走 world_serve.py 寫回那一份。
⚠ 這些表在城鎮規劃的指紋裡（town_store.js TOWN_CODE）⇒ 改了參數，規劃要重烘。
不在本單：公共建築（TOWN_CORE，生成器擺的那一套）搬成設定檔 —— 動到生成器，之後另說；漁場、鹽田的臨水試放規則。
