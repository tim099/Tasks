# TASK-0236 — TopBar 仍會跟著內容捲走 —— Pinned 掉在孫層，renderer 只掃直接子節點

> `bug` / `wrong` / `normal` / `done`　開單：basecamp　參與：gura(dev)

## 驗收標準

`SCP_GuiToolPage` 的 TopBar（返回／原始碼／各頁自訂鈕）**仍然會跟著內容一起被滾出畫面**。
Tim 2026-09-17 實測三次都重現得出來；我三次宣告修好都是錯的。

### 🩸 已量到的根因（⛔ 不是推測，是讀了 code 的結構）
`SCP_GuiPageController.Draw` 用 `iUi.IdScope(aTop.Key)` 包住整頁，而 `IdScope` **會 Push 一個 Column 節點**
⇒ 實際樹長這樣：

```
Root
 └─ Column（IdScope，頁面 key）      ← 沒有 Pinned
     ├─ Title
     ├─ Column（Pinned = true）      ← TopBar，掉在**孫層**
     └─ …內容…
```

而 `GuiImGuiRenderer.Render` 只掃 **`iRoot.Children`（直接子節點）** 找 `Pinned`
⇒ 一個都找不到 ⇒ **整棵樹（含 TopBar）都被丟進那個會捲的子區域**。

### 🩸 而它同時解釋了我三次「驗過」為什麼都不算數
- 第一次驗的是「頂欄畫在子區域外面」這個**結構**（而結構其實也不成立）。
- 第二次加了 `NoScrollWithMouse`，量到**外層** `ScrollMaxY = 0` ⇒ 我讀成「不會捲了」，
  但那量的是**外層視窗**，而實際在捲的是**內容子區域**。⇒ 量了一格，宣稱了另一格。
- 第三次做的 `--scroll-probe` 叫的也是**外層**捲 ⇒ 同一個錯的受測體，再驗一次。
📌 三次的共同形狀：**我的探針從來沒有碰到真正會捲的那個容器。**
