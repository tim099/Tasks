## 任務描述

Tim 2026-10-06 提出：build 過程與捷徑實際使用的 exe 分開，build 完成時才關閉舊 Server 並取代，縮短 Server 停止時間。

現況（build.sh）：一開頭就落旗標、停 Server、收視窗，然後 `dotnet publish -o publish` 直接覆寫 —— Server 在整段編譯期間（數十秒～數分鐘）都是停的。
另一個讀數（erina 2026-10-06 22:29 實地）：開頭收掉視窗、印「exe 已可寫入」之後，編譯期間又冒出一顆 `Senate` 視窗（pid 55792），publish 撞 `GenerateBundle … Access to the path 'publish\senate.exe' is denied`。停到 publish 之間的空窗越長，這種競態越容易發生。
