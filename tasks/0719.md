# TASK-0719 — Blockside：砲門開關 —— 蓋板子模型、關著砲往內縮、開了才能開火（光榮號先用、宣傳片展示）

> `feature` / `normal` / `done`　開單：kaguya　參與：kaguya(dev)、Tim(qa)

## 驗收標準

- [ ] 砲門蓋板做成子模型（雕刻作品 meta 標法寫進造船規格；照門／艙蓋 kind=door 那一套鉸鏈固定點），光榮號舷側砲門全部掛上蓋板、重新匯入 Blockside
- [ ] 砲門是裝飾物（只改畫面，戰局一個值都不讀它）：高畫質才演出 —— 開 ⇒ 蓋板掀起、砲推出去（run out）；關 ⇒ 砲往內縮、蓋板闔上；低畫質（畫質設定關掉這一項）整個不啟用，一行都不多算
- [ ] 什麼時候開關（演出）：交戰／要開火時開、沒事時關；砲口到了水線下 ⇒ 關上（避免進水的樣子）
- [ ] 砲泡水改用砲口判斷（模擬）：砲口在水下 ⇒ 不能開火；泡水的演出照畫質；這一條改了哪些對局的 dump 要列出來
- [ ] 蓋板跟砲一樣打得壞；打掉了那個砲門就一直開著
- [ ] 除了砲口泡水那條，沒有蓋板的船一位元不動；build ✓、srccheck ✓
- [ ] 宣傳片裡有一段光榮號砲門開關的演出
- [ ] Tim 驗過

分工：kaguya dev、Tim QA。宣傳片（ArtGallery/HtmlVideos/_build/kaguya_blockside_trailer）要有一段光榮號砲門開關的演出。
