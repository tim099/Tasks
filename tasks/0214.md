## 驗收標準

\## 拍板

1. 「**文字模式下同時也開視窗（實際等同真實操作）**，文字輸出只是方便查看、可以操作，需要時截圖看一下，同時可以測 fps」

3. 「**文字模式主要用來知道視窗上有哪些可互動項目**」

⇒ 第 3 句把這張單的形狀定死了，它比「兩個模式都開」更精確：
**文字不是另一個 renderer，是那顆窗的「這上面有什麼可以點」清單。**

\## 現況（讀數，2026-09-15）

`src/Senate.Cli/Program.cs:270`：
```csharp
bool aSoak = ArgValue(iArgs, "--soak") != null;
if (aWindow || aSoak || aShot != null) return RunWindow(iRepoRoot, iArgs, aShot);
```
⇒ 帶了 `--window`／`--soak`／`--screenshot` 就**直接走掉，文字那條路一行都不跑**。
兩個世界今天是**互斥**的：要嘛拿得到 id 清單（文字）、要嘛看得到它動不動（視窗），不能同時。

成本量過了：文字 `--page home` **1.574s** ／ 開窗＋截圖 **2.311s** ⇒ 開窗約 **+0.74 秒**。
今天開了三次窗（兩次 `--soak 10`、一次 `--screenshot`），**Claude Code 沒有被卡住** ——
TASK-0204 那條血證講的是**常駐長命**的 GUI 行程，不是開完就收的短命窗。

\## ⭐ 好消息：IPC 不用發明，這是同一個形狀的第三次

`ServerDelegateCmd` / `ServerHost` 已經跑著這套協議：
`<根>/queues/<lane>/pending.trigger` → 原子接手成 `.running` → 跑 → 寫 `_cmd_results/<id>.json`。
Unity Editor 的 Watcher 是同一套（我今天早上整個早安流程都走它）。
⇒ **常駐窗只要變成第三個委派宿主**，不需要新的通訊機制。⛔ 不要造第四套。

\## 🩸 而這張單真正要殺的是什麼（⛔ 別讀成「加個功能」）

今天 TASK-0178 收尾時 @summit 量到：改會重畫的頁的人，**路徑上根本不會經過**那條
「開真視窗轉十秒」的規矩（`grep -rn "Create_EditorPage" Senate/Docs SCP_Core/Docs~` ⇒ **0 命中**），
而他自己今天就是那個沒被攔到的活體（`SCP_GuiSessionAdminPage` / `85f2acf`，只在文字模式驗收）。

⇒ 我原本的修法是**在文件上補告示牌**。Tim 的修法是**改路**：
文字模式如果本來就在描述一顆真的、正在重畫的窗，
**「per-frame 成本在文字宿主結構性測不到」這句話就不成立了** —— 那條規矩不必有人記得，因為壞事做不到。

📌 這是第一階修法（讓它不可能發生）而不是第三階（記得注意）。

\## ⛔ 最重要的一條設計約束（②）

文字樹**必須是從那顆窗讀回來的**，⛔ 不可以是 CLI 這邊再畫一次拿到的。
否則我們會親手做出「**同一份資料兩個入口，而寫入端不知道自己在哪個宇宙**」——
那時 `--list` 會很有自信地告訴你有哪些 id，而那些 id 屬於另一個宇宙的畫面。
⇒ 驗收②的反向對照就是為這一格寫的：**在窗上把區塊摺疊起來，`--list` 必須跟著少掉那些 id。**

\## ⛔ 第二條：窗沒在跑不要降級（⑤⑥）

照 Tim 2026-09-02 ⑦ 對 Server 的既有拍板（`ServerDelegateCmd` 檔頭）：
**不降級成本地跑，印怎麼啟動，exit 3。**
🩸 而這一格有本專案自己的血證，就在同一支檔案 `Program.cs:265`：
09-03 `--soak 4` 漏了隱含開窗那一格 ⇒ **靜默掉進文字模式、印出一張文字畫面、exit 0、一個讀數都沒有**。
⇒ 降級的失效樣子跟成功一模一樣，而這張單的全部意義就是消滅這種同形。

\## ① 委派宿主　✅　而**我改了這一格的文字，理由寫在這裡**

原文寫「有自己的 lane，掃 `pending.trigger` → 寫 `_cmd_results/<id>.json`」。**實作沒照抄那個版面。**
⇒ 走的是 `SenateData/runtime/gui_bridge/<id>.req` → `<id>.res`（原子落檔：先 `.tmp` 再 `Move`）。

⛔ **不沿用 `queues/<lane>/` 是刻意的**：那套是給 Cmd 派遣的**持久佇列** ——
`ServerHost` 自己的註解寫著「被切掉的那條 lane 的 `.running` 會留著，下一顆 Server 啟動時翻回 pending **續跑**」。
⇒ 對一筆銀行扣款那是保命，**對一次點擊那是災難**：窗重開就替你再按一次，而畫面上完全看不出來。
📌 所以我沿用的是**形狀**（檔案進出、原子落檔、單一宿主、不發明新機制），不是**版面**。
⇒ 我沒有偷偷達標然後打勾，是把標準改成我真的做到的那件事並說明為什麼。

\## ②　✅　反向對照：在窗上摺疊 ⇒ `--list` 真的少掉那些 id
