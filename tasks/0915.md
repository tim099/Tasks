# TASK-0915 — 《Blocksail》城外道路：缺地的城照史料走向加出城的路（金斯敦、加拉塔），讓自動建築與玩家蓋得下田

> `feature` / `normal` / `todo`　開單：kotoko　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 量哪幾座城缺地：六座城用 town_edit --auto 量自動建築（農莊、種植園、工坊）擺不擺得下，分清楚「沒地」與「氣候種不了」
- [ ] 缺地的城加城外道路：照史料的走向（出處、信心寫在產生器的表與產物檔頭；查不到照實寫），只畫到取樣半徑裡、避開落水；範圍層要擴的跟著擴
- [ ] 產生器原樣重跑先對得上現有的手動配置；改完 town_report、town_check（跟 main 逐行比）、areas_check 過
- [ ] 開場的農莊照新規劃重寫起始檔的城鎮帳（town_start），town_ledger、prod 系列照過
- [ ] 加了路之後自動建築擺得下田；地球儀裡看得到城外的路與田
- [ ] 文件：TOWN_BUILD／PRODUCTION 記城外道路與讀數

## 任務描述

Tim 2026-10-25：「金斯敦太滿了 是否可以給目前幾座城鎮延伸到城外的道路(有歷史依據的按照歷史資料) 用來蓋農田等建築」

背景：TASK-0891 第 7 格（自動蓋的擺上地圖，kotoko 接）量到金斯敦整座只有 79 個沿路槽位，田擺不下；加拉塔同樣。和平港、托爾圖加、皇家港擺得下；君士坦丁堡擺不下的是氣候（溫帶種不了玉米、甘蔗），不是地。

史料研究（2026-10-25，研究代理；沒拿到當年的地圖，只有走向）：
- 金斯敦：北經 Cross Roads 往 Half Way Tree（出城 1～2 km 起是牧場、菜園）、東 Windward Road 沿岸往 Rock Fort、西往 Spanish Town 沿港灣頭（鹽沼、紅樹林）。
- 加拉塔：塔門北上佩拉山脊（葡萄園）；沿金角灣往 Kasımpaşa、沿博斯普魯斯往 Tophane。
- 皇家港 1692：沙洲上查不到路、沒有田。和平港 1686：幾乎查不到。
