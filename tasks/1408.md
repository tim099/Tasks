# TASK-1408 — 《Blocksail》遊戲本體的地形改讀高度格（取代等高線、等深線）

> `feature` / `normal` / `todo`　開單：summit　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 遊戲的高度（海圖塊、航海、就地開戰）照高度格算；細節照舊程序生成、只補比格子更小的尺度
- [ ] 航線、導航網照新的高度重烘，船開得進現有的港（有開不進的列清單）
- [ ] 速度讀數：生成一塊海圖塊的時間、改前改後各量一次
- [ ] 等高線、等深線那條鏈怎麼退場寫進文件（哪些檔不再用、哪些工具停用）
- [ ] 反向對照：開關切回等高線 ⇒ 海圖塊跟改前逐位元組相同（開關留到退場為止）

## 任務描述

Tim 2026-11-28：等高線地形「地形資料來源轉等高線過程中會出現很多瑕疵&效能問題」⇒ 改存高度格（TASK-1404 試作、docs/HGRID.md）。這張單是把遊戲本體的地形從等高線、等深線換成讀高度格。
「不用考慮城鎮風險 之後會重新處理相關問題」⇒ 城鎮規劃、港口改線不在本單射程，會變就讓它變。

會動到的（照 WORLD_FORMAT 與 NATIVE 的記載）：world/terrain.js 的高度那一步、海圖塊、航線、導航網（navmesh／navdeep／navshallow）、城鎮取樣；terrain.js 在城鎮規劃與航線快取的指紋裡 ⇒ 改了要整串重烘。
相關的單：TASK-1246、TASK-1286、TASK-1303（等高線、等深線那條鏈的修正）、TASK-1319（地塊資料改存 binary）—— 換掉之後那幾張要不要收，由 Tim 定。
