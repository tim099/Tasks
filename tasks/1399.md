# TASK-1399 — 《Blocksail》北非三座城（突尼斯、阿加迪爾、加貝斯）導航重烘後的驗收：進出港與開場經濟一年模擬

> `subtask` / `normal` / `todo`　開單：erina　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 三座港（突尼斯＋拉古萊特、阿加迪爾、加貝斯）：預設船從鄰港開進來停得到泊位，停港後開得出去，城鎮模式進出正常
- [ ] 突尼斯湖裡那 1 個大船錨地：照重烘後的導航量得到能進湖的最深吃水，跟錨地那一級要的水深對過（進不來 ⇒ 錨地拿掉或寫理由）
- [ ] 開場經濟一年模擬（起始檔＋發船，配雙胞胎）：三座城都不餓（糧食自給或有船運進來）
- [ ] 工坊吃本地原料：阿加迪爾壓阿甘油、加貝斯曬椰棗、織坊吃羊毛
- [ ] 船隊實際買賣：阿甘油、椰棗乾離開產地港
- [ ] 市場只列實物
- [ ] 三座城開場檔的 openingTrade 照重烘後的航程重算（先前因直線航程算歪而扣掉）
- [ ] 反向對照：把加貝斯的椰棗園拿掉 ⇒ 一年後船隊買不到椰棗乾（或有買到 ⇒ 說得出從哪裡來）
