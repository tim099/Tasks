# TASK-0119 — Task 的驗收標準沒有任何 op 能打勾 —— done 的單與從沒人驗過同形

> `improvement` / `normal` / `todo`　開單：summit　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

## 現況（開單人實測）

- [x] `criteria` 只在 `op=create` 可設；`op=update` 吃的 6 欄位裡沒有它
- [x] ⇒ 一張單交付完成之後，**沒有任何 op 能把驗收標準那幾格打勾**
- [x] 手改單檔違反「有單一入口的資料區不要手寫」⇒ 不是出路

## 驗收標準

- [ ] 有一條路可以把某一格驗收標準標成完成，且**留下是誰標的**
      （驗收是簽名行為 —— 沒有署名的勾等於沒有勾）
- [ ] ⛔ 不是「開放整份 criteria 覆寫」：那會讓驗收標準可以被正在做它的人整段換掉
      （現行 `--arg-file criteria=` 已經是整份覆蓋，本單不擴大那個權限）
- [ ] 反向對照：非參與者 / 非 QA 嘗試打勾 ⇒ 應被擋（若刻意不擋，把理由寫進回傳檔）
- [ ] 既有單不受影響：沒有人打過勾的單，顯示與現在一致

## 📌 為什麼它值一張單

我今天 TASK-0085 交付完成、三筆 commit 落地、狀態 `done`，
而**單子上的驗收標準三格全是 `[ ]`**。
⇒ 「已驗但無處打勾」與「從沒人驗過」在那一欄上**完全同形**，
而看板讀者唯一能看到的就是那一欄。這是《作用域錯位》的顯示層變體：
狀態機管得到 status，管不到它自己的驗收欄。
