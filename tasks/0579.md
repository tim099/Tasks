# TASK-0579 — 遊戲：帆的貼圖支援透明、解析度跟著貼圖走（憲法號對轟）

> `improvement` / `normal` / `in_progress`　開單：summit　參與：summit(dev)

## 驗收標準

- [ ] 帆照 UV 在片段著色器取貼圖：貼圖透明（alpha 低於 vxk 的 alpha_min）的地方 discard ⇒ 遊戲裡看得到洞、看得到洞後面的東西，不再是白斑
- [ ] 解析度跟著貼圖走、不跟布料頂點數：同一面帆，改前改後近看各截一張，細節看得出差別
- [ ] 陰影（陰影圖那一趟）跟反射也認透明：洞的地方不投影子
- [ ] 沒有貼圖的帆、旗、撕下來的布片照舊（顏色跟改前一樣）；憲法號、夜隼號沒有破洞貼圖的帆畫起來跟改前一樣
- [ ] 主控台沒有錯誤；風暴角號開打 60 秒照常（帆被打、撕、掉照舊）
- [ ] 建置（admin.py build）、成品內嵌照舊；README 的檔案表補一行

## 任務描述

Tim 2026-10-14：「目前遊戲的帆 透明部分會變白色 需要可以支援透明（另外解析度是否也能提高）」；「這部分交給你了 可以開 task 然後全包 GO」。

病根（讀碼，ArtGallery `HtmlGames/_build/ame_constitution_broadside/js/30_rig_physics.js` texColors）：
- 遊戲沒有把帆的貼圖貼上去，而是每個布料頂點取周圍不透明像素的平均色；周圍全透明 ⇒ 填 242 白（第 196 行）⇒ 破帆的洞變白斑。
- 細節只到布料網格的頂點數（每面帆約 25×25 點），跟貼圖本身多大無關 ⇒ 解析度上不去。

做法：帆的貼圖連同 UV 交給 shader，片段著色時取貼圖、透明的地方 discard；陰影那一趟也認透明。遊戲是 ame 的（Tim 決定由 summit 改，動手前在酒館跟 ame 說）。
