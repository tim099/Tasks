# TASK-0913 — 《Blocksail》航行與貿易後續：逆風走之字形、航行時避開擱淺、船隊走導航圖、概略層海盜數值與付錢

> `feature` / `normal` / `todo`　開單：gura　⚠ **尚無參與者**（沒有人在做這件事）

## 驗收標準

- [ ] 逆風走之字形：地球儀上的船、概略層的商船，目的地在逆風方向時照最佳 VMG 搶風；讀數列出幾段往東逆信風的航程，搶風前後各要幾小時（現在慢 4～7 倍）
- [ ] 反向對照：順風、側風的航段路徑與時間跟現在一樣
- [ ] 航行時避開擱淺：地球儀找航線時，水深不到「選的那艘船的吃水＋餘裕」的水域不走；讀數：同一組起訖點，吃水深、淺兩艘船走的線與時間
- [ ] 沿著航線挑幾個點進航海 ⇒ 船都不擱淺、不用自動漂到安全位置；反向對照：拿掉水深條件 ⇒ 至少一個點會擱淺
- [ ] 簡易船隊的航程改用導航圖的航行時間（現在是大圓距離 × 1.3）；讀數列出幾條航線換之前、之後各幾天
- [ ] 海盜的機率與劫走比例、班表與船的載量，照史實的運量與損失率重訂；數字與出處寫進 TRADE_SIM
- [ ] 概略層的商船付錢：每一筆運輸算在某個家族頭上、照市場報價付錢；跑 365 天每天全世界的錢總數不變
- [ ] TRADE_SIM（與相關文件）補上量到的數字

## 要什麼
Tim 2026-10-25（結 TASK-0724 時）：「逆風走之字形以及其他 另外開一張單(同時補上 之後想要讓航行時會自動避開擱淺地帶 目前進入航海時有機會觸發擱淺船會自動飄到安全位置 希望之後直接在航行時就避開)」

「以及其他」＝ Blocksail repo `docs/TRADE_SIM.md` §9.3 留下的：
- 搶風：概略層與地球儀上的船都還不搶風，往東逆信風的帆船慢 4～7 倍。
- 海盜機率、劫走比例、班表、載量都是隨手訂的。
- 概略層的商船只記帳、不付錢（簡易船隊 TASK-0911 已經走城鎮金庫，概略層還沒接）。

另外併進來的：
- 簡易船隊 `world/fleet.js` 的航程還是大圓 × 1.3，要換成 TASK-0724 的導航圖（`world/navgraph.js`）。

## 擱淺現況（2026-10-25 查的）
- 地球儀的航線（`world/route.js`）只避陸地與向量淺灘／岩石（礁區照 Tim 10-19 可以通行），不看水深與船的吃水。
- 進航海時，地球儀照「吃水＋1.5 m」找夠深的起點（`globe.html` boatDepth）⇒ 開到淺水裡才進航海，會在 Blockside 擱淺再漂到安全的位置。Tim 要的是航行時就不開進去。

## 邊界
- 精細層（真的船隊、海盜船隊開打）與兩層交接（TRADE_SIM §2.2、§2.3 第 2～6 條）不在這張。
- 程式與讀數放 Blocksail repo；動到 Blockside 照它的 dev 流程。
